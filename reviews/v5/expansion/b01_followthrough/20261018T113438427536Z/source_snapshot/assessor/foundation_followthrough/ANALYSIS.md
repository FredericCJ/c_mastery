# B01 completion analysis (assessor only)

The interval commits a two-field value only after fd_extent succeeds. The empty
endpoint at SIZE_MAX is a legal mathematical interval, not pointer formation.
The early-begin and strict-less-than mutations discriminate transactionality and
the exact endpoint predicate. An inclusive last-index representation cannot be
converted to this half-open size_t representation when last==SIZE_MAX.

Character copying from the live FDValue into actual allocated storage is a
different type argument from casting a declared byte array or zeroing bytes.
The selected draft's6.5p6 includes copying as an array of character type; the
source's effective type governs the destination for the described accesses.
All copied bytes, including possible padding, are transported without assigning
them semantic meaning. A memberwise read checks the value, not padding equality.
The declared-FDValue transfer adapter remains a separate case with declared type.

The wrong pair remains invertible: swap count octets after encode and before
decode. Consequently all round trips pass even when high and low octets differ.
The independent golden bytes for258 distinguish the required wire. The native
and big-endian object observations cannot be substituted for a wire definition.

The symbolic pool model increments its mathematical issue count at acquire;
the C implementation increments generation at release. Agreement therefore does
not arise from reading or copying the implementation's representation. Exhaustive
length5 schedules cover interleaved live slots and overwritten handle registers;
the separate long history reaches retirement. This finite scope does not prove
all histories, concurrency, owner lifetime or maintenance quiescence.

The semantic probe compares only admitted outcomes. A nonfatal diagnostic can
produce an object after a constraint violation; no object is executed from that
case. Function-body executions are indeterminately sequenced, so both shared
state result/final-state pairs are allowed. Replacing the bodies by argument
expressions s++,s++ changes the rule and gives no executable golden result.

The lifecycle controls are compiled from retained generated copies of the
original provider: one admits premature publication, one invokes the supplied
destructor on initialization failure. Their explicit assertion failures matter;
a compiler rejection or sanitizer crash does not constitute the required kill.
No modified provider is installed into the canonical source tree.

Original source records, original detailed analyses and existing withheld
transfer solutions remain applicable within their recorded scopes. This is
same-author support. It does not manufacture inspected published C17/C23 text,
human independence, elapsed delay or learner mastery.
