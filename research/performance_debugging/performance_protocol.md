# T43 research protocol

This research extends the accepted curriculum with complexity and performance measurement. Teaching remains gated. Existing T13 effects ledgers, T15 operation counters, T30 scheduling traces, T34 paired benchmark/profiling experiments and T37 C/assembly measurements are reuse inputs; their implementations and hours remain in their original modules.

Start with broad searches across all SWE works/element-linked works, data-structure lineage and the actual held-publication catalog. Record query, result identities, selection/rejection and metadata limitations. Write a reflection before focused passage inspection. Then inspect edition-specific textbook/paper passages and current official tool/kernel/vendor documentation, assigning only exact readable locators. Finish with a source registry, synthesis and original measurable taxonomy for the root research gate.

Questions to resolve:

- Which input size, primitive, case assumption and representation justify exact, asymptotic, amortized or external-memory bounds?
- How do an abstract operation, instruction, measured cycle, CPU second and elapsed second differ? Which target, workload, clock, scheduling, blocking and asynchronous-completion assumptions connect them?
- Which resource is counted: live/retained/peak payload, allocator storage, stack/static sections, resident memory, file bytes, syscall bytes, bus/cache traffic or physical I/O? Where are observation and completion boundaries?
- How do perf permissions/multiplexing, cgroup delegation/quota/pressure, compiler instrumentation and DWT/timers perturb or limit the result?
- Which statistics, consumed outputs, paired runs, clock resolution/wrap bounds and uncertainty records prevent unsupported conclusions?
- Which useful measures include comparison/move/probe counts, branch/cache/traffic/amplification, code size, cyclomatic control-flow complexity, deadline/jitter or energy? Each needs its own model and evidence; none substitutes for runtime cycles or Big-O.

Actor `/root/alg_sim` applies the library's chief-librarian and metadata-provenance instructions only for read-only discovery. Current census/database pointers and rules are pinned privately; ordinary PDFs are selected by stable document ID and verified existing rebased path. Opaque packages, `Library/_old`, companion archive internals and library writes are excluded. Catalog descriptors and graph provenance seed discovery; they do not establish a source passage's technical correctness. Public research records contain no private book paths or raw extracts. Captures and derivatives stay under `research/private/performance/`.

The proposal will have about 12–14 topics and about 12 bounded 4–12-hour milestones. Bare-metal and delegated cgroups require explicit prepared environments; no-root/no-PMU host fallback remains a truthful route with unavailable evidence reported. It will not provide solved C or claim learner/hardware results.
