# Changed-condition audit

Directly read the original X Problem, rubric and Variants sections. The richer
parent packages already supply actual VLAN frame encoding, bridge loop traces,
PHY reset/reprobe, ring ownership and full EDU7 integration. They did not supply
the specific borrowed partial stream, padding-dependent trailer, VLAN-keyed
table, changed PHY register query, arbitrary cycle or partial-fragment timer
contracts. This package adds those mechanisms instead of treating adjacent
tests as equivalent coverage. Original roots/rubrics and the other variants
are reconciled separately against their exact existing evidence.

The changed PHY uses official DP83848-EP revision0 source interpretation and
the actual retained MDIO producer. It neither silently accepts future silicon
revisions nor claims a physical port. The original record/framing variants
remain synthetic service contracts; they do not alter the original wire.

Exploratory shell looping initially interpolated a PowerShell variable before
WSL, so it accidentally repeated selector0. That exploratory output was not
recorded as full validation. The corrected explicit subprocess argument list
executed selectors1–5 successfully; the canonical runner passes argument arrays
directly and validates an exact unique command inventory.

The initial isolated export compile exposed the pre-existing broad EDU7 stub's
unused parameters under strict warnings. That provider was left unchanged.
The exporter now uses a separate two-function, still-unimplemented prerequisite
codec stub with explicit unused-argument casts; no warning is disabled and no
assessor implementation enters the learner workspace. The reference campaign
continues to link the actual unchanged producer.

The first complete reference attempt passed all six native profiles and their
semantic controls, then failed target linking because the new guest omitted
the startup's fault-handler symbol. Its 199-command receipt and exact guest
source are retained as attempt01. The explicit handler now exits42 with a fault
marker, distinct from the intended semantic rejection41; no target failure is
credited as detecting an intended defect. The complete campaign is rerun.

No accepted historical receipt or learner assessment is rewritten. Current
source-bound campaigns and the original delayed tasks remain separate.
