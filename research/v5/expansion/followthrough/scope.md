# Scope of the implementation follow-through

The active edition manifest, T01–T76 taxonomy, both implementation plans, every
canonical project and X exercise, their original rubric criteria and changed
conditions define the required curriculum. Historical elective labels and hour
records do not remove an obligation. The recursive registers named by
`curriculum/v5/expansion/completion_ledger.json` add discovered implementation,
source, target, integration and evidence obligations. `work_inventory.json` keeps
their original identities and source pointers; `implementation_updates.json`
adjudicates dimensions separately. Neither file replaces the original contract.

The inspected reference corpus supporting current claims consists of the exact assigned passages in the
active source registers, the retained modern census and its 100 dispositions,
and the accessible primary passages inspected while resolving their gaps. The
library and SWE indexes are discovery aids. Unread titles are not inspected
sources, and an inaccessible final standard is not replaced by a similarly
numbered draft. The source registers retain editions, sections, local hashes
where bytes were available, retrieval failures and limits of each inspection.
The discovery obligation also extends beyond those assigned passages and the
existing taxonomy: accessible library and SWE topics must be screened for
relevance, with omissions and exclusions explained. That screening is separate
from passage inspection and is tracked under G-CORPUS. The boundary on current
source claims does not close that broader obligation. This is a finite
curriculum audit, not a claim to have read every book in the private library or
exhausted all future C research.

The bounded [corpus screen](../corpus_followthrough/README.md) now resolves all
84 selected, actually read design descriptions through
[exact mechanism mappings](../corpus_followthrough/mechanism_resolutions.json).
The map includes completed longest-token scanning, persistent semantic-model
and read/evaluate/print work, the actual Treiber stack and the paired textual
escape/dialect adapter. It also records justified reuse such as the maintained
secondary term index. The remaining 999 SWE elements have metadata routing
only; neither that routing nor a library category is passage inspection or
implementation evidence. Their existing assigned-source and objective
obligations remain active in the global inventory. This finite discovery
decision does not redefine those obligations or close final integrated validation.

The work has followed actual mechanism gaps: compiler extension semantics and
backends; component imports and target runtime closure; real I/O cancellation
and fallible cleanup; allocation authority and callback lifetimes; delayed
algorithm and data-structure changes; storage and network state machines;
privileged guest execution and hardware adapters. Ordinary and delayed variants
remain distinct. Narrow retained tests are comparison anchors, not evidence for
unrelated rubric criteria. Source inspections also produced required comparisons
for POSIX close semantics, allocation lifetime, epoch guards and Intel HEX
address modes. Those fit existing objectives; their registers explain the scope
without manufacturing taxonomy leaves to increase counts.

For each obligation, read all six dimensions: teaching, implementation, author
validation, external technical review, independent learner performance and
physical observation. A source-dependent board route, unspecified USB request,
unavailable proof text or unbuilt licensed target remains open in its affected
dimension. The available implementation, capture protocol and assessor analysis
remain separately credited. A seven-day learner interval does not block writing
and checking the transfer package today.

The final checks must use the resulting sources: canonical regeneration, exact
provider and export guards, current campaigns, target object/link audits,
learner workflow, publication and assessor exclusion. Report actual command
results and source identities. Passing finite author tests does not establish
absolute mastery, independent review, physical timing or acceptance of a release.

The starting checkout and pre-existing work are recorded in
`starting_state.json`. `continuation.json` records an interruption only; it is
not a completion certificate. Historical receipts, identities and accepted
hour records are preserved. Active state is corrected through canonical
successors and regenerated outputs.
