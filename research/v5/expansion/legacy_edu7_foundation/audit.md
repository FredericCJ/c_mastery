# T40 foundation coverage/depth audit

T40 contains24 original leaves with24 unchanged seven-day V1 tasks across eight
projects. This dependency-ordered package owns the twelve leaves in PR01,03,04,07;
PR02,05,06,08 remain mandatory subsequent integration work. The original EDU7
contract is actual protocol evidence; X.200 defines model concepts, not these
bytes. The maintained reference codec/route implementation and edu7_depth
admission API were inspected before designing the successor.

Adequate retained mechanisms are CRC recurrence, v1 byte framing, typed UTF-8
record decoding, static routing decisions and local grant admission. They are
actually imported, not claimed from names. Missing mechanisms were capacity-aware
encoder publication, strict escape canonicality, delayed egress storage,
generation-bound zero-copy release, versioned wider representation and explicit
changed-profile experiments. Those are implemented in the separate foundation
provider, leaving frozen baseline bytes and acceptance receipts intact.

Every objective has its own private analysis anchor and ordinary/V1 mapping.
The tests combine independent polynomial division/signed serialization with
poisoned inputs, output sentinels, every stream split and compiled semantic
defects. Native LP64, selected i386 ILP32 and Cortex-M4 CPU evidence are separated
from physical RS485/radio and general portability. A successful serializer does
not authorize a SET; a valid CRC can be recomputed by the synthetic attacker;
a release token is not hardware-quiescence evidence. Original tasks remain
unaltered and independent learner/external review are not inferred.

Remaining scope: actual grant/channel binding to final UART completion, receive
expiry and transport/session epoch isolation, uncertain two-endpoint token
transfer, complete reverse routed response and physical two-segment captures.
The initial retained source contracts explicitly named these missing integrations;
this package does not close them by reference. Exact full external standard
and held-source access gaps remain registered rather than silently removed.
