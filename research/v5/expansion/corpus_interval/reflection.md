# Interval depth decision

Actual T17 module/project inspection found scalar error ledgers, Q7 saturation, accumulation, filters and exact-reference testing. Those are relevant prerequisites but do not implement a set enclosure. A saturating numerical kernel can be correct for its scalar contract while unsound as an interval bound; the distinction needs its own exercise and falsification controls.

The first representation is a bounded fixed grid so the required mechanism is outward containment without conflating it with compiler-specific floating-environment support. The exercise explicitly compares the missing binary64 obligations as analysis, and does not claim that fixed-grid execution validates them. Precision change, correlation and division-domain changes assess transfer. Accepted historical records and hours remain unchanged; this required addition is separately accounted.
