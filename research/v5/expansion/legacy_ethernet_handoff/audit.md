# T39 PR08 author implementation audit

The original six criteria and six delayed tasks are retained verbatim. Original
finite `ed_budget`, `ed_capture` and first-failure functions supplied useful
models but did not implement the requested HTTP/frame/time/event composition,
routed namespace construction or drift extension. The successor consumes the
actual now-frozen T41 and T39 producers rather than assigning coverage by title.

The ordinary/changed mapping is explicit in completion_dispositions.json:
T39.09.a owns local/gateway link selection with unchanged final IP; .09.b owns
actual raw-frame/ARP/IP/TCP/stream/HTTP ownership and retirement; .09.c adds an
actual bounded reassembly consumer and its missing interoperability obligations;
T39.10.a owns offset/drift intervals and transactional overflow admission; .10.b
owns actual corrupt-frame/route divergence; .10.c owns equivalent serialization
accounting and minimum padding. Each has an objective-specific private analysis
anchor and preserved original seven-day variant. Author implementation is not
an independently administered learner assessment.

Actual provider inspection found an important boundary: NbNet's configured ARP
peer is its TCP peer. Therefore the routed-envelope test is not a routed HTTP
exchange. The same-link HTTP experiment uses the actual producer contracts;
general routing, arbitrary protocol options, full current standards conformance
and physical Ethernet remain outside its measured claims. The drift model's
rate bound is supplied, not a measured oscillator fact. Frozen baseline criteria
still retain their historical missing-work prose; additive current support is
the versioned successor, not a rewrite of accepted evidence.

Two primary RFC scopes were actually read from retained bytes: routing and
fragmentation/reassembly. RFC791's illustrative overlap/timer policy is compared
with the retained stricter bounded policy, not relabeled as that standard's
mandate. Full published C17/C23 and current IEEE bodies remain source gaps.
Private source caches are not learner publication artifacts. Security execution
uses only original synthetic peer/model programs; no external network or host
security setting is changed. Physical clocks, peers, captures and wire behavior
remain a separate required observation dimension.
