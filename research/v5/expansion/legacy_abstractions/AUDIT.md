# T19 actual scope and depth reconciliation

Starting evidence was the original T19 module, four project contracts, thirty
ordinary and thirty changed AX criteria, actual API/foundation producers and the
already implemented T19.08 stream successor. A domain heading or a green legacy
smoke test did not discharge these obligations. This extension adds27 exact
criterion packets and reuses the three stream packets; it does not recreate them.

Session/table work covers construction callbacks, suspension, typed embedding,
layout/version admission and context adapters. Registry work distinguishes snapshot
delivery from immediate logical suppression, then permits actual terminal freeing.
Generic work provides owning staged rollback, move transfer, type diagnostics,
malformed/owned sum cases and an independent decimal oracle. Reducer work separates
pure requests from committed effects, retains retry identity and leases old strategy
contexts. Traversal imports actual epoch views and adds deferred cancellation and
explicit bounded continuation stacks. Handles implement retirement/quiescent reuse,
strong cycles, weak promotion/last-drop races and a separate payload protocol.
Dispatch imports the retained stream and measures direct/table/fixed/shared-library
variants under common byte and progress contracts, including a third backend.

Each packet has public teaching, compiling unfinished learner source, explicit
constraints/tests and private technical analysis/reference code. Campaign observations
map each ordinary and changed criterion separately. Source-bound oracles and
semantic mutants supplement, rather than replace, ownership/state arguments.
Imported reference execution is author integration, not evidence of learner reuse.

No taxonomy split is required: these are concrete implementations of existing
T19.01–10 outcomes. Concurrent T19.09 changed variants explicitly require later
T25/T51 synchronization knowledge; this is a delayed revisit, not an introductory
prerequisite cycle. T19.08 retains its independent source/producer support and
separately refreshed canonical binding after additive PR-T19-04 changes.

Active C17 and exact source editions remain distinct. The held K&R text5.11 was
read; its historical casts receive explicit counterexamples rather than being
copied as modern safe adapters. N1570 is labeled a2011 draft; DR481 and actual
C11/C17/C23 compiler probes delimit generic controlling-expression claims. The
public Modern C2024 third-edition interface and ordering passages are freshly
inspected. Missing published C17 access remains open. Native, sanitizers, finite
enumeration, object inspection and microbenchmarks support their stated bounds;
they do not create independent review, physical measurements or learner attempts.
