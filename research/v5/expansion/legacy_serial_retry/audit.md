# Exact remaining I2C tasks

The old bit model had unbounded stretching; the actual transaction and retry policy lacked a timer-composed byte adapter and bus-idle/backoff scheduler. This package supplies those exact three variants. Old electrical/register/recovery obligations remain required. Synthetic tick budgets are application policies, not universal NXP timeouts; physical tBUF must be rounded upward under the actual clock quantum.

First full campaign preserved a strict GCC optimized diagnostic in unrelated frozen s_reduce. Its unchanged whole translation unit is now compiled at O0 in GCC profiles; adapter/tests retain declared optimization. No warning is disabled or frozen source modified. Clang strict M4 refuses unused64-bit atomic functions in the full timing source; record that refusal and separately execute GCC target images with final helper closure. Neither refusal is called a passing execution.
