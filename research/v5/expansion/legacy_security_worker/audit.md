# T35 descriptor/worker depth audit

All six PR-T35-02 original tasks and delayed variants, project contract and
fixture were read. T35 module teaching was inspected. Retained hosted descriptor
code only duplicates an owned CLOEXEC handle; it does not implement the worker,
pathname replacement, application policy or MPU comparison. The frozen T23
pn_open_confined interface, contract and complete implementation were read and
are actually linked into the new tests without changes.

New work executes acknowledged final-name replacement, intermediate-link
replacement, exclusive creation, copied descriptor staging, exact exec inventory,
literal argv and child option interpretation, acquisition cleanup, read-only
rights and actual worker ambient reopen. The concurrent-open/fcntl fork task is
the original requested logical schedule, not an invented native stress claim.
Four-byte synthetic objects and local owned processes confine all demonstrations.

Primary passages read on2026-10-18: Linux man-pages6.19 open DESCRIPTION object
identity/access modes plus O_CLOEXEC/O_EXCL/O_NOFOLLOW; execve DESCRIPTION explicit
argv/envp; write ERRORS EBADF; close_range DESCRIPTION CLOEXEC; openat2
RESOLVE_BENEATH/NO_SYMLINKS/NO_MAGICLINKS and failures. ST PM0214 revision10
pp.195–205 were extracted from the existing private PDF and read for AP/XN,
update barriers, subregions, DMA limits, control bits and alignment. The official
CMSIS MPU page's RASR/control explanation was also read, but PM0214 and the actual
producer govern the selected model. No source extract is published.

Actual B06 boot_handoff C, boot_guest assembly and prior source-bound
boot_pair_validation.json were read: two nonoverlapping code/RAM regions,
privileged background, RAM-execute/code-write fault variants on MPS2 Cortex-M4/M7.
The new analysis verifies its current pins and reuses those prior observations;
it makes no fresh CPU or physical observation claim. Privileged reconfiguration
and DMA remain explicit limits. Exact published C17/C23 remain inaccessible.

The first worker campaign found an optimized GCC ignored-result diagnostic in
the error-report write; its failure receipt is preserved. The repaired branch
checks the write result and exits distinctly. Error-channel EOF is not an
unconditional ready-service guarantee when a child can die before reporting;
the contract explicitly retains final-wait responsibility and the bounded
normal-setup assumption. Other T35 hardening/secrets/artifacts and T36/T37 remain
separate required work. Original acceptance, criteria and delayed IDs are intact.
