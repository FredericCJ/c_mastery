# X-T51-002: Once publication: failure policy, recursion and waiter progress

## Prerequisites

Bring X-T25-002 publication evidence and your PR-T51-10 execution/waiting artifacts with source hashes and fresh enrollment reasoning. The host anchor runs independently; D2 target integration requires learner-owned execution code. Know data races, CAS failure ordering, task ownership and cleanup. PR-T51-11 permanent failure remains the original target milestone.

## Environment

C17 and the parent dependency profile remain in force. The anchor uses Linux x86-64, GCC/Clang, CMake and pthreads for host verification only. No libc mechanism implementation, ready-made arena/once/reclamation library, libatomic or hidden helper may enter a strict freestanding target. Record compiler/flags, data model, alignment, atomic lock-free properties, undefined symbols and disassembly. Source-language/library comparisons have their own cited contracts, not additional ISO C guarantees. N1570 is a C11 draft; exact C17 remains an access gap.

## Problem

Implement MBOnce for three participant identities and two ordinary values. The winner returns INIT, another participant BUSY and recursive owner entry RECURSIVE. Only the owner finishes. Success publishes17,34; READY readers copy both. Permanent failure becomes stable FAILED; the separately configured retry policy returns to EMPTY after failure. No reader sees a partial object. Add a target adapter using the learner execution wait queue: initialize t[i]=17*i+1 for i0..7 and publish checksum484 only after every entry is ready. Inject owner cancellation after entries0..3 through the owner cleanup path; permanent failure wakes all waiters with failure. Host pthreads do not implement the target scheduler.

Supplied artifacts: `labs/modern_bridge/include/bridge.h`, compiling unsolved `src/bridge.c`, `tests/tests.c`, `fixtures/modern_bridge/cases.json` and the incorporated `labs/modern_bridge/CONTRACTS.md` version1. The contract defines representation, operations, preconditions, error precedence, ownership, finite limits and complexity. Preserve the interface. Target adapters remain separate learner sources; retain imported learner source hashes rather than copying assessor code.

## Necessity

Admission, data visibility, failed initialization, recursive self-wait and waiter wakeup are separate mechanisms. Historical execution tests retry after failure while PR-T51-11 specifies permanent failure. This exercise exposes both contracts and records the mismatch; historical acceptance evidence is preserved.

## Reasoning

Draw competing CAS, recursion, wrong-owner finish and cancellation transitions. Give the release/acquire happens-before proof for ordinary fields and the table. Explain why relaxed publication can cause a C data race, not merely stale data. Prove enrollment-before-recheck and wakeup on every terminal state; cancellation removes only the cancelling waiter. MBOnce excludes asynchronous thread cancellation, abandonment and process crash. Rust OnceLock panic leaves uninitialized; Go Once considers a panicking invocation returned. Neither automatically equals our error status or effect rollback. Pre-C11 work requires a named platform threading contract; the inspected C11 draft is not exact C17.

For each operation state pre/postconditions, invariants, ownership and failure preservation. Assign guarantees to ISO C, compiler/ABI contract, runtime checks, external verification or caller discipline. Supply one plausible incorrect explanation and minimal counterexample. Complete the13-dimension modern cost review, with justified non-applicability; compare equal correctness and ownership contracts.

- D4: The named delayed transfer at least seven days after the source-bound study event, with a fresh derivation of changed invariants, ownership, failure semantics and costs.

## Verification

Permanent failure has1 attempt; a fail-then-success retry history has2 attempts/1 successful publication. Recheck after spurious wakeups. Kill early-READY and unconditional-retry mutants, then independently kill a lost-wakeup target mutant. Run a supported race detector; unavailable evidence stays open. A sanitizer-free run is not the ordering proof.
