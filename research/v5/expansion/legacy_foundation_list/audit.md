# Exact list-workflow gap and implemented scope

The original nine PR-T01-03 criteria and nine delayed variants require actual
compiler stages, ABI observations, distinct link/loader/runtime failures, clean
revision replay, chunked parsing, collect-all ownership and stale-build causality.
The retained single foundations prefix/size test is not evidence for these tasks.
This additive successor keeps the original criteria/baseline objects byte-content
equivalent and supplies independent executable and reasoning evidence.

Actual inspected sources are the named primary passages in resources.json. An
initial Windows HTTP request returned403; a normal WSL request with a browser
User-Agent obtained the same official pages. The psABI snapshot is identified by
its retrieved bytes, not relabeled as a numbered release. N1570 remains C11 draft.

Pilots caught two checker errors: Clang uses64-bit argument register spellings
inside LEA, and quoted inclusion from the old caller directory silently selected
the old header despite a new -I path. Both were corrected before the final
source-bound campaign. The first two failed pilot reports remain under
build/foundation-list-workflow/20261018T043144286954Z/report.json and
build/foundation-list-workflow/20261018T043235218814Z/report.json; the third pilot
20261018T043329770398Z passed92 commands. A later243-command initial campaign is
preserved in history/before_teaching_freeze. It predates the final teaching files
and therefore is not the current package evidence.

The independent oracle uses whole-token regex, arbitrary-precision conversion
and direct slice sums, distinct from the C digit/checked-add recurrence. Actual
C signed overflow remains compile-only. Defined synthetic-range failures and
wrong-but-defined mutants are assessed separately from negative translation.
The package does not close other foundations, corpus-access or external learner,
review or physical obligations.
