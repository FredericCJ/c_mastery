# Exact semantic diagnostic gap

The original PR-T01-02 supplement had three specific ordinary tasks and three
changed-condition tasks, but a narrow generic semantic verdict table cannot
implement row-pointer traversal, the two-dimensional transfer, a path-sensitive
initialization repair or the comma-operator comparison. The successor provides
actual typed interfaces and defined executable repairs plus separate compile-only
faulty specimens. Its five semantic mutants are defined programs, not UB probes.

The original criteria, variant tasks/delays and baseline bindings remain unchanged.
Additive attachments route the new public material through the real initializer;
private answers and faulty specimens remain assessor-only. No empty top-level
leaf list or passing table lookup is used as whole-domain completion evidence.

Actual N1570 PDF passages were read for pointer/lvalue conversions, arithmetic,
sequencing, comma, short circuit, parameter adjustment and initialization. This
is a C11 committee draft, not published C17. The separate original project and
shared legacy contract remain authoritative for predictions before execution and
analysis-only treatment of undefined examples.

Author checks record six hosted profiles, separately compiled semantic mutants,
constraint diagnostics, compile-only warning observations and libc/CRT dependency
inspection. This is profile A, not a strict freestanding image claim. Finite runs
do not establish every permitted function-call order, arbitrary object validity,
independent review, learner performance or completion of the seven-day delay.
