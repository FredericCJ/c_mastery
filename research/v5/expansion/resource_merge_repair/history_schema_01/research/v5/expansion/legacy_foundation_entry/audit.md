# Exact entry-assessment gap and scope

The original PR-T01-01 card specified six distinct ordinary tasks and six
seven-day changed-condition tasks, but its recorded `foundations.prefix` and
`foundations.size` anchors did not execute recursion traces, explicit activation
records, unbounded staging/aliasing, total maximum, a three-octet codec,
forbidden-permission policy or saturation reassociation. Those obligations are
implemented as an additive successor; the original criterion and baseline
objects are compared against HEAD by its integration and package guards.

The original `f_prefix` reference body was inspected and is imported explicitly,
without edits. It checks before adding, stages sixteen results, then publishes.
The successor does not relabel the original narrow test as evidence for all six
objectives. The mapping selects distinct mutation checks and exact assessor
analysis for each objective. The six ordinary tasks still require manual trace,
induction, cost and representation reasoning as well as executable checks.

Primary source inspection used the actual cached N1570 PDF and extracted text:
6.2.5p9 (unsigned reduction), 6.5p5 (exceptional expressions), and 6.8.5.3p1–2
(for-loop control order). This is an older C11 committee draft. It does not close
published C17 access, the historical CLRS/EWD249 inspection gap or other domains.
The original synthetic16 fixture remains distinct from this explicitly32-bit
hosted profile. No undefined signed expression is used as a portable output test.

The initial104-check native receipt omitted the profile-C target dependency
audit and is preserved under `history/before_dependency_audit/`. Its narrower
semantic result is valid; it was insufficient for complete dependency evidence.
The successor adds five-object M4 images, four compiler/optimization executions,
actual object/map/undefined-symbol/disassembly and bounded-stack inspection,
plus a compiling target-stub rejection and isolated target exports. Original
memory helpers are explicit providers, never a hidden runtime archive.

The active completion packet records teaching, implementation, author validation,
external review, independent/delayed learner evidence and physical observation
separately. The first three may close only after current campaign/export/guard
