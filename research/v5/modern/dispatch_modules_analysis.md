# Opaque implementation observation

`dispatch_modules_probe.json` retains commands, current source pins, compile/relink durations, disassembly, linker maps and all measured samples. Both implementations performed400000 callbacks and checksum2800000 for each200000-call trial. After one warmup, the seven-sample medians in nanoseconds were GCC original550962, alternative629847; Clang original510867, alternative547014. These local observations compare the same successful two-read contract and do not estimate a universal opacity cost. Callback loop/branch arrangement differs, scheduling and frequency are uncontrolled, and each binary runs in its own process.

The actual O2 original implementation has two indirect call instructions. GCC emits a loop containing one indirect call site for the alternative; Clang unrolls it to two sites. Two call sites and one twice-executed call site have the same observable callback count. GCC also emitted a stack-check helper, reinforcing that this hosted measurement is not a strict freestanding dependency audit. The link drops unused wrapper/map code; binary totals therefore describe the raw service comparison, while separately recorded object frame reports include the owned wrapper functions.

The13 cost/enforcement dimensions are enumerated in `dispatch_modules_cost_review.json`; intrusive representation observations are in `dispatch_intrusive_cost_review.json`. Author reference measurements are not independent learner assessment. A full standalone callback stack or blocking-time bound requires the actual client callback bodies and environment.
