# B02 depth contract, version 1

This contract is normative for these original teaching APIs. C17 is the target language; the inspected N1570 document is a C11 draft, not C17 text. Exact-width types must exist and CHAR_BIT must be 8. Profile C components use loops, arithmetic and caller storage; the hosted harness may use libc. No target parser, container, sorting, allocator or conversion library may implement the exercise. Declare and inspect all generated undefined symbols before claiming a freestanding port. These hosted runs do not establish that claim.

All required control/output pointers denote distinct, live correctly typed objects. Input arrays may be null only when length is zero, unless a function explicitly rejects the empty grammar. All advertised lengths correspond to actual accessible arrays. Output storage and control objects do not overlap input or scratch. A bad pointer cannot be validated portably. State objects may only arise from their initializer and legal API transitions; arbitrary byte corruption is outside this API and must be analyzed separately. Error returns preserve output and component state unless specified. Callbacks are synchronous and do not reenter, mutate, longjmp out of the component or retain temporary control pointers. Concurrent access requires external synchronization.

`b2_parse` consumes an ASCII octet span, with grammar `0 | -?[1-9][0-9]*`. Empty, leading plus/space/zero, negative zero, non-ASCII, suffixes and embedded zero are INVALID. Full grammar validation precedes RANGE classification. Range is exactly signed 32 bits. On OK publish one int32_t; all rejection preserves it. No NUL terminator or locale is involved.

`B2Map` has seven typed slots, states 0 empty, 1 live, 2 tombstone, hash key modulo seven, and linear forward wraparound. Keys are copied uint16_t values. `put` replaces an existing value without changing count, or inserts into the first reusable slot on its probe path, but must search beyond tombstones for a duplicate first. A new key at full occupancy returns FULL unchanged. `get` preserves output on ABSENT. `remove` tombstones only a matching live key. Every probe terminates within seven visited slots even if no empty slot exists. Init requires live nonnull state. O(7) worst case is an instance of O(capacity), not a probabilistic constant-time promise. Resizing/chaining remain parent-project obligations.

`b2_sort` sorts by ascending key stably, preserving serial order for ties and the entire multiset. For length at least two, distinct caller scratch has at least length items, or FULL occurs before mutation. Null scratch with nontrivial length is INVALID. Length zero admits null data/scratch; singleton needs no scratch. Implement merge sort with O(n log n) comparisons and O(n) caller scratch; account for recursion separately. Do not rely on object-padding byte equality for semantic equality.

`B2Arena` models offsets into a 64-byte region, with no T* creation. `reserve` rounds cursor to requested alignment 1,2,4,8 and admits length only if padded extent fits. Zero length still applies padding and succeeds at the resulting cursor. Marks save cursor and issue owner/depth/monotonic identity tokens; at most four active marks, IDs 1 through 15. Rollback accepts only the exact current top token and restores cursor/pops it; reuse, foreign owner and out-of-order tokens are STALE unchanged. IDs never wrap or recycle: after issuance 15, further marks return FULL permanently in that owner's lifetime. Never reinitialize a live owner while tokens survive. Init requires live nonnull owner at stable address. Raw escaped pointers are not detected: an optional checked borrow must carry region identity and an allocation token. Byte reclamation does not invoke destructors. Alignment here is relative to a base; physical absolute alignment needs a separately established base contract.

`b2_q7` accepts at most 1024 signed 8-bit pairs. Compute exact sum of integer products, divide once by 128, round nearest with ties away from zero, and saturate once to [-128,127]. Empty sum is zero. Length admission precedes array access. Oversize length returns RANGE; required output null or nonempty null inputs INVALID. Per-term rounding/saturation is a different operation.

`b2_transaction` acquires resources 0,1,2 using callbacks; zero means success, nonzero means failure with no resource ownership transferred for that failed call. On first failure release every prior successful acquisition in reverse order, return FAILED and preserve published. Releases cannot fail in v1. On success publish 3 and transfer all three resources to the caller, which must eventually release them in reverse order. No retry, durable commit or crash atomicity is promised. This is a single-use construction, not an update of an already-owned resource set; caller cannot alias published with backend state. Callback events are observable and not rolled back, although ownership is.

`B2Result` tags 0 integer, 1 borrowed byte span, 2 error integer. Only its active member is accessed. `b2_render` writes a counted ASCII decimal for integer/error in [-9999,9999], or exact borrowed text including embedded zero. No terminator is added. Invalid tag/span returns INVALID, out-of-range integer RANGE, insufficient capacity FULL, each before any write or count mutation. Tag validation cannot prove union consistency: constructors/caller discipline must establish active payload. Borrowed text remains live through the call. This is not an owning sum type or an ISO C exhaustiveness guarantee.

`B2_IDENTITY(x)` supports precisely int and unsigned int, returns the same type and value, and evaluates its argument once via a selected typed function. Other types require a diagnostic. The facade is an exercise in `include/facade.h`; no GNU statement expression or typeof is allowed. The separate raw and expanded stringify macros must show argument prescan difference. Diagnose ill-typed unselected expressions through compile-only examples; never execute unsequenced side effects.
