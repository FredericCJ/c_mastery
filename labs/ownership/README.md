# Ownership mechanisms

Implement src/ownership.c against include/ownership.h and CONTRACTS.md. The
intentionally flawed tenant writer is supplied for the bounded security case;
all other functions begin as compiling unsolved stubs. Assessor implementations
are outside this directory and excluded from learner initialization.

Use the standard cmastery exercise workflow once the catalog is regenerated.
For a local scaffold build: `cmake -S . -B build -G Ninja`,
`cmake --build build`, then `ctest --test-dir build --output-on-failure`.
The initial semantic failures are expected. Linux pthreads are a harness
dependency. Do not change host settings to accommodate a diagnostic runtime.

The source-bound author campaign is produced by tools/run_ownership.py. The
independent fixture/set checker is tools/verify_ownership_fixtures.py. Counts
and observed compiler behavior belong to their actual receipts; this README
does not assert execution, learner mastery or a strict target audit.
