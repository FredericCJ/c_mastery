## Problem and concrete inputs

Implement `scheduler.h` and the two explicit submit adapters using permitted imported operations. First derive sixteen SCK transitions, sample positions and MOSI bits for A6 against MISO3C in modes0–3. Then run all256×256 byte pairs in all four modes. A mode is `(CPOL<<1)|CPHA`; bit order and multi-byte register order are separate properties.

The only peer is an original synthetic register protocol. Version1 sends `[0xc0|register,0,0]`, register0–31, under one CS interval. Response `[0xa6,low,high]` represents a16-bit little-endian value. For register3 and value1234 hexadecimal, the transaction has three bytes and24 clocks; a one- or two-byte transport is incomplete. Do not decode zero-filled padding or infer status success from successful transport. Wrong status preserves the application value. Preserve the original version0 comparison through the imported protocol contract; no third-party device protocol is implied.

The tests supply a read/write-effect model, source bytes, deadlines and observed register transitions. A deliberately flawed original send-only client writes two bytes on TXE and never reads DR: the model must show OVR, retained first byte11 hexadecimal, zero DR reads, and two writes. The corrected client consumes every RXNE while respecting TXE. A CPU read, DMA memory acknowledgement and last wire edge are three distinct milestones.

## Representation, ownership and failure semantics

Zero-initialize a live `SsScheduler`. Its address is stable until all jobs are retired and no interrupt/callback can refer to it. Its two `SsSlot` objects own copied command bytes and receive buffers; each also owns aligned uint16_t DMA arrays, one halfword per eight-bit wire frame. The actual `algo_ring` holds slot indices, not borrowed stack pointers. Slot transitions are FREE→QUEUED→RUNNING→DONE→FREE. At most one slot is active; DONE still occupies that slot until `ss_take`. Queue admission, current transfer completion and result retirement are separate events.

All API calls are serialized by one owner, including IRQ delivery. Callback functions are bounded, nonreentrant and cannot mutate scheduler storage, retain temporary pointers, or free the object. Buffers/control/result objects supplied to an operation are live and disjoint unless explicitly copied before publication; internal state is trusted, not a hostile-input parser. This discipline is not enforced by ISO C. The target experiment masks foreground operations and admits only the selected IRQ at a deliberate boundary. It does not establish a general concurrent implementation.

`ss_open` requires no active/nonfree slots and delegates clock/mode checks to PsSpi; reopening preserves the high-water token. `ss_enqueue` accepts a nonzero strictly increasing uint32 token, count1–16, dma0/1, budget1–2^31−1 and setup/hold each smaller than budget. Capacity includes queued, active and unconsumed results. Full admission returns BUSY without consuming a token or changing caller data. Successful admission copies command bytes; subsequent changes to the original command cannot affect the queued transfer. Token UINT32_MAX is usable once; the object is then exhausted for new requests, with no wraparound alias. Replacing the object requires an externally distinguished lifetime and quiesced old observers.

`ss_run` dispatches FIFO through the supplied adapter. The time budget starts when the actual controller accepts the head, not when it enters the queue. No fairness or queue-latency bound is promised behind a permanently unquiescent device or unconsumed result. Repeated calls do bounded work, at most one received and one transmitted PIO byte through the retained producer. A monotonic modulo32 clock must be observed frequently enough that successive deltas stay below2^31. Setup is measured after CS falls; hold is measured after final wire-idle or acknowledged reset. The clock and progress premises must be re-established after reset.

`ss_event` validates the delivered token before any register access or conversion to the active driver's token. Tokens distinguish operation identity; they are not cryptographic authority. An old completion arriving after cancellation/reset/reopen must neither touch registers nor advance the new job. `ss_cancel` requests stop. TX and RX ownership remain independently held until their respective disabled acknowledgements. A timeout records failure and requests cancellation; it never grants storage reuse. `ss_reset` is permitted only under the imported cancelling/acknowledgement conditions, may truncate a command and invalidates controller readiness. It is not automatic retry, and external peer side effects are not rolled back.

`ss_take` succeeds only for a DONE active slot with all actual ownership/phase claims cleared. It copies the received prefix, returns status/sent/received and leaves output suffix bytes unchanged. Counts describe CPU consumption or stopped DMA memory progress, not peer commit. Rejection preserves the output/result. A queued request that cannot start after destructive reset becomes a failed result; retire queued results before reopening. A caller cannot bypass the lifetime protocol by freeing a job on an error return.

For F439 DMA, use `ss_f439_submit` with the actual F439 PsIo and stable scheduler storage in inspected SRAM. The adapter validates aligned disjoint halfword arrays entirely in [20000000,20030000) hexadecimal; CCM is excluded. Each stream needs2×count bytes and NDTR counts frames. Byte PIO and halfword DMA are different memory layouts for the same wire content. The mapped composition deliberately rejects native process addresses while admitting the actual MPS2 SRAM-resident scheduler arrays; that demonstrates address admission and compiled adapter composition, not physical DMA. A callback paired with another PsIo or a scheduler placed outside the selected SRAM does not satisfy this target contract. DMA barriers and volatile accesses are compiler/ISA/peripheral rules, not ISO C synchronization.

## Rubric and graduated hints

For .a, level2 derives all four sample positions and explains why little-endian byte order leaves within-byte MSB order unchanged; level3 independently adapts the16-bit peer and diagnoses a wrong-edge or status counterexample. For .b, level2 proves every borrow against its real acknowledgement and distinguishes memory/wire/CS completion; level3 handles the actual cancellation→reset→new request→late IRQ transfer without reusing storage or accepting a stale identity. For .c, level2 demonstrates the original no-RX-read loss and missing-dummy-clock framing failure; level3 constructs the bounded scheduler with setup/hold and retained leases under timeout. Output-only reproduction is level1; wrong ownership, unexplained constants or inflated target evidence is level0. Passing finite tests is necessary evidence, not absolute mastery.

Hints, used only after retaining an unaided attempt: (1) mark the owner of each span, CS and queued index at each observation; (2) place each clock sample after the event that makes the prior one obsolete; (3) draw an old token at the API boundary before the active token substitution, and count memory frames separately from wire bits. Assessor analysis and implementations remain separate.
