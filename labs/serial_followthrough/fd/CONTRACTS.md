## Contracts, invariants and failure semantics

All input/output objects are live, aligned and disjoint. One serialized caller owns each operation. Components perform no allocation, recursion, I/O or external calls other than the declared prerequisite. Raw flags are validated before conversion. Admission errors preserve output and lengths. `FdPacket` is produced by `fd_admit` or `fd_length`; callers must not fabricate inconsistent internal packets. Work is bounded by64 payload bytes,16DLC entries and720 one-byte wire bits.

`fd_admit` requires exact DLC/payload length agreement and validates raw FDF/BRS/ESI/remote/capability values. `fd_length` accepts exact or round-up policy, with0..64bytes; it copies input and zeroes every remaining payload slot. `payload_length` retains the original logical length, while `padding` records the added bytes. The application must carry its logical length separately if padded data is later decoded; zero padding does not recover it uniquely.

**Versioned ESI interpretation:** the accepted baseline's simple active/passive wording is insufficient for the current ISO clause. `fd_esi(passive, requested)` returns the transmitted bit from both actual state and the LLC request. An active sender with a set request transmits ESI1, so ESI1 alone does not prove passive state. The original metadata admission still accepts both raw states. Explain this counterexample without editing historical acceptance evidence.

`fd_wire` emits one strict standard data-frame transcript, with transmitter-recessive ACK and seven recessive EOF bits. It accepts only packets from the above constructors and ID0..0x7FF. Current mode uses an initial CRC with its most significant bit set, counts dynamic stuff bits modulo8 with Gray coding/even parity, includes count and dynamic bits in CRC, excludes fixed bits, and inserts the fixed first CRC-field bit once even when the data ends in five equal bits. Historical mode names the exact archived2012 document, uses its zero initial CRC and no protected count. The polynomial representation includes the high-order term in source notation; the C feedback masks omit that term. The total conservative bound is709 bits in720slots. The experiment is not an interoperability claim for every historical implementation, extended FD/XL, receiver tolerance, bus arbitration, error signalling or physical timing.

`fd_transaction` reports selected framing and complete-word progress after chip select has ended. For TCAN, all payload units are four bytes; MCP SFR uses bytes and its RAM uses four-byte aligned words. An incomplete suffix does not undo earlier complete words. RAM wraparound is deliberately rejected locally rather than using the device's rollover. `fd_header` constructs only selected RAM read/write headers,1..16 words, within the2KiB region: TCAN0x8000..0x87FF or MCP0x400..0xBFF. It fails unchanged on insufficient output capacity. TCAN's length byte is words; its zero encoding for256words is outside this bounded API. These routines do not drive chip select or initialize ECC/controller state.

`fd_power` checks declared selected circuits. TCAN requires VSUP6..24V and VIO3.135..5.25V; its integrated transceiver is not a second external part. The selected MCP typical route uses3.3V controller/MCU/transceiver logic and a separate5V transceiver supply. This exact route is narrower than every legal MCP circuit. Actual device limits, board wiring and recommended conditions still require physical evidence. TCAN MRAM has unknown ECC at power/wake/reset; a real later driver must initialize its memory and meet the minimum payload-word write rule before enabling transmission.

`fd_tdc` uses a synthetic minimum-quantum trace with prescaler1,1..64 transmitted bits,1..64ticks/bit, an ordinary sample strictly inside the bit, measured-delay input0..63 and offset1..63. Received samples must cover exactly `count*bit_ticks+sample_ticks`. Validate every bit before changing output. Compare saved transmitted bit i against received sample at `i*bit_ticks+delay+offset`, skip samples at/after the data-phase endpoint, and report a mismatch at the next ordinary sample point. A source-supplied “measured delay” is synthetic until an actual capture exists. Cost is linear in the bounded input trace; this model does not configure hardware compensation or prove receiver timing margins.
