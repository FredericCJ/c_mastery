# Required PR-T38-11/12 physical protocol

No board has been flashed or measured by this package. This protocol is required authoring; it does not close either physical milestone. Build/execute on original synthetic models first. Only operate an isolated dedicated teaching setup after the user explicitly authorizes the physical operation.

Record exact MCU/MCP2518FD/transceiver/peer board revisions and schematics; selected MCP DEVID,40MHz oscillator identity/tolerance, controller3.3V rail, MCU3.3V logic, transceiver supply/VIO, common reference and terminated bench cable. Use F439 SPI1 PA5/6/7 AF5 and PD14 CS only after checking those nets against the actual board; poll the controller INT status or separately wire/configure an input. No assumed board revision or pin wiring is evidence. Derive termination, stub length, probe loading and allowed common-mode range from the selected actual transceiver datasheet; PR38 transceiver producer evidence does not automatically cover a replacement.

Capture source and image SHA256, compiler/linker commands and closure, clock tree, measured SCK/CS setup/hold, waveform instrument/model/serial/settings/sample interval/probe points, and unmodified raw files. CS belongs to one complete command. Decode reset/configuration acknowledgement, DEVID, oscillator-ready, RAM write/read challenge, FIFO/filter configuration and internal loopback with zero and64-byte FD. Repeat with disconnected controller and wrong SPI mode; preserve first contradictory raw trace and bounded failure before repair. All-ones and internal loopback are insufficient for a physical bus claim.

Use an independent FD-capable peer with its own source/build/configuration. For each BRS0 and1, exchange the six frames from mc_bench_frame: ID0x300+i carries sequence even when DLC0; nonempty payload begins with i, follows the specified pattern and ends in XOR check. This selected driver has one exact-ID RX filter: before each peer frame, quiesce the previous device epoch, reinitialize with accepted_id0x300+i, and let the peer send only after the new readiness acknowledgement. Do not pretend one unchanged exact filter receives all six IDs. The reset/configuration gap belongs in the measured service-cost ledger. An additive masked-filter implementation is a separate changed-condition option requiring its own source/readback/fault tests. A second series must be generated by the peer using a new seed and independently checked rather than echoed by the same program. Record all received IDs/lengths/payload bytes at the application, the associated decoded/raw CAN waveform and source clocks. A link ACK may come from another receiver and does not prove correct peer application sequence/content.

Nominal500kbit/s; chosen data1M or2Mbit/s and75% sample point must be supported by every component and actual topology. Show the BRS sample-point transition and CRC-delimiter return; record sample resolution and uncertainty. Repeat a fresh series at the other data rate. The optional decoder must not label an ordinary software timestamp as the actual sample point. Record propagation/transceiver delay and compare TDC offset/delay range; do not substitute the synthetic FD TDC model for measurement.

Remove the peer only inside this isolated bench. The driver restricts retransmission; observe terminal error/status and no unbounded successful-delivery wait. Restore a peer, explicitly recover/reinitialize a new device epoch and rerun. Use a nonmatching ID to show local filter rejection without claiming it prevents link ACK. Withhold application RX service until the bounded FIFO overflows; capture the coalesced overflow flag and surviving contents. Do not infer an exact loss count from one flag. Compare cancelled-before-SOF and success-winning-cancel where observable, preserving uncertain cases rather than forcing a verdict.

After seven days, assess a different board revision or oscillator. Re-derive power/pins/clock/SPI bound/timing/errata and repeat relevant captures. Preserve earlier results. The dossier checker can reject missing files, wrong sequence/rates and absent changed-condition records; it cannot authenticate that a human instrument was physically connected. Assessor judgment and actual source-bound observations remain mandatory.
