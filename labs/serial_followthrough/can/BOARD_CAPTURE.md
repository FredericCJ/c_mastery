# Dedicated Classic CAN board observations

Use two original teaching nodes on a dedicated non-operational bus with synthetic identifiers/payloads. Record selected boards, silicon and errata revisions, firmware/image hashes, clock tree and independently measured clock, pin mappings, transceiver part/rails/mode pins, reference path, cable/stubs, termination at both ends and instrument setup. Keep a transceiver supply distinct from a controller logic rail. Check the selected datasheet's recommended operating limits; absolute maximum ratings are not operating targets.

Capture physical TX/RX/CANH/CANL for one correct standard-data frame and compare start, identifier, stuffed bits, CRC, ACK and end fields with the independent wire oracle. Repeat actual competing11-/29-bit identifiers, arbitration loss and successful retry. An internal loopback test ignores external acknowledge behavior and cannot replace these observations. Do not inject an uncontrolled dominant bus state; bounded faults use the teaching node's explicit test mode or isolated fault-injection fixture.

Pause the receiving foreground consumer while four accepted messages arrive; separately record locked/unlocked FIFO values and sticky overrun before explicit acknowledgement. Capture the copied frame before each RFOM write. Exercise normal auto retry and NART in independent reset configurations. Record an abort request while a frame is pending and while transmitting; accept either eventual transmitted-success or acknowledged abort when consistent with the hardware trace. Never infer quiescence from elapsed time alone.

For manual bus-off recovery, use a bounded synthetic fixture and document the exact error mechanism. Record BOFF, INAK, TME/RQCP and the bus idle sequences. An isolated sender missing ACK can stop at passive under the specified exception, so do not call that a bus-off experiment. Report failure to create the intended state honestly. After recovery, prove only the recorded frame exchange and independently check physical health assumptions.

Repeat the timing experiment with a changed clock or topology and recalculate propagation/sample margins. The software search's BS1 allowance is only one constraint. Preserve raw timestamp uncertainty and decoding disagreements; never fill in expected readings. Physical work is unperformed until actual captures and review exist.
