The component remains profile C: ISO C17, caller storage, no runtime C-library calls, allocation or dynamic loading. `depth.h` requires eight-bit bytes and its declared exact-width integers. Compile `cursor.c` and the selected foundation producer separately, inspect their undefined references, then inspect the final linked image and map. The exact GCC/Clang Cortex-M4 audit uses no libc, libgcc or compiler-rt. Host `malloc`, Python, `memcmp`, sanitizers and the loader belong to verification or the explicitly separate hosted comparison. The loader exercise is profile A on Linux/glibc, not a new permission in the profile C component.

All pointers designate live, appropriately aligned real objects of the declared type and truthful extent. No operation validates arbitrary bits or proves ownership from size metadata. Unless explicitly allowed, outputs, wire bytes, control records and input objects are disjoint. Operations are single-owner, non-reentrant and synchronous. Borrowed data must remain live until the consumer finishes. The common accessor callback respects the same output-preservation contract and does not mutate its context during a call.

`struct oc_rows` owns no storage and requires `count` actual rows of exactly three ints. `struct oc_table` requires actual pointer and length arrays with `count` elements; each admitted nonempty row names its own live int array. `struct oc_matrix` additionally bounds its logical row/column rectangle. `oc_representation` requires capacity exactly `sizeof(int[2][3])`; observed bytes are not a portable wire format or scalar-value oracle.

For `oc_difference`, `base` names one actual byte array with n elements; indices may equal n. The mathematical magnitude must fit `PTRDIFF_MAX`. A synthetic `SIZE_MAX` length does not permit manufacturing an impossible actual pointer. The logical-order function accepts length metadata without backing storage and can therefore test overflow using `{SIZE_MAX,1}` safely. Empty fragments are valid; count0 has no valid position. All logical sums must fit `size_t`.

The nullable-index encoder accepts null or a live element pointer, including a live foreign element which it can reject by equality search. One-past, dangling and arbitrary reconstructed pointers are excluded. Pointer equality cannot prove provenance: adjacent end/start representations may compare equal, so this API is not an ownership authenticator. On success its result refers to this explicit owner, which must not move or end while decoded pointers remain borrowed. Wire input/output must have four real bytes. Record format, owner identity and lifetime are distinct contracts.

## Hosted module boundary and failure ownership

Only build/load the supplied `plugin.c` variants by explicit paths in a local build directory. They export actual complete `struct oc_plugin` objects and use the same declared C ABI. ABI/size checks cannot validate arbitrary memory exported by malicious native code; constructors can run before admission. `RTLD_LOCAL` is symbol visibility, not a sandbox.

`struct oc_module` begins zero-initialized and has one owner. Successful `oc_open` retains a handle and admitted table. Failed open leaves it empty unless cleanup itself fails, in which case a nonnull handle with null table records cleanup-only ownership; retry `oc_close`, never borrow. `oc_borrow` increments the bounded outstanding count; `oc_return` consumes one matching returned pointer and clears that variable. The caller must not copy/forge borrow bookkeeping or reenter/mutate the module through a callback. ISO C does not enforce this affine discipline.

`oc_close` returns `OC_LOAD_BUSY` with live borrows, leaves ownership intact on loader-close failure, and clears handle/table on success. Successful close releases this reference; it does not prove physical unmapping. All aliases must already be withdrawn regardless of whether bytes remain mapped. The synchronous function-address experiment uses an already open admitted module and saves only its integer result. Compile that platform boundary separately from the ISO-only component; GCC/Clang diagnostic differences are observations, not standards judgments.

## Reasoning, resource costs and deliverables

D1 is the nine-row authority/formation/lifetime ledger with actual containing array, before/after state and the incorrect explanations: contiguous bytes authorize flattening; integer zero always means a null constant; equal addresses prove ownership; successful close proves unload. Falsify each under its precise assumptions. D2 is the implementation and layout diagrams linked above, with normal/failed transitions and borrow accounting. D3 is reproducible commands, compiler versions, independent interval expectations, diagnostics, native/i386 observations, object imports and final map/assembly. D4 preserves all nine exact delayed tasks and pre-recorded study timestamps; author reference runs do not satisfy the delay.

Accessors, ordinary cursor operations, decoding and fixed-size representation copy use constant auxiliary storage; parameterized representation copying is linear in bytes. Nullable encoding searches count elements; fragmented ordering scans the length list, including overflow admission. Both are linear with constant storage. The local module owner and borrows are constant-sized bookkeeping; loader latency/allocation is an external OS/library cost and has no bound here. Explain the costs of callback indirection and changed row allocation without claiming universal performance superiority.

## Security and validation limits

This is a semantic/lifetime laboratory, not an exploit exercise. Targets are original local arrays and original local modules with synthetic data. No third-party module, external service, real credential or host security change is permitted. The observable failures are rejected coordinates, preserved outputs, diagnostic differences and refused live-borrow closure; no arbitrary-code-execution conclusion follows from them. Native plugins inherently execute trusted code; the repair controls lifecycle and interface admission, not hostile-code isolation.
