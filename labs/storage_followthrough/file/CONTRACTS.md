## A staged nonblocking operation

Implement `SfiOp` and its exact-owner/generation `SfiTicket`. `sfi_init` requires fresh nonowning storage. Controls must remain live, noncopied and serialized. Controls, ticket outputs, callback context and caller buffers are disjoint; no callback may reenter, destroy the operation or retain a borrowed suffix. Every callback returns before its borrowed buffer can be reused. ISO C cannot enforce these ownership premises.

Begin accepts a page within the declared backend, computes its uint64 byte offset and increments the nonwrapping generation. A write copies its whole4096-byte input into the operation; a read borrows a4096-byte output until terminal completion. Busy, bad arguments or exhausted generation preserve state and ticket output. GenerationMAX may issue once; release remains possible, but no later begin may wrap.

Each step admits at most the specified number of callbacks, including EINTR. Positive counts accept exactly that prefix, `SFI_INTR` accepts none, `SFI_AGAIN` transitions to WAIT, and zero/error/malformed count makes the operation terminal IO. WAIT without a fresh external readiness observation issues no callback. Readiness can be spurious and may lead to AGAIN; it is not a reservation. A zero budget performs no callback. Budget exhaustion preserves progress and permits a later bounded step. The caller owns any total-call limit or deadline across steps; there is no claim that a perpetually interrupted backend eventually succeeds.

Read success publishes all4096bytes once. Read refusal/cancellation leaves the caller output unchanged. Writes expose accepted prefix through `done`; cancellation cannot undo it or promise durability. Terminal steps make no callback. Release clears owner state while retaining the finite generation; stale tickets cannot act on a later operation. Cancellation only ends this synchronous callback state machine: it is not permission to abandon a different asynchronous provider's outstanding buffers.

Run8 ordinary chunk/direction cases with two interrupted calls, two readiness waits and chunk sizes1,127,4095,4096. Add cancellation after17bytes, zero progress, oversized callback count, stale tickets and generation retirement. The independent oracle expects `4+ceil(4096/chunk)` callbacks and an empty released operation. A real O_NONBLOCK pipe first returns EAGAIN, then poll supplies readiness for a13-byte prefix and the remaining4083bytes plus writer hangup. This selected ordered page stream validates one page operation; it is not a seekable file or a complete network block protocol. The backend callback verifies the expected sequential byte offset.
