# T11 inspected primary passages

Only the named passages were inspected. The active C17 baseline is unchanged.

- **R-LFREE-N1570**: [C11 committee draft execution environment](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf), WG14 N1570 April12,2011 C11 committee draft. 4p6 PDF25/printed8;5.1.2–5.1.2.1 PDF29/printed12. Draft minimum library and implementation-defined startup; not relabeled as published C17.
- **R-LFREE-N3096**: [C23 working-draft freestanding comparison](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf), WG14 N3096 April1,2023 working draft. 4p6–7 PDF26/printed8;5.1.2–5.1.2.1 PDF29/printed11. This draft expands required library facilities; no claim that its memalignment wording survived unchanged into the published standard.
- **R-LFREE-GCC-LINK**: [GCC link options](https://gcc.gnu.org/onlinedocs/gcc-15.2.0/gcc/Link-Options.html), GCC15.2.0. nostartfiles/nodefaultlibs/nostdlib paragraphs; linker-output/LTO controls. Language mode, header search and link exclusions are independent controls.
- **R-LFREE-CLANG-FREE**: [Clang freestanding requirements](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/clang/docs/UsersManual.rst), LLVM21.1.8. Freestanding Builds lines983–1007. Compiler code generation may require standard memory support despite freestanding mode.
- **R-LFREE-CLANG-RUNTIME**: [Clang toolchain runtime boundaries](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/clang/docs/Toolchain.rst), LLVM21.1.8. Runtime and atomics lines116–197; sanitizer runtime235–245. Atomic/instrumentation support belongs in an explicit runtime policy.
- **R-LFREE-LLVM-DIV**: [128-bit unsigned helper implementation](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/compiler-rt/lib/builtins/udivmodti4.c), LLVM21.1.8. Complete149-line file. Optimized two-limb nonzero division differs from the original fixed128-step reference.
- **R-LFREE-LLVM-WRAP**: [128-bit quotient wrapper](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/compiler-rt/lib/builtins/udivti3.c), LLVM21.1.8. Complete22-line file. Quotient wrapper delegates to divmod with no remainder destination.
- **R-LFREE-LLVM-ABI**: [Compiler runtime declaration boundary](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/compiler-rt/lib/builtins/int_lib.h), LLVM21.1.8. Lines15–31 ABI macros;98–109 helper declarations. Declarations and target PCS must agree with the emitted call.
- **R-LFREE-LLVM-TYPES**: [Compiler runtime integer types](https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-21.1.8/compiler-rt/lib/builtins/int_types.h), LLVM21.1.8. Lines22–114 integer widths, TI types and limb unions. Internal type widths/endianness cannot be inferred from similar names.
- **R-LFREE-ARM-RT**: [Arm runtime ABI](https://raw.githubusercontent.com/ARM-software/abi-aa/2025Q1/rtabi32/rtabi32.rst), Arm abi-aa2025Q1. Long long helpers1108–1181;32-bit division1190–1288;memory helpers1311–1378. Multiple-register quotient/remainder and div0 hook policy are distinct from ISO division semantics.
- **R-LFREE-SEMI**: [Arm semihosting interface](https://raw.githubusercontent.com/ARM-software/abi-aa/2025Q1/semihosting/semihosting.rst), Arm abi-aa2025Q1. Trap/register interface281–340;exit674–788;WRITEC/WRITE0 1331–1378. Debugger service is explicitly selected; extended exit support is a QEMU profile assumption.
- **R-LFREE-QEMU-UART**: [CMSDK UART emulator model](https://raw.githubusercontent.com/qemu/qemu/v10.2.1/hw/char/cmsdk-apb-uart.c), QEMU10.2.1. Register definitions28–47;baud validation67–89;transmit181–215;write225–281. UART state/transport model supports emulated register access only.
- **R-LFREE-QEMU-MAP**: [MPS2 emulator mapping](https://raw.githubusercontent.com/qemu/qemu/v10.2.1/hw/arm/mps2.c), QEMU10.2.1. RAM193–197;UART268–291. AN386 original firmware uses these emulator regions; no STM32 board claim.
- **R-LFREE-NEWLIB**: [newlib-nano concrete output service boundary](https://sourceware.org/pub/newlib/newlib-4.6.0.20260123.tar.gz), newlib4.6.0.20260123 with Ubuntu package4.6.0.20260123-1. newlib/libc/reent/writer.c: Complete file; newlib/libc/reent/sbrkr.c: Complete file; newlib/libc/stdio/printf.c: Complete file; newlib/libc/stdio/makebuf.c: Lines1–140 buffer allocation/fallback; newlib/libc/stdio/stdio.c: Lines1–130 output/seek/close wrappers; newlib/libc/stdio/findfp.c: Lines1–260 standard FILE state, dynamic glue and initialization; newlib/libc/stdio/nano-vfprintf.c: Lines1–160 service contract;170–290 string-only growth contrast;330–490 actual stream emitter/init; newlib/libc/stdio/fflush.c: Lines1–150 API and core entry;210–300 actual partial-write loop and error propagation. Tiny formatted-output proposal requires specific hooks and owns stdio/reentrancy state; raw-byte continuation removes that library.
