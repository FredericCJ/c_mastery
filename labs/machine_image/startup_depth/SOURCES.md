Versioned sources and exact limits; a source title alone grants no coverage.

- **R-LSTART-KERNEL**: [Linux ELF loader](https://raw.githubusercontent.com/torvalds/linux/v6.18/fs/binfmt_elf.c), Linuxv6.18 tagged source. padzero118–129; create_elf_tables153–341; elf_map347–381; elf_load387–430; load_elf_binary778–1295. - **R-LSTART-GLIBC-INIT**: [glibc initialization/main/exit](https://packages.ubuntu.com/resolute-updates/glibc-source), Ubuntu glibc-source2.43-2ubuntu2.4. csu/libc-start.c153–203 and222–360; sysdeps/nptl/libc_start_call_main.h complete body. Static init/fini traversal, relocation/TLS/guards and actual main/exit handoff.
- **R-LSTART-GLIBC-PIE**: [glibc static-PIE relocation](https://packages.ubuntu.com/resolute-updates/glibc-source), Ubuntu glibc-source2.43-2ubuntu2.4. elf/dl-reloc-static-pie.c complete92-line file; matching git-updates.diff hunk. - **R-LSTART-GLIBC-TLS**: [glibc TLS and DSO init consumers](https://packages.ubuntu.com/resolute-updates/glibc-source), Ubuntu glibc-source2.43-2ubuntu2.4. elf/dl-tls.c467–800; elf/dl-init.c20–76. Allocation/resize/init/deallocation and DT_INIT/INIT_ARRAY consumer, bounded to these bodies.
- **R-LSTART-MUSL-INIT**: [musl environment and startup](https://musl.libc.org/releases/musl-1.2.5.tar.gz), Official musl1.2.5 source archive. src/env/__libc_start_main.c complete file. Auxv/environment work, calls to TLS/guard initialization, stage2 init/main/exit; no whole-libc inspection.
- **R-LSTART-MUSL-ERRNO**: [musl errno TLS dependency](https://musl.libc.org/releases/musl-1.2.5.tar.gz), Official musl1.2.5 source archive. src/errno/__errno_location.c complete file; arch/x86_64/pthread_arch.h complete file; src/internal/pthread_impl.h first4400characters through TLS/self definitions. - **R-LSTART-SYSCALL**: [Linux syscall conventions](https://man7.org/linux/man-pages/man2/syscall.2.html), Linux man-pages6.19 page2026-02-02, inspected2026-10-17. Description lines35–51; ARM EABI aligned64 example64–103; architecture/argument tables106–236. Raw conventions versus libc errno wrapper; alternate architectures require explicit adapter evidence.
- **R-LSTART-N1570**: [C execution environment and termination](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf), WG14 N1570 C11 committee draft2011-04-12. 5.1.2,5.1.2.1,5.1.2.2.1–.3 printed12–14;7.22.4.2/.4/.5 printed350–352. Hosted main/return/handlers versus freestanding implementation contracts; _Exit stream cleanup is implementation-defined in this draft.
- **R-LSTART-AMD64**: [AMD64 entry and calls](https://refspecs.linuxfoundation.org/elf/x86_64-abi-0.99.pdf), Draft0.99.6 July2,2012. Previously inspected T08:3.2.2–3.2.3 stack/argument classes; newly read3.4.1–3.4.3 printed27–32/PDF28–33 initial state, stack and auxiliary vector. Historical ABI draft corroborates platform derivation; no ISO or current-edition equivalence.
