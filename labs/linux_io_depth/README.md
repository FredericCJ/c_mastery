# Advanced Linux I/O and completion ownership laboratory

C17 portable state/extent core with Linux syscall adapters. Kernel/liburing versions and feature probes are recorded. No external network targets, raw block devices or system configuration changes.

Portable core controls are independent of required guest/board observations. Ordinary init copies compiling learner stubs, tests and contracts. Explicit `-DCMASTERY_ASSESSOR_ROOT=/absolute/repository/assessor` selects reference sources; never use that flag for learner evidence.

Actual epoll, eventfd/timerfd/signalfd, io_uring feature/error paths, splice/sendfile and fsync/rename observations are required; unavailable kernel features are explicit gaps and never simulated passes.

See the canonical project briefs and `CONTRACTS.md`.
