# Memory safety offense and defense in original teaching programs laboratory

C17 original local teaching targets only, synthetic bytes and sentinel state. No third-party service, deployed firmware, real credentials or host security changes. Actual undefined-behavior demonstrations run in separate disposable sanitizer processes.

Portable core controls are independent of required guest/board observations. Ordinary init copies compiling learner stubs, tests and contracts. Explicit `-DCMASTERY_ASSESSOR_ROOT=/absolute/repository/assessor` selects reference sources; never use that flag for learner evidence.

Each security dossier must retain attacker input, violated property, necessary exploitability assumptions, harmless target-local success, repaired result and residual mitigation limits. Model violations do not imply arbitrary code execution or privilege escalation.
