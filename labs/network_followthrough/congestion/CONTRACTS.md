# Required congestion-control construction contract

This is the required successor to T41.07.c's one-flight/general-host comparison, refining that existing objective rather than rewriting its historical acceptance. Implement the byte-accounting controller in `src/congestion.c`; its public declaration and guided traces are `congestion.h` and `tests.c`. The separate assessor simulator supplies an original, inspectable packet network. It calls the actual preceding `NiParse` and `struct s_checksum` implementations. It does not call the operating system's TCP implementation. Neither this controller nor the simulator is a complete TCP endpoint; reuse the T41.06 header, sequence-window and ownership arguments when explaining that boundary.

## Mechanism and progression

First derive `FlightSize = SND.NXT - SND.UNA` using unsigned arithmetic with a live interval shorter than half the32-bit sequence space. Flight is committed new sequence bytes lacking a cumulative ACK. It includes retransmitted positions only once. It is not allocated buffer capacity, cwnd, advertised rwnd, bytes submitted to DMA, or bytes physically on the wire. Start with100-byte MSS, cwnd800, rwnd400 and actual flight400: reducing after loss uses400, not800. Derive ordinary admission as `max(0,min(cwnd,rwnd)-FlightSize)`.

Implement initialization, copied admission and ACK validation before growth. Then add slow start, congestion avoidance, duplicate-ACK recovery, timeout collapse and idle restart. Add the Limited Transmit policy only after these invariants hold. Finally implement the private changed receiver and network schedules independently from the worked trace. The prerequisite artifacts are your own checked circular sequence model, IPv4/checksum implementation, T41.06 retained-send ownership dossier and T41.07 RTT/RTO calculations. A reference-provider execution is author integration, not evidence that your prerequisite artifacts integrate.

## Exact API, representation and operations

Use ISO C17, GCC/Clang with warnings as errors. `struct nr_control` is caller-owned, initialized once before use and confined to one serialized event loop. Its public fields support deliberate state fixtures; ordinary callers must not mutate them. `mss` is1..1460; advertised window0..65535; `NR_LIMIT` caps cwnd at1048576. `una`/`nxt` wrap modulo2^32; flight remains less than2^31. `credit` is already acknowledged bytes accumulated toward a congestion-avoidance increase. Two disjoint Limited Transmit intervals record only still-unacknowledged extra bytes. `timeout_una` identifies the earliest position whose repeated timer expiration must not repeatedly halve the threshold. A new cumulative ACK clears that episode marker. All timestamps are monotonic uint64 milliseconds within one controller lifetime; reset requires a new established connection and no outstanding caller references.

* `nr_init(s,mss,isn,rwnd)` constructs no-flight state, IW=cwnd=MSS, ssthresh65535, time0, Limited Transmit disabled. This conservative initial window is an explicit model choice, not a claim to use the maximum permitted IW.
* `nr_policy(s,0|1)` changes policy only with no flight; outstanding work returns BUSY. Enabling the policy does not modify cwnd. Inputs outside the stated domains return INVALID.
* `nr_flight` and `nr_usable` require a valid initialized nonnull state. The latter includes a permitted Limited Transmit grant; it does not imply available application bytes, a reusable descriptor or a free packet buffer.
* `nr_send(s,bytes,copied,now,&sequence)` admits1..MSS new bytes. The caller has checked actual send-window freshness and owns the bytes. Beyond the allowance returns BUSY. `copied=0` returns WAIT, preserving sequence, controller and quota. `copied=1` is a serialized notification that the complete lower copy already succeeded; return OK and the old NXT, advance NXT exactly once and record last-send time. A failed copy must never be reported as success. Do not call this for retransmission: retransmission reuses retained bytes at UNA and does not add flight. Output storage and state are disjoint live objects.
* `nr_ack(s,ack,window,payload_length,flags,now)` takes an externally validated established-connection ACK. Header checksum, peer tuple, TCP state, receive sequence acceptability and SND.WL1/WL2 window-update freshness have already been established. Flags are ACK or ACK|PSH; SYN/FIN/RST are outside this controller. A future ACK is INVALID without mutation; an old half-range ACK is WAIT without mutation. New ACKs advance UNA, trim the two Limited Transmit intervals and clear the duplicate count. A qualified duplicate requires flight, ACK=UNA, no payload, and an unchanged advertised window. A window update or payload-bearing ACK is not such a duplicate. Do not mistake a payload length parameter for proof of its backing storage.
* Below ssthresh, a new ACK adds min(newly acknowledged bytes,MSS), preventing arbitrary growth by splitting one cumulative acknowledgement into one-byte ACKs. At/above ssthresh, accumulate acknowledged bytes; once the accumulated total reaches the pre-increase cwnd, add one MSS and discard excess credit. This conservative byte-counting variant never credits the same bytes twice. Clamp growth at NR_LIMIT. Derive why `credit + new_bytes` cannot overflow under the stated live-flight bounds.
* The third qualified duplicate sets threshold=max(floor(adjustedFlight/2),2*MSS), cwnd=threshold+3*MSS and returns FAST_RETRANSMIT. The caller retransmits UNA and restarts its own retransmission timer. Additional duplicates inflate by MSS only up to the number of original outstanding segments (ceiling division); cap is a defense against unbounded synthetic duplicate inflation. Keep its consumed budget for the whole recovery episode: window updates may reset duplicate classification but must not replenish that budget. The first ACK of any new byte deflates to threshold and leaves recovery. This is Reno, so a partial ACK can leave another loss waiting for its timer; it is not NewReno or SACK.
* With Limited Transmit enabled, each of the first two qualified duplicate ACKs grants at most one extra new segment while Flight<=cwnd+2*MSS and rwnd permits it. No cwnd change occurs. A normal-window send consumes no extra grant. A send using the extension stores its complete interval in one of two available slots and consumes the grant; partial ACKs trim intervals. Exclude still-unacknowledged Limited Transmit bytes from the third-duplicate threshold, but include them in a timeout's FlightSize. No SACK is negotiated in this model. A refused lower copy preserves the grant.
* `nr_timeout` requires actual outstanding flight and a caller-confirmed expired timer; it is not a clock scheduler. Set loss window=MSS, clear credit/recovery/grants, and compute threshold from actual flight only on the first expiration of that earliest position. Repeated expiry without ACK progress keeps threshold. Caller retains bytes, performs one retransmit, and applies RTO backoff. New ACK progress permits a new loss episode.
* `nr_restart` requires no flight and RTO1000..60000. If time since last accepted data send is strictly greater than RTO, reduce cwnd to min(IW,cwnd) and clear credit. A recently received HTTP request must not hide a long send-idle interval. Exactly RTO and RTO+1 must differ.

Every input that mutates state must respect the monotonic clock; ignored old ACKs do not advance the controller clock. INVALID/BUSY/WAIT paths never transfer application ownership. No allocation, recursion, implicit library congestion algorithm or pointer ownership transfer is permitted. Core operations have constant work and fixed storage; two-slot trimming has a fixed bound. On the supplied ABIs sizeof(NrControl) is measured rather than assumed. ISO C gives unsigned wrap and object rules; neither C17 nor C23 enforces valid controller state, serialization, a fresh ACK, ownership, or a monotonic clock. No exception, borrow checker or language-native protocol type is reproduced by this struct.

## Contained adversarial investigation

Target only the original array controller/simulator or your own implementation on the local host/dedicated emulator; no external traffic. The attacker controls synthetic duplicate ACK arrival and ACK subdivision within a pre-established fixture; tuple/authentication is an explicit input premise, not bypassed against a real endpoint. Compare mutant4 (MSS growth per tiny ACK) and mutant5 (unbounded duplicate inflation) with corrected code. Harmless success means an observed excess cwnd/invariant failure inside this model. Demonstrate the effect of byte counting and capped recovery inflation, rerun regressions, and retain the residual limit: an ACK is not authenticated, a malicious receiver can lie within accepted sequence bounds, and finite rate limits are not a proof of network fairness. A failed assertion or sanitizer observation is not arbitrary code execution.
