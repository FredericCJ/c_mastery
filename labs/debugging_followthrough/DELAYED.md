# Independent diagnosis protocol

An assessor schedules a new attempt at least seven days after the learner's last
exposure. Record actual dates and identity; do not backdate author execution.
The assessor selects a withheld ownership-boundary defect, builds it with a fresh
configuration and stores executable/symbol hashes before handing over only the
public API, failure input and contract. Use an independently selected seed.

Before revealing source or a reference repair, the learner submits an immutable
four-column evidence table, competing hypotheses, predicted discriminating
probe, replay manifest, first-invalid-state claim and proposed repair. Hash that
submission. Then permit controlled debugger/tool access and retain the transcript.
The learner must distinguish publication from completion, preserve old ownership
on failure and show a changed-condition regression. Record any hint or disclosure.

The assessor compares against its separate hidden oracle only after the frozen
prediction. A self-authored run is an author check, not independent performance.
This repository currently contains an assessor exercise and author validation;
the independent seven-day result remains unobserved.
