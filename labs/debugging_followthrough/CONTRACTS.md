# Diagnosis from first invalid state to repaired contract

This additive C17 laboratory covers the exact tasks and changed conditions in
`criteria.json`. Implement `diagnosis.c`; it intentionally returns failures now.
Run `python3 labs/debugging_followthrough/build.py --output /tmp/diagnosis` after
implementing the imported learner providers. The assessor implementation is an
explicit optional input to the build script. Hosted pthread, debugger and tool
experiments use separate executables. None adds a target runtime dependency.
The freestanding core audit records compiler-generated byte-fill dependencies;
the explicit original byte-fill support closes that dependency before a target
link. Hosted stdio, pthread and diagnostic runtimes are not part of that core.

Start each investigation with a prediction, a frozen source/executable/symbol
manifest, input bytes, configuration, environment, seed, working directory and
finite timeout. Record four columns: expected, observed, inferred and untested.
An accepted input that should be rejected is an observation. Assignment instead
of comparison is one causal hypothesis. Removed validation or stale capacity
can produce overlapping outputs. Observe the parameter before and after the
guard and the capacity separately; input zero alone cannot distinguish an
unchanged zero from a parameter assigned zero. `specimen.c` supplies all three
probe boundaries and an environment-selected capacity.

Warnings are evidence about source patterns. Compile the assignment defect
with GCC and Clang, then add parentheses without repairing its semantics.
Compare debug and optimized executables by their hashes and their disassembly.
Required validation, cleanup and ownership changes must execute regardless of
logging. A macro that expands to `(void)0` skips its argument; an inline function
still evaluates its argument. `macros` exposes this difference with a diagnostic
counter. Keep immutable first cause per operation and a three-event ring for
recent context. The ring has no allocation and counts discarded events. Nested
operations own different first-cause records; a deliberate global policy would
need a different ownership contract.

The reducer consumes an ordered universe of at most16 chunks. Its callback has
three answers, PASS, the selected FAIL, and UNRESOLVED. Start fresh processes,
replay every candidate twice, and require a matching selected transition; a
timeout, malformed input or unrelated abort is UNRESOLVED. Keep outer delimiters
fixed for the parser exercise. The C reducer tries subsets then complements,
increasing granularity when neither succeeds; its 512-entry bounded cache is
local to one frozen oracle identity. A budget-exhausted result is a candidate,
not a completed minimality certificate. Independently enumerate all256 fixture
subsets and delete each member of `[1,7,8]`. The original fixture has88 FAIL sets;
the three-member witness is1-minimal although `[2,3]` is smaller. Re-certify all
three two-deletion neighbors when that rewrite is admitted. Tree deletion
preserves balanced subtrees and changes the set of candidates and the meaning
of minimality. No reducer output is itself a causal repair.

For GDB, preserve ASLR and work only on owned bounded specimens. Stop before
the fifth acquisition, select the correct frame, record `used` and `capacity`,
then compare source stepping with `stepi` and raw instructions. The faulty path
publishes5 before clamping4, so a callback can observe5. The repair rejects
before commit. A pure `used == capacity` condition does not modify the target;
calling the acquisition helper in a condition would. Watch only a live object,
delete its watch before freeing it, and establish a new watch after relocation.
`gdb_observe.py` records command output, unavailable values, selected frames,
and watchpoint type. The width8/limit4 and three-watch/two-slot examples are
models, not host capacity measurements. Insertion can fail on resume. A software
watch cannot establish all-thread coverage.

The first watch stop concerns the selected storage. A private candidate can
already violate its invariant before publishing to that storage; buffered log
delivery can occur still later. Distinguish each boundary. A backtrace is a
current stack observation. Inlining adds logical frames, tail calls can remove
physical frames, and optimized-out locals are unknown rather than zero. Compare
Og, O2 and LTO mappings. A bounded saved observation records present registers
and selected variables; omitted heap bytes are unknown. It is not a native core.
Reject different image/symbol hashes even if their source line numbers agree.

An ABI diagnostic must compare the return value, stack and preserved registers
independently. The retained x86-64 probe checks RBX/RBP/R12–R15 and entry stack
alignment. The Thumb scalar AAPCS probe checks R4–R11, including this selected
platform's R9 convention, and eight-byte public-interface alignment. The
deliberate assembly defect clobbers one preserved register after calculating the
correct lower bound. QEMU execution is emulated functional evidence, not a board
timing or interrupt claim. Re-derive obligations for each selected ABI.

Model allocation identities as integers before running native negative cases.
Bounds, initialization and lifetime are independent: an in-bounds read can use
uninitialized data; a successful resize ends old aliases even if address bits
would be equal. Failure preserves the old allocation. Native tests allocate a
replacement while the old allocation is still live, copy the valid prefix, then
free; they never compare or dereference a stale pointer. Run negative cases in
separate processes, ASan and UBSan separately, and Memcheck on unsanitized code.
Copying an uninitialized value can defer the diagnostic until a branch uses it.
A legal-address wrong-field write needs the semantic oracle. Callback borrowing
ends at its declared boundary; later use requires an independently owned copy or
a still-valid generation. Inject every allocation failure prefix and check both
resource cleanup and unchanged publication, under debug and release policies.

The writer offset is the sum of positive accepted counts. EINTR and EAGAIN accept
no bytes, zero progress is distinct from read EOF, and an over-report is an
adapter contract violation. Test all64 positive partitions of seven bytes with
bounded retries and compare the complete output, including empty iovec entries.
Save ENOSPC before a logging seam changes errno to EIO. A pthread function's
direct status is not errno. Owned subprocesses exercise default SIGPIPE and
ignored-SIGPIPE/EPIPE separately. Descriptor exhaustion here is a bounded ledger
of eight slots, with two already occupied, not a system-wide exhaustion test.
Linux close releases the descriptor before a possible late error, so a retry
can close a new generation. The explicit POSIX.1-2024 EINTR model retains it.
Select the platform contract first; no speculative native close retry occurs.

Draw wait-for and happens-before relations separately. A lock-order cycle
indicates a possible cycle; a stopped deadlock diagnosis needs actual ownership
and waiting stacks. The bounded opposite-lock experiment permits timed waits,
so timeout breaks a wait edge and eventual completion is not a permanent
deadlock. The lost-notification specimen is data-race-free: it checks under a
mutex, unlocks, then waits after the producer already signaled. The retained
queue waits and rechecks the predicate with the same mutex. Test producer-first,
consumer-first, empty broadcasts, two and three consumers, timeout and
cancellation near wake. Cancellation request, delivery and completed transfer
are distinct. Join all workers and verify active users, queued payloads and
references before destroying synchronization objects.

Captured MCU addresses are labels, not host pointers. Validate capture bounds,
alignment, EXC_RETURN, Thumb/IPSR state and basic-frame policy before reading
words. The simple policy rejects extended FP and padding; the explicit extended
decoder policy accepts the ninth alignment word only when its premises hold.
BFAR is usable only with its validity bit. A reset/startup sequencing fault, bad
stack capture and premature DMA reuse require different hypotheses. Do not
poll side-effect registers to reconstruct history. Cancellation preserves device
ownership until completion or acknowledged stop. Timeout cannot manufacture
quiescence. Reset changes epoch only after the device-stop premise is established;
old completion tickets cannot release a new transfer. A cached target also needs
the selected cache maintenance and visibility contract. These are not physical
observations of the current host or an attached board.

Map each property to an oracle: ASan for selected invalid extent/lifetime
accesses, Memcheck for initialization propagation, TSan for instrumented
unordered conflicts, Eva for admitted static paths, and exact semantic checks
for defined narrowing. Instrumentation does not extend automatically into an
uninstrumented dependency. The saturated-u8 oracle enumerates all65536 pairs;
32640 narrowing results disagree, and the minimum failing sum is256. The checked
addition variant preserves its output on failure. Compare a static alarm with a
dynamic report and a minimized source transition; an unreached branch can stay
silent dynamically. Weaken the admission premise and re-run the static analysis.

A clamp after publication repairs a final number while preserving the causal
defect. Reject invalid work before commit, and for an asynchronous consumer
establish validation before release publication and acquire before payload use.
Validate the minimized trigger, neighboring inputs and every acquisition failure
prefix with semantic expectations. Diagnostic wording is not the specification.
The hidden assessment in DELAYED.md has a separate authority: no author execution
here establishes independent diagnosis, retention after seven days, review or
physical behavior.
