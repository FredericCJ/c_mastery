# Ethernet depth: original portable contracts, revision 1

These C17 models make seven missing mechanisms executable. They do not implement a complete Ethernet driver or authorize transmitting on any network. Inspect `include/ethernet_depth.h`; learner changes belong in `src/`. Target dependencies are C type/limit headers and explicit compiler-generated byte-copy/clear helpers audited in the campaign. Host tests may use libc/Python. No library may implement the mechanism being studied.

All supplied pointers designate live objects of the stated lengths. Controls begin zeroed, are used through this API, and have one serialized owner. Caller-owned inputs, controls and outputs are disjoint unless this document says otherwise. Callbacks must not reenter, mutate, destroy or retain borrowed API storage. Concurrent interrupt/device changes require a separate adapter and ordering proof. C17 does not enforce these lifetime and ownership preconditions. No pointer is retained except the receive borrow; its backing buffers remain live and unmodified until release. Positive token numbers increase strictly within their slot, never wrap, and exhaustion retires the slot. Resetting control bytes to evade exhaustion is invalid while any old handle can exist.

Status names and numbers are in the header. Invalid arguments return INVALID; finite capacity/exhaustion returns FULL, unavailable ownership BUSY, invalid incarnation STALE. Except the explicit RX drop state, TX abort/completion state and initialization diagnostic below, rejection leaves output/control unchanged. No rollback of external callback effects is promised. All loops have stated finite bounds. Distinguish logical token validation from an actual device stop guarantee.

## Layers: X-T39-002

`ed_wrap` accepts 0..4 unsigned 32-bit header sizes and an application size. Output `i` is the mathematical sum through header `i`; every sum must fit UINT32_MAX. Compute/check all sums before publishing any. NULL with count zero is legal and performs no pointer arithmetic. Example 12 with 8,20,14 gives 20,40,54. These synthetic sizes are not valid protocol encoders.

`ed_compatible` requires nonzero protocol/version IDs, shape 0 frame or 1 stream, ownership 0 copied or 1 borrowed. Compatibility is equality of all four fields. Result is 0/1. Equal layer numbers, names or signatures alone do not establish this contract; it is an original finite checker, not universal negotiation. Time/space O(count)/O(4); compatibility O(1).

## Frame: X-T39-003

Build untagged frames from six-octet DA/SA, 0..1500 payload octets, a 16-bit type/length field and FCS mode 0/1. Fields 1501..1535 and 0x8100 are excluded. A field <=1500 must equal the unpadded payload length. Store DA, SA, big-endian field, payload and zero padding to at least 46 payload octets. Optional four-byte FCS is little-endian reflected CRC32 over DA through padding: polynomial 0xEDB88320, initial/final XOR 0xFFFFFFFF. Check string `123456789` gives CBF43926. Output lengths are 60..1514 without FCS and 64..1518 with it. No preamble, SFD or interpacket gap goes in this buffer. Insufficient output capacity returns FULL with bytes and written count unchanged.

Parser requires the corresponding total-length bounds, admitted field, length-field <= stored payload, and optional valid FCS. A borrowed `payload` points into the still-live original buffer. For length frames, `payload_length` excludes padding; for EtherType frames it equals all stored bytes because this layer cannot infer the upper protocol's meaningful length. `stored_payload` always includes padding. The parser does not require received padding to be zero. Excluded field returns UNSUPPORTED; CRC failure IO; other invalid lengths INVALID. No metadata publishes on failure. The CRC helper permits NULL+zero and lengths <=1518. Build O(n), <=1518 temporary bytes; parse/CRC O(n), constant metadata. The historical RFC1952 CRC algorithm is an arithmetic cross-check, not an Ethernet conformance authority.

## Bridge: X-T39-004

A four-entry learning bridge has three ports numbered 1..3 and TTL 10 nonwrapping uint32 ticks. The caller supplies nondecreasing time. Reject group source addresses (low bit of first octet set). Expire entries with age >=10 before learning and destination lookup; source learning refreshes/moves an entry. If no free entry and source is unknown, return FULL atomically: even expiry/time/output changes do not commit. No eviction is hidden.

Output mask bit0/1/2 names port1/2/3. Unknown or group destination floods all except ingress. A known destination on ingress filters to mask0; another known port forwards only there. Four slots bound all work/storage. This model omits spanning tree, VLANs, address authorization and multicast membership. Local address administration is not uniqueness or authentication.

## PHY: X-T39-005

`ed_mdio_word` accepts HCLK 20..180 MHz, PHY/register 0..31 and busy 0/1. Busy returns BUSY before publication. Select divider/code by half-open ranges [20,35):16/2, [35,60):26/3, [60,100):42/0, [100,150):62/1, [150,180]:102/4 in MHz. The original endpoint convention resolves vendor table shared boundaries explicitly. Word=(phy<<11)|(reg<<6)|(code<<2)|1, MW clear. HCLK168MHz PHY1 register31 gives 0xFD1 and divisor102. These are F439 MAC management fields, not RMII frequency.

Bus `read/write` return zero on success and nonzero on failure; CSR0 is MACMIIAR, CSR1 MIIDR. Before any write, read CSR0 and reject MB set. Write the configured word with MB clear, then MB set. Poll CSR0 until MB clears, then read low16 MIIDR. A transaction has both a positive timeout and 1..1024 poll budget; clock is nonwrapping and monotonic. Regressing clock or elapsed >=timeout returns TIMEOUT. A frozen clock cannot defeat the poll bound. Callback failure returns IO. Output remains unchanged. Any failure after a write can leave the actual device busy; this model cannot undo a bus transaction. The hardware adapter must recover/confirm idle before retry and preserve device-owned storage.

`ed_phy_query` reads IDs registers2/3, BSR1 twice, then special31. Require ID1 0007 and (ID2&FFF0)==C130; revision nibble is accepted. The first BSR link bit2 records latch-low history, the second current link. Link clear returns LINK_DOWN. Both current BSR bit5 and special bit12 must indicate negotiation complete, otherwise NEGOTIATING. Special bits4:2 code5=>10/full and6=>100/full; half/other modes are UNSUPPORTED. Only ready results publish `EDPhy`; failures leave it unchanged. Identity mismatch WRONG_PHY. A ready observation does not promise continued link. Derive the selected PHY meaning from the inspected LAN8742A revision, not another PHY's register layout. At most five transactions, each bounded above. No callbacks perform real MMIO in supplied tests.

## Chained RX: X-T39-006

One acquisition supplies one or two normal-descriptor snapshots. Each live buffer has 1..1536 capacity; combined capacity <=1536. OWN bit31 on either descriptor returns BUSY before trusting its other status. The first must have FS bit9; last must have LS bit8. Intermediate LS or later FS is malformed. Error summary bit15 or descriptor error bit14 is IO. FL bits29:16 of the final descriptor includes FCS; require 64..1518, <=combined capacity and, for two descriptors, >first capacity. These snapshots assume retained-FCS configuration and a contiguous logical split: the first buffer is full if a second descriptor is used.

Only the final valid chain exposes FL-4 bytes, split across the original buffers. If FCS straddles buffers, subtraction still applies to total length, not independently to each buffer. A zero second exposed length uses NULL second pointer. Successful acquisition increments generation and sets held; another acquire is BUSY. Matching nonzero release succeeds once; stale/duplicate release is STALE. UINT32_MAX retires further acquisitions with FULL. Release ends the borrow but does not itself write hardware OWN.

Missing FS returns IO and marks dropping; missing LS returns BUSY and marks dropping; malformed status/length returns IO and marks dropping. A later LS-only fragment remains rejected. A fresh FS restarts chain validation, clears dropping before later checks, and may publish only a complete valid chain. Thus drop state may change on rejection, while the borrow output never does. The caller must drain/recycle discarded descriptor buffers through its separate hardware adapter; this function cannot recover a lost prefix from later fragments. O(2) time and constant control storage, zero payload copies.

## Queued TX and initialization: X-T39-007

Two slots each own up to1514 copied bytes. `prepare(slot,token,frame,n)` requires n14..1514 and a strictly increasing nonzero token for an idle slot; caller mutation after success cannot alter the owned copy. Prepare sets FS bit28 on head, LS bit29 on tail, phase1. `tail` sets tail OWN bit31 then phase2. `publish` requires phase2, a nonnull barrier and no other slot in published/abort-pending phase. Barrier runs before head OWN becomes visible; then phase3. This is an ordering model, not an ISO C device barrier implementation. The hardware adapter must prove actual descriptor layout, bus ordering and visibility.

`complete` accepts only phase3 and boolean returned/error. Without returned ownership it is BUSY. Confirmed return frees slot, clears both status words and returns IO on local error or OK otherwise; neither proves peer delivery. Abort without stop confirmation enters phase4, returns BUSY and retains storage; peer publication remains blocked. Confirmed stop frees storage. A completion for phase4 or a freed/incarnation-changed slot is STALE. Tokens are never reset on release. An unconfirmed abort even before publication is conservatively held until the adapter confirms stop. Copies cost O(n), transitions O(1), two fixed1514-byte payloads.

`ed_reachable` is an original selected SRAM policy: start in [0x20000000,0x20030000), four-byte aligned, length1..1536 and full interval inside that range. CCM 0x10000000 fails. A linker-map proof must establish actual objects inhabit the admitted range; this arithmetic check cannot relocate memory or change DMA reachability.

Initialization event IDs:0 reset asserted,1 RMII selected,2 clocks enabled,3 reset complete,4 descriptors ready,5 bases set,6 negotiated PHY mode,7 MAC start,8 DMA start,9 filters set. Each appears exactly once. Dependencies:1/2 need0;3 needs0/1/2;4/6/9 need0..3;5 needs0..4;7 needs0..3 plus6/9;8 needs every other event. Successful complete count10 gives first_bad10. On duplicate/ordering failure publish the offending index; on a valid but incomplete prefix publish count and return INVALID. This diagnostic publication is intentional. NULL+zero reports incomplete at0. Canonical order0,1,2,3,4,5,6,9,7,8 succeeds. This conservative dependency model is not the vendor register-write sequence itself; actual reset timeout/error cleanup and registers remain required by the parent project.

## Cross-layer handoff: X-T39-008

`ed_budget` admits 0..1460 application bytes, fixed20-byte TCP plus20-byte IPv4 headers, and10/100 Mbit/s. IP=40+app; frame=14+max(46,IP)+4; accounted slot=frame+8 preamble/SFD+12 gap byte-times. Nanoseconds=slot*8*1000/megabits. App0 at100 gives IP40/frame64/slot84/6720ns; app1460 at10 gives1500/1518/1538/1230400ns. This is one ideal serialization slot, excluding processing, propagation, negotiation, retransmission and handshakes. The gap is time, not stored frame bytes.

`ed_capture` maps up to16 nondecreasing uint32 times through a known signed32 offset with uint32 symmetric uncertainty. Publish inclusive lower=t+offset-uncertainty and upper=t+offset+uncertainty in uint64. Reject any negative lower, nonmonotonic trace or invalid count; unknown offset returns UNSUPPORTED. Check all intervals before writing any. NULL+zero with known offset succeeds. This constant-offset model excludes drift; overlapping intervals do not establish event order.

`ed_first_failure` takes six passed bits in order PHY readiness, descriptor ownership, accepted frame integrity, network route, transport progress, application result. Return least clear bit, or6 if all set; outside0..63 invalid. This supplied precedence identifies a failing prerequisite, not a universal root-cause inference from unordered symptoms. Size/time work is O(1); correlation O(n) with two16-entry temporary arrays.

## Assessment and containment

Every exercise requires its derivation, implementation, falsifying traces, cost audit and delayed changed-condition variants. CTest/oracle observations assess named facets only. Original mutants intentionally violate local arithmetic, validation or ownership properties. Targets are these original programs with synthetic bytes, register callbacks and descriptor snapshots, run on an isolated local host; no external packets, credentials, production devices, kernel settings or board flashing. Demonstrate wrong local result, malformed-frame acceptance or premature simulated reuse, then repair and add regression. An injected status bit is an attacker capability in the model, not proof that a remote attacker can control a real DMA register. A crash is not demonstrated code execution. Parent device adapters, physical measurements, independent learner assessments and full protocol conformance remain separate required evidence.
