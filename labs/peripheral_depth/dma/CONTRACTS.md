## Mechanism and representation

`struct pd_transfer` is a single-owner, non-reentrant state machine: idle0 -> running1 -> stopping2 -> ready3 -> idle0. A successful submit copies1–4 descriptors into owned state and borrows every source and destination payload until one finalize. Each nonzero token strictly exceeds `last_token`; UINT32_MAX retires that state instance. Caller descriptor storage may be reused after submit returns, because these are CPU-consumed software scatter/gather descriptors, not a hardware linked list. Source bytes and destination bytes must remain live and inaccessible to every other CPU, ISR and DMA master while borrowed. ISO C cannot enforce those leases or validate the numeric address of a real allocation.

An extent has source, destination, byte length, two capacities and element width1,2 or4. Length1–4096, width alignment, divisibility and capacities are checked before any enable. Every full declared capacity must fit the selected bank: F439 `[0x20000000,0x20030000)`, H745 `[0x30040040,0x30048000)`. CPU-only F439 CCM at0x10000000 is rejected. Destination transfer ranges cannot overlap any source or another destination. Source/source overlap is allowed because all are immutable. Cached extents additionally require each address, length and capacity to be a multiple of32. At most16384 bytes are admitted; additions cannot overflow uint32_t. The checks do not establish that firmware actually reserved or owns the addresses.

`struct pd_io.configure` may fail, publishes no transfer, and leaves the stream disabled on refusal. Other callbacks are bounded, non-reentrant and infallible under their selected device preconditions. A bus fault is not an integer callback failure. The selected port exclusively owns DMA2 stream0, its flags and configuration; no ISR or other component acknowledges them concurrently. RCC clock-register updates require serialized startup ownership. Configure clears only stream0 flags with a direct W1C write, sets PAR to source and M0AR to destination, equal widths, incrementing addresses, single bursts, memory-to-memory direction and full FIFO. Memory-to-memory mode forbids circular/direct mode; F439 requires DMA2. H745 M2M starts on EN without a DMAMUX request. No UART request, double buffer or linked-list capability is implied.

## 10.b — Stop is a request, terminal is an observation (C,D,F,G,I,J)

A cancellation sets stopping and requests EN clear; it returns BUSY while ownership persists. Poll requires the same generation, EN=0, FIFO empty and TC before finalization. RM0090/RM0399 permit FIFO draining after EN clear; EN alone is not a memory publication boundary. The adapter reads EN first, then flags, and only after EN=0 reads FIFO state and NDTR. A same-owner snapshot cannot be reused across reconfiguration. READY means a result is available, not that finalize occurred.

With equal element widths and a quiescent non-error stream, partial bytes are `(initial_NDTR - final_NDTR)*width`. Cancellation after8 of16 bytes gives status CANCELLED, complete8, possible8. A transfer error returns the previously completed extent prefix as guaranteed complete and the entire current extent as the conservative possible-write upper bound. An error/invalid remaining count is not an exact zero-copy result. Unexpected nonzero remaining on ordinary TC also yields IO. A subsequent descriptor configure failure guarantees only the already completed prefix. Count is always bounded by total; do not retry an uncertain prefix as if no effect occurred. Polling may remain BUSY indefinitely if the hardware never demonstrates quiescence. Retain/quarantine storage and escalate to a separately proven supervised reset procedure; a timeout cannot free it.

Deliver schedules for cancel-before-progress, each element cut, late TC, FIFO drain, stale token, repeated cancel/finalize, error, next-configure refusal and generation exhaustion. Distinguish success of the integer model from a silicon observation. Analyze why masking an error flag or suppressing a sanitizer report does not repair premature ownership return.

Changed condition, withheld at least7 days: `pd_suffix` derives the uncompleted suffix into temporary storage, then commits outputs; reject malformed extents even if done==total. Independently compare every cut across three extents and widths1/2/4. Retry is valid here because immutable-source, disjoint-destination memory copy is idempotent. It is not generally valid for a FIFO write, actuator command or increment transaction. For an uncertain error prefix, either abandon the result or replay a whole idempotent extent only after quiescence. A cached partial suffix may cease to own whole cache lines and must be rejected by submit; allocate a new whole-line destination or safely replay the entire owned extent. No unaligned invalidation shortcut.

## 10.c — Cache lines and peer ownership (B,C,D,F,G,H,I,J)

Before H745 enable: clean source, clean destination (preserves unwritten bytes on a partial result), invalidate destination, complete barriers. After quiescence: invalidate destination again, then acquire visibility before result publication. A speculative clean line fill may occur while DMA owns the payload, so only pre-invalidation is insufficient. Cache maintenance covers whole exclusively owned32-byte lines. Invalidating a line with a dirty unrelated neighbour destroys that neighbour; volatile and a compiler barrier do not repair it. The actual B06 cache-range implementation emits DSB before/after and ISB after maintenance, with the selected privileged M7 cache registers; the M4 adapter has no D-cache and still supplies barriers. This test model is original and explicit, not a cycle-accurate cache emulator.

Changed condition, withheld at least7 days: implement H745 `struct pd_notice` and its HSEM1 port. Reserve the first SRAM3 line for B06 peer state, the second for the32-byte notice; payloads start at0x30040040. A trusted cold start, with peer held in reset, DMA idle and all old leases invalidated, initializes one fresh nonzero epoch. `pd_h745_notice_cold_start` is never timeout recovery. Bring the B06 startup/MPU/clock configuration and merge the64-byte NOLOAD reservation into both link maps before board execution. Neither this function nor the audit image initializes clocks/MPU or boots the second CPU.

The producer publishes one finalized extent and becomes a payload lender again. READY1 -> TAKE/READING2 -> ACKED3. TAKE copies the notice and invalidates payload on a cache-bearing receiver; it does not return ownership. Only a matching epoch/sequence ACK and QUERY success permit reuse. PUBLISH requires increasing sequence and FREE/ACKED; UINT32_MAX retires the mailbox within that epoch. For multi-extent transfers publish/ack each extent serially, retaining every unacknowledged payload; no implicit aggregate notice. Before publication use actual `fw_peer_step(...,FW_BEGIN)` reservation; after ACK/QUERY, END permits peer health confirmation. Missing peer acknowledgement keeps the reservation outstanding and prevents healthy promotion. A reset/epoch transition requires full-system quiescence, not a stale generation comparison alone.

The port takes HSEM1 once using RLR1=0x58026484, COREID3(M7)/1(M4), PROCID0; masks/restores PRIMASK locally, uses barriers, invalidates metadata before access, cleans it before release through R1=0x58026404. One local serialized caller; no NMI/fault-handler entrants or recursive acquisition. HSEM can report success to a repeated same-core/process entrant, so it does not itself prevent local recursion. A failed lock restores the prior mask and performs no metadata/cache access. Notification is bounded polling: no interrupt delivery, wakeup or latency guarantee is claimed. Receiver scheduling, polling budget, timeout quarantine and watchdog policy are explicit integration responsibilities. No peer may write/retain payload after ACK.

Deliver actual adapter source and cross-core state/lease proof, plus a dirty-neighbour and stale-read counterexample. Inspect generated M7 and M4 objects, cache-provider imports, barriers and linked images. Compare code/local-stack costs under identical contracts, including the software SG CPU gap between extents. Full cache coherency, throughput, interconnect arbitration, interrupt latency and board reset behaviour require the physical protocol, not a passing host model.
