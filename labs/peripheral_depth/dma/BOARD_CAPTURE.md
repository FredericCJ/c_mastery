# Dedicated-board DMA observation protocol

No physical run is claimed. F439 and H745 audit images only link; bring the corresponding T27/B06 boot/clock/MPU image, actual silicon and board revision, isolated power/debugger, and authoritative schematic. No external payload wiring is needed for M2M. Reserve DMA2 stream0 exclusively, exclude concurrent HASH DMA on H745 and retain a reset supervisor independent of the test loop. Do not alter a deployed board or host security configuration.

For H745 reserve SRAM3[0,32) for B06 peer metadata and[32,64) for the notice, with whole-line payloads above64. Verify both link maps and the actual MPU/cache register readback, write-back/write-allocate attributes, no alias, SRAM3 clock allocation, HSEM clock, startup of both cores and initial peer hold. Run cold initialization once with DMA idle and peer held. Record both ELF hashes and debugger/load method; an audit link is not that evidence. Use selected B06 startup configuration rather than inventing another register sequence. Never initialize metadata to recover an unacknowledged transfer.

Use synthetic source bytes `(index*17+3)&255`, destination initial0x5a and32-byte guard lines0xa5. Run full transfers of32,64,256 and4096 bytes; widths1/2/4; then software SG across unequal whole-line extents. Record source/destination addresses and capacities, configured NDTR/CR/FCR, each sampled EN/flags/FIFO/NDTR tuple, and final byte arrays from both CPUs. A sample is an observation at its own ordered read, not an atomic snapshot of all registers. Debugger reads can perturb timing: use a bounded preallocated trace and export only after quiescence.

Request cancellation at several observed progress points and while a FIFO flush is pending. Do not promise a particular cut: record actual remaining count and compare only after EN0/FIFO-empty/TC. Verify unchanged guards, exact guaranteed prefix and retained unwritten tail. If no quiescence arrives within the declared observation budget, retain all buffers, log an inconclusive timeout and let the separate supervisor reset the isolated target. Do not force free or claim an exact partial count from a transfer error. Error-flag injection remains a register-model experiment unless a separate documented safe hardware fault protocol is supplied.

On H745 dirty the CPU source and destination tail before submit; verify DMA sees the source and a cancelled unwritten tail survives. Compare cached and explicitly noncacheable configurations only with corresponding revised MPU/alias proofs. Observe the receiver through publish/take/ack and prove producer refuses reuse before ACK. Hold the receiver after TAKE to demonstrate outstanding peer reservation; release it and verify END permits HEALTHY. Retain cache maintenance/barrier trace and both cores' byte comparisons. These tests cannot directly observe all speculative fills or prove coherency for all interleavings.

Capture `capture_template.json` with raw debugger/trace files and SHA256 identities. Timestamps require a declared counter frequency, wrap strategy and measurement overhead; compare equivalent byte-count and correctness contracts for CPU copy, single DMA and software SG. Report setup/poll/cache/notification cost separately from transfer duration. Repeat after optimization, bank, width or cacheability changes. No universal latency upper bound follows from the largest sample. The checker validates format and the lease ordering for each observed transaction; a reviewer must verify authenticity and interpret hardware limitations.
