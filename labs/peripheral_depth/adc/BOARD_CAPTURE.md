# Dedicated-board acquisition, ramp and comparator protocol

This is an unexecuted physical protocol, not a flashing command. Use only an owned teaching board, synthetic stimuli and isolated low-voltage instruments. Record actual board and silicon markings, schematic revision, instrument models/calibration, source impedances, probe loading, wiring and compiler/image hashes. Stop if any supplied pin is driven by another device, if supply/ground identity is uncertain or if input may exceed the selected part's analog operating range. No network or deployed target is involved.

## F439 acquisition and DAC

For NUCLEO-F439ZI MB1137, use PA0/PA1 only after checking the current board routing. UM1974 Rev11 Table12 connects PA1 to the Ethernet PHY through SB13: isolate that drive before an analog experiment. PA0 requires the CN10/29 routing through SB179 and isolation from the button through SB180. Record the observed bridge positions and continuity; software Ethernet disable alone does not establish isolation. Identify PA4/DAC_OUT1 on the exact schematic/header before connecting it; absence of that identification blocks the physical wiring step, not host analysis. Verify common analog ground and measured VDDA/VREF. Do not perform modifications as part of curriculum authoring.

1. Use the T27 boot/clock/timebase artifact and the actual pu_rates/pt_choose providers. Fix SYS64MHz, APB1/APB2 division2, ADC16MHz, channels0/1, sample84. Log actual RCC/ADC register snapshots and flash prefetch/cache settings from ES0206. Prove the monotonic timebase tick bounds, no half-range ambiguity and exclusive ADC1/common-clock/TIM3 ownership.
2. Initially use a current-limited calibrated DC source at three interior voltages, measuring voltage at the input with a high-impedance meter. Record at least256 samples/level, raw codes, timeout/OVR count and reference before/after. Report mean, distribution and interval estimates without promoting sample count to an accuracy guarantee. Repeat with a declared resistor/capacitor fixture at10k and50k; derive the changed sampling setting before acquisition. Keep all absolute electrical limits and source-loading premises explicit.
3. Stop TIM3; open ADC, sample readiness after enable, wait the prescribed four ticks; admit one batch; then start TIM3 without UG. Observe a spare output trace marking timer/start/service events using an explicitly documented T29 ISR or polling adapter. Compare1ms periods with a deliberately faster bounded sequence and delayed CPU service. Record attempted events, complete output batches, private partial count and OVR/timeout. A missing trigger cannot be reconstructed from EOC alone. Contain every terminal path by stopping TIM3 and ADC before output reuse.
4. Configure buffered DAC1/PA4; write initial512 and trigger once. Timestamp after enable/write; allow at least11 quantized1us ticks for startup. For each of17 ramp points512..3584, write/trigger and allow at least7 such ticks before an independent sample. These waits cover the documented10us/6us maxima only under their supply, temperature, load and step-definition premises. Use a meter/scope independently: DOR is only digital readback. A DAC-to-ADC loopback shares reference errors and is not independent calibration. Measure source and reference separately; retain results with endpoint range and uncertainty, not a claimed universal12-bit settling bound.
5. Fit two-point engineering correction from independent known voltages; withhold a third level and compare corrected residual against quantization/reference/source/nonlinearity/measurement contributions. Never combine total-unadjusted-error with its components twice. Diagnose whether increased sampling, filtering or a better reference addresses the actual error.

## G474 changed-condition comparator

Use dedicated NUCLEO-G474RE MB1367: PA1 positive on CN8/2 (CN7/30 alternative), PA0 negative on CN8/1 (CN7/28), and identified analog ground. Disconnect conflicting shields. Measure a1650mV threshold source and its uncertainty; apply only an interior positive-input ramp under the datasheet range. Record silicon revision Z/Y/X from marking/debug identity; ES0430 changes Z/Y offset to−20..+3mV. Configure COMP1 external inputs, HYST3, no polarity/blanking/scaler/lock; first poll after enabling starts the six-tick stabilization wait.

Sweep slowly up and down and record each last-old/first-new level bracket at least16 times. Report rising/falling brackets and width, probe/source uncertainty, and metastable/noisy repeats. A nominal hysteresis label is not an exact threshold. Separately apply the datasheet's fast-step/overdrive/load conditions if claiming its31ns propagation bound; the slow-ramp experiment cannot borrow that bound. To timestamp, capture two adjacent polls with calibrated tick duration and a bounded service-jitter premise, then apply analog_analysis.timestamp_interval. Supply a pulse entirely between polls as the missed-event counterexample; hardware capture would require a separately implemented route and contract.

## Capture and acceptance

Copy capture_template.json, retain nulls until observed, and preserve raw CSV/logic/waveform files with hashes. Run `python labs/peripheral_depth/adc/board_capture.py <capture.json>`. The checker rejects missing premises and malformed/out-of-range observations; it does not authenticate provenance or judge analog accuracy. A passing schema is not a physical observation by the author. Physical pass requires independent source identification, actual register/trigger traces, complete outputs or explicit loss, justified error bounds, predicted versus observed settling, both hysteresis directions, and a reviewer checking the raw artifacts. A numerical disagreement is a finding to explain, not a value to edit away.
