## Mechanism and guided derivation

An ADC conversion produces a code for a sampled analog state. Its sampling capacitor must settle; its reference and transfer function introduce distinct uncertainty. A 12-bit result does not establish 12-bit absolute accuracy. Derive the ordinary fixture: 84 sampling cycles plus12 successive-approximation cycles is96 cycles; at16MHz this is6us. This excludes power-up stabilization, external trigger latency and any source settling before/during acquisition. RM0090 Rev21 pp393–403 and Figure45 p395 separate these phases. DS9484 Rev14 Table75 specifies stabilization up to3us and regular external-trigger latency up to2 ADC periods plus1 APB2 period under its stated conditions. With ADC16MHz/APB2 32MHz, that added latency is156.25ns. Neither number bounds interrupt service time.

Use actual `pu_rates`, then choose the first divisor in2/4/6/8 producing an integral ADC clock in0.6..16MHz. This bounded profile fits the selected supply range but does not configure flash/voltage/PLL itself. `pu_rates` also checks APB1: a nominally acceptable ADC rate must not hide an illegal whole clock tree. Sample selections are3,15,28,56,84,112,144,480. `pa_timing` reports channel-count times(sample+12), and a ceiling microsecond duration; the duration is a model value, not a deadline that hardware must meet.

## Representation, lifetime and operations

Zero-initialize PaAdc once per external lifetime. Never reuse its storage while an old token or borrower remains. The descriptor holds its clock generation, monotonically increasing32-bit token, phase, two private sample slots and borrowed output. Token UINT32_MAX may complete, then the object retires; resetting the counter while old identities exist is forbidden. One owner serializes every call, including an ISR, and exclusively owns ADC1 and the common ADC clock. ADC2/3 and injected conversions are disabled in this exercise. Callbacks are bounded and non-reentrant. ISO C provides none of this ownership enforcement.

`pa_open` accepts one channel(PA0/ADC1_IN0) or an ordered two-channel sequence(PA0,PA1), right-aligned12-bit data, PIO transfer and either software or TIM3_TRGO rising-edge triggering. It first stops conversion by ADON0, configures sample/sequence while stopped, sets EOCS1 and ADON1. The sequence must not be edited in flight: ES0206 §2.5.1 contradicts a casual assumption that a software-triggered sequence will automatically restart after an edit. EOCS1 enables overrun detection; ADC_SR is rc_w0, unlike DAC_SR's DMA-underrun rc_w1.

The first `pa_ready` call timestamps **after** `pa_open` returns. Only subsequent calls may establish readiness. Four ticks cover the ADC's3us requirement if each tick is at least1us and timestamp quantization is below one tick. The timebase owner must prove these premises; a fast or uncalibrated counter cannot borrow this guarantee. Capturing the start timestamp before the register writes would be unsound. All modulo32 observation deltas and budgets are positive/bounded below2^31. `pa_begin` requires readiness, matching clock generation, fresh nonzero token, live output capacity for the configured channel count and a budget. It clears old status and arms the selected trigger. The output remains borrowed until terminal return.

`pa_step` reads at most one result. It checks OVR before DR and again afterward: a completion between the first status read and data read can destroy channel identity. An overrun rejects the whole sequence. Partial private samples remain diagnostic data but never publish as a complete batch. Timeout/cancel power down the ADC and preserve caller output; success publishes the complete ordered batch and also powers down. Stop the timer trigger source before reopening, then repeat stabilization. There is no DMA buffer or hidden outstanding transfer in this PIO contract. A completed batch is not a count of all timer triggers.

`pa_f439_timer` with enabled0 resets/configures exclusively owned TIM3, removing inherited slave-mode/interrupt/output state, then, creates the preload update while TRGO is disabled, clears status and selects update as TRGO. Enabled1 checks the stored PSC/ARR and starts without another UG; generating UG after ADC admission would create an unintended trigger. Import the actual `pt_choose` artifact to derive the period. The provided model uses64MHz timer input, PSC63/ARR999 for1ms. Timer3 is an exclusive resource; the earlier PWM exercise cannot own it simultaneously.

## Changed acquisition and diagnosis

Derive the two-channel timer-triggered sequence before coding it. Compare trigger attempts, admitted conversions, EOC events, DR reads and published batches. The original event model orders trigger, completion, CPU service and explicitly ignores triggers while busy. It is a declared teaching model, not an asserted cycle-accurate STM32 implementation. At6us/channel, a sequence started at5 finishes channels at11 and17. Triggers every4us and polling every1us produce four attempts but one retained sequence; polling first at30 encounters overrun and must publish nothing. Polling every13us can retain both samples while a later trigger has already started an unwanted sequence; final ADON0 contains it. The hardware experiment must correlate a timer trace and result/service traces, including missed/overrun cases, without claiming an exact missed-trigger counter from EOC alone.

Diagnose seven compiled flaws: omit conversion cycles, bypass stabilization, ignore overrun, omit the second status check, publish partial output, truncate two-point correction and erase hysteresis memory. Diagnose four F439 mapping/configuration faults and two G474 comparator faults. A wrong implementation must compile and then fail for its violated property; a translation failure is not a semantic kill.

## Analog analysis and correction

For the explicitly synthetic full-scale RC step, residual error is exp(−t/RC). Requiring at most fraction q of an LSB at N bits gives t≥RC ln(2^N/q). With N12,q1/4,C10pF,f16MHz and R10kΩ, the minimum is16 cycles and the first available setting is28. R50kΩ needs78 cycles(setting84); including an additional6kΩ switch model needs87(setting112). R1MΩ needs1553 cycles, beyond480: reject that setup or change the front-end/clock. Do not clamp to480 and claim it settles. The10pF model is an explicit combined assumption, not the device's internal capacitor specification. The datasheet separately supplies RADC/CADC and input-impedance constraints.

Submit separate quantization, source, reference, settling, offset, gain, nonlinearity and measurement columns. Identify correlated/overlapping terms: total-unadjusted-error and its component offset/gain bounds must not be added twice. Increasing sample time addresses settling, not a drifting reference. Averaging uncorrelated noise does not remove deterministic gain/offset. ES0206 §2.2.8 identifies internal ADC noise; record the prescribed flash prefetch/cache configuration and investigate filtering under the actual workload rather than claiming that the ideal code distribution proves accuracy.

`pa_calibrate` implements a two-point engineering correction using two distinct ordered codes and millivolts, bounded to12-bit codes and0..3600mV calibration points. Derive gain/intercept; signed32-bit products remain within14,742,000. Round the delta to nearest millivolt, halves away from zero; explicitly allow extrapolated negative/out-of-supply estimates and report them as such. Two calibration points do not remove nonlinearity, source/reference drift or measurement error. This software operation is not an invented F439 ADC self-calibration register. The documented temperature and VREFINT factory calibration addresses apply to their own quantities.

## DAC and comparator transfer

The exact F439ZI package has DAC_OUT1 on PA4. DAC1 and DAC2 configuration must be exclusively owned: this adapter writes the shared DAC_CR. The original ramp512..3584 avoids the buffered rail limits at the selected3.3V bench. Configure analog pin, buffered12-bit right-aligned DAC1 and software trigger. DHR is writable; DOR is read-only. The software trigger transfers DHR to DOR in **one** APB1 cycle(RM pp449–451), unlike the generic three-cycle hardware-trigger path. DOR readback is digital evidence, not analog settling. Honor startup up to10us and the stated6us settling/load conditions before an independent observation. Table86's settling definition is not a universal quarter-LSB guarantee for arbitrary12-bit steps.

F439's analog watchdog is conversion-dependent; it is not a dedicated asynchronous comparator. Retarget the unchanged delayed objective to verified NUCLEO-G474RE: external PA1 positive/PA0 negative inputs, COMP1, no blanking/polarity/scaler, HYST code0..7. The source-inspected official device and LL headers establish selected addresses/fields and IO routing; they are not linked. `struct pa_comparator` timestamps its first poll after enable, waits six ticks under the same timebase premise to cover5us startup, then returns VALUE. It refuses an already enabled or locked comparator and does not set LOCK. ISO C cannot make MMIO reads physical measurements.

For HYST3 the datasheet gives11..47mV, typical27mV; the LL symbolic name “30mV” is not an exact threshold. DS12288 offset−9..+3mV changes to−20..+3mV for affected Z/Y silicon under ES0430. Inspect revision markings/ID. Derive a conservative threshold enclosure and then measure rising/falling transitions separately; do not infer their precise placement from a nominal hysteresis name. Polling can miss narrow pulses. A timestamp bracket needs quantization, service jitter and propagation premises; the31ns bound applies to the specified fast step/overdrive/load, not an arbitrary slow ramp.
