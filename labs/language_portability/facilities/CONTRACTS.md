## Representation and operations

Complete facilities.c against facilities.h. All pointer outputs must be live, correctly typed and exclusively writable; no pointer is retained. Null outputs reject. Each refusal preserves the entire old output. No dynamic allocation, callbacks, library arithmetic or implicit helper is permitted in the baseline. `lf_add` computes the mathematical sum of two int32_t values, accepting exactly representable results. `lf_mixed` changes the problem to int32_t plus uint32_t with uint16_t result; usual C unsigned conversion is not the mathematical specification. Handle INT32_MIN magnitude without negating it directly and preflight the final result range. Do not silently change the result type to make a failure disappear.

`lf_bits` returns leading/trailing zeros and bit width for uint32_t. For zero both counts are32 and width0. For nonzero the trailing count is the index of its lowest set bit; width is its highest set index plus1. Baseline loops operate only on unsigned values and never shift by the type width. `lf_div` accepts every uint64_t numerator and nonzero divisor, returning floor division; zero divisor rejects unchanged. Derive a64-step restoring division with a separate high carry before the remainder shift, so the mathematical intermediate may be65 bits without an overflowing signed type. Both baseline and enhanced variants must preserve this identical observable contract.

`lf_select` accepts observation masks0..31 and strict flag0/1. Bits1,2,4,8 represent language/header/link/run observations; bit16 means no implicit helper was found in the selected emitted closure. Enhanced is selected only when all first four bits are observed, and in strict mode also bit16. Invalid metadata rejects unchanged. An edition macro contributes only to the language observation; it cannot supply missing headers, helper definitions or an execution result.

## Deliverables, pass criteria and rubric

D1: source/edition/capability ledger with actual commands and exact stage results. D2: first-principles core and proof of every intermediate, output-publication point and64-step division invariant. D3: independent arithmetic oracle, raw compiler diagnostics, mutations, binary-resource before/after hashes, linked-dependency and target maps. D4: each six changed-condition variants with explicit changed premises and no copied assessor solution.

Six C17 compiler/optimization/sanitizer profiles must pass the named anchors and oracle; the compiling learner stub must fail each anchor. Five compiled controls alter overflow publication, mixed-result range, zero trailing-count semantics, zero-divisor output and language-only capability selection; each must fail its intended assertion normally, not through undefined execution. The enhanced C23 implementation uses the same oracle and tests. Pass requires the argument as well as these finite results.

Score0: missing artifact or wrong boundary. Score1: ordinary examples pass without source/layer/overflow justification. Score2: exact ordinary contracts, independent corpus and all failure controls pass with defensible cost and ownership analysis. Score3: independently reproduces the six delayed changes and diagnoses an unfamiliar layer failure without confusing compilation with execution or emulation with physical validation. Hints progress from checking destination range, to staging a temporary, to retaining a65th remainder bit, to separating capability columns. Assessor solutions remain private.
