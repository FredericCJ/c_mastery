## Representation, operations and failure

LwObservation contains separate left/right counters, sink-call count, result value and32-byte text. Each public function accepts a scenario number and live disjoint output. Valid scenarios are trace0..5, minimum0..3 and statement0..5. Invalid numbers or null output return-1 and leave a nonnull output byte-for-byte unchanged. A valid operation computes in a local observation and publishes once; a formatting failure also refuses publication. There is no retained borrowed storage or dynamic ownership. Component control storage/work is constant apart from the stated formatting-provider cost; no application allocation is requested. The provider's internal allocation behavior is not inferred from that count.

The trace cases are empty format, one value, two values, explicit zero-payload literal form, named-format nonempty payload and compile-time-disabled tracing. Separate functions return3/7 while incrementing distinct counters. Argument evaluation order is not specified or tested. The same scalar is never incremented twice unsequenced. Enabled wrappers call the sink once; disabled wrappers evaluate no argument and produce no sink call. All actual format strings and promoted argument types are fixed and valid; this is not an untrusted format API. The literal-only alternate forwards through %s so percent characters in a message would not become conversion directives.

The minimum cases deliberately retain two original flawed macros as defined counterexamples, then implement an int inline function and a Box-valued generic facade selecting typed function designators. The generic controlling expression is unevaluated; each actual function argument is evaluated once. No claim that inline forces machine-code inlining or that this facade supports arbitrary compatible-looking structures is permitted.

The statement cases show a two-operation do-while wrapper in both if branches, continue/break confined to the wrapper's own loop, a defined inner-temporary collision, and two typed setter calls in one block. The collision initializes its inner variable before use; it does not read an indeterminate self-initialized temporary. The repair uses typed functions instead of promising globally hygienic macro temporaries.
