## Representation, operations and failure

`struct at_pool` owns an actual64-slot `algo_avl`, a64-entry free-slot stack, per-slot observation generations and allocation-mode selection. Call `at_init`, then use one allocation mode for that lifetime:0 retains the actual linear scan,1 changes only allocation/release to the free list. The first successful insertion selects the mode; later mode mismatch is rejected unchanged. A successful deletion advances the released slot's unsigned observation counter. Those counters are not unforgeable handles, cannot promise uniqueness after wrap, and are used only in bounded immediate certificates. A slot ID identifies storage, not a permanent key: the original two-child deletion copies the successor key into an existing slot. Tree, work and certificate objects must be live, aligned and disjoint; caller synchronization and lifetime remain mandatory.

`at_insert` returns explicit `AT_DUPLICATE` without changing the tree/free-list/generation state when the key already exists. The original baseline remains a successful no-op. Under serialization the adapter checks then invokes the actual insertion; no algorithm is silently rewritten. Work counters may be published even when a duplicate/full/missing operation leaves the tree unchanged. `at_delete` preserves the original missing status. `at_contains` returns0/1, or−1 for invalid/mismatched mode. Observation bindings are serialized global instrumentation context and cannot be nested or called concurrently without the supplied common mutex; this limitation applies across distinct trees too. No callback/nonlocal exit is permitted while bound.

`at_certificate` copies all actual64-slot child indices, keys, live bits and cached heights and derives parents from those links. `at_cd_certificate` copies actual32-slot parent links as well. Never call these against concurrently mutating or deliberately corrupted live objects. Corruption testing applies to the separate copied certificate. `at_check(c,policy,height)` checks bounds before indexing, unique reachability, every live slot reached exactly once, strict key order across whole subtrees, root/child parents and count. Policy0 checks cached heights but permits imbalance,1 additionally checks AVL balance,2 checks color/root/black-path properties instead of treating AVL cached heights as evidence. On rejection the height output is unchanged. Null children have AVL height0 and black certificate sentinel contribution1; only equality of black counts is used, not a claim that this convention equals every textbook black-height definition.

## Limits and containment

All states, thread events and images are original local synthetic teaching programs. Forged pointers and live-memory corruption are excluded; malicious graph certificates are copied index records checked before dereference. Emulator results are functional, not physical timing. Finite sanitizer, mutation and certificate checks cannot establish absolute correctness, external review or learner mastery. Separate source-bound report dimensions record author implementation/execution, outside review, learner assessment and physical observation. Remaining T36/T37 work is not closed by this package.
