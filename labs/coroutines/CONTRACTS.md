# Coroutine and continuation contracts

Portable kernels use ISO C17 with -Wall -Wextra -Wpedantic -Werror. Public N1570 is inspected as a C11 draft; exact published C17 remains an access gap. ISO C supplies calls, structs, switch and arithmetic, not suspension, stack switching, closure capture, automatic cleanup or move-only values. C23 comparison probes are syntax-only and do not change this baseline. All controls are initialized fresh, live and exclusively serialized; callbacks do not reenter, retain temporary loans, mutate controls or escape by longjmp. Inputs, output objects and controls are disjoint unless the API explicitly consumes a pointer-to-owned-object. Borrowed arrays remain unchanged and live throughout use. Output canaries apply on errors except explicit progress counters, memo workspaces and side effects listed below. Undefined-lifetime counterexamples are analyzed rather than executed as evidence.

## Pull and dataflow

CORange is half-open [current,end), step>0, end<=65536, current<=end. A next call returns current then advances without overflow; exhaustion returns DONE and leaves payload unchanged. COFlow lazily filters evens, squares them and takes remaining outputs. Zero remaining must not pull the source. pulls counts attempted next calls, including an exhaustion observation; it is bounded descriptive accounting, not an ownership generation. Internal co_fold calls a typed callback once per consumed output:0 continues,1 breaks, another result returns IO. The triggering item is consumed; after break the external iterator resumes at the following item. Callback effects before an error are not rolled back.

COQuery opens an immutable array of at most64 CORow values and provides open/next/close. Consecutive equal keys form a group; filter out negative values, then checked-sum remaining int32 nonnegative values into uint32. Groups with no survivors are skipped. Each successful pull publishes one key/sum and advances just past that group; it must not consume later output groups. Overflow returns RANGE with index and outputs unchanged, including previously skipped empty groups in that pull. Exhaustion advances to count and leaves outputs unchanged. Close drops the borrowed pointer and is idempotent. Next after close returns STATE. This anchor is the fused scan/filter/group pipeline. The required unfused Volcano operators and bounded push alternative preserve exactly these filtering, ordering, failure and consumption contracts; a faster different contract is not an equivalent optimization.

## Allocated generator and explicit trampoline

co_generator_create allocates one suitably aligned COGenerator through caller callbacks. count0..47 yields F0 through F(count-1), with F0=0,F1=1; F46 fits uint32. Allocation failure returns RANGE and leaves the output pointer unchanged. Only the generator owns this frame; callers borrow it for next. DONE is repeatable with unchanged output. Destroy takes a pointer to that sole owning pointer, clears it, and invokes the saved allocator's release once; destroy of a null owned pointer is idempotent. Copies of the owning pointer are forbidden by contract, not by C. The allocator must return one fresh correctly aligned block or NULL with no retained partial allocation. A release callback cannot access the frame afterward.

COTrampoline represents factorial0..12 using a12-entry explicit continuation stack. Init sets accumulator1. In phase0 each step pushes the current multiplier and decrements n; the base step enters phase1. Each phase1 step pops and multiplies; an additional step with empty stack publishes the result and enters phase2. Thus factorial6 takes14 steps. Zero budget makes no progress and returns PENDING. Partial progress is stored in the frame; payload output changes only on the transition to DONE. DONE is stable. Cancel drops continuations and enters phase3, whose step returns STATE. There are no captured owned resources in this anchor; the transfer version introduces destructors and must define abort unwinding explicitly.

## Parser combinators and memoization

COParser is an immutable DAG of1..16 nodes, root0, children at strictly larger indices. Kinds are literal, sequence, ordered choice, many and empty. Literals consume one matching octet; sequence rolls back the cursor if either child fails; ordered choice tries the right branch at the original cursor only when the left returns NO_MATCH. RANGE or invalid structure is not an alternative mismatch. Many greedily consumes matches and succeeds when its child mismatches; a successful zero-length child returns STATE to reject nonprogress. The buffer may be NULL only for length0; no NULL arithmetic is allowed. Start<=length. A caller budget bounds node visits; steps always reports actual visits after structural admission, while end changes only on success. Fixed-depth recursion<=16 is admitted. General recursive grammars and precedence parsing are separate mechanisms.

Packrat uses S <- 'a' S 'b' / 'a' S 'c' / 'x', length<=64, and a caller-owned COMemo array with capacity>=length+1. It memoizes both success/end and failure per position, resets the table each parse, and accepts only when the root consumes the whole input. Each S-position is evaluated at most once. calls is an observable work counter even on mismatch; end remains unchanged unless full success. Cache cells and input stay live and immutable in meaning throughout the parse. A changed grammar, input revision or semantic environment cannot reuse old cells. This grammar has no left recursion; adding it requires cycle handling rather than assuming memoization alone guarantees termination. The reference counter is algorithmic work, not elapsed time or a universal linear-time proof for arbitrary semantic actions.

## Readiness frame

COAsync reads exactly wanted1..8 octets into its own frame, using a nonzero externally allocated generation. The read callback receives only remaining writable space and returns DATA/AGAIN/EOF/ERROR plus count. Count cannot exceed offered capacity; AGAIN must have count0. Other statuses may report partial progress; bytes written before an ERROR remain recorded but no final output is published. The callback itself must respect the provided memory bound; checking its returned count cannot repair an earlier overrun. Poll makes at most two reads: after the first incomplete result it registers readiness and rechecks immediately, closing the lost-wakeup window. A repeated readiness hint is not proof of data; the second read may still return AGAIN. Active registration remains until completion, failure or cancellation. arm failure is failure-atomic and leaves no registration. disarm must synchronously quiesce all callbacks and queued notifications for that generation before it returns. No callback is permitted during a poll/cancel operation in this serialized adapter model. Async notifications reject stale generations and terminal frames; ready is only a scheduling hint. A completed poll returns DONE idempotently without republishing the payload. EOF before wanted returns NO_MATCH; ERROR returns IO. Cancellation disarms then marks cancelled; polling a cancelled/error frame returns STATE. The caller must not recycle a generation while any external stale reference can be presented.

The final adapter maps learner-owned io.reactor, io.deadline and io.stream operations to this port, with explicit registration lifetime and partial-I/O conversion. Parser adapters map bytes.cursor and parser.integer without copying their assessor implementations. Supply ADAPTERS.md with producer hashes, impedance mismatches and actual import-consumption checks. Fake ports establish state-machine behavior only; real pipe/reactor composition is an additional required deliverable, not already validated by these tests.

## Resumable effect

A fresh COEffect represents two sequential questions followed by checked addition. Start emits question1 with a continuation identifying owner address and generation1. Resume consumes the matching token exactly once; the first answer is stored and produces question2 at a new generation. The second answer produces DONE and the sum. Overflow leaves token, frame and output unchanged, so the handler can choose a different answer or abort. Abort consumes a matching live token and enters terminal state. Stale copies reject while the frame remains live; C does not prevent copying tokens, dangling pointers or reinitialization ABA. No frame may be reused until all tokens have been discarded. This is a manually defunctionalized single-shot algebraic-effect subset, not arbitrary native-stack capture, automatic effect typing, multi-shot continuation copying or Koka equivalence.

## Actual stackful fiber

fiber.h and the assembly implement Linux x86-64 System V ABI, with compiler extension __asm__ and GCC/Clang sanitizer hooks. They are not portable ISO C and are excluded from Cortex-M4 builds. One fresh COFiber owns no allocation but borrows a distinct16-byte-aligned stack object of at least65536 bytes and a persistent callback/context. Its address and stack cannot move. Same OS thread only; no signal-handler switching, foreign unwinding, async cancellation, stack overflow recovery, thread-local isolation, CET shadow-stack support or arbitrary context migration is claimed. The build's -fcf-protection=none is a binary toolchain choice; no host security setting is changed. Inspect ELF notes before claiming compatibility with a particular execution environment.

States are fresh0, suspended1, running2, completed3, destroyed4. Resume accepts fresh/suspended only; callback return completes. Yield accepts the currently running fiber and preserves its stack locals. Destroy accepts fresh/completed only; suspended destruction rejects because automatic locals may still own resources. A later changed-contract cancellation design must execute cooperative cleanup before destruction. Save/restore RSP, RBX, RBP, R12–R15 and floating-point control; stack-entry alignment follows SysV, including its red-zone convention. Caller-saved registers are not a general CPU snapshot. ASan start/finish hooks bracket switches and destroy the final fake stack; TSan switches logical fiber contexts and destroys their detector objects after completion. These annotations enable the detector model but do not prove correctness of uninstrumented assembly. Tests separately observe architectural RSP and preserved locals because ASan can relocate a local to a fake stack.

## Assessment, costs and security

D1–D4 and the shared13-dimension COST_REVIEW are required. Compare fused/unfused consumption, owned/caller-provided frame allocation, parser memo storage, context size, instructions, indirect calls, stack use and cleanup under equal contracts. Python and libc allocation in the host harness are not target dependencies. Two semantic mutants per public anchor must fail specific assertions; compiler failure alone does not count as a killed semantic mutant. Reproduce independent expected values and disclose limited model sizes. No source-bound author campaign claims independent learner assessment, physical timing or absolute mastery.

All adversarial inputs target only these original local parsers, frames and synthetic callbacks. An attacker may choose byte strings, stale tokens and scripted readiness timing within the stated live-object assumptions. Harmless success is a duplicated continuation result, premature frame destruction, lost progress or incorrect parse acceptance recorded by the harness. Compare repaired traces and residual lifetime/ABI assumptions. Crashes, sanitizer reports and undefined behavior are not called arbitrary execution or privilege escalation. Kernel/board work requires separately isolated environments and is not performed by this family.
