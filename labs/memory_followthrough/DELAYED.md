# Independent delayed assessment

After at least seven days, an assessor selects the original changed condition
from `criteria.json` and supplies unseen capacities, failure stages, callback
order, generation limits, tree shape, or target premises. Freeze the learner's
prediction before any run. Require the exact original identifier, a causal
argument, the changed implementation or explicit premise derivation, and source-
bound raw evidence. Hide assessor sources and prior answers. Record elapsed time,
assistance, and the independent observer. Author tests in this repository do not
claim that this assessment occurred. Physical observations require their own
board, firmware, manual revision, probe, and reproducible measurement record.
