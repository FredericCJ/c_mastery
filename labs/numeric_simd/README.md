# Numerical contracts and SIMD from first principles laboratory

Hosted C17 with int16_t, int64_t and binary64 double verified by the experiment. fabs, fmax, sqrt and isfinite are permitted primitives; no reduction, matrix or SIMD library may implement the assigned mechanism. Explicit GCC vectors are a separately named compiler extension.

Portable core controls are independent of required guest/board observations. Ordinary init copies compiling learner stubs, tests and contracts. Explicit `-DCMASTERY_ASSESSOR_ROOT=/absolute/repository/assessor` selects reference sources; never use that flag for learner evidence.

Required extension evidence includes scalar versus explicit-vector differential tests, emitted assembly and target feature checks, fast-math counterexamples, reproducible resource/timing experiments and changed-size/data-layout transfer. Portable core tests alone do not establish SIMD execution or a performance advantage.
