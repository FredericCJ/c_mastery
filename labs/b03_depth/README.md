# B03 depth laboratory

Five required exercise adapters cover persistent short-write progress, finite cancellation identities, two-way SPSC publication, invented W1C/consuming-read semantics and bounded modular time. CONTRACTS.md defines the complete synthetic protocols and separates them from OS and board behavior.

Default CMake builds learner stubs. CTest anchors fail through B03_ASSERT until implemented. Assessor mode adds five compiled mutation controls and a separate actual two-thread smoke test. The memory-order mutant is detected by the source-coupled conservative order policy check; it is not presented as a weak-memory outcome. Exhaustive deadline checks use an unwrapped mathematical interval as their oracle.

Do not flash a board, modify security settings or contact network targets. No physical timing, kernel cancellation or peripheral contract is inferred from host models. Canonical exercise rubrics require separate reasoning, independently designed cases and delayed variants. Historical acceptance records remain unchanged.
