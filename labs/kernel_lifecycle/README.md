# Linux kernel programming and lifetime boundaries laboratory

Portable model: C17 hosted, serialized event driver. Kernel adapter: Linux kernel GNU C dialect and matched headers, separate Kbuild, disposable VM only. No workstation module insertion is authorized.

Portable core controls are independent of required guest/board observations. Ordinary init copies compiling learner stubs, tests and contracts. Explicit `-DCMASTERY_ASSESSOR_ROOT=/absolute/repository/assessor` selects reference sources; never use that flag for learner evidence.

Actual guest module build/load/unload, concurrent open/remove traces, allocation-fault injection and lockdep/KASAN observations remain mandatory target evidence; host model tests do not satisfy them.
