# A C-subset compiler with original x86-64 and Thumb backends laboratory

Compiler implementation C17 hosted with bounded caller storage. Generated x86-64 SysV and Thumb AAPCS32 integer leaf functions have no runtime dependencies; assembler/linker are tools, not compiler-mechanism libraries.

Portable core controls are independent of required guest/board observations. Ordinary init copies compiling learner stubs, tests and contracts. Explicit `-DCMASTERY_ASSESSOR_ROOT=/absolute/repository/assessor` selects reference sources; never use that flag for learner evidence.

Execute emitted x86-64 code against an independently compiled C oracle, execute Thumb output in a dedicated emulator, and complete changed-condition extensions. Public IR anchors do not certify a general C compiler.

See the canonical project briefs and `CONTRACTS.md`.
