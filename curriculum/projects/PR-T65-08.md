# PR-T65-08: Contract off, observe and enforce modes with safe violation traces

## Contract

Implement er_contract_counter on a caller-owned counter in0–100 and amount in-100–100. The candidate counter+amount is safely representable on every supported C int. The contract predicate is that the candidate remains0–100. `OFF` clamps and commits without reporting; `OBSERVE` increments reports on a violation, then clamps and commits; `ENFORCE` increments reports and returns ER_CONTRACT with counter unchanged. On report-count exhaustion return ER_RANGE before changing either object. Invalid mode, null objects or out-of-domain initial inputs return ER_INVALID unchanged. This is an original local state-integrity experiment, not a general safe unchecked-call API.

The full required exercise is {ref}`X-T65-008`. Its explicit shared contract, four deliverables, objective rubric, source inspections and delayed variant are part of this project. Eight hours is descriptive author accounting, not a study deadline or scope ceiling.

## Inputs and expected results

Starting counter90/reports0, adding20 in `ENFORCE` returns `CONTRACT`,90,1; `OBSERVE` then produces OK,100,2; `OFF` adds no report. With reports=SIZE_MAX an observed violation rejects without wraparound.
