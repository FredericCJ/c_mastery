# PR-T46-06: Conditionals, mutation and bounded loops

## Contract

Every expression leaves one value. An if consumes a Boolean condition and leaves exactly the chosen arm value; its two joins must agree. set updates an existing local and leaves the assigned value. do evaluates and discards its first expression before returning its second. while repeatedly checks a Boolean condition, discards each body value and returns nil when false. Emitted branch offsets are absolute offsets into the code region. These policies make stack equations simple enough to prove. A source loop is not trusted to terminate merely because it was compiled. Implement the minimal per-dispatch fuel stop here so an infinite guest loop has a finite test; checkpoint 09 later compares all three independent budgets.
