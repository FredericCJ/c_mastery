# PR-T66-07: Copy-on-write values with transactional detach

## Contract

Implement OwCow over caller-owned live controls and int32_t arrays acquired through V4Allocator. Clone increments a nonzero reference count with overflow refusal. A write to a unique owner changes its element in place without allocation. A shared write requires a distinct empty fresh control: allocate the same length, copy all elements locally, apply the update, initialize the fresh control, decrement old references and publish the caller owner pointer. A failed allocation or invalid index/control leaves all old owners, counts, values and fresh output unchanged. Drop releases backing storage only on the last reference; the caller controls metadata lifetime.

The full required exercise {ref}`X-T66-007`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Two references to[1,2,3], write index1=9, fail-at2: `NOMEM` and both logical values remain[1,2,3]. Retry succeeds with old[1,2,3], new[1,9,3], one reference each and two buffers. Dropping both releases both buffers. A unique write must leave allocator attempts unchanged.

## Steps

- **T66.07:** Implement reference sharing, failure-preserving detach, unique mutation and last-owner release with explicit control-block and mutable-borrow lifetimes. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Compare every owner value to independently copied Python lists across clone/write/drop traces, inject allocation failure at each detach, test index bounds and reference overflow, and count allocations/copies for unique versus shared mutation. Reject a mutant that writes shared backing in place. Check that a borrowed mutable alias cannot legally survive cloning.

## Acceptance and evidence

- **T66.07:** Explain logical value independence, shared representation and detach cost; distinguish copy-on-write from a deep copy guarantee or automatically synchronized shared mutation. Every leaf has a separate rubric criterion in X-T66-007. Public test passage alone does not assess independent understanding.

## Hints and recovery

Allocate and populate the replacement before decrementing the old count. Then Logical independence depends on forbidding mutations through stale private aliases. Record the failed hypothesis before using further hints.

## Transfer challenge

Change the backing value to contain owned resource handles whose copies can fail: derive a partial-clone frontier and rollback. Delayed assessment permits concurrent readers and one writer; define snapshot publication, reference acquisition and reclamation rather than relying on the non-atomic COW counter.
