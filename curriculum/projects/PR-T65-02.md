# PR-T65-02: Single-evaluation propagation and atomic parser publication

## Contract

Implement er_parse_pair over a borrowed byte sequence of known length, not a NUL-terminated string. Grammar is one or more ASCII decimal digits, colon, one or more digits, and exact end. Each field and their sum must be at most 65535. Leading zeros are permitted; signs and whitespace are not. On malformed input return ER_INVALID with the first offending byte offset; a missing digit or delimiter at end reports length. On an overflowing field return ER_RANGE at the first digit that exceeds the bound; sum overflow reports length. On failure sum is unchanged. Implement both explicit goto/out-parameter propagation and a C17 do-while macro variant, evaluating each supplied expression once.

The full required exercise is {ref}`X-T65-002`. Its explicit shared contract, four deliverables, objective rubric, source inspections and delayed variant are part of this project. Eight hours is descriptive author accounting, not a study deadline or scope ceiling.

## Inputs and expected results

1:65534 succeeds with 65535. 65536:0 fails `RANGE` at offset4; 1:2x fails `INVALID` at3; 1: fails at2; :1 fails at0. 1:65535 fails `RANGE` at7 and must not publish the first field.

## Steps

- **T65.02:** Implement strict checked accumulation and two single-evaluation propagation forms without statement expressions, strto* or parser libraries. Complete the exercise D1–D4 and preserve prior artifact contracts.

## Failure cases

Explain which failure stage owns the error offset, and why early-return propagation is not transaction rollback or automatic cleanup.
