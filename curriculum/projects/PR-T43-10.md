## Contract

Add a keyed parser and observation dossier for permitted cgroup v2 files around a reused bounded workload. Core route: read the current permitted hierarchy, available controllers and before/after files without configuration writes. If access/controller support is absent, record the actual unavailable interface and complete the captured-data analysis. Optional route: an already prepared delegated subtree may provide an isolated temporal-quota comparison within the same project. No root setup, ancestor policy change or migration outside that subtree is required.

Use 7 hours implementation and 3 verification. Configuration files such as cpu.max, memory.high/max and io.max express policy; accounting files express scoped observations. Record ancestor restrictions, descendants and sibling contamination.

## Inputs and expected results

[The fixture](../../fixtures/performance/PR-T43-10.json) sees 800 µs usage, 400 user and 400 system in a 2000-µs window: aggregate CPU fraction 0.4. cpu.max=500 1000 represents a temporal quota ratio 0.5, not a processor frequency or guaranteed observed fraction. memory.current falls 4096→3072 while read memory.peak is 12288. With no same-FD reset, that peak is historical and fresh-window peak is null. Device 8:0 deltas are 8192 read/8192 written bytes and two read/two write operations. CPU/memory/I/O PSI total deltas 200/50/400 µs must not be summed into exclusive component waiting.

## Steps

1. Discover the permitted mount/path and list available/enabled controllers, delegation permissions and inherited limits. Classify every inspected file as policy, counter, gauge or pressure summary.
2. Parse cpu.stat and io.stat by keys/device identity, not line order. Read before/after with monotonic window timestamps and reject counter resets; allow memory gauge decreases.
3. State whether memory.peak was reset through an authorized open descriptor and then read on that same descriptor. In the read-only route it was not; retain historical peak and uncertainty.
4. Compare unchanged-policy observations. Only in a prepared delegated route change the authorized quota, retain prior values/cleanup, and account for fair-class/burst/window/ancestor limits. Do not migrate processes repeatedly as a measurement substitute.

## Failure cases

A missing controller is unknown/unavailable, not zero use. Counter wrap/reset requires a new baseline. Shared descendants and shared-file writeback can contaminate attribution; filesystem writeback support does not eliminate the shared-inode limitation. memory.high pressure differs from memory.max/OOM and temporary overshoot. A reading of memory.peak after reopening an FD is not automatically the requested isolated window.
