## Inputs and expected results

The bytes `48 3D FF FF FF FF` encode a 64-bit CMP with sign-extended −1 and length 6 bytes. The separate bytes `77 FE` at `0x1006` branch to `0x1006` when CF=0 and ZF=0. Thumb bytes `05 2A` decode CMP r2, #5, T1, 16-bit. First halfword F000 announces 32-bit Thumb. RAX byte/word writes preserve high bits; EAX 89ABCDEF clears them. Base 1000 hex+3*4+8 yields 1014 hex with end 1018 hex.

Include wrong next-instruction branch base, wrong signed rel8 and zero-extending every partial register write. Out-of-scope encodings return unsupported, never guessed fields.

## Hints and recovery

Decode the first-halfword width before advancing. x86 relative targets add displacement to the following instruction. The source locator covers T1 only; do not expand T2 modified immediates from intuition.
