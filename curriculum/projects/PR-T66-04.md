# PR-T66-04: Runtime borrow tracking, range splitting and finite token identities

## Contract

Implement OwBorrows for one declared element extent and four active loan slots. ow_borrow accepts offset,length and writer exactly0/1, validates bounds using subtraction, and rejects overlap whenever at least one overlapping nonempty loan is a writer. Readers may overlap; empty ranges touch no element. A successful acquisition returns slot plus a fresh uint32 serial. Release consumes exactly the matching live token. A slot at maximum serial is retired rather than wrapped. ow_split consumes one live writer and creates adjacent left/right writers covering the same range; invalid length, serial exhaustion or insufficient slots must leave the book and both output tokens unchanged.

The full required exercise {ref}`X-T66-004`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

A writer[0,8) blocks a reader[3,4). Splitting it at3 creates[0,3) and[3,8), invalidates the parent token and admits no gap or overlap. A writer[8,8) may coexist because it touches no element. A released token cannot release a later loan in the same slot.

## Steps

- **T66.04:** Implement bounded acquire/release and transactional writer splitting with arithmetic-safe extent checks, generation retirement and an explicit guard ownership rule. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Use an independent finite-set intersection oracle for all small extents/ranges/read-write combinations, then test SIZE_MAX bounds and UINT32_MAX serial retirement. Exhaust the slot table before split and compare complete pre/post books and output canaries. Kill the conflict-check omission mutant; explain that reduced exhaustive checks do not prove arbitrary C lifetimes.

## Acceptance and evidence

- **T66.04:** Derive reader/writer interval exclusion separately from pointer lifetime, then explain finite identity exhaustion and why a runtime token does not prevent illicit raw aliases. Every leaf has a separate rubric criterion in X-T66-004. Public test passage alone does not assess independent understanding.

## Hints and recovery

Half-open ranges overlap only if both contain an element. Then Simulate the whole split in temporary state before committing either child. Record the failed hypothesis before using further hints.

## Transfer challenge

Change numeric intervals into a strided view: two disjoint bounding intervals are sufficient but not necessary for disjoint element sets. Delayed assessment splits a two-dimensional tile with padding; derive exact touched indices and decide whether a conservative rejection or richer borrow representation is justified.
