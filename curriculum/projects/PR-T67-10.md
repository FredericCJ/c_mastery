# PR-T67-10: Zero-copy packet view with precise error sum

## Contract

Implement ad_packet for [kind:u8,length:u16 big-endian,payload]. Kind1 data accepts any declared payload includingempty;kind2 acknowledgement requireszero. Check header first, then kind, exact extent, then ack constraint. Return distinct ADPacketError values and publish ADPacket only on success; keep payload pointing into stable caller backing. Compose the parser with the retained io.frame/cursor interfaces via a learner adapter and reject fragmentation until a complete frame is available.

The full required exercise {ref}`X-T67-010`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

01 00 02 07 08 yieldskind1,length2,payload=input+3.02 00 00 isvalidack.01 00 01 07 08 islengtherror;02 00 01 07 isackerror;03 00 00 iskinderror.

## Steps

- **T67.10:** Derive a state table for every failure stage and prove length-3 subtraction is reached only after header validation. No struct overlay, unaligned integer load, allocation or payload copy is permitted. Compare C tag/error conventions with census C++ variant/expected/span without treating the example as an authoritative language specification. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.packet and enumerate header/extent/tag combinations against the independent byte parser. Kill trailing-byte acceptance and nonempty-ack acceptance separately. Test all truncations and prior-output preservation, then integrate actual learner io.frame and bytes.cursor artifacts with recorded source identities. Public direct-parser anchors do not establish that integration.

## Acceptance and evidence

- **T67.10:** Port the supplied census packet-view artifact to C while preserving its admitted wire states, error distinctions and borrowed-payload lifetime; identify guarantees supplied by the C API versus the compared language wrappers. Every leaf has a separate rubric criterion in X-T67-010. Public test passage alone does not assess independent understanding.

## Hints and recovery

Write the error precedence before parsing. Then Exact length rejects a suffix that a prefix parser would leave for another protocol. Record the failed hypothesis before using further hints.

## Transfer challenge

Add segmented zero-copy payloads from a receive ring with wraparound and a retained borrow token. Prove storage cannot be recycled while a consumer holds the packet; compare copying and borrowing under equivalent release/cancellation semantics.
