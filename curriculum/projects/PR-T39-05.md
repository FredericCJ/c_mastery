## Steps

2. Implement the validator and dependency checker; distinguish descriptor policy from generic pointer validity.

3. Write the concrete clock/reset/select/base/mode sequence with bounded readiness/error outcomes using the inspected manual.

5. Run the minimal target initialization and preserve descriptor/base/control observations; failure leaves engines stopped and storage CPU-owned.

## Failure cases

CCM/unreachable or crossing region, overflow, local misalignment, omitted dependencies, wrong reset distinction, unavailable PHY result and reset timeout. A hardware barrier does not cure incorrect address reachability. Never continue starting engines after a failed prerequisite.
