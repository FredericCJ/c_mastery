# PR-T67-06: Read-only strided views and ownership boundaries

## Contract

Implement ad_view and ad_view_get for2D uint32 data. Nonempty views require positive strides and required_span=1+(rows-1)*row_stride+(columns-1)*column_stride<=capacity with checked arithmetic. Empty rows or columns permitNULL and zero strides; no access succeeds. Overlapping indices are allowed for this read-only view. Input storage must be live and stable; view fields are not freely forgeable.

The full required exercise {ref}`X-T67-006`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Backing[1,2,99,3,4],shape2x2,strides3/1 yields4 at(1,1) and needs5elements; capacity4fails. Shape0x3 is empty. Strides1/1 admit read-only overlap.

## Steps

- **T67.06:** Prove multiplication and addition guards before computing the last element offset; explain why logical element count need not equal required span. Compare span contiguous access and mdspan layout_stride preconditions. Define when two logical indices alias and why a writable transfer needs stronger validation or an explicit alias contract. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.views; enumerate small shapes/strides/capacities against a Python coordinate-set oracle. Kill row-major-assumption and missing-capacity-admission mutants. Audit zero/SIZE_MAX boundaries and distinguish arithmetic acceptance from existence of a real caller object of that extent.

## Acceptance and evidence

- **T67.06:** Derive required backing extent from shape and strides, including empty shapes and overflow, and distinguish a read-only overlapping view from a mutable injective layout. Every leaf has a separate rubric criterion in X-T67-006. Public test passage alone does not assess independent understanding.

## Hints and recovery

Derive the largest coordinate offset before using rows*columns. Then Zero extents require no last element. Record the failed hypothesis before using further hints.

## Transfer challenge

Implement mutable transpose/submatrix views and a SIMD reduction adapter. Establish injectivity or documented repeated-write semantics, equivalent overflow/alias contracts, and measure scalar/vector behavior only on admitted layouts.
