# PR-T76-01: Positioned event logs and persistent snapshot roots

## Contract

Implement RPLog and rp_log_init/append/get. The original in-memory log contains at most16 events (position1..16,key0..31,int32 value) and17 snapshot roots. Each append first updates the imported persist.hamt arena, then publishes the event and root together. get(position,key) queries the exact retained prefix; position0 is empty. Invalid key/position, log full and injected hash array mapped trie allocation failure preserve published state and output. Replay an admitted prefix into a fresh fixed-address arena; values are latest event payload per key, not accumulated balances. No filesystem durability is implied.

The full required exercise {ref}`X-T76-001`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Append(3,7),append(3,9): prefix1 returns7 and prefix2 returns9. Inject each allocation ordinal1..3 on the next append: count stays2, used count is restored and prior roots still resolve. The17th append returns RP_FULL without consuming nodes.

## Steps

- **T76.01:** Retain the actual PR-T70-07 learner artifact and its64node/3nodes-per-update contract. Prove16 appends use48nodes, every published root remains immutable and an interrupted failed append cannot advance count. Initialization requires no surviving borrowed roots; do not copy/relocate a live arena and interpret roots in another owner. Account for unpublished cells and allocation counters separately from reachable state. State a release/publication order for a future concurrent adapter. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run replicated.log and the three allocation-cut assertions, compare every prefix against an independent key/value dictionary and rebuild into a fresh arena. Reject count-before-commit and latest-root-for-all-snapshots mutants. Inspect source/link dependencies to establish that the real imported hash array mapped trie is used. Separately implement the required codec.records/storage.pages adapter with short writes and process-stop schedules at write, flush and publication boundaries; the memory anchor does not validate that adapter.

## Acceptance and evidence

- **T76.01:** Distinguish immutable event history, a current projection, a retained snapshot root and durable storage. Derive why replay requires event-version and external-query assumptions, not merely a list of bytes. Every leaf has a separate rubric criterion in X-T76-001. Public test passage alone does not assess independent understanding.

## Hints and recovery

Write the invariant linking count, events and roots. Then Inject failure before each of the three path clones. Record the failed hypothesis before using further hints.

## Transfer challenge

Replace the in-memory append with versioned checksummed records on the prior storage.pages artifact; enumerate every tear/flush prefix and recover the longest committed prefix. Persist snapshots with their event position and schema identity. Demonstrate why replaying an external effect twice or using a changed external query result changes semantics; retain original responses as events where required.
