## Contract

Implement a nonprivileged Linux parent and worker with explicit argument vectors, controlled descriptor inheritance and a private test directory. Pass an O_RDONLY descriptor for a disposable log to the worker; reads must succeed and write through that same descriptor must fail with EBADF. Separately deny write-config in the application capability policy. This is a narrow enforced descriptor property: the worker retains its ordinary user filesystem authority and may be able to reopen a path writable by that user.

Use dependency profile A under {ref}`guide-profiles`. Implement the studied mechanism yourself; a mature library may be a separately declared hosted oracle. This 8-hour milestone includes implementation and verification, with reading/assessment budgeted in the module.

## Inputs and expected results

The supplied fixture `fixtures/embedded/PR-T35-02.json` contains concrete inputs and exact expected fields; use the supplied-fixture download below in the local handbook. FDs 0 and 4 lack close-on-exec and are inherited; FD 3 is closed at successful exec. A declared read-log capability allows read-log but denies write-config.

Filter declared close-on-exec flags/capability membership independently. It models policy; actual OS enforcement requires process/descriptor observations.

## Steps

Create disposable files in a private test directory without changing system-wide permissions. Open the log O_RDONLY, arrange only declared descriptors for exec, and report inherited descriptors. In the worker, read the expected log bytes, attempt write on the inherited descriptor and record -1/EBADF plus unchanged file bytes. Run authorized read-log and denied write-config requests and confirm denied requests create no effects. Test exclusive temporary creation and a competing name. Record whether reopening the path is permitted by the current user; explain that CLOEXEC and a private directory do not remove ambient authority. Compare this narrow process boundary with a separately verified MPU design at awareness depth.

First write the public interface, storage/effect limits and expected failure state. Derive at least one supplied value by hand before coding. Implement one normal path, then add each boundary/failure path. Run the independent fixture oracle and your own implementation checks separately; preserve versions, commands, binary identity and raw observations.

## Failure cases

Unexpected inherited descriptors, successful write through the read-only descriptor, denied application requests with effects, stale competing names, partial spawn cleanup and shell interpretation fail the contract. Reopening a writable path is an explicit residual authority, not evidence of isolation failure in a falsely claimed complete sandbox.
