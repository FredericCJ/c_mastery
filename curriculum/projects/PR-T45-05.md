# PR-T45-05: Fixed RAM, startup and collision diagnosis

## Contract

Build an independent aligned interval checker for the synthetic region and reuse the T27 linked-image/startup implementation. Classify fixed section overflow, guard/reservation failure, startup-range error and a stray legal-address logical write separately. .bss is a fixed output interval; it does not grow during allocation. The synthetic custom heap shares the declared region with a descending reserved stack; do not transplant that map to hosted malloc. Validate copy/zero/retained ranges before mutation, and refuse overlap or out-of-region access.

## Inputs and expected results

The 1024-byte region at 0x20000000 contains aligned data 96, bss 400, retained 64. Offsets are [0,96),[96,496),[496,560); stack low is 768. Heap 160 ends 720 and leaves 48, satisfying guard 32; heap 192 ends 752 and leaves 16, failing it. With bss 900, retained storage is aligned to 1000 and fixed placement ends 1064, exceeding the region by 40. A separate 16-byte startup example copies 01020304, zeros [4,12) and preserves [12,16). Wrong bss end 13 first threatens retained byte 12 and is rejected. These are synthetic map/memory inputs, not actual board layout.

The supplied finite fixture is [fixtures/memory_lab/PR-T45-05.json](../../fixtures/memory_lab/PR-T45-05.json). Run `python tools/verify_memory_lab_fixtures.py` from the handbook source root for arithmetic/history/catalog checks. Actual C/tool/hardware evidence remains a separate learner obligation.

## Steps

1. Draw the fixed and reserved intervals, including alignment gaps; derive every supplied endpoint and failure verdict.

2. Implement an independent interval/image checker using offsets and checked integers, not pointer subtraction between unrelated C objects.

3. Modify your qualified linker study in a separate experimental image to exceed a fixed region, retaining map, script and linker error. Restore it and inspect reserved stack/heap assertions and memory-region report.

4. Reuse T27 startup with live bounded buffers in the host model; challenge wrong copy/zero ranges and preserved retained bytes. Actual pre-main target observations remain separately labeled.

5. Exercise an allocator request exceeding the declared shared dynamic boundary; reject before mutation rather than physically colliding with the stack.

6. In a defined reserved logical-cell experiment use an incorrect legal index to change an adjacent logical value. Record corruption, unchanged section size and a first-write hypothesis/watch. Repair its indexing contract.

## Failure cases

Include alignment causing an overflow, an omitted stack reservation, heap guard failure, zeroing into retained bytes, inverted/range endpoints and a stale map from another image. The fixture covers arithmetic and startup transformation; the actual linker failure and logical stray-write/watch experiments are mandatory learner-created evidence. No arbitrary physical memory writes or global RAM clearing are required.

## Acceptance and evidence

Deliver separate verdicts for link capacity, runtime reservation, initialization and logical corruption; independent interval results; actual matching script/map/linker output; startup sentinels; rejected heap request and defined wrong-cell repair. The explanation must show why .bss did not grow and why a successful link does not prove the allocator or startup correct.

## Hints and recovery

Use the inspected MEMORY, LMA and ASSERT scopes, including assertion symbol timing. A MEMORY report accounts for linked sections; it is not a heap or worst-case-stack measurement. Finish the named T27 selected leaves for actual target startup, or keep the finite host model explicitly limited until that route is ready.

## Transfer challenge

Move retained storage to another declared bank or add alignment to one section. Update the checker and startup ownership before observing; reject a mixed-image map or unsupported DMA bank without pretending the synthetic region is an electrical result.
