# PR-T72-06: Cursor parser combinators with rollback and progress checks

Implement literal/empty/sequence/choice/many on the bounded immutable parser DAG with a node-visit budget, output rollback and no parser library; integrate an explicit bytes.cursor adapter. The full required specification is {ref}`X-T72-006` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

choice(sequence(a,b),a) parses ac through position1 and ab through2. many(empty) returns STATE with end unchanged; budget0 returns RANGE with zero visits.

## Steps

## Failure cases
