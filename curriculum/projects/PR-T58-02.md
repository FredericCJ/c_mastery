# PR-T58-02: Callee state and platform registers

## Contract

Implement po_saved(arch,reg), with arch0 RV64 integer ABI and arch1 AArch64. Report saved integer registers: RISC-V x2,x8,x9,x18..x27; Arm x19..x29 and synthetic register31 for the stack pointer. Other fields return0. Independently compare hostile-caller assembly against the declared set; exclude x18 from portable allocation.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-PO-02A` and `LAB-PO-02B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-RVABI, R-B06-AA64, R-B06-RVISA, R-B06-RVPRIV in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: Reconstruct an x86 call frame and an original linker map. Derive aligned downward stack growth without unsigned underflow. Explain why a C function-call save set is insufficient for an asynchronous trap.
