# PR-T03-02: Nested array and bounded cursor

## Contract

Implement a caller-storage matrix cursor with explicit row and column counts and a one-past end state. Use pointer-to-row or an equally explicit representation; do not substitute int ** for row arrays. The component uses no external C-library calls. Document null handling only for states that do not require pointer arithmetic or access.

## Failure cases
