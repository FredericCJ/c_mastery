# PR-T60-07: Original Thumb code emission

## Contract

Implement cc_thumb emitting Thumb-2 GNU assembly using r3 to retain x, r0/r1 temporaries, word pushes/pops and bx lr. Constants fit movw. No nested calls or FP operations are supported. Stage output transactionally and preserve the exact same unsigned32 semantics as x86.

unit IDs are `LAB-CC-07A` and `LAB-CC-07B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-AA32 in
`research/v5/b06_resources.json`, using only its inspected locators.

## Failure cases

The backend omits argument preservation, so expressions that load x after a constant compute from the constant instead. A constant-only test cannot detect this.

Retain the first divergent transition and distinguish the cause from a symptom.
