# PR-T72-01: Lazy fused pull pipelines and typed early termination

## Contract

Implement co_next, co_flow_next and co_fold without an iterator library, then build an unfused equivalent and compare exact source-pull and callback counts before timing. The full required specification is {ref}`X-T72-001` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

range0..10, step1, take3 emits0,4,16 after1,3,5 source pulls; the next call returns `DONE` without a sixth pull. Breaking after two outputs leaves16 as the next output.

## Steps

- **T72.01:** Complete D1–D4, the named public anchor, independent falsification and changed-contract implementation.

## Failure cases

Enumerate half-open ranges, nonunit steps, empty take, exhaustion and early break against a materialized mathematical oracle. Check UINT16-edge squaring and resumed iteration; reject extra-pull-after-take and skipped-map mutants.

## Acceptance and evidence

- **T72.01:** Satisfy all four leaf rubrics and source-bound verification; passing supplied tests alone is insufficient.

## Hints and recovery

Place the take check before the source call. Count rejected filter inputs as pulls. Fusion is equivalent only when it preserves evaluation and failure contracts.

## Transfer challenge

Replace pure mapping with a callback that acquires resources and may fail. State whether a rejected item was consumed and which resources remain owned; delayed assessment adds zip with unequal lengths and forbids over-reading the shorter input.
