# PR-T58-05: Signed immediates and relocation ranges

## Contract

Implement po_sign12(raw) for the low12 bits as a mathematical signed value -2048..2047, ignoring higher bits. Implement po_branch(delta,bits,align) accepting only bits2..30, align2 or4 and aligned signed delta in [-2^(bits-1),2^(bits-1)-align]. Use this as a relocation admission oracle, not as a complete instruction encoder.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable

## Steps

- **T58.05:** Instruction immediate fields are bit patterns interpreted with instruction-set-specific sign extension. An unsigned C shift implements bit extraction; a shift of a negative signed C operand has different rules. Alignment and range checks precede truncation.
- **T58.05:** Implement po_sign12(raw) for the low12 bits as a mathematical signed value -2048..2047, ignoring higher bits. Implement po_branch(delta,bits,align) accepting only bits2..30, align2 or4 and aligned signed delta in [-2^(bits-1),2^(bits-1)-align]. Use this as a relocation admission oracle, not as a complete instruction encoder.
- **T58.05:** Derive sign-extension using unsigned extraction and subtraction in a range representable by int. Separate field representability, target instruction alignment and linker relaxation.

## Failure cases

Truncating an odd branch displacement silently redirects execution. A range-only check is insufficient; a passing assembler can still hide linker-added veneers.

Retain the first divergent transition and distinguish the cause from a symptom.
The named mutation control must fail for its intended reason; compilation
failure is not a successful mutation kill.
