# PR-T67-03: Typed flag sets and reserved-bit admission

## Contract

Construct ADFlags from uint32 raw input. Bits0,1,2 are independently allowed; zero is a valid empty set. Any other bit fails transactionally. Provide union/intersection operations in the learner extension and show that their closure depends on validated operands.

The full required exercise {ref}`X-T67-003`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Inputs0 and7 succeed unchanged;8 andUINT32_MAX fail while preserving the prior ADFlags value.

## Steps

- **T67.03:** Define the valid mask invariant raw & ~7 ==0, all eight admitted states and ownership-free value semantics. Explain integer promotions when complementing a narrow mask; use an explicit uint32 mask. A public struct can be forged, so only constructor-admitted values have the promised invariant. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.flags; exhaustively test0..255 and each single bit position. Reject the silent-mask mutant and empty-set rejection mutant. Show a newly reserved bit cannot be accidentally converted into success by masking.

## Acceptance and evidence

- **T67.03:** Distinguish a set of independent options from a mutually exclusive sum, and explain why reserved bits must be rejected or retained under a documented evolution policy rather than silently cleared. Every leaf has a separate rubric criterion in X-T67-003. Public test passage alone does not assess independent understanding.

## Hints and recovery

Write the set of all admitted bit patterns. Then Complement the mask in its intended unsigned type. Record the failed hypothesis before using further hints.

## Transfer challenge

Negotiate separate required and advisory bit sets between two schema versions. Preserve unknown advisory bits for forwarding while rejecting unsupported required bits, and prove the union operation cannot manufacture support.
