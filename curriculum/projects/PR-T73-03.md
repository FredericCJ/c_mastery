# PR-T73-03: Senders, receivers and immovable operation-state lifetimes

## Contract

Implement MsgOperation transitions `NEW`→`STARTED`→`DONE`. Connect records receiver/context, start succeeds once, cancellation records intent only, and complete accepts exactly one value/error/stopped result. Set terminal state before invoking the receiver and never touch the operation after that call: a receiver may reclaim it. Add an io.async backend adapter whose terminal callback carries partial progress and releases retained ownership exactly once.

The full required exercise {ref}`X-T73-003`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Complete before start is INVALID. Start then stop leaves `STARTED` with cancellation requested. Complete CANCELLED,3 invokes one receiver and reaches `DONE`. Duplicate complete on a still-live test state is INVALID and leaves callback count1. A separate heap-owned completion test frees the state inside its receiver without later access.

## Steps

- **T73.03:** Implement the serialized state protocol and backend lifetime adapter, including synchronous completion, competing cancellation and completion transitions, callback reentrancy policy and exactly-once terminal release. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Enumerate invalid start/complete orders, value/error/stopped alternatives and cancellation-before-completion. Use a receiver that frees a heap state to detect post-callback access under ASan. Reject duplicate-completion and cancel-as-completion mutants. For a concurrent adapter, use one atomic winner and demonstrate that losers never inspect reclaimed storage without their own retained reference.

## Acceptance and evidence

- **T73.03:** Separate sender recipe, connected operation storage, start permission and completion ownership; identify the dated C++ proposal guarantees that an exposed C struct does not enforce. Every leaf has a separate rubric criterion in X-T73-003. Public test passage alone does not assess independent understanding.

## Hints and recovery

Completion may be the last permitted access to the state. Then A stop request does not authorize storage reclamation. Record the failed hypothesis before using further hints.

## Transfer challenge

Allow an operation to complete inline during start and let the receiver destroy its enclosing object. Delayed assessment connects a chain of two operations; ensure the successor starts only after ownership transfers and no predecessor field is accessed after its receiver may have destroyed it.
