## Steps

1. Record exact board revision, Ethernet pins/solder bridges, PHY address/ID and 50 MHz reference source. Measure the clock with adequate instrument bandwidth/sampling.
2. Derive PA/MR/CR/MW/MB fields from the actual register scope; require idle before writes, select fields with MB0, then start the read and wait boundedly for completion before consuming data.
3. Implement reset polling and ID masking; unknown/all-ones reads are diagnostic results, not a discovered matching PHY.
4. Read BSR twice, record both values, confirm register 31 done and mode, and configure MAC mode only from a ready result.

## Failure cases

Busy no-write, unsupported clock range, absent reference, reset/access timeout, wrong IDs, link down, incomplete negotiation, unknown mode and half-duplex exclusion. A latched-low first read is not alone current link status, and a ready observation is not an everlasting link guarantee. A PHY status fault cannot be inferred solely from a synthetic adapter timeout.
