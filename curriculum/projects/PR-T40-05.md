## Contract

Implement L4 over the unreliable routed datagram service. DATA/ACK/PROBE headers carry type, source/destination port, transfer ID, fragment index/count and credit. DATA has 1–24 octets; non-final fragments are exactly 24 and the message is at most 120. Ports 7↔8 select the endpoint service. Keep one outstanding fragment and one bounded reassembly per direction; no partial message reaches L5.

Transfer IDs start at 1 and increase within the session without reuse/wrap. Keep highest-completed ID and one last-completed receipt including final fragment bytes. Re-ACK an identical duplicate final fragment without redelivery; older completed IDs drop. Keep a complete message pending upper consumption with credit zero. Reopen the session before ID wrap.

## Inputs and expected results

The fixture has a 25-octet message, repeated first fragment after a lost ACK, a credit-zero pause/probe, credit reopening, final fragment and repeated final fragment. Expected upper bytes appear once only after completion; ACK indices and probe time are exact. Separate failure traces reach retransmissions at 100, 200, 300 ms then fail at 400 ms; blocked credit reaches its independent 500-ms deadline.

Report transfer result, complete delivery bytes/count, matching ACKs, retransmitted bytes/indices, retained/free state and timeout counters. Both failure traces retain unchanged upper output. The supplied oracle derives fragment sizes and abstract event outcomes, not a solved transport stack.

## Steps

1. Spend the first 4 h defining sender/receiver tuple and states, checked fragment arithmetic and matching ACK rules; run a normal 25-octet transfer.
2. Add duplicate receipt and atomic upper publication. A completion callback may refuse consumption, so keep the SDU and advertise no credit.
3. Start clocks only after lower submit accepts transmission; BUSY/grant waiting alone must not consume a retry.
4. In the remaining 6 h, inject lost ACK, wrong ID/index/count, credit pause, reset and final-ACK loss. Advance virtual time exactly through boundaries.
5. Relay on both measured segments and compare application delivery count with frame/retry count. Record which delays come from grants and which from transport timers.

## Failure cases

A mismatched ACK frees nothing. Duplicate accepted data appends nothing. Wrong non-final length, unexpected index/count, total over 120, old completed ID, unsupported port and no capacity are distinct rejects. Credit probes do not restart the blocked deadline. At retry or blocked failure, clear partial state and publish a failure event, never a partial SDU. Session reopen clears old receipts and separates ID incarnations.

## Acceptance and evidence

Retain the sender/receiver state diagram, exact fragment/ACK ledger, injected-clock log, complete upper bytes and failure cleanup witnesses. For all three objectives show checked segmentation/reassembly, match/retry/credit transitions and absence of partial publication/leaks. Capture one dropped-ACK retry on the bench if available. An eventual successful transfer alone cannot replace the timeout/duplicate evidence.

## Hints and recovery

If a repeated byte appears upward, distinguish duplicate fragment append from repeated complete-message publication. If retries fire during BUSY, move the timer origin to accepted transmission. If credit probes prolong blocking forever, retain a separate resource-deadline origin.

## Transfer challenge

Change the message from 25 to 120 octets and predict all five fragment sizes, retained storage and final-ACK behavior. Explain why adopting a byte-stream API would require a different service contract.

For this milestone, retain three separately labeled evidence items:

- **T40.05.a:** Segment and atomically reassemble bounded messages using the exact transfer/fragment contract.
- **T40.05.b:** Trace matching acknowledgments, retransmission, duplicates and credit probes with an injected clock.
- **T40.05.c:** Prove that failed or blocked transfers publish no partial message and free their bounded state.
