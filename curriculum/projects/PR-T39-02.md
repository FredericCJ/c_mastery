## Contract

Implement an allocation-free untagged Ethernet frame builder/parser: six-byte source/destination, a checked length/type field, payload≤1500, fixed caller capacity 1518 including optional FCS. Local output uses zero pad to 46 payload bytes; the host oracle computes declared reflected CRC32. VLAN, jumbo and the 1501..1535 gap are excluded. Separate buffers with/without FCS and physical preamble/SFD/gap; never place gap bytes in a DMA buffer. Record the prepared 100BASE-TX board/PHY/media path.

This 8-hour milestone includes implementation and verification. The module budgets reading, assessment and delayed consolidation separately. ## Steps

1. Draw MAC/RMII/PHY/magnetics/cable boundaries and document exact board/clock/media identities.

2. Implement checked field/length/capacity parsing without casting unaligned network bytes into C structs.

3. Implement the declared CRC arithmetic and compare independent recurrence/zlib results; keep the RFC appendix’s arithmetic purpose distinct from Ethernet normative status.

4. Exercise minimum/maximum/pad/type/gap/tagged cases and distinguish meaningful length from padding.

5. Observe prepared physical link establishment/loss and a selected captured frame; identify whether its capture point exposes FCS/preamble. PHY management details follow PR-T39-04.

## Failure cases

Short header, oversized/overflowing length, capacity, length mismatch, unsupported tag/gap and bad declared FCS. VLAN is excluded, not universally invalid Ethernet. Unknown capture FCS stripping cannot be guessed. A virtual NIC or QEMU run does not prove cable/media/clock behavior.
