# PR-T47-05: Deletion, redistribution and page reuse

## Contract

Implement missing-key deletion, sibling borrowing, merging, root contraction and reuse. Delete the 92-key tree in the permutation (37*i) mod 92; this visits every original key. Check invariants and surviving values after each step. Reinsert another 92 records and prove that released pages are reused rather than leaked.

Budget 6 implementation and 4 verification hours. Reuse the same engine throughout; previous milestones are not charged again. The public API and original disk format are in the storage laboratory.

## Inputs and expected results

Use [the contract fixture](../../fixtures/storage/PR-T47-05.json) and the actual C tests `storage.deletion`. The image has 67 pages of 4096 bytes; the tree owns 32 logical data pages. The reference transaction changes the complete map from {1:10,2:20} to {1:11,3:30}. Compare whole maps. No fixture asserts physical power-cut durability.

## Progressive execution

Defer `storage.tree`, `storage.differential` until PR-T47-09/10 integrates opening, durable publication and recovery. Passes cover their finite mechanism only; retain the separate invariant, failure and transfer evidence.

## Failure cases

Skip a separator refresh, leave a freed page in the leaf chain or free a still-referenced sibling. Use the minimum failing deletion prefix to distinguish these violations.

An unavailable compiler, sanitizer runtime, syscall or device produces unavailable evidence; it never counts as a clean run. A wrong implementation must fail a semantic assertion after successful setup.

## Acceptance and evidence

Include the exact source-reading locator and fault assumptions. A CTest family pass supports its executed cases, not automatic completion of every objective. Use `tools/verify_storage_fixtures.py` for contract-index consistency; it neither compiles your C nor awards runtime mastery.

## Hints and recovery

Deletion may change an ancestor minimum even when no node underflows. Non-root leaves require four records and internal nodes require three separators. Borrow from a sibling with spare occupancy; otherwise merge, remove the corresponding parent separator/child and propagate the underflow. If an internal root loses its last separator, replace it with its only child. A freed page becomes reusable only after no tree or leaf-chain reference names it. The allocation bitmap and reachable-node set must agree after every transition.

The staged laboratory hints separate invariant, observation and repair direction. Keep the original failing image or key sequence and compare it with a clean control.
