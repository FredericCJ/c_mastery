# PR-T76-03: Lamport, vector and hybrid logical clock boundaries

## Contract

Implement checked Lamport receive max(local,remote)+1, fixed3-replica vector merge-then-increment and partial-order comparison (-1 before,0 equal,1 after,2 concurrent). Implement hybrid logical clock Figure5 using uint64 physical and uint32 logical components, local/send events via remote=NULL and receive events via a remote pair. Apply every max/tie branch; backwards wall time is allowed. Counter overflow returns RP_RANGE with output unchanged; do not wrap and silently violate causality.

The full required exercise {ref}`X-T76-003`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Lamport(2,8)=9. Vectors[1,0,0] and[0,1,0] are concurrent; receive at replica0 gives[2,1,0]. For a hybrid logical clock, local(10,2),remote(10,7),wall9 gives(10,8); wall11 on a subsequent local event resets logical to0. UINT32_MAX logical overflow fails unchanged.

## Steps

- **T76.03:** Show two concurrent events with ordered Lamport timestamps, two incomparable vectors and every hybrid logical clock equality case. Separate physical-clock closeness claims from the synchronization assumptions in Corollary1. On local overflow choose explicit failure; neither arbitrary sleep nor silently increasing physical time is equivalent. Outputs are ordinary C structs, so validity and per-replica serialization remain caller obligations. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run replicated.clocks and independent exhaustive small hybrid logical clock branch enumeration plus uint64/uint32 extrema. Kill ignoring-remote Lamport and incorrect equal-physical HLC-counter mutants. Build small message histories and derive causal relations from graph reachability before comparing clock outputs; timestamp ordering alone is not the oracle.

## Acceptance and evidence

- **T76.03:** Derive three different clock contracts: Lamport timestamps preserve happened-before in one direction, vectors characterize causality under fixed known membership, and hybrid logical clock pairs retain a physical component without eliminating physical-clock assumptions. Every leaf has a separate rubric criterion in X-T76-003. Public test passage alone does not assess independent understanding.

## Hints and recovery

Enumerate which physical sources tie for the maximum. Then Keep physical selection separate from logical-counter selection. Record the failed hypothesis before using further hints.

## Transfer challenge

Change replica membership and persisted restart identities; show why resetting a vector slot or reusing a timestamp identity loses history. Add a bounded clock-skew model and prove exactly which hybrid logical clock closeness bound follows. Compare scalar timestamp wire size, vector growth, and a protocol that waits versus rejects on finite counter exhaustion.
