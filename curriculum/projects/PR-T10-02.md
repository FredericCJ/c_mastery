## Contract

Compare the inspected glibc/musl startup files and specify exactly which services a custom entry retains. Demonstrate hosted buffering/handler effects separately from a non-returning raw exit path. Each retained library call has an initialization owner; unsupported services fail visibly.

## Failure cases

- Challenge the mistaken claim: Calling a libc symbol from custom startup is safe because it links. Preserve a minimal failing trace or explain the valid precondition that excludes it.
- Challenge the mistaken claim: Every exit mechanism flushes streams and runs handlers. Preserve a minimal failing trace or explain the valid precondition that excludes it.

Exercise empty/singleton or zero-progress states where the operation admits them, exact capacity, one beyond capacity, repeated completion/cleanup and a deliberately invalid precondition. For storage-owning work, inject acquisition failures and verify unchanged old ownership. For build/binary/source studies, inject a wrong edge, symbol, width, target assumption or unsupported environment and require a visible failure verdict. Never execute malformed pointers or privileged instructions just to demonstrate a negative case. Apply these cases to the declared operation; document any inapplicable case and its reason.
