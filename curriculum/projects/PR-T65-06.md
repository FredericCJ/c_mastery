# PR-T65-06: Typed nonlocal-jump boundary with explicit cleanup ownership

## Contract

Implement er_run, er_defer and er_raise using the caller-owned zero-initialized er_frame. er_run rejects an active or cleaning frame, sets a live jump destination, calls body once and returns either its result or the raised error. Register at most four non-null cleanup callbacks while active, then execute each exactly once in reverse registration order after normal return or a jump. Registration failure preserves the stack. Popping precedes calling cleanup; callbacks may not reenter, raise or register on the cleaning frame. er_raise outside a live frame or with ER_OK/unknown code returns ER_INVALID. A valid raise stores the typed error in the external frame then longjmps. No cross-thread jumps, signals, escaped jmp_buf, variable length arrays or nested reuse of the same frame.

The full required exercise is {ref}`X-T65-006`. Its explicit shared contract, four deliverables, objective rubric, source inspections and delayed variant are part of this project. Eight hours is descriptive author accounting, not a study deadline or scope ceiling.

## Inputs and expected results

Register callbacks appending digits1 and2, then raise ER_THROWN: return `THROWN` with trace21, count0 and inactive frame. Normal return with callback1 also cleans it. A raise after er_run returns is rejected before any jump.

- **T65.06:** Implement a bounded explicit cleanup stack and typed jump-to-result boundary without pretending that longjmp unwinds C resources. Complete the exercise D1–D4 and preserve prior artifact contracts.
