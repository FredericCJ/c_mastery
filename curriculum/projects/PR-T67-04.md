# PR-T67-04: UTF-8 smart constructors and validated borrowed text

## Contract

Implement ad_text over at most65535 bytes. Return a borrowed immutable pointer/length and Unicode scalar count. NULL is permitted only for length0. Reject truncated continuation sequences, stray continuations, overlong forms, surrogates and scalars aboveU+10FFFF. No normalization, grapheme segmentation or allocation is performed. Failure leaves output unchanged.

The full required exercise {ref}`X-T67-004`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

41 E2 82 AC F4 8F BF BF is8bytes/3scalars; C0 80 and ED A0 80 fail; empty NULL input succeeds with0scalars; prefix41 E2 82 fails.

## Steps

- **T67.04:** Track input position and remaining continuation count without forming an out-of-range pointer. For each sequence derive minimum scalar value and maximum scalar value; compare scalar count with byte count. State storage lifetime and mutation restrictions explicitly, including a safe constructed example where another alias changes a previously validated buffer. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.text and the Python strict UTF-8 differential oracle for all one/two-byte strings plus specified three/four-byte boundary samples. Kill overlong and surrogate acceptance mutants. Record that Python decoding is an independent implementation, not a proof of normalization or all higher-level text properties.

## Acceptance and evidence

- **T67.04:** Derive a UTF-8 validation predicate from RFC3629 and explain why successful construction proves byte encoding only while the backing bytes remain live and unchanged. Every leaf has a separate rubric criterion in X-T67-004. Public test passage alone does not assess independent understanding.

## Hints and recovery

Keep the sequence minimum alongside the accumulated scalar. Then Treat ED A0 80 and F4 90 80 80 separately. Record the failed hypothesis before using further hints.

## Transfer challenge

Add an incremental decoder across chunks with at most3retained bytes and finalization. Test every split of each boundary sequence, cancellation that drops pending bytes, and a copying owner that can preserve validation under caller mutation.
