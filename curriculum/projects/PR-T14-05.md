## Contract

Implement binary heap build/insert/extract and an unbalanced ordered tree with all deletion shapes. Declare tie policy and either exclude update-key or supply stable handles. Traverse using bounded explicit storage where recursion is disallowed, and check parent links, reachability and ordered contents after each mutation. Storage legality is part of acceptance. Under the selected C17 baseline, an aligned declared unsigned-char array is still a declared character array; alignment alone does not license arbitrary T* lvalue access. The portable byte arena uses byte APIs and explicit copying into/out of actual typed objects. A typed pool uses a real array of the selected T. A hosted harness may separately supply genuine allocated storage through a backing callback, while the studied allocator/container policy stays local. Firmware casts or mapping-backed typed objects need an explicit, inspected implementation contract and are reported under that contract, not as a blanket ISO C guarantee. Check effective type, alignment, bounds and lifetime independently.

The reusable target is Profile C: implement each studied algorithm/container/allocator/byte operation locally. A hosted test oracle may call mature libraries, but the target may not delegate its mechanism to qsort, bsearch, malloc/realloc/free, strto*, printf-style conversion, external memory primitives or equivalent library substitutes. Allocator callbacks/backing storage and compiler helpers must be explicitly scoped and audited.

- Challenge the mistaken claim: Deleting a key always frees the exact node originally returned by search. Preserve a minimal failing trace or explain the valid precondition that excludes it.
