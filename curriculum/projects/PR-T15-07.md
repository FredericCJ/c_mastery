## Contract

Implement bounded copy/compare/search/split/trim and checked integer parse/format using explicit byte spans. Define aliasing, output capacity, bases/prefixes/signs, partial consumption and signed minimum handling. No strlen/strtol/sprintf/memory primitives or equivalent external C-library calls implement the studied operations. Share the small kernel with T11 through one-way dependency contracts.

The reusable target is Profile C: implement each studied algorithm/container/allocator/byte operation locally. Allocator callbacks/backing storage and compiler helpers must be explicitly scoped and audited.
