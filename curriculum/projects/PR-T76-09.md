# PR-T76-09: Pure reducers, explicit effects and rollback replay

## Contract

Implement RPState{tick0..8,position0..15,score0..65535,random:uint32}. rp_step consumes movement-1/0/1, wraps position on a16cell ring, advances LCG random=random*1664525+1013904223 modulo2^32, adds(random&3) with checked score limit and returns RPEffect{tick,score} as data. No clocks,I/O,allocation or callbacks occur in the reducer. rp_replay stages at most8 steps and effects, preserving outputs on failure. Restore the state before a changed input and replay the suffix; compare with a fresh fold of corrected inputs. rp_checkpoint composes two actual hash array mapped trie updates for position/score under one root publication and injects failure at each of6allocation ordinals; it is a projection checkpoint, not the full replay snapshot (tick/random remain in the explicit RPState snapshot).

The full required exercise {ref}`X-T76-009`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Initial(0,0,0,1),movement-1 gives position15,random1015568748,score0; next movement1 gives position0,score3. Eight inputs[1,1,0,-1,1,0,1,-1] produce score12. Replacing input4 with1 and replaying from the prior snapshot equals a fresh corrected fold. All six checkpoint failure cuts preserve the published root and used count.

## Steps

- **T76.09:** Prove determinism from complete state/input and defined unsigned arithmetic. Identify every effect boundary and distinguish speculative requests from committed presentation. Derive rollback of the hash array mapped trie used cursor after a failed second update while preserving old reachable roots; staged unreachable arena cells and allocation counters may differ. All arena users must be quiescent during the transaction, and roots from unpublished intermediate updates must never escape. Score overflow or invalid movement must not partially publish a state/effect. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run replicated.replay and exhaustively compare all movement histories of length0..8 with a Python integer model; verify suffix rollback versus full replay. Kill omitted random-score contribution and failed second-update allocation-leak mutants. Build a synthetic effect adapter with idempotency key(timeline,tick) and injected failure; record one duplicate-effect counterexample if replay directly invokes the adapter. Inspect undefined symbols to confirm the core has no time/random/I/O dependency.

## Acceptance and evidence

- **T76.09:** Implement the T20.03 functional-core boundary: explicit state and recorded input produce new state and effect requests, while an adapter owns effects. Demonstrate rollback equivalence without replaying externally visible effects or claiming that ordinary C enforces purity. Every leaf has a separate rubric criterion in X-T76-009. Public test passage alone does not assess independent understanding.

## Hints and recovery

List every bit that can influence the next state. Then Retain effects as data until the adapter chooses a commit policy. Record the failed hypothesis before using further hints.

## Transfer challenge

Introduce two local simulated players, predicted remote inputs and delayed corrections using ipc.local/io.frame, with bounded rollback horizon and retained snapshots. Separate authoritative committed effects from speculative presentation and define replacement/cancellation semantics. Reuse the actual T20.03 learner reducer adapter and storage.pages snapshot backend, then vary compiler/endianness and compare canonical state hashes. Implement a hidden wall-clock/random dependency as a deliberately failing counterexample, not a production change.
