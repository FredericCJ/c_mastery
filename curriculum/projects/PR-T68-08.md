# PR-T68-08: Typed formatting and transactional bounded sinks

## Contract

Use the supplied MP_ARG category-selection scaffold from the earlier generic-selection work, implement its uint32/text factories, and implement mp_format for decimal uint32 or literal zero-terminated text. Derive the scaffold expansion independently in D1. MPSink appends raw bytes with no terminator guarantee. Validate used<=capacity; failure leaves bytes/used unchanged. Text is live terminated storage, disjoint from output; percent sequences are literal data. Unknown argument kinds fail. No printf-family routine may implement the conversion.

The full required exercise {ref}`X-T68-008`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Appenduint32zero yieldsbyte30; appendliteral%n yieldspercent/n, with no conversion interpretation. Appending4294967295 to a sink with9freebytes fails unchanged; with10freebytes writes exactly10digits.

## Steps

- **T68.08:** Derive the10digit bound for UINT32_MAX and reverse temporary digits only after capacity admission. For text, prove scan stops on insufficient capacity without publishing a prefix. Compare C++ basic_format_string constant-evaluation compatibility with this narrower C factory: it enforces argument categories, not arbitrary formatting grammar or backing lifetime. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run metaprog.formatting, compile an unsupported MP_ARG category probe, and test every capacity0..11. Kill failure-used-count modification and zero-as-empty-output mutants. Compare against an independent decimal-string oracle and a guard-filled output suffix; distinguish valid text termination preconditions from bound checking.

## Acceptance and evidence

- **T68.08:** Distinguish compile-time argument-category checking from compile-time parsing of an arbitrary format string, and prove bounded sink failure does not publish partial output. Every leaf has a separate rubric criterion in X-T68-008. Public test passage alone does not assess independent understanding.

## Hints and recovery

Count the maximum decimal digits independently. Then Do not advance used before the full append can succeed. Record the failed hypothesis before using further hints.

## Transfer challenge

Add a parsed format domain-specific language with typed placeholder records specifying each argument category and format operation. Add partial streaming sinks with explicit capacity and progress. Specify format validation separately from argument typing, and make partial writes/retry offsets explicit rather than silently keeping the transactional API promise.
