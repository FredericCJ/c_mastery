# PR-T61-03: Stateful property harness and ownership

## Contract

Implement vf_ring_step for VFRing with positive capacity, head<capacity, size<=capacity. op0 push rejects full and increments size; op1 pop rejects empty, advances head modulo capacity and decrements size. Reject invalid state or operation without mutation. Build a sequence harness using a Python list oracle and generation from valid/invalid transition classes.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-VF-03A` and `LAB-VF-03B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-CBMC, R-B06-FUZZ, R-B06-ASAN, R-B06-KUNIT in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: State a loop invariant and a decreasing variant for a bounded array search. Show a counterexample to the assertion that branch coverage proves correctness and explain signed overflow before enabling a solver.

assessment of PR-T61-02. Keep these artifacts and

does not satisfy the prerequisite. Use the already accepted artifact interface
