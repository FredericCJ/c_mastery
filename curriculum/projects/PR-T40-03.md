## Contract

Implement only L2's exact delimiter/escape/header/CRC decoder and encoder above the granted byte channel. Body fields are version 1, kind 0/1/2, local source, local destination, payload length 0..40, payload and big-endian CRC-16/CCITT-FALSE. Encode CRC over the unescaped header/payload, then escape 0x7e/0x7d; delimit with 0x7e. Maximum unescaped body 47 and escaped frame 96 are checked capacities, not allocation suggestions.

Decoder publication occurs only after delimiter, escape, CRC, version, kind, actual length, local destination and grant checks all pass. A POLL/EMPTY has zero payload. A DATA received on the wrong ownership turn does not deliver upward.

## Inputs and expected results

The supplied fixture contains a body with both escape characters, exact encoded wire hex, CRC and known ASCII check vector 123456789→0x29b1. Its negative inputs are isolated candidates for truncated escape, corrupted CRC, foreign destination, impossible declared length, capacity overflow and missing grant. The oracle classifies each isolated candidate; it does not execute a streaming receiver or count callbacks across consecutive candidates.

Create a mandatory learner stream containing an overlong candidate, a resynchronizing delimiter and then a valid frame. Assert exactly one upper callback with only the valid payload. Repeat with truncated escape and foreign traffic preceding a valid frame, and split each stream at every octet boundary.

Your decoder output is an immutable borrowed local SDU plus metadata, or a counted rejection. Splitting input at every octet boundary must produce the same valid payload/event sequence as coalesced input.

## Steps

1. Derive the CRC vector independently on paper for a small prefix, then compare with the supplied finite verifier's polynomial calculation.

2. Design SEARCH/BODY/ESCAPE/DISCARD state and an explicit reset/resynchronization rule for every delimiter.

3. Implement bounded incremental parsing without publishing a partially decoded header or payload.

4. Enumerate every split of the encoded frame and append noise/truncation followed by the valid frame.

5. Integrate grant metadata; serialize one frame on each measured segment and compare the actual unescaped header/CRC with the host expectation.

## Failure cases

Trailing escape, candidate over 47, incorrect CRC/version/kind, mismatch between actual and declared length, foreign addresses and ungranted DATA publish no upper callback. Empty delimiters publish nothing. After DISCARD, the next delimiter permits a fresh candidate; a broken prefix must not poison an indefinitely long stream.

## Acceptance and evidence

Submit exact encoder hex, independent CRC witness, exhaustive split table, rejection/resynchronization counters and actual frame capture if bench is available. Show that a valid local frame can still be lost later and that CRC does not authenticate a sender. The objectives' evidence is the parser/encoder contract, bounded recovery traces and scoped delivery/drop observations. Preserve output sentinels and borrowed-span lifetime on rejected input.

## Hints and recovery

Check whether the CRC was computed before or after escaping. If only split input fails, trace the stored escape state rather than changing wire bytes. If noise grows memory, switch to DISCARD with a bounded counter rather than retaining the entire candidate.

## Transfer challenge

Use a payload composed entirely of delimiter/escape octets and recompute the maximum wire size. Explain why worst-case expansion does not double a physical bit error probability into a reliability guarantee.
