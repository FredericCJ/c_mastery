## Failure cases

Do not run an undefined expression to discover its value. A missing warning is recorded as tool behavior, not semantic permission. Reject negative indices before unsigned conversion and ensure the empty-array policy does not manufacture a valid element.

## Acceptance and evidence

The notebook contains explicit bounds proofs, call-signature reasoning, a sequencing classification and three minimized repairs. Every observation includes the build command and compiler version. Link the supplied index results to actual examples without treating numeric addresses as object validity.

Record contract, build/dependency evidence, independent cases, minimized failures and the specific evidence file for every linked objective. A passing synthetic oracle does not establish a passing implementation. Use {ref}`guide-assessment` for the review gate.

## Hints and recovery

For difficult expressions, list reads and writes separately and then draw the sequencing edges. Start the array proof from 0 <= i < n; use i == n only for pointer formation.

If stuck, separate the violated contract from the observed symptom and reduce the input before changing the implementation. Revisit the linked teaching section and retain the minimized case after repair.
