## Contract

Implement normal-descriptor RX validation and `ethernet_frame_channel_v1` receive handoff. At most 2 descriptors per frame and 1536 combined caller bytes; configured CSTF=APCS=0 retains FCS, accepted FL64..1518, publish FL−4 bytes from DA. Require all OWN clear, first FS, last LS, no ES/DE and capacity before publication. The core target baseline can reject multi-descriptor frames; the model still exercises a declared two-descriptor complete chain. A borrowed span/token may be released exactly once, and recycling waits until the consumer releases it.

This 10-hour milestone includes implementation and verification. The module budgets reading, assessment and delayed consolidation separately. ## Steps

1. Decode normal RDES0 fields and validity conditions before interpreting FL.

2. Implement validation with no pointer/length publication on failure. Track dropped partial frame state so a later LS-only fragment cannot become a new accepted frame.

3. Implement borrow/release token generation and counters; reject duplicate/stale release and demonstrate consumer backpressure.

4. Bind the reusable C mechanism to the selected E descriptor adapter, retaining separate object/image audits. Observe OWN/status before/after one actual received frame.

5. Export receive span, exact FCS/pad policy, status/drop counters and capacity ownership to T41 without duplicating its future network parser.

## Failure cases

DMA ownership, missing FS/LS, error/truncation, runt/oversized/capacity, duplicate release, stale generation and recycling while borrowed. RX buffer unavailable is explicit suspension/backpressure/drop, not permission to overwrite a live consumer. Do not subtract FCS again downstream.

## Hints and recovery

OWN gates status validity, LS gates final length, and consumer ownership gates recycling. Separate malformed/drop state from temporary lack of completion. Start with one complete descriptor before adding the bounded chain model.
