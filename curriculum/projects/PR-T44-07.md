## Hints and recovery

The lost-wakeup fixture has consumer check false, producer set true/signal, consumer waits. Fixing only the sleep length leaves that window. Reuse T25's predicate-under-the-same-mutex protocol: the wait releases atomically, the producer changes state while holding the mutex, and the consumer rechecks after reacquisition and every wakeup. Save forced schedules, thread identities, direct API statuses and a written ordering/lifetime argument. Supported detector runs and stress add exercised evidence. Halting or logging can hide a race; a detector's silence and one deterministic history do not close all schedules or establish fairness. On disagreement, minimize the first failing prefix, check identities and units, and change one hypothesis-driving variable. Feedback should name the incorrect inference or violated invariant; retry a changed variant instead of repeating unrelated work. Use {ref}`guide-assessment` for evidence/feedback policy.
