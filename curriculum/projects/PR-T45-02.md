# PR-T45-02: Extent, underflow and terminator repair

## Contract

Implement checked fill, bounded NUL scan and caller-storage byte-to-string publication. Inputs have explicit capacity and source length. Reject a negative external index before conversion/pointer formation, index beyond capacity even for count zero, any count beyond remaining capacity, embedded NUL in the byte-to-string payload and insufficient NUL space. Accept index==capacity only for a zero-length fill without accessing storage. On rejection preserve every destination byte and observable length. A successful string contains its terminator within capacity. The target owns the bound checks and copying mechanism; a hosted harness may use independent mature helpers.

## Inputs and expected results

Capacity is 8 with initial eight 0xaa bytes. The supplied cases include lower/upper rejection, exact fill, one-past zero-length acceptance, beyond-one-past zero rejection, seven-octet string success, eight-octet failure, missing NUL in a bounded scan and a legal-address logical-bound violation at index 6 against logical_limit 4. Expected output hex and first invalid index are literal finite results. The logical case denies publication; it does not claim ASan will report an application-field error.

The supplied finite fixture is [fixtures/memory_lab/PR-T45-02.json](../../fixtures/memory_lab/PR-T45-02.json). Run `python tools/verify_memory_lab_fixtures.py` from the handbook source root for arithmetic/history/catalog checks. Actual C/tool/hardware evidence remains a separate learner obligation.

## Steps

1. Specify index/count/source units, overlap exclusion, publication and zero-length behavior before implementation.
2. Hand-check the supplied extents; implement validation before forming pointers or mutating output.
3. Add nonzero and empty strings, NUL at first/last valid position, embedded NUL rejection, exact and one-over boundaries.
4. Write separate hosted faulty versions for lower-bound, off-by-one and missing-terminator observation, one defect per child. Their UB outcomes are recorded, never golden outputs.
5. Repair each version with the checked API and test sentinel/length preservation.
6. Write a legal array access to the wrong logical cell, then add a semantic-field invariant that detects it.

## Failure cases

Include negative indices, count overflow relative to remaining space, zero-length at valid and invalid positions, a nonterminated source and an invalid overlap precondition. Source and destination must be actual live bounded objects in repaired C. A guard byte after an object does not license reading it to find a terminator.

## Acceptance and evidence

Provide hand-derived fixture results, C semantic tests, failure snapshots, each negative/repaired observation and the legal-address counterexample. The first invalid index explains the contract failure without relying on crash location. The repaired code must not form an out-of-range pointer to perform validation.

## Hints and recovery

Use remaining capacity rather than an unchecked index+count sum. Preserve staged output or prove that every potentially failing check precedes the first write. Revisit T03 arrays/pointer arithmetic and the selected book string passage if data length and NUL space are confused.

## Transfer challenge

Change capacity from 8 to 1, then introduce a sliced subobject inside a larger allocation. Demonstrate that the slice's bound remains decisive even when the surrounding allocation is addressable.
