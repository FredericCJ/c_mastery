## Contract

Reuse the T28 register adapter and prior ring/ownership abstractions. 0xA6 TX/0x3C RX is traced in all four CPOL/CPHA modes with 16 numbered edges per byte. Final cases include correct drained completion, one missing received byte, BSY still set and cancellation before DMA is confirmed stopped. Mode 0/2 sample odd edges and mode 1/3 even edges.

## Steps

1. Draw MOSI/MISO and capture/change edges independently for all modes.
2. Define transfer parameters, lengths, buffer lifetime, status and callback reentry restrictions; reject invalid requests before touching select.
3. Implement one polling path: TXE write, RXNE consume and final TXE/BSY completion. Reuse prior DMA sequencing only for a declared adapter with stop confirmation.
4. Replay timeout, undrained receive and cancelled-in-flight traces; buffer ownership remains with the adapter until completion/confirmed stop.
5. Capture one bounded matched-target transaction, including select setup/hold and final clock. Audit object and image dependencies under the declared E boundary.

## Failure cases

Null/capacity/length/mode rejection, receive overrun, wrong target select policy, BSY timeout, early deselection and buffer reuse while DMA remains active. A request with no meaningful receive payload still needs receive draining. Never change configuration while the selected peripheral transfer is active.
