## Contract

Publish a tiny C library with target-local usage requirements, installation and exported imported targets. A separately rooted consumer repository must configure and link from the installed prefix after the original build tree is hidden. Generate and replay one compilation-database command; retain configure/build/test presets with no private absolute paths.
