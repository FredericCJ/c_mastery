# PR-T58-03: Argument register exhaustion

## Contract

Implement po_arg(index,reg,offset) for the deliberately restricted nine-or-fewer uint64_t scalar interface: index0..7 maps to abstract argument registers0..7 with offset0; index8..15 maps to regUINT_MAX and stack offset8*(index-8); index>=16 rejects transactionally. The assembly adapter translates abstract registers to a0..a7 or x0..x7.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-PO-03A` and `LAB-PO-03B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-RVABI, R-B06-AA64, R-B06-RVISA, R-B06-RVPRIV in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: Reconstruct an x86 call frame and an original linker map. Derive aligned downward stack growth without unsigned underflow. Explain why a C function-call save set is insufficient for an asynchronous trap.

assessment of PR-T58-02. Keep these artifacts and
their evidence identities in D1; reading or copying their assessor solution
does not satisfy the prerequisite. Use the already accepted artifact interface
where integration is assigned; do not substitute a library for this mechanism.

## Failure cases
