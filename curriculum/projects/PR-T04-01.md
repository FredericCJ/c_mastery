# PR-T04-01: Checked arithmetic and signed division kernel

## Contract

Implement a no-library checked arithmetic kernel for a documented signed range and a size conversion boundary. Provide add, subtract, multiply, truncating quotient/remainder and a positive-modulus normalization operation. Outputs remain unchanged on rejected operations. The hosted harness may use wider or arbitrary-precision reference arithmetic.

The declared profile **C** applies to the boundary named here; specify harness versus component dependencies in {ref}`guide-profiles`. Budget 10 h for implementation and verification together. Start from your own sources and the listed fixtures, with prior modules as prerequisites; no starter repository or solved program is required.

## Inputs and expected results

Synthetic signed bounds are -128..127. The fixture contains add(120,10), subtract(-128,1), multiply(-12,10), divide(-7,3), divide(-128,-1) and divide(1,0). Expected statuses/results distinguish range failure, valid -120, quotient -2 remainder -1, and invalid divisors. The component’s actual type limits are recorded separately.

## Failure cases
