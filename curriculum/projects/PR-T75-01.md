# PR-T75-01: Cancellation trees and budgets across clock domains

## Contract

Implement RZScope init/cancel/check/remaining over immutable parent links, atomic cancellation flags and injected uint64 ticks. Limit depth to8, choose the earliest inherited deadline, and reject unrepresentable standalone addition. Then implement a request-budget envelope for two simulated hosts with unrelated clock origins: it carries remaining duration, never a raw local absolute deadline. Deduct local elapsed work and state the transport-delay assumption. Add a completion acknowledgement owned by each asynchronous borrower, retaining scope storage until all acknowledgements arrive.

The full required exercise is {ref}`X-T75-001`; its shared contracts, D1–D4, objective-specific rubric and delayed variant are part of this project. Eight hours is descriptive accounting, not a ceiling on required work.

## Inputs and expected results

Parent created at10 with budget10 expires20. A child at13 asking100 still expires20; at19 remaining is1 and at20 it is expired. Cancelling the parent makes the child `CANCELLED`. No borrowed storage becomes reclaimable solely because cancellation was requested.

## Steps

- **T75.01:** Implement checked scope construction and cross-clock remaining-budget encoding, including zero budget, numeric horizon, depth exhaustion and stale parent-lifetime counterexamples without executing invalid access. Complete every exercise deliverable, including separately specified extensions.

## Failure cases

A timeout is a local wait limit, not proof that remote work stopped. C has no automatic context-lifetime or deadline-propagation rule; both need explicit ownership and clock assumptions. Exhaust now0–16/budget0–16 across parent/child creation and every cancellation/finish permutation for two borrowers. Use mathematical min and arbitrary-precision addition as an oracle. Test UINT64_MAX edges and chain depth8/9. Compare Go Context documented cancellation and deadline behavior with the C runtime checks and caller lifetime discipline; never infer acknowledgement from an atomic flag.

## Hints and recovery

Compute the earlier budget before adding an unnecessarily large child timeout. A stopped wait and stopped operation are different events. Clocks with different origins can compare durations, not arbitrary local timestamps.

## Transfer challenge
