# PR-T20-02: Layer responsibility and portable service slice

## Contract

Implement a small portable indicator/sensor service interface and map its adapter path through HAL, BSP, driver and service responsibilities. Compare a vendor-HAL path with a purpose-built minimal path. The project implements the service and selected adapter glue, not an entire peripheral stack; reuse the embedded laboratory driver when physical execution is attempted.
