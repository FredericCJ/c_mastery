# PR-T04-03: Fixed-point rounding and saturation

## Contract

Implement a fixed-point multiply using a declared scale of 16, widened intermediates, ties-away-from-zero rounding and signed saturation at -128..127. Return the saturated integer and an explicit saturation flag. Derive the required intermediate range and the quantization error before choosing a C type.

The declared profile **C** applies to the boundary named here; specify harness versus component dependencies in {ref}`guide-profiles`. Budget 6 h for implementation and verification together. Start from your own sources and the listed fixtures, with prior modules as prerequisites; no starter repository or solved program is required.

## Inputs and expected results

The fixture pairs are (3,8), (-3,8), (64,64) and (0,127). Exact scaled products are 1.5, -1.5, 256 and 0; expected rounded/saturated outputs are 2, -2, 127 and 0, with only the third saturated. Rational arithmetic is the independent oracle.

## Steps

Test positive/negative ties, one step around ties and both saturation bounds. Record why the result error is bounded by half a quantum before saturation and why saturation requires a different error statement.
