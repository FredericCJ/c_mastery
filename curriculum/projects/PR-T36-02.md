## Steps

Derive the half-open invariant and `lo+(hi-lo)/2` progress. Draw register liveness and each load address before assembly. Use SysV scalar argument registers and AAPCS r0–r3 under the pinned sources; document any wrapper rearrangement. Assemble/disassemble both actual files and execute x86 under Linux plus Thumb on a declared Cortex-M4 ISA emulator or board. Add a probe caller that seeds preserved registers, poisons permitted scratch values and tests nested-call SP alignment/LR preservation. Compare with prior C outputs and trace/count certificates.

## Failure cases

Reject unsorted input or bad extent in the checked wrapper before invoking the unchecked internal kernel. Include n 0/n 1, duplicates, high-bit unsigned keys, signed-branch mutation, loading a[n], wrong scaling and preserved-register corruption. A boundary test must not manufacture undefined C accesses merely to obtain a crash.

## Hints and recovery

On x86, 32-bit arithmetic registers zero-extend their 64-bit parent; keep pointer width separate. On Arm, unsigned lower uses the no-borrow interpretation of C. A nested BL overwrites LR, even if the leaf search never did. Before changing instruction sequences, find the first load/interval/preserved register that disagrees.
