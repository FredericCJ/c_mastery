# PR-T02-04: Header definitions and negative compilation matrix

## Contract

Produce a self-contained header with one static-inline helper and one external API function. Compile two independent consumers under the C17 baseline and GNU17, then isolate a documented GCC historical-inline experiment using -fgnu89-inline where available. GNU17 alone uses the modern ISO inline model; do not manufacture a difference merely from the GNU spelling. Build a negative compilation matrix separating syntax, constraint and runtime obligations.

The declared profile **A** applies to the boundary named here; specify harness versus component dependencies in {ref}`guide-profiles`. Budget 6 h for implementation and verification together. Start from your own sources and the listed fixtures, with prior modules as prerequisites; no starter repository or solved program is required.

The fixture supplies declarations classified by explicit synthetic flags: malformed tokens, incompatible redeclaration and a valid declaration with a runtime bounds precondition.
