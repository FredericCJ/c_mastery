# PR-T72-04: Actual x86-64 stack switching, ABI state and sanitizer fibers

## Contract

Implement the assembly context switch plus fresh/resume/yield/completed/destroyed lifecycle on a caller-owned aligned stack; preserve FP control and integrate ASan/TSan fiber APIs. The full required specification is {ref}`X-T72-004` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

The callback sees its own128KiB stack, local17 then29 survive yields, caller rounding changes remain independent of fiber FE_DOWNWARD, and destruction while suspended rejects.

## Steps

- **T72.04:** Complete D1–D4, the named public anchor, independent falsification and changed-contract implementation.

## Failure cases

Run real two-yield callbacks with persistent locals, architectural RSP inside the supplied stack and independent caller/fiber rounding modes. Reject FP-control omission and suspended-destruction mutants. Inspect ELF notes, disassembly, registers, detector results and exact unsupported ABI features.

## Acceptance and evidence

- **T72.04:** Satisfy all four leaf rubrics and source-bound verification; passing supplied tests alone is insufficient.

## Hints and recovery

Start from the ABI preserved-register table. A new stack enters after ret with a different alignment from a call site. ASan fake-stack addresses and architectural RSP answer different questions.

## Transfer challenge

Add nested fiber scheduling and cooperative cancellation with owned automatic resources. Design guard-page allocation only in an isolated process without host-policy changes, and explain why CET, unwinding, signals and thread migration each require a new backend contract; delayed assessment ports the context layout to another ABI on paper before code.
