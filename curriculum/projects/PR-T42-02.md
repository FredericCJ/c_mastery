# Incremental header and authority parser

## Contract

Write a portable header state machine with consumed-length reporting and configured authorities. This is milestone2 of the hosted HTTP family. The shared contract is the supplied contract fixture; preserve its capacities, routes, body bytes and close behavior. The application owns the studied mechanism. The operating system supplies TCP/IP and the physical network. Reuse earlier C/ownership/Linux components and accepted evidence; this budget charges the new HTTP boundary work. No equivalent HTTP parser/server library may implement the target.

## Inputs and expected results

Use the accompanying finite fixture and shared contract. Its expected object is an oracle for the declared examples, not proof of every runtime path. The /health representation is exactly hex `6f6b0a`. Record consumed, retained, published and discarded octets separately. Match every listed status, length, ownership and timing result, and explain any environment-dependent evidence separately.

## Steps

1. Read the corresponding T42 topic and its assigned source locators; predict the fixture before coding.
2. State input preconditions, live storage, output ownership, error results and progress measure.
3. Write a portable header state machine with consumed-length reporting and configured authorities.
4. Run every split of the valid examples and selected two-request coalescings; demonstrate no early publication.
5. Compare the smallest observed trace with the independent fixture calculation and preserve the first disagreement.
6. Audit component dependencies, record actual commands/versions and retain separate evidence for objectives a,b,c.

For a GET header ending at offset 46, feed prefixes of lengths 0 through 46. Every proper prefix reports NEED_MORE with no complete request; the final LF completes the header once. Feeding two headers in one span completes only the first and returns its consumed length, leaving the second unchanged. Absolute-form http://localhost:8080/health selects authority localhost:8080, even if the syntactically valid single Host says other.example. Origin-form uses the single Host. Validate bounded configured host/port authorities; do not implement filesystem normalization. Missing/duplicate/malformed HTTP/1.1 Host returns 400 and close. A complete header is not yet a complete body. Retain split/coalescing, target-authority and smallest malformed-octet evidence.

## Failure cases

Include empty input, every relevant incomplete prefix, malformed syntax, exact capacity and one beyond capacity. Exercise error then retry/cleanup, pending output and a later event referring to a recycled descriptor. For a portable parser, no failure may publish a partial request or retain a span after its owner releases storage. For an adapter, no failure may leak a descriptor, advance an unsent offset or claim peer consumption from local send success.

## Hints and recovery

Reduce a failing exchange to one request, one state and one split point. Compare the promised consumed offset and ownership before adding logging. Keep the raw input immutable for diagnosis. If the oracle disagrees, recompute byte lengths or deadline arithmetic independently before changing expected data. Return to the corresponding entry foundation when the defect is a pointer lifetime, integer overflow, partial-I/O or event-ownership mistake.
