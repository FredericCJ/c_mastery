## Contract

Compile a defined integer/array computation, trace registers and addresses, and decode at least one short instruction from opcode and immediate bytes. Use the synthetic MOV-immediate vector as a declared x86 encoding example. Annotate actual instruction length, addressing mode and optimizer changes; timing observations are outside the ISA correctness claim.

## Steps

1. Write the operation/state/effects contract and predict the fixture result by hand.

2. Establish the smallest supported positive case and record environment/provenance.

- **T08.01:** Trace an indexed structure access instruction by instruction and calculate its effective addresses.

- **T08.02:** Track a signed and unsigned branch over the same bit pattern, and poison preserved registers before a call.

- **T08.10:** Compare a defined strength-reduction example with a separately diagnosed overflow-invalid variant.

3. Add boundary and deliberate-failure cases before broadening the implementation.

4. Minimize each disagreement and retain the earliest broken invariant.

## Failure cases

- Challenge the mistaken claim: One measured cycle count is an ISA guarantee. Preserve a minimal failing trace or explain the valid precondition that excludes it.

- Challenge the mistaken claim: A register that happened to survive one call is preserved by contract. Preserve a minimal failing trace or explain the valid precondition that excludes it.

- Challenge the mistaken claim: An unexpected instruction sequence proves an optimizer bug. Preserve a minimal failing trace or explain the valid precondition that excludes it.

Exercise empty/singleton or zero-progress states where the operation admits them, exact capacity, one beyond capacity, repeated completion/cleanup and a deliberately invalid precondition. For storage-owning work, inject acquisition failures and verify unchanged old ownership. For build/binary/source studies, inject a wrong edge, symbol, width, target assumption or unsupported environment and require a visible failure verdict. Never execute malformed pointers or privileged instructions just to demonstrate a negative case. Apply these cases to the declared operation; document any inapplicable case and its reason.
