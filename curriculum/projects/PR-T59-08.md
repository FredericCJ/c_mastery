# PR-T59-08: Fault capture and recovery evidence

## Contract

Implement lc_capture_valid(words,n) for exactly4 uint32_t words [reason,pc,check,commit], `check = reason ^ pc ^ 0x9e3779b9` and commit0xc0de. Reject wrong count, invalid check or missing marker. Build a minimal firmware fault record producer that writes commit last and never allocates, then cut the model after every store.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-LC-08A` and `LAB-LC-08B`. Families: A, B, C, D, F, G, I, J;

2. Store validity last and clear it before reuse.
3. Treat captured addresses as data to inspect, never as trusted control flow.
