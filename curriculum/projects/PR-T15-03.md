## Contract

Implement counting and stable LSD radix sorting for a declared fixed-width integer domain. Name key range, signed-order transformation and every scratch array. Compare small-range versus large-range suitability; no external sort or memory primitive implements the target.

Allocator callbacks/backing storage and compiler helpers must be explicitly scoped and audited.

## Failure cases

- Challenge the mistaken claim: Unsigned byte order automatically matches signed numerical order. Preserve a minimal failing trace or explain the valid precondition that excludes it.

Exercise empty/singleton or zero-progress states where the operation admits them, exact capacity, one beyond capacity, repeated completion/cleanup and a deliberately invalid precondition. For build/binary/source studies, inject a wrong edge, symbol, width, target assumption or unsupported environment and require a visible failure verdict.
