# PR-T62-07: Durable replacement and power-loss cuts

## Contract

Implement li_durable(write_done,file_synced,renamed,directory_synced) requiring all flags exactly1. Then write a local temporary-file replacement adapter: write fully, fsync the new file, rename within its temporary directory, fsync that directory, and report exactly which stage failed. Use a synthetic power-loss-cut ledger; do not claim real power-loss durability from a normal process exit.

## Failure cases

Retain the first divergent transition and distinguish the cause from a symptom.
