# PR-T68-06: Single-source field reflection and explicit wire operations

## Contract

Use MP_RECORD_FIELDS to describe code:uint16 and value:uint32 with wire widths2/4. Generate MPRecord and the MPField descriptor table from that list; implement exact6byte big-endian encoding. A short output capacity fails unchanged. Do not memcpy the struct to wire bytes; do not serialize padding or assume offsetof values equal wire offsets. Add a field through the single registry and rebuild every generated consumer.

The full required exercise {ref}`X-T68-006`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Record{code0x1234,value0x89abcdef} encodes12 34 89 AB CD EF. The field schema table has two records; native offsets are offsetof(MPRecord,code/value), independent of wire positions0/2.

## Steps

- **T68.06:** Explain stringification/token substitution and why the field list is a local schema, not arbitrary introspection of undeclared C types. Distinguish native field offset, native sizeof, wire width and schema identity. Compare the declared generated interface with language macro/derive facilities; no C++26 reflection claim is inferred without inspected final specification. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run metaprog.reflection and regenerate a changed schema in a temporary workspace. Kill endian reversal and missing-field-descriptor mutants. Compile under altered packing/alignment only as an implementation-specific comparison and retain canonical wire bytes unchanged.

## Acceptance and evidence

- **T68.06:** Derive declarations, field names, offsets and wire operations from one authoritative field list without confusing implementation layout reflection with a portable serialization format. Every leaf has a separate rubric criterion in X-T68-006. Public test passage alone does not assess independent understanding.

## Hints and recovery

Keep native offsets and wire offsets in separate columns. Then derive the field schema table length from the actual array. Record the failed hypothesis before using further hints.

## Transfer challenge

Add an optional tagged field and derive decode, equality, validation and visitor operations. Define migration/version rules and demonstrate a stale generated consumer that still compiles; design a build-time schema fingerprint check that catches it.
