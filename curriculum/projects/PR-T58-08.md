# PR-T58-08: Link closure and changed-target defense

## Contract

Implement po_closure(required_mask,provided_mask) returning true exactly when every required helper bit has an approved implementation. Bits represent memcpy, division, atomic fallback and stack protector for the synthetic map. Then derive the real closure from nm/readelf/map output for both ports and record every unresolved or policy-disallowed symbol.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-PO-08A` and `LAB-PO-08B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-RVABI, R-B06-AA64, R-B06-RVISA, R-B06-RVPRIV in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: Reconstruct an x86 call frame and an original linker map. Derive aligned downward stack growth without unsigned underflow. Explain why a C function-call save set is insufficient for an asynchronous trap.
