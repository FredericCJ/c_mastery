# Router and HTTP response serializer

## Contract

Add the original route table, HEAD metadata, status/Allow, Date and 100-continue state. This is milestone5 of the hosted HTTP family. The shared contract is the supplied contract fixture; preserve its capacities, routes, body bytes and close behavior. The application owns the studied mechanism. The operating system supplies TCP/IP and the physical network. Reuse earlier C/ownership/Linux components and accepted evidence; this budget charges the new HTTP boundary work. No equivalent HTTP parser/server library may implement the target.

## Inputs and expected results

Use the accompanying finite fixture and shared contract. Its expected object is an oracle for the declared examples, not proof of every runtime path. The /health representation is exactly hex `6f6b0a`. Record consumed, retained, published and discarded octets separately. Match every listed status, length, ownership and timing result, and explain any environment-dependent evidence separately.

For an admissible POST with Expect: 100-continue and body not yet received, enqueue the interim 100 immediately, then wait for the framed body. If headers already establish an error, enqueue that final error instead. Waiting for the body before 100 can deadlock a cooperative client. Emit Date using a reasonable UTC clock; fixture epoch 1672531200 yields Sun, 01 Jan 2023 00:00:00 GMT in the required fixed-date format. Use a separate monotonic clock for deadlines. Length is an octet count, not Unicode character count. User data never becomes unchecked header syntax or a format string. Evidence includes exact serialization, binary echo, HEAD boundary, Allow and expectation traces.

## Failure cases

Exercise error then retry/cleanup, pending output and a later event referring to a recycled descriptor. For a portable parser, no failure may publish a partial request or retain a span after its owner releases storage. For an adapter, no failure may leak a descriptor, advance an unsent offset or claim peer consumption from local send success.
