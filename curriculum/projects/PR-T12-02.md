# PR-T12-02: Byte buffers, locale boundary and chunked text

## Contract

Implement a caller-storage byte-buffer component and a strict UTF-8 validation boundary. Its component storage is allocation-free; individually allowed memory/classification calls and callback effects are listed. Use a hosted comparison harness for memmove, ctype and restartable locale conversion. Do not equate the UTF-8 validator with normalization or grapheme processing.

## Failure cases

Reject overlong forms, surrogate encodings and invalid continuation bytes. Preserve incomplete state only under a documented streaming policy. Do not pass negative char values to ctype or invent null-pointer exceptions for zero-length memory calls. Failure leaves the buffer invariant intact.
