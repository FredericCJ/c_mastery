# PR-T67-09: Evolution-aware sums and lossless tolerant readers

## Contract

Implement original teaching TLV [tag:u8,length:u8,payload]. Tag1 has exactly2payloadbytes,tag2 has0; tags3..127 are unknown advisory variants retained as borrowed bytes;0 and128..255 fail. Require exact input extent and lossless re-encoding. Write into disjoint caller storage only after complete capacity validation, with used/output unchanged on failure. This is not a Protobuf-compatible wire implementation.

The full required exercise {ref}`X-T67-009`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

09 03 04 05 06 round-trips byte-for-byte;01 01 07 fails as malformed known data;80 00 fails as unsupported required semantics.

## Steps

- **T67.09:** Define a sum of known-number, known-empty and unknown bytes; retain tag and payload even when semantics are unavailable. State lifetime, disjointness, maximum255payloadbytes and overflow-free size calculation. Compare binary unknown-field preservation with the inspected Protobuf guide and demonstrate a field-wise rebuilding path that loses unknown data. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.evolution and construct a two-version relay trace. Kill unknown-payload-discard and malformed-known-acceptance mutants. Test all truncation points, trailing bytes, capacity shortages, zero-length unknown payload and borrowed-buffer mutation. Record which operations preserve unknown data and which deliberately reject it.

## Acceptance and evidence

- **T67.09:** Distinguish tolerance from permissiveness: an unknown noncritical alternative can be retained exactly, while malformed known alternatives and unknown required semantics must fail. Every leaf has a separate rubric criterion in X-T67-009. Public test passage alone does not assess independent understanding.

## Hints and recovery

Model unknown data as an explicit branch. Then Do not repair a malformed known branch by treating it as unknown. Record the failed hypothesis before using further hints.

## Transfer challenge

Add duplicate fields and canonical ordering to an extensible record format. Specify how unknown duplicates participate in signatures and forwarding, and demonstrate why accepting arbitrary unknown fields can violate a higher-level security policy.
