# PR-T63-08: Observable work, timing and mitigation limits

## Contract

Implement md_equal(a,b,n,steps) scanning all n bytes, accumulating bitwise exclusive-or difference, reporting steps=n and returning equality. Empty spans compare equal without dereference. Compare with an intentionally early-exit mutant using synthetic secrets only. Inspect optimized code and measure distributions without treating equal loop counts as a universal constant-time guarantee.
