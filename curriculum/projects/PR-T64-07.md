# PR-T64-07: Saturating lanes and scalar tails

## Contract

Implement ns_add(a,b,n,out) saturating int16_t sums for n<=65535 with disjoint arrays. Widen each addition, clamp then narrow; handle every element including tails. Empty input succeeds without dereferencing arrays, invalid length fails before writes. Implement an explicit-vector adapter separately and compare it against this scalar oracle.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-NS-07A` and `LAB-NS-07B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-VECTOR, R-B06-GCCMATH in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: Derive integer ranges and floating-point representation error; distinguish overflow, rounding, cancellation and conditioning. Demonstrate a checked array extent and a reproducible timing harness before optimizing.

## Steps

- **T64.07:** A SIMD vector is a collection of fixed-width lanes governed by compiler and instruction-set architecture rules. Scalar promotions, overflow behavior, alignment and tail handling cannot be assumed to carry over unchanged.
- **T64.07:** Implement ns_add(a,b,n,out) saturating int16_t sums for n<=65535 with disjoint arrays. Widen each addition, clamp then narrow; handle every element including tails. Empty input succeeds without dereferencing arrays, invalid length fails before writes. Implement an explicit-vector adapter separately and compare it against this scalar oracle.
- **T64.07:** Specify lane width, widening, alignment and disjointness. Prove the vector body and scalar tail partition [0,n), and distinguish GCC vector operators from ISO C scalar promotions.

## Failure cases

The mutant rounds n down to a four-lane boundary and leaves the tail unchanged. A benchmark using only multiples of the lane count can conceal this correctness failure.

Retain the first divergent transition and distinguish the cause from a symptom.
The named mutation control must fail for its intended reason; compilation
failure is not a successful mutation kill.
