# PR-T71-06: Stackless resumable functions with persistent explicit state

## Contract

Implement the three-value checked summation frame and a PT_BEGIN/WAIT/END version; store every value live across suspension in the frame and reserve label0 and UINT32_MAX. The full required specification is {ref}`X-T71-006` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

Available10, unavailable, available20, available30 produces60 only on the third value. UINT32_MAX followed by1 rejects without incrementing count.

## Steps

- **T71.06:** Complete D1–D4, the named public anchor, independent falsification and changed-contract implementation.

## Failure cases

Exercise unavailable input between every accepted value, overflow with unchanged state, stable `DONE` and distinct interleaved frames. Compile duplicate-label and wrong-scope proposals as diagnostic/analysis cases; reject reset-sum and unchecked-overflow mutants.

## Acceptance and evidence

- **T71.06:** Satisfy all four leaf rubrics and source-bound verification; passing supplied tests alone is insufficient.

## Hints and recovery

Mark every value read after a return. A case label resumes control, not local initialization. Persist ownership and cleanup state along with the program counter.

## Transfer challenge

Turn the sum into a cancellable framed decoder that owns a partially initialized buffer, then compose two waiting child functions. Compare the explicit subframe requirement with actual stackful fibers; delayed assessment delivers timeout and third-value notifications in both orders. Specify which event commits the terminal state and prove that the losing event cannot publish a second result or release the buffer twice.
