# PR-T69-07: Intrusive membership, initial-member recovery and external behavior

## Contract

Implement the4-item circular intrusive DSList with DSLink as the first member of DSItem. Items stay at stable addresses while linked and belong to one list. Recover a genuine item from its first-member link only after excluding the sentinel. Add a separate external operation dictionary that processes item payloads without changing the link representation. Investigate conventional arbitrary-offset container_of in an isolated compiler probe with offsetof and explicit provenance/alignment assumptions; do not claim the first-member proof establishes every extension.

The full required exercise is {ref}`X-T69-007`; its shared contracts, D1–D4, objective-specific rubric and delayed variant are part of this project. Eight hours is descriptive accounting, not a ceiling on required work.

## Inputs and expected results

Appending values1,2,3 produces sum6. Removing2 repairs both neighboring links, clears its membership and produces sum4. Duplicate insertion and repeated removal reject. Removing all items restores both sentinel links to itself.

## Steps

- **T69.07:** Implement bounded insertion/removal and checked traversal using the inspected first-member conversion rule; attach external behavior without assuming an object hierarchy. Complete every exercise deliverable, including separately specified extensions.

## Failure cases

Intrusive linkage avoids an allocation by putting lifetime and movement obligations on the payload owner. A familiar container_of macro does not establish provenance, active object type or sentinel identity. Check count and both link directions after every admitted trace of up to7 operations over four items. Test empty/singleton/head/tail/middle removal and checked-sum overflow. Retain removed objects live so rejection tests do not use ended storage. A separate diagnostic/assembly report must distinguish standard initial-member conversion from compiler-supported arbitrary-offset recovery.
