# PR-T72-02: Volcano scan/filter/group operators with pull backpressure

## Contract

Implement the fused contiguous-key nonnegative-sum query, an unfused scan/filter/group operator chain and a bounded push adapter with identical error and order contracts. The full required specification is {ref}`X-T72-002` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

Rows(1,-1),(1,3),(1,4),(2,-8),(3,5),(4,6) produce(1,7),(3,5),(4,6). A first next stops at index3 and cannot consume group3.

## Steps

- **T72.02:** Complete D1–D4, the named public anchor, independent falsification and changed-contract implementation.

## Failure cases

Compare all short key/value streams against an independent grouping oracle, including negative-only groups, overflow, repeated keys separated by another group, early close and output canaries. Reject negative-value inclusion and consuming-later-groups mutants.

## Acceptance and evidence

- **T72.02:** Satisfy all four leaf rubrics and source-bound verification; passing supplied tests alone is insufficient.

## Hints and recovery

A group boundary is determined by input keys before filtering. Keep a temporary index until the group sum is admitted. An ordering operator changes storage needs even when its next signature looks identical.

## Transfer challenge
