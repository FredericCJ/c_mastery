# PR-T22-03: Foreign consumer and dependency provenance

## Contract

Expose a narrow C ABI with explicit buffer lengths, encoding, ownership and release pairing, then consume it from a separately written Python ctypes harness. Document supported version/layout boundaries and negative version-skew behavior. Produce a pinned direct/transitive dependency and license ledger, distinguishing original implementation from reused source and comparison oracles.

The declared profile **A** applies to the boundary named here; specify harness versus component dependencies in {ref}`guide-profiles`. Budget 10 h for implementation and verification together. Start from your own sources and the listed fixtures, with prior modules as prerequisites; no starter repository or solved program is required.

## Inputs and expected results

The fixture transfer ledger creates resource X under allocator lib, borrows it to client, then attempts release with allocator client before correct release lib. Expected mismatch occurs at event 2 and final live set is empty. The policy forbids cross-allocator release, independent of whether one machine happens to share a heap implementation.

## Failure cases

Never infer calling convention or return width from a successful nominal foreign call. Reject incompatible interface versions. Borrowed buffers are not released by the client. Missing license/provenance information blocks a distribution claim but can remain a documented research gap.

## Acceptance and evidence

Submit independent FFI commands/tests, ABI/ownership table, version-skew evidence and dependency/license inventory. Show exactly which source is reused and which mechanism is independently authored. Do not claim legal compatibility from popularity or a top-level label alone.

Record contract, build/dependency evidence, independent cases, minimized failures and the specific evidence file for every linked objective. A passing synthetic oracle does not establish a passing implementation. Use {ref}`guide-assessment` for the review gate.
