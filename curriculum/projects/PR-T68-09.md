# PR-T68-09: A bounded hygienic token expander written in C

## Contract

Implement mp_expand for at most32template tokens. kind0 is a literal token whose context is retained;kind1 substitutes argument indexsymbol and preserves the argument token completely;kind2 is an introduced binding/reference token whose symbol is retained but context becomes one fresh expansion context. Validate kinds, argument indices, capacity and context exhaustion before publishing output/used or incrementing next_context. Context0 andUINT_MAX are rejected; all supplied objects are disjoint and live. This bounded token model does not parse C or implement the complete Rust macro grammar.

The full required exercise {ref}`X-T68-009`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Pattern[introduced7,arg0,introduced7],argument(symbol7,context5),next12 producescontexts12,5,12 andnext13. ExhaustedUINT_MAX, insufficient output capacity or bad argument index leaves state unchanged.

## Steps

- **T68.09:** Define identifier equality as(symbol,context), track binding/reference identities through an expansion, and show how call-site symbol7/context5 remains distinct from introducedsymbol7/context12. Explain nested expansion context retention and finite namespace exhaustion. Compare the inspected Rust mixed-site hygiene rules precisely; the model uses an explicit stronger uniform context scheme for introduced names. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run metaprog.hygiene and compare against an independent token/context transformer. Kill retagged-call-site-argument and wrapping-context mutants. Build a tiny environment resolver to demonstrate harmless capture: the flawed output resolves the argument to the introduced synthetic binding instead of its caller binding. Retain corrected and flawed token traces.

## Acceptance and evidence

- **T68.09:** Explain variable capture using symbol identity plus syntax context, and distinguish preserving call-site argument context from assigning a fresh context to introduced bindings. Every leaf has a separate rubric criterion in X-T68-009. Public test passage alone does not assess independent understanding.

## Hints and recovery

Compare identifiers as pairs, not strings alone. Then Do not give substituted caller tokens the new expansion context. Record the failed hypothesis before using further hints.

## Transfer challenge

Add nested macros, repetition with equal-length metavariables and a depth/token expansion budget. Specify intentional capture escapes explicitly, prove budget consumption, and distinguish nontermination prevention from complete macro-language equivalence.
