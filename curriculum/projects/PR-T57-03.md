# PR-T57-03: Reference acquisition before handoff

## Contract

Implement kl_ref with op0 acquire and op1 release for a live KLRef initialized to {1,0}. Reject unknown operations, zero/dead acquisition and UINT_MAX overflow; reject repeated release. Last release sets dead exactly once. Failed transitions preserve the struct. Map each transition to kref_init/get/put and protected lookup in the VM adapter.

## Steps

- **T57.03:** A count protects an object only if the operation accessing the count already has a lifetime guarantee. Starting work and incrementing afterward permits the worker to consume the last reference first. Protected lookup needs both table serialization and successful reference acquisition.
