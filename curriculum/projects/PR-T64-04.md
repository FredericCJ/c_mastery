## Steps

- **T64.04:** Small terms can disappear when added to a much larger partial sum. Neumaier compensation retains an estimate of that lost contribution, but depends on a particular arithmetic model and does not solve ill-conditioned data in general.
- **T64.04:** Implement ns_sum(a,n,out) using Neumaier compensated summation in the supplied order. Accept n<=65535 and finite inputs; reject any nonfinite intermediate or final result without modifying out. Empty input returns0. Assume binary64 and ordinary non-reassociated operations, and record these assumptions explicitly.
- **T64.04:** Derive the correction for each magnitude ordering and identify every rounding point. Compare naive, compensated and exact-rational reference results without claiming a universal relative-error bound near a zero sum.

## Failure cases
