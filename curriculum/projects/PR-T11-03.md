## Contract

Implement byte copy, overlap-safe move, set and unsigned-byte lexicographic comparison in an independent component. The copy API rejects or excludes overlap explicitly; move has snapshot semantics. No memcpy/memmove/memset/memcmp or equivalent external C-library calls may implement the target. Check optimized objects for accidental self-recursive helper emission; a hosted oracle is allowed outside the component.
