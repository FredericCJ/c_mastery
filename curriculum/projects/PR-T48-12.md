# PR-T48-12: One portable VM core inside a user process

## Contract

Porting means changing adapters while retaining the VM relation and bytecode. The kernel never interprets VM object references or accepts native addresses from bytecode. Its user process owns Cvm and program storage, supplies a bounded numeric callback and preserves separate instruction and host-call budgets.

This 10-hour milestone includes implementation and verification. Reading, assessment and delayed retrieval are in the module budget. Reuse accepted prerequisites; implement the studied mechanism in the learner workspace.

## Inputs and expected results

Use `fixtures/kernel/PR-T48-12.json` for the declared finite calculation and `labs/kernel` for actual C/guest controls. Static arithmetic does not close the executable gate. The relevant CTest names are `kernel_runtime`. For early projects 03–10, a full kernel_guest run is a later cumulative regression: the immediate component dossier must include the project-local trace specified below; the full run cannot be claimed until its later dependencies exist. The first project uses only kernel_boot_smoke and stops after the actual C-entry serial marker. Cross-family projects explicitly enable the original runtime/store source paths; a standalone kernel pass is insufficient.

## Steps

Link the original T46 core into a freestanding ELF, audit compiler helpers and user stack usage, then execute a hand-encoded CVM1 program. Keep the hosted compiler outside this guest milestone.

Keep the contract, pre-run prediction, exact image/build identity, raw observation and first invalid transition. Reveal hints in `labs/kernel/HINTS.md` in stages. The default stubs compile but fail; selecting an assessor solution changes the evidence category.

## Failure cases

Duplicated interpreter, silently linked libc, missing stack budget, arbitrary FFI pointer, failed callback returned as successful VM execution and an exhausted host budget ignored.

## Acceptance and evidence

Actual ring-3 execution computes 42 through a bounded callback and independently returns CVM_HOST_BUDGET with zero callback allowance. Record the shared source identity.
