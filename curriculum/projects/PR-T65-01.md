# PR-T65-01: Optional and Result representations without fictitious layout guarantees

## Contract

Implement er_ok, er_error, er_optional_pack and er_optional_unpack. The optional encoding is a uint32_t: zero means absence; a present zero is unrepresentable and must return ER_RANGE without changing the output. present is exactly 0 or 1. Absence ignores value and stores zero. All nonzero uint32_t values are representable. A result tag selects value or error offset as defined by the shared contract. Reject an unknown tag before interpreting a payload. Also implement a separate fully tagged optional representation that can represent present zero, and compare its contract and layout with the niche encoding.

The full required exercise is {ref}`X-T65-001`. Its explicit shared contract, four deliverables, objective rubric, source inspections and delayed variant are part of this project. Eight hours is descriptive author accounting, not a study deadline or scope ceiling.

## Inputs and expected results

Packing (value=0,present=1) into an output initially 91 rejects with 91 unchanged; (17,0) stores zero; UINT32_MAX is a valid present value. Unpacking zero produces ER_ABSENT. The full tagged alternative must distinguish absent from present zero.

## Steps

- **T65.01:** Implement total constructors and checked accessors while preserving output on rejected niche construction; do not copy uninitialized union members or compare padding. Complete the exercise D1–D4 and preserve prior artifact contracts.
