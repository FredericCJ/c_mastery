# PR-T58-07: Privilege-aware memory access

## Contract

Implement po_access(user_page,supervisor,sum,mxr,r,w,x,operation), with boolean flags and op0 read,1 write,2 execute. User execution rejects supervisor-only pages. Supervisor execution always rejects user pages; supervisor reads/writes user pages require sum. Read requires r or mxr&&x; write requires w; execute requires x. This models the inspected supervisor access to user memory (`SUM`) and executable-page readability (`MXR`) controls, not a complete page walk.
