# PR-T76-02: Command–query responsibility segregation projection admission and atomic position advancement

## Contract

Implement RPProjection with sixteen retained applied events, a contiguous count and int64 total of int32 event values. Admit positions1..16 in order. A byte-independent semantic duplicate (same position,key,value) succeeds without mutation; conflicting payload at an old position returns RP_CONFLICT; a gap returns RP_GAP. Publish total, retained event and cursor as one serialized transition. Supplied pthread adapter holds one mutex across this entire call; two threads each deliver the same ordered1..16 stream.

The full required exercise {ref}`X-T76-002`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

Apply(1,0,7) twice yields total7,count1. Reuse position1 with8 conflicts; position3 before2 is a gap. Two synchronized threads each delivering values1..16 yield count16,total136;128 fresh concurrent runs test the adapter.

## Steps

- **T76.02:** Prove the invariant count=k implies exactly the first k events contributed once and applied[i].position=i+1. A 16-term int32 sum fits int64 on the declared target. Retain history for conflict checks rather than trusting a reused position from a new log. The caller must associate a projection with one log identity. Explain why a mutex around cursor alone is insufficient, and why an external email/file effect cannot become atomic with this state by naming it command–query responsibility segregation. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run replicated.projection, including actual pthread schedules under GCC TSan when available. Kill duplicate-reapplication and gap-acceptance mutants with semantic assertions. Record mutex boundaries and model process termination between query-state and cursor persistence. A TSan pass observes these executions only; it does not certify arbitrary effects or all schedules.

## Acceptance and evidence

- **T76.02:** Separate query-model choice from delivery semantics. Establish exactly-once application only within one serialized projection and one retained immutable log identity; reject the stronger claim of exactly-once external effects. Every leaf has a separate rubric criterion in X-T76-002. Public test passage alone does not assess independent understanding.

## Hints and recovery

Write the prefix invariant before choosing a cursor type. Then A duplicate must refer to the same event, not only the same integer. Record the failed hypothesis before using further hints.

## Transfer challenge

Add a durable inbox/outbox with log UUID and idempotency keys using storage.pages and ipc.local. Enumerate process-termination and retry points on both sides of a local synthetic receiver. Produce one duplicate-side-effect counterexample without receiver deduplication and show the residual requirement for atomic receiver state. Compare rebuildable read models with authoritative event history.
