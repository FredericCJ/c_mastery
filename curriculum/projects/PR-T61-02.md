# PR-T61-02: Loop invariants and binary-search termination

## Contract

Implement vf_lower_bound on a sorted nondecreasing uint32_t array, returning the first index with value>=key or n. Use half-open[lo,hi), calculate midpoint without overflow and retain O(log n) comparisons. Empty input permits a null array. Establish sortedness as a precondition, not a fact proved by a search test.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable

## Failure cases

A <= comparison implements upper_bound, which passes unique-key examples. An incorrect midpoint update can also loop forever on a singleton interval.

Retain the first divergent transition and distinguish the cause from a symptom.
The named mutation control must fail for its intended reason; compilation
failure is not a successful mutation kill.
