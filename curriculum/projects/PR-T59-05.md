# PR-T59-05: Redundant journal and torn commit records

## Contract

Implement lc_journal_select over two LCJournal records. A valid record has commit0xa5 and `check == (seq ^ value ^ 0x5a5a5a5a)`. Select the valid record with greatest nonwrapping seq; equal valid seq with unequal values is ambiguous and rejects. Return selected index through output only on success. Sequence exhaustion requires a migration policy, not wraparound.
