# PR-T65-07: Arithmetic policy and serial-number partial order

## Contract

Implement er_add16 over uint32_t inputs constrained to0–65535. Checked overflow returns ER_RANGE with output unchanged; wrapping returns the mathematical sum modulo65536; saturating returns min(sum,65535). Reject other inputs or policies. Implement er_serial16(a,b,order): equal gives0, forward distance in1–32767 gives1, distance32769–65535 gives-1; exact half-range32768 is ambiguous and returns ER_RANGE without changing order. This relation is not a total transitive ordering over unrestricted populations. Use no signed overflow or out-of-range signed conversion.
