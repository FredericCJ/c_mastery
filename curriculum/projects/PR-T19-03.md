# PR-T19-03: Pure state strategies and two traversal styles

## Contract

Implement a small pure state machine with effects returned as data, plus a fixed-capacity collection traversable by cursor and callback. Compare switch/table state dispatch and an injected runtime strategy with a static alternative. Both traversal styles must have explicit order, early-stop and mutation invalidation.

## Failure cases

Unknown events and stale iterators must not index tables or access invalid elements. A callback cannot silently mutate during a traversal that forbids it. End state is distinct from an error, and early stop is not treated as failure.
