## Contract

Implement one passive connection on 8080 with MSS 256 and checked options. Use exact tuple/header/checksum/window validation, modulo 2^32 predicates with live spans<2^31 and SYN/FIN consumption of one sequence number. A pure ACK consumes none. Reject ACK beyond SND.NXT before releasing any output; guard accepted window updates with SND.WL1/WL2.

Accept only admissible in-order bytes, trim old prefixes, ACK duplicates and drop gaps with duplicate ACK. Validate FIN's position before consuming it. Exact-RCV.NXT RST aborts; unequal in-window RST produces a challenge ACK, outside-window drops. Trace all declared passive/close states and 240 s TIME-WAIT, including repeated FIN timer restart. No active/simultaneous open, arbitrary reordering queue, urgent processing or general-host conformance is claimed.

## Inputs and expected results

The fixture starts peer SYN 0xfffffff0/localISN 1000. Sixteen bytes at 0xfffffff1 advance RCV.NXT to 1; identical repeat adds none. Twelve bytes at 0xfffffff9 contain an eight-byte old prefix and four new bytes, advancing to 5. A gap is dropped, unsent ACK 1002 when SND.NXT 1001 is rejected, and FIN at 5 advances to 6/CLOSE-WAIT. Local FIN 1001 and matching ACK 1002 complete LAST-ACK.

Expected accepted stream is the 20 octets abcdefghijklmnopqrst, with exact ACK/state list. Additional close/reset table covers simultaneous close, TIME-WAIT/repeated FIN and reset categories. Window guards use the same modular ordering: with WL1=WL2=0xfffffff0, updates (seq=0x10, ack=0xfffffff0) and (seq=0xfffffff0, ack=0x10) are both newer and accepted under the declared half-range assumption.

## Steps

2. Next 4 h: derive circular intervals and run duplicate/overlap/gap/unsent-ACK traces, including stale window update guards and 512-byte capacity.

4. Collect actual handshake/data/close packets from an independent client. Test a split/coalesced stream that crosses the sequence wrap in host fixtures; physical ISNs use recorded isolated-lab incarnation policy.

5. Inspect the state ledger against the selected RFC9293 branches and maintain an omitted-event matrix.

## Failure cases

Malformed option length, bad checksum/tuple/header, urgent/SYN-data subset exclusions, ACK of unsent bytes, out-of-window content and stale window updates have no unauthorized publication/free. Trimming duplicates cannot trim new tail bytes or count FIN twice. An RST is abort, not EOF; a local reset must flush owned queues without falsely acknowledging application delivery.
