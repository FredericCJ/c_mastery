# PR-T12-03: Allocation adapter and strict conversion parser

## Contract

Build a small allocation adapter with injected failure and a line-oriented strict decimal parser. Use nonzero resize plus explicit release for an empty object. The parser separates tokenization, numeric conversion, trailing-data policy and application range; compare its clarity with one width-bounded scanf example.

The declared profile **A** applies to the boundary named here; specify harness versus component dependencies in {ref}`guide-profiles`. Budget 10 h for implementation and verification together. Start from your own sources and the listed fixtures, with prior modules as prerequisites; no starter repository or solved program is required.

## Inputs and expected results

The fixture tokens are 0, -12, 12x, an empty token and 999 with range -128..127. Expected statuses are ok, ok, invalid, invalid and range. Valid values are 0 and -12; no partial output is published for the other tokens. The grammar intentionally uses ASCII decimal and does not import C23 binary-prefix behavior.
