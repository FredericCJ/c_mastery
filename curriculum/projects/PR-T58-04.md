# PR-T58-04: Owned context images

## Contract

Implement po_save(dst,arch,registers) copying only po_saved registers into a zero-filled32-slot image; reject arch>1 before mutation. po_restore validates image arch equals requested arch and copies only saved slots into a live register model, preserving others. Destination/source are disjoint. Extend assembly context switches using the same documented offsets.

Shared requirements: [B06 exercise contract](../v5/contracts/b06.md). Stable
unit IDs are `LAB-PO-04A` and `LAB-PO-04B`. Families: A, B, C, D, F, G, I, J;
source records: R-B06-RVABI, R-B06-AA64, R-B06-RVISA, R-B06-RVPRIV in
`research/v5/b06_resources.json`, using only its inspected locators.

Prerequisite knowledge: Reconstruct an x86 call frame and an original linker map. Derive aligned downward stack growth without unsigned underflow. Explain why a C function-call save set is insufficient for an asynchronous trap.
Prerequisite learner artifacts: the source, contract argument and recorded
assessment of PR-T58-03. Keep these artifacts and
their evidence identities in D1; reading or copying their assessor solution
does not satisfy the prerequisite. Use the already accepted artifact interface
where integration is assigned; do not substitute a library for this mechanism.
Target-specific supplied materials are in `labs/architecture_ports/targets/` and remain
subject to the named outstanding evidence requirements.

## Steps

- **T58.04:** A context image is an owned snapshot of a defined machine-state set. Copying arbitrary register bytes is not sufficient if the architecture tag, stack lifetime or asynchronous state differs. Its representation must reject cross-architecture restoration.
- **T58.04:** Implement po_save(dst,arch,registers) copying only po_saved registers into a zero-filled32-slot image; reject arch>1 before mutation. po_restore validates image arch equals requested arch and copies only saved slots into a live register model, preserving others. Destination/source are disjoint. Extend assembly context switches using the same documented offsets.
- **T58.04:** Prove a save/restore preserves exactly the declared set and leaves nonowned registers untouched. State stack ownership, resume-address validity and exclusion of asynchronous FP/trap state.

## Failure cases

Repair restoration of an RISC-V image as Arm by rejecting mismatched tags before any register mutation. A C struct size match does not establish semantic compatibility.

Retain the first divergent transition and distinguish the cause from a symptom.

failure is not a successful mutation kill.
