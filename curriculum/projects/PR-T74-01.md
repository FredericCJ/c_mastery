# PR-T74-01: Pointer tags, NaN payloads and representation trust boundaries

## Contract

Implement numeric NaN canonicalization, int32 boxing/unboxing and checked two-bit pointer tags from the exact contract. Build a discriminated-union alternative and a character-copy double bridge with verified format assumptions; never truncate a pointer into a payload. The full required specification is {ref}`X-T74-001` and its explicit shared contract. Twelve hours is descriptive author accounting, never a ceiling.

## Inputs and expected results

0x7ff9000000000042 as numeric input canonicalizes to0x7ff8000000000000; int32 minimum round-trips as -2147483648; negative zero remains0x8000000000000000. A low-bit-misaligned pointer rejects without changing output.

## Steps

- **T74.01:** Complete D1–D4, the named public anchor, independent falsification and changed-contract implementation.

## Failure cases

Enumerate signed extrema and NaN payload collisions, signed zero, infinities, misaligned integer mappings and reserved bits. Reject missing-canonicalization and sign-loss mutants; compare integer decoding with Python integers and verify native pointer round trips only for admitted live objects.

## Acceptance and evidence

- **T74.01:** Satisfy all four leaf rubrics and source-bound verification; passing supplied tests alone is insufficient.

## Hints and recovery

Separate a numerical encoding from an actual C double object. Restore the exact original integer pointer representation before conversion back. Alignment is not a universal grant of unused address bits.

## Transfer challenge

Change to a capability-pointer target or a binary32-only implementation: derive an explicit handle representation and revise every pointer/NaN assumption. Delayed assessment introduces a serialized attacker-controlled NaN word; demonstrate why decoding it cannot authorize a host pointer.
