# PR-T76-07: Merkle commitments and bounded anti-entropy

## Contract

Implement local SHA-256 for byte lengths0..65 directly from RFC6234 equations, and RFC9162-style Merkle roots over0..8 uint32 leaves encoded big-endian. Empty root is SHA256(empty), leaf is SHA256(00||four bytes), internal node is SHA256(01||left||right), split at largest power of two strictly below count. Implement recursive equal-subtree skipping and return a bitmask of differing leaf positions for equal-length trees. No target hash library, network service or certificate-transparency implementation may replace these mechanisms.

The full required exercise {ref}`X-T76-007`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

SHA256(empty)=e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855. Trees[1,2,3] and[1,2,9] differ only at bit2 (mask4); empty trees give mask0. Compare every count0..8 with a separately implemented Python hashlib construction.

## Steps

- **T76.07:** Derive padding across55/56/63/64/65-byte boundaries, uint32 modular arithmetic, round constants and endian conversion. Prove the tree shape for non-power-of-two counts and that a subtree comparison is meaningful only with the same position/range/domain. Account for hash collision and corrupt-peer assumptions; a matching root alone authenticates no sender and guarantees no retrievability. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run replicated.merkle, standard empty/abc hash vectors, all padding boundaries and independent randomized hashlib differential cases. Kill omitted leaf-domain prefix and ignored right-child mutants. Inspect the generated code for the intended unsigned operations; benchmark nodes hashed versus full leaf comparison under equal correctness/security contracts.

## Acceptance and evidence

- **T76.07:** Derive a domain-separated Merkle root for an exact ordered leaf sequence, distinguishing hash equality under a collision assumption from identity authentication, availability or a proof that arbitrary bytes are well formed. Every leaf has a separate rubric criterion in X-T76-007. Public test passage alone does not assess independent understanding.

## Transfer challenge

Add inclusion proofs with explicit leaf index/count, verify malformed/truncated/extra paths, then implement anti-entropy over a synthetic local framed transport. Vary chunking and domain identifiers and show root incompatibility. Model a malicious peer returning a missing or inconsistent node; fail without publishing partial repaired state. Do not claim collision resistance from a finite test suite.
