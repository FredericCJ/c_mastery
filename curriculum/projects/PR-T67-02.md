# PR-T67-02: Newtypes and checked dimensional conversions

## Contract

Implement ad_milliseconds(ADSeconds,ADMillis*). Conversion succeeds exactly for seconds<=UINT32_MAX/1000, with exact multiplication and unchanged output otherwise. Separate nominal dimensional distinction from runtime range validation. Add diagnostic probes for passing ADMillis to the ADSeconds parameter and for the unsafe typedef-only alternative.

The full required exercise {ref}`X-T67-002`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

42seconds becomes42000milliseconds;4294967seconds becomes4294967000;4294968seconds fails without modifying output;zero succeeds.

## Steps

- **T67.02:** Derive the division-before-multiplication admission test and show that the largest accepted seconds value maps below UINT32_MAX. Compare the inspected C++ duration_cast ratio formulas; static_cast or a distinct duration type does not itself establish arbitrary destination representability. Specify round/truncate behavior before adding fractional units. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.quantities and reject wrong nominal type in a separate compilation. Kill missing-range-check and wrong-scale mutants, then test both sides of the quotient boundary. Show an explicit cast or field extraction bypass and identify programmer discipline rather than claim unforgeability.

## Acceptance and evidence

- **T67.02:** Explain why two distinct struct wrapper types reject accidental argument substitution while two typedef names for uint32_t do not; derive the exact safe seconds-to-milliseconds domain. Every leaf has a separate rubric criterion in X-T67-002. Public test passage alone does not assess independent understanding.

## Hints and recovery

Separate unit identity from numeric range. Then Rearrange x*1000<=MAX before computing the product. Record the failed hypothesis before using further hints.

## Transfer challenge

Introduce signed microseconds and rational tick periods with a nonintegral ratio. Implement checked conversion with explicit rounding toward zero and a loss-of-precision result; derive bounds without a wider integer type.
