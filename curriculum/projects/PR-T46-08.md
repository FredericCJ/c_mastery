# PR-T46-08: Nonmoving mark-sweep and temporary roots

## Contract

The root set consists of live operand-stack values, initialized locals in live frames and an explicit host/temporary-root stack. Marking visits each object at most once, so cycles do not require recursive C calls. Sweep begins only after complete marking and a reserved sweep budget; a budget failure cannot free an object that marking did not finish examining. The critical allocation experiment fills the heap, keeps a child only in a C temporary, then constructs its parent. cvm_pair must temporarily root both operands before collection. A returned object held outside the VM must be pushed as a root before a subsequent allocation can collect it.
