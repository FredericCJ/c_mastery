# PR-T46-09: Guest, collection and host budgets

## Contract

Guest fuel counts dispatched instructions, GC budget counts root/edge inspections and the fixed sweep pass, and host budget counts callback invocations. The ledgers are independent: an infinite loop consumes fuel while leaving host and GC budgets unchanged if it performs neither activity. These units are educational accounting, not CPU cycles or wall-clock deadlines. Verification and compilation have their own finite size bounds. The embedding adapter must bound blocking work separately and cannot reenter the same VM from a callback. Resource refusal is a supported result and does not demonstrate application correctness. Introduce a supplied finite identity/error callback and the hand-encoded HOST opcode here to count invocation and refusal. The next checkpoint owns store embedding, I/O policy and uncertain commit outcomes.
