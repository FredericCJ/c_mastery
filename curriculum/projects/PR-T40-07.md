## Contract

Implement L6 schema 1, ascending unique tag/length/value fields and at most 80 octets. Tags 1–5 encode verb u8, request ID big-endian u16, signed big-endian two's-complement centidegrees value, unit u8 and optional UTF-8 label of at most 16 octets. Every record needs verb/request ID; SET and REPLY need value/unit 1. GET need not carry them. ERROR may report retained setpoint/unit 1. Unknown tags are rejected.

Validate all syntax/required fields, exact lengths, integer representation, unit and canonical UTF-8 before publishing a typed record. Use staged output so failure preserves sentinels. Label is display data and never a format string or routing authority.

## Inputs and expected results

The fixture encodes SET request 42, value -4000 and unit 1. Its exact presentation wire hex is independently reconstructed; signed bytes are f0 60. Invalid cases include duplicate/out-of-order tag, wrong field length, missing unit, truncated TLV, overlong UTF-8, surrogate encoding and schema mismatch.

Output exact wire bytes or a typed staged value plus deterministic error category. Distinguish representable 12501 from application's disallowed setpoint: L6 can represent it, while L7 rejects its effect.

## Steps

1. Derive the canonical 15-octet SET record by hand; do not copy a native struct.

2. Implement checked encoder capacity and staged decoder with all required-field checks.

3. Decode negative values with unsigned intermediates and explicit representable conversion. Test -32768, 32767 and the application boundaries separately.

4. Validate UTF-8 across each split of a multibyte label; reject overlong, surrogate and >U+10FFFF sequences before publication.

5. Compare outputs with the independent fixture and integrate one encoded record through session/transport without giving presentation access to route/token state.

## Failure cases

Truncation, duplicate/out-of-order or unknown tag, wrong known-field length, missing required tag, invalid unit/schema, label over 16 octets and malformed UTF-8 leave output unchanged. Encoder insufficient capacity writes no partial record under the selected staging contract. A decoded out-of-application-range integer is not silently clamped or applied.

## Acceptance and evidence

Retain exact encode/decode round trips, negative-value derivation, invalid-case sentinels and UTF-8 byte-count/split evidence. For the objectives show representation portability, validated publication and separation of presentation from routing/session/application authority. Measure serialized bytes, not sizeof a host struct. Integrate on the bench only after finite representation tests pass.

## Hints and recovery

If a negative value differs by 65536, inspect signed conversion and byte order. If labels work only unsplit, keep bounded incremental state or decode after complete L6 SDU rather than treating callback boundaries as code points. Do not repair malformed input by replacing characters under a canonical-wire contract.

## Transfer challenge

Replace ASCII label with a legal multibyte label near 16 octets. Predict packet/fragment lengths and explain why the numeric unit remains unchanged even if the display language changes.
