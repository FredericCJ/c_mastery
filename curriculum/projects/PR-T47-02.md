# PR-T47-02: A bounded clean page cache

## Contract

Implement read-through caching of four pages and instrumentation for backend reads, writes, flushes and cache hits. Show one repeated lookup served from cache, then an aliasing page that evicts the entry. After committing a changed value, verify that a lookup cannot read the earlier generation from an old cache slot.

Budget 4 implementation and 2 verification hours. Reuse the same engine throughout; previous milestones are not charged again. The public API and original disk format are in the storage laboratory.

## Inputs and expected results

Use [the contract fixture](../../fixtures/storage/PR-T47-02.json) and the actual C tests `storage.cache`. The image has 67 pages of 4096 bytes; the tree owns 32 logical data pages. The reference transaction changes the complete map from {1:10,2:20} to {1:11,3:30}. Compare whole maps. No fixture asserts physical power-cut durability.

## Progressive execution

The immediate learner gate is `storage.cache`. Early tests inject declared valid component states; they do not require a completed opener, recovery engine or later mutation API. Defer `storage.corruption` until PR-T47-09/10 integrates opening, durable publication and recovery. ## Failure cases

Omit publication invalidation and construct a stale-value counterexample. Inject a read failure and require an error, not a hit with partially initialized bytes.

An unavailable compiler, sanitizer runtime, syscall or device produces unavailable evidence; it never counts as a clean run. A wrong implementation must fail a semantic assertion after successful setup.

## Hints and recovery

A cache hit means the requested physical page and the cached identity agree, not merely that two logical IDs collide in a slot. The four-entry direct-mapped cache retains only clean bytes. Transaction scratch owns dirty nodes separately. Publication switches reads from home to redo images; checkpoint switches them back. Both transitions invalidate cache entries. Count backend reads and hits rather than calling a warm run evidence of faster storage hardware. Bound cache memory as four full pages plus tags, independently of the transaction workspace.

The staged laboratory hints separate invariant, observation and repair direction. Keep the original failing image or key sequence and compare it with a clean control.
