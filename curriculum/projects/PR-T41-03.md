## Contract

Implement the selected polled F439 Ethernet driver, reusing T39's descriptor/lifetime models as design evidence. Four RX/two TX normal 16-byte descriptors use contiguous, word-aligned DMA SRAM and one 2048-byte buffer each; no CCM, enhanced format, chained mode, skip words or timestamping. RBS1=2048/RBS2=0; RER marks final RX. TBS1 is actual transmit bytes/TBS2=0; TER marks final TX.

Use store-and-forward, software checksums, CSTF=APCS=IPCO=0, no error/undersized forwarding. Normal TDES0 controls are rebuilt on every reuse; OWN is published last after required ordering. RX exposes FL-4 bytes only with OWN clear, FS+LS, no ES/DE and FL 64..1518. MAC pads and appends TX CRC; preamble/SFD are not user packet bytes.

## Inputs and expected results

Fixture statuses cover DMA-owned, valid 64/1518, partial, error, descriptor-error and overrange frames. Valid64 exposes 60 bytes, valid 1518 exposes 1514. The ring/buffer cost is 12384 bytes. Independent bit arithmetic derives last TX control mask and validates configured normal-ring size; snapshots deliberately show writeback-cleared control bits.

Outputs are frame spans, completion/error events, ring indices, counters and register/ownership logs. A synthetic descriptor oracle does not establish a functioning target driver.

## Steps

1. First 4 h: prove map-file addresses are reachable, initialize reset/clocks/filter/MAC mode, stopped list bases and normal ring metadata. Use exact inspected register descriptions, including address 0 octet ordering.
2. Build a host side-effect model for OWN/control writeback, W1C status and poll demand. Reject premature reuse.
3. Remaining 6 h: implement target RX/TX and wrap both rings repeatedly. Keep retransmission copy ownership separate from DMA-buffer reuse.
4. Rebuild FS/LS/IC/TER on reused TDES0, then publish OWN with target ordering. Refill suspended RX before poll demand; transmit demand follows new ownership.
5. Exercise ring-full, consumer delay, unavailable-buffer status, failed completion and bounded reset/stop. Fatal bus error stops service and reports its snapshot.

## Failure cases

Wrong SRAM/unaligned descriptor, CPU payload read with OWN set, absent FS/LS, ES/DE, invalid FL, double CRC subtraction, reused control bits lost, ring-full and unknown W1C bits all fail deterministically. Configure list bases only stopped. Fatal error cannot be recovered by merely acknowledging status while continuing corrupted queues.

## Acceptance and evidence

Submit build-map memory proof, exact initialization/register table, all ownership traces and real repeated ring wrap/reuse plus external frame capture. For the objectives show initialization/reachability, publication/reclaim/error checks and exact length/recovery. Root's source ledger identifies the generic IC reference conflict; use the actual normal TDES0 detail, not a guessed TDES1 bit. Host-only results leave hardware evidence open.

## Hints and recovery

If the first TX works but reuse fails, inspect writeback reset of TDES0 controls. If payload is four bytes short, audit both hardware strip bits and software subtraction. If RX stalls, restore ownership before issuing poll demand; do not write every status bit as a blind reset.

## Transfer challenge

Temporarily hold one RX consumer span and predict remaining ring capacity. Explain why switching to timestamps, enhanced descriptors or a cached MCU requires a different memory/descriptor contract and inspected source scope.

For this milestone, retain three separately labeled evidence items:

- **T41.03.a:** Initialize bounded RX/TX rings in DMA-accessible memory using the selected actual controller contract.
- **T41.03.b:** Publish/reclaim descriptor and frame ownership with ordering, first/last and error checks.
- **T41.03.c:** Calculate the exposed frame length with padding and CRC handled exactly once and recover from unavailable buffers.
