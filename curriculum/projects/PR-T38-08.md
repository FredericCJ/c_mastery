## Contract

Implement `rs485_byte_channel_v1`: enqueue up to 16TX bytes with a caller token, accept/copy at most 16RX bytes into fixed storage, and emit byte, framing_error, overrun, tx_done, aborted and unavailable events. Return busy/accepted/consumed counts and explicit backpressure. The channel supplies no record delimiter, address or retry protocol. One transaction/driver at a time; callbacks cannot retain borrowed input, allocate or reenter. Reuse the UART adapter and a short two-node THVD1410-class prepared bus; peer scheduling is explicit.

This 10-hour milestone includes implementation and verification. The module budgets reading, assessment and delayed consolidation separately. Apply profile E under {ref}`guide-profiles`: fixed caller storage and explicit component/image dependencies. A hosted harness may print/use library oracles; that permission does not extend to the studied component or target image.

The fixture has two 8N1 bytes at 100 kbaud, DE assert 0,600 ns enabled-receiver startup,200 ns disable and 2 µs guard. ## Steps

1. Define IDLE→ENABLING→TX→WAIT_TC→DISABLING→RX_READY states and token/abort ownership. Derive delay rounding for the actual timer.
2. Implement event/capacity handling with final-TC completion and confirmed stop before abort returns ownership.
3. Replay early release, overlap and RX overflow; use synthetic traces for forbidden active-driver overlap.
4. Record actual termination, bias/failsafe, load, reference and transceiver enabled/shutdown mode. Capture DE, UART TX and differential waveform for a scheduled two-node exchange.
5. Export the byte/event header, resource bounds and measured physical receipt to T40; keep application framing outside this channel.

## Failure cases

Premature DE release, simultaneous drivers, shutdown wake delay mistaken for ordinary enable delay, capacity overflow, stale token completion and unconfirmed DMA abort. On unknown device-stop state report unavailable and retain ownership until reset/stop is confirmed. A timeout cannot manufacture tx_done.

## Hints and recovery
