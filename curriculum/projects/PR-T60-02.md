# PR-T60-02: Precedence parser and bounded syntax construction

## Contract

Implement cc_parse from the declared expression grammar, generating postfix `CONST`/`ARG`/`ADD`/`MUL` followed by `RET`. Multiplication binds tighter than addition; parentheses override. Limit nesting to16 and intermediate representation capacity to caller storage. On failure used remains unchanged; partially written intermediate representation scratch is unspecified and must never be executed. Reject every unconsumed nonspace byte.
