## Inputs and expected results

[The synthetic fixture](../../fixtures/performance/PR-T43-03.json) executes 100 instructions at model CPI 1, 40 at 2 and 20 at 4. Thus IC=160, cycles=260, weighted CPI=1.625. At 100 MHz, one cycle is 10 ns and modeled time is 2600 ns.

Both connected function graphs have six nodes and seven edges, so v=e−n+2=3. Their declared sequential versus nested bodies execute 2n versus n² times: 16 versus 64 at n=8. Graph cycles are a static test/design metric. They are neither processor cycles nor an asymptotic bound. Variant B's 240 model cycles beat A's 260, but B's 256 code bytes/96 retained bytes exceed limits 200/80. A's 128/64 fit.

## Steps

1. Take one accepted assembly path and count actual executed instructions from a trace. Record ISA, ABI, input, build and taken branches; a disassembly listing alone is not an executed count.

2. Recompute the fixture's weighted model with units. Contrast it with the accepted native or silicon measurement, including an observed residual and possible working-set effect. Calculate a bounded Amdahl estimate with a declared affected fraction; label it a model.

3. Draw the two original CFGs, retain the connected-entry/exit convention, and explain their equal static v despite different loop work. Do not claim every algebraic basis path is executable.

4. Build a decision table containing model/work counts, observed time or unavailability, code bytes, retained storage, traffic and jitter evidence from later projects. Declare why energy or an event was omitted.

## Failure cases

Reject an unknown edge endpoint, disconnected node or duplicate edge in this scoped graph certificate. Unit errors such as treating 100 MHz as 100 ns per cycle fail the gate. Do not substitute an assumed one-cycle cost for a missing measurement. Mark a unsupported measurement unavailable rather than assigning zero. Static branch predicates may have infeasible combinations.

## Hints and recovery

Start with the time identity IC×CPI/f and cancel units before inserting numbers. Draw the CFG before counting edges. A same-v pair is an effective counterexample to using cyclomatic complexity as a speed predictor. If no faster variant meets the constraints, keeping the baseline is a valid decision with evidence.
