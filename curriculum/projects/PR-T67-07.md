# PR-T67-07: Recursive arena values and typed indices

## Contract

Implement ad_eval for1..32ADNodes. Kind0 is uint32 literal; kind1 adds two child indices, each strictly less than the current node index. Validate every node, even if unreachable from root. Root must be in range. Addition is mathematical uint32 with overflow rejection, output unchanged on failure. Use iterative evaluation and fixed32word scratch storage, no recursion or library graph engine.

The full required exercise {ref}`X-T67-007`, its shared contracts and objective rubric are part of this project. Eight hours is descriptive author accounting, not a learner-time or scope ceiling.

## Inputs and expected results

CONST7,CONST9,ADD(0,1),root2 yields16. A self-child2 fails. UINT32_MAX+9 fails without changing prior output.

## Steps

- **T67.07:** Prove by induction on node index that each value is available before its parent; separate index category from actual range validity. Give O(count)time/O(32)stack and compare a recursive tree that duplicates shared children. For validate-once extension, make the arena immutable or invalidate its certificate after every structural mutation. Submit the exercise D1–D4 and retain prerequisite interfaces.

## Failure cases

Run adt.arena and independent postfix/tree evaluation cases. Kill forward-reference acceptance and arithmetic-overflow omission. Add unreachable malformed nodes, multiple roots, shared children, empty and maximum count, then record stack-use output.

## Acceptance and evidence

- **T67.07:** Derive acyclicity from a topological child-index invariant and explain when a checked arena can support unchecked internal traversal without allowing later mutation to invalidate the proof. Every leaf has a separate rubric criterion in X-T67-007. Public test passage alone does not assess independent understanding.

## Hints and recovery

Ask what child values exist at iterationi. Then A typed index can still be numerically invalid. Record the failed hypothesis before using further hints.

## Transfer challenge

Support bounded cyclic graphs for a monotone dataflow analysis. Replace topological induction with a lattice/worklist convergence argument and distinguish no fixed point, insufficient iteration budget and successful convergence.
