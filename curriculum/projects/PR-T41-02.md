## Contract

Reuse T39's bounded MDIO/PHY query interface and record actual NUCLEO-F439ZI MB1137 revision, pins/bridges and fitted LAN8742A. New work is stack readiness and link-incarnation integration, with actual measured reference/link and reset/failure evidence. Configure RMII during documented reset/before ETH clocks; confirm the PHY-generated 50MHz reference and ensure MAC speed/duplex matches the fitted PHY result.

Finite original policies are 10 ms per MDIO transaction,500 ms reset and 5000 ms negotiation. Busy timeout, failed identity, incomplete/down/half-duplex result prevents readiness. Cable loss terminates the old TCP incarnation and retained sends with an abort event.

## Inputs and expected results

Fixture PHY ID 2=0x0007 and ID 3=0xc131 match0xc130 under0xfff0. Basic Status first 0x0020 and second0x0024 report historical down and current up, with negotiation bit5. Register31=0x1018 has done bit12 and speed code 110, hence100 full. HCLK 180MHz with divider 102 gives the declared MDIO clock calculation. A synthetic reset/busy deadline failure must never set READY.

Outputs include raw identity/status reads, decoded current/historical state, speed/duplex, deadlines, MAC-mode decision and incremented incarnation after a genuine new bring-up.

## Steps

1. Read the exact Rev8 board Ethernet table and inspected LAN8742A register scope. Compare actual board marking/jumpers; do not assume a newer manual's table was inspected.
2. Implement bounded query/reset/negotiation sequencing around the reused MDIO service. Keep latch-first and current-second samples separately.
3. Decode the four speed/duplex codes and allow only full-duplex readiness; set MAC DM/FES from that result.
4. Measure actual reference clock and link establishment with equipment/settings recorded. Capture MDIO/query logs and independent peer link state.
5. Remove cable, try traffic while down, reconnect and reset the board. Show old transport state is not silently continued.

## Failure cases

Invalid ID, reset never clearing, MDIO busy never clearing, missing clock, negotiation incomplete, half duplex and current down each produce a bounded not-ready result. A low first latch read is not erased from diagnostics by the second current-up read. A query fixture cannot prove a physical clock or cable exists.

## Acceptance and evidence

Retain identity/mode/deadline decode tables, two-read link witness, measured clock/link evidence and old/new incarnation records. For the three objectives show exact physical component boundaries, correct status/timeout readiness and actual board/cable observation separate from mocks. Reuse earlier MDIO evidence by link, then add these integration observations without duplicating T39 hours.
