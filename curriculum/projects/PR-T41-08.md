## Contract

Reuse the original portable T42.02–T42.05 parser/framing/chunk/serializer core, without charging those projects here again. This milestone owns the embedded stream adapter, custom-stack interoperability and physical/fault closure. Configure one connection, queue depth 1, one request, Connection: close. Preserve T42's grammar, body/chunk/trailer limits, target/Host and rejection policies. GET/HEAD /health use representation hex 6f6b0a; POST /echo returns identical bounded binary bytes.

Feed only accepted ordered TCP prefixes; retain unconsumed bytes and output offsets. ACK transport bytes retained safely independently of complete HTTP parsing. Keep response immutable for segmentation/retry, send FIN only after all response bytes are acknowledged and stop interpreting trailing optimistic requests after close/error. Configure authority 192.0.2.2:8080 for this adapter; use the hosted profile's declared loopback authority there. Change only configuration/callbacks, never disable Host or absolute-target authority validation.

## Steps

## Failure cases

TE+CL/ambiguous framing, incomplete body/chunk/trailer and parser limit violations cannot publish partial application success. Peer half-close does not complete body framing. Unsent or invalidly ACKed response bytes cannot be freed. After error/close, trailing requests are never dispatched. Link down aborts the old incarnation; a new cable link does not magically finish an old request.

## Acceptance and evidence

Retain exact shared response/adapter tests, independent real packet captures, measured PHY/RMII/driver evidence from earlier milestones and cable/reset/fault records. For the objectives show unchanged portable HTTP semantics, independent selected-protocol interoperability and actual physical/incarnation closure. A TAP/canned pcap/emulator can supply useful host evidence but cannot replace any physical gate. State full-host omissions even after the cooperative client succeeds.

## Hints and recovery

If the body loses bytes at packet edges, inspect consume counts and leftover spans before altering HTTP grammar. If final response disappears on close, wait for valid ACKs before FIN and preserve output ownership. If a host capture shows unusual checksums, record offload/capture position before blaming the wire.
