# PR-T19-04: Composable short-write stream and stable handles

## Contract

Compose a bounded framing/checksum layer with a transport that accepts short writes and can apply backpressure. Retain pending bytes in caller storage and expose partial progress. Use generation-counted slots for request identity, with an exhaustion policy, and compare direct versus table-dispatched transport costs under identical contracts.

## Failure cases

A zero-progress backpressure result must not busy-loop without a policy. Prevent duplicate completion and stale-slot access. Do not treat reference counting as synchronization or allow generation wrap to revive old requests. Failure preserves a valid pending-state invariant.
