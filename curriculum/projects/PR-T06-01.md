# PR-T06-01: Preprocessor laboratory and safe wrappers

## Contract

Create a token-transformation notebook and a small wrapper header. Cover line splicing/comments, invocation rules, prescan/rescan, two-level stringification/pasting, empty/nonempty variadics, evaluation count and statement-macro scope. Prefer typed inline functions for value computations where possible; any retained macro has an explicit evaluation contract.
