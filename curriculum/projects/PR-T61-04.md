# PR-T61-04: Parser fuzzing with semantic oracles

## Contract

Implement vf_frame for bytes[length,payload...,xor]. Require n>=2, length<=16, exact n=length+2 and bitwise exclusive-or of payload equal final byte; publish length only on success. Empty payload is valid with bytes[0,0]. Fuzz all inputs0..64 bytes, check round-trip canonical encoding on success and output sentinel on failure.
