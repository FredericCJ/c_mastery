## Failure cases

Reject unknown family/revision, CPU-only CCM DMA placement, bank-crossing declared allocation, arithmetic extent overflow and access during DMA ownership. A CPU-accessible or aligned byte array is not thereby a live typed DMA object. Unsupported clocks/peripheral rules are evidence gaps; never test an unverified map by issuing arbitrary MMIO.
