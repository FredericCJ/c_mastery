## Contract

Implement a temporary-directory byte-copy/positioned-I/O utility with checked offsets and short-transfer policies. Compare dup-shared offset with positioned access, sparse holes, umask and renamed open handles. Define symlink/directory-relative lookup policy and reject permission/lookup assumptions that cannot be established.

## Failure cases

- Challenge the mistaken claim: read or write either handles the whole buffer or transfers nothing. Preserve a minimal failing trace or explain the valid precondition that excludes it.

- Challenge the mistaken claim: Checking a path once authorizes all later uses of that name. Preserve a minimal failing trace or explain the valid precondition that excludes it.

- Challenge the mistaken claim: Requested mode is always the final mode. Preserve a minimal failing trace or explain the valid precondition that excludes it.

- Challenge the mistaken claim: Logical file size equals allocated disk space. Preserve a minimal failing trace or explain the valid precondition that excludes it.

Exercise empty/singleton or zero-progress states where the operation admits them, exact capacity, one beyond capacity, repeated completion/cleanup and a deliberately invalid precondition. For storage-owning work, inject acquisition failures and verify unchanged old ownership. For build/binary/source studies, inject a wrong edge, symbol, width, target assumption or unsupported environment and require a visible failure verdict. Never execute malformed pointers or privileged instructions just to demonstrate a negative case. Apply these cases to the declared operation; document any inapplicable case and its reason.
