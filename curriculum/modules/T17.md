## Purpose and outcomes

Build small numeric kernels whose units, finite representations and error contracts can be defended. The result is a reusable caller-storage kernel library, not an assumption that more floating-point digits guarantee a better model.

## Entry check and remediation

Without coding, convert 0.5 to Q7, multiply a 2x3 shape by a 3x2 shape, distinguish absolute from relative error at zero, and trace a three-value sum. Repair only the failed skill: binary scaling in T04, loop/index invariants in T14, or a one-page units/algebra exercise. For filters, practice geometric decay; for the elective ODE, review a derivative as rate and Euler as a tangent step. Neither calculus nor advanced linear algebra blocks the accumulation/fixed-point projects.

Use {ref}`guide-entry` for the diagnostic policy and {ref}`guide-roadmap` for route order. Only the stated prelude leaves must precede a dependent project.

## Component progression

**A numerical result with an error model.** State units, ranges, conditioning and rounding before choosing a layout. Compare residuals and convergence rather than treating one floating result as exact.

Before implementation, predict this discriminating case: **A small residual masking a large forward error in an ill-conditioned problem.** Carry its evidence into the projects below. Reuse one accepted component revision; new projects charge their new mechanism or experiment, not a second implementation of the old one.

## Study sequence and teaching

### T17.01 — Numerical problem formulation

Start with the quantity, not its C type. A sensor reading in millivolts and a normalized controller input are different domains even if both are doubles. For a reference value r, use absolute error near zero and relative error only where |r| is bounded away from zero. Write a units/domain/error ledger for the supplied accumulation cases. The misconception is that extra precision repairs an inaccurate physical model. Evidence is a separately justified model, representation and algorithm error allowance.

Apply this mechanism in [PR-T17-01](../projects/PR-T17-01.md).

### T17.02 — Stable accumulation

Accumulation loses information when an addend is too small to change a rounded partial sum. With binary64 round-to-nearest, the ordered values 2^53, 1, -2^53 can produce zero although the exact sum is one. Pairwise grouping and compensation change the rounding history; neither removes poor conditioning. Implement three accumulators, permute inputs and compare to exact integer/rational references. Preserve the algorithm, order and compiler flags with each result rather than declaring one tolerance pass universally stable.

Apply this mechanism in [PR-T17-01](../projects/PR-T17-01.md).

### T17.03 — Fixed-point kernels

Fixed point stores an integer q representing q/2^F. Multiplying two such values doubles the fractional-bit count, so widen before multiplication, round at the declared shift and saturate only after rounding. For Q7, 64 times 64 represents 0.25 and returns 32; a half-way negative result requires an explicit rule rather than a signed-shift guess. Implement a scaled multiply-accumulate with ties away from zero, test positive/negative saturation, and show that the intermediate bound fits the widened type.

Apply this mechanism in [PR-T17-02](../projects/PR-T17-02.md).

### T17.04 — Vector and matrix representations

A matrix interface needs rows, columns, stride, extent and overlap rules. Row-major address i*stride+j is valid only after dimensions and multiplication/addition bounds are checked. Multiply a 2x3 by a 3x2 matrix using a simple reference order, then add transposed and blocked traversals. A contiguous allocation does not imply stride equals the logical width. Evidence includes sentinel-preserving padded rows, rejected incompatible shapes and a dependency argument for any in-place operation.

Apply this mechanism in [PR-T17-03](../projects/PR-T17-03.md).

### T17.05 — Interpolation and approximation

Linear interpolation joins two neighboring samples: y0+(x-x0)*(y1-y0)/(x1-x0). Sorted distinct knots are a precondition; clamping, rejection and extrapolation are different APIs. Implement clamped lookup interpolation, then compare a sampled quadratic table with a degree-two polynomial on a dense grid. The misconception is that passing the knots bounds the error between them. Report the maximum observed error, its location, evaluation cost and the limited grid scope.

Apply this mechanism in [PR-T17-04](../projects/PR-T17-04.md).

### T17.06 — Digital filters

A FIR output is a finite weighted history; an IIR also feeds prior outputs back into future state. For the teaching recurrence y[n]=0.5*x[n]+0.5*y[n-1], zero initial state and a unit step give 1-2^-(n+1). Implement caller-owned FIR and first-order IIR state with sample and block interfaces. Changing block size must not reset state. Test impulse/step responses, chunk equivalence and quantized coefficients; use |a|<1 only for this first-order pole, not as a general filter-stability rule.

Apply this mechanism in [PR-T17-05](../projects/PR-T17-05.md).

### T17.07 — Linear systems and iterative methods

Gaussian elimination transforms equations but dividing by a tiny pivot magnifies perturbations. Partial pivoting chooses the largest available magnitude in a column; it is a strategy, not proof that a system is well-conditioned. Solve the supplied 2x2 systems, detect singular pivots with a scale-aware rule, and report residual ||Ax-b|| and a perturbed-input comparison. A small residual alone does not imply small solution error. Count arithmetic and bytes touched for your representation.

Apply this mechanism in [PR-T17-06](../projects/PR-T17-06.md).

### T17.08 — Signal transforms and simulation

**Elective extension.** The elective Euler experiment separates the differential model from its integrator. For y'=-y and step h, forward Euler gives y[k+1]=(1-h)y[k]; stability for this equation requires |1-h|<1, while accuracy still depends on h. Implement a finite-step solver with explicit initial/time units and compare step halving against exp(-t). An accurate implementation of an unsuitable model remains unsuitable. Preserve both convergence evidence and the model assumptions; do not require calculus fluency for the rest of T17.

Apply this mechanism in [PR-T17-07](../projects/PR-T17-07.md).

### T17.09 — Data-oriented representations

Array-of-structures interleaves fields; structure-of-arrays groups values used together. If a loop needs only x, interleaved cold labels enlarge its accessed footprint even when object count is unchanged. Implement both layouts for the matrix/vector workload and calculate useful versus touched bytes under a stated synthetic cache-line model. Alignment alone does not guarantee locality or speed. Evidence includes padding/stride diagrams, identical semantic outputs and separately observed timing on the selected host.

Apply this mechanism in [PR-T17-03](../projects/PR-T17-03.md).

### T17.10 — Reproducibility and reference testing

Reference testing needs a stronger independent computation, not the same loop at a different optimization level. Use rational/integer cases, analytic filter responses and a higher-precision hosted oracle; record rounding mode, contraction/fast-math settings and exceptional-input policy. Test reproducibility separately from accuracy: changed reduction order can be accurate yet bitwise different. Retain a distribution of errors and a failing-input replay, with explicit limits of the reference precision.

Apply this mechanism in [PR-T17-01](../projects/PR-T17-01.md).

## Mastery gate and feedback

Reimplement one numeric kernel from its contract, then explain a cancellation case and a rejected shape/range. Pass exact integer cases, stated numeric tolerances, ownership/dependency audits and perturbed-input analysis. If result error is acceptable but conditioning is unexplained, redo the reference/error ledger; if bounds fail, return to the indexing or widening derivation before optimizing.

For every linked objective, retain a separately labeled explanation, implementation/analysis artifact and check. Use {ref}`guide-assessment` for the rubric; one passing fixture does not establish all three objectives of a topic.

## Consolidation and transfer

After a delayed closed-book replay, change input scale, accumulation order and layout independently. Predict which exact values, error margins and costs should change before measuring. Explain one case where a numerically smaller error does not improve physical-model accuracy.
