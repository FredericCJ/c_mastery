# T67: Algebraic data modeling and representation-safe views

## Purpose and outcomes

Build and explain the representations and state transitions below, preserving the imported artifact contracts. The complete exercises are core work; descriptive hours do not cap depth. Distinguish ISO semantics, implementation diagnostics, runtime checks and programmer discipline.

## Entry check and remediation

Derive ownership through a failed acquisition and a retained borrow using the prerequisite artifacts. State the backing lifetime, aliasing and failure contract before composing the prerequisite artifacts.

## Environment and limits

Use profile A: hosted Linux x86-64 and ISO C17 with extensions disabled and -Wall -Wextra -Wpedantic -Werror. The [ADT laboratory contract](../../labs/adt/CONTRACTS.md) defines the permitted representations and disjoint live-object inputs/outputs. The family declares GCC and Clang debug, release and ASan/UBSan profiles. Python independent oracles, CMake and compiler diagnostics are host tools; no Unicode, parser, graph or algebraic-data-type library may implement the mechanism being assessed.

The supplied operations are serialized. Validated text borrows at most 65,535 stable bytes and promises Unicode scalar validation, not normalization or grapheme segmentation. The branded pool has four slots with nonwrapping generation retirement; its live address cannot be reused while handles survive. Recursive values contain at most 32 nodes and use fixed iterative scratch storage. Read-only strided views may alias logical elements, but their backing extent and lifetime remain caller obligations. Public tags, handles and views are forgeable C representations; successful numeric checks do not validate arbitrary pointers or provide static lifetime enforcement.

The TLV and packet grammars are original bounded formats, not general Protocol Buffers compatibility. Keep source-bound hosted anchors distinct from the required learner io.frame/cursor integration and changed-condition work. Security demonstrations use only synthetic local inputs and property violations in these teaching programs. Strict freestanding dependency closure, concurrent adapters and physical execution need separate evidence; finite tests and sanitizers do not prove all representations safe. Exact published C17 wording remains an access gap.

## Study sequence and teaching

### T67.01 — Products, tagged sums and checked elimination

Derive product versus sum cardinality and distinguish a C union representation from an automatically checked discriminated union; show why -Wswitch-enum is a diagnostic policy, not an ISO C exhaustiveness theorem.

`PAIR`(UINT32_MAX,5) measures4294967300; `NUMBER`(0) is distinct from `EMPTY` despite equal measurement. Invalid tag99 leaves prior result unchanged. A `PAIR` requested as `NUMBER` leaves its output sentinel untouched.

Construction: Draw all admitted tag/payload states, establish uint64 sufficiency for two uint32 values, and explain which inactive-member operations are avoided. Derive a counterexample to the claim that adding a default branch makes future variants exhaustively handled. Compare Rust enum constructors and binding behavior with C aggregate initialization and private-header discipline. The full assessed work is {ref}`X-T67-001`.

Misconception: An explicit default error path and a missing-case compiler probe address different assumptions.

Evidence: Run adt.sums and compile the missing-enumerator probe with -Wswitch-enum -Werror. Both semantic mutants must fail: omitted second product member and silently accepted invalid tag. Add every variant and invalid boundary, inspect enum size without assuming it is the wire tag size, and compare debug/release generated branches.

### T67.02 — Newtypes and checked dimensional conversions

Explain why two distinct struct wrapper types reject accidental argument substitution while two typedef names for uint32_t do not; derive the exact safe seconds-to-milliseconds domain.

42seconds becomes42000milliseconds;4294967seconds becomes4294967000;4294968seconds fails without modifying output;zero succeeds.

Construction: Derive the division-before-multiplication admission test and show that the largest accepted seconds value maps below UINT32_MAX. Compare the inspected C++ duration_cast ratio formulas; static_cast or a distinct duration type does not itself establish arbitrary destination representability. Specify round/truncate behavior before adding fractional units. The full assessed work is {ref}`X-T67-002`.

Misconception: Wrapper types can be explicitly dismantled; document the enforcement boundary.

Evidence: Run adt.quantities and reject wrong nominal type in a separate compilation. Kill missing-range-check and wrong-scale mutants, then test both sides of the quotient boundary. Show an explicit cast or field extraction bypass and identify programmer discipline rather than claim unforgeability.

### T67.03 — Typed flag sets and reserved-bit admission

Distinguish a set of independent options from a mutually exclusive sum, and explain why reserved bits must be rejected or retained under a documented evolution policy rather than silently cleared.

Inputs0 and7 succeed unchanged;8 andUINT32_MAX fail while preserving the prior ADFlags value.

Construction: Define the valid mask invariant raw & ~7 ==0, all eight admitted states and ownership-free value semantics. Explain integer promotions when complementing a narrow mask; use an explicit uint32 mask. A public struct can be forged, so only constructor-admitted values have the promised invariant. The full assessed work is {ref}`X-T67-003`.

Misconception: A zero flag set is a boundary state, not automatically an error.

Evidence: Run adt.flags; exhaustively test0..255 and each single bit position. Reject the silent-mask mutant and empty-set rejection mutant. Show a newly reserved bit cannot be accidentally converted into success by masking.

### T67.04 — UTF-8 smart constructors and validated borrowed text

Derive a UTF-8 validation predicate from RFC3629 and explain why successful construction proves byte encoding only while the backing bytes remain live and unchanged.

41 E2 82 AC F4 8F BF BF is8bytes/3scalars; C0 80 and ED A0 80 fail; empty NULL input succeeds with0scalars; prefix41 E2 82 fails.

Construction: Track input position and remaining continuation count without forming an out-of-range pointer. For each sequence derive minimum scalar value and maximum scalar value; compare scalar count with byte count. State storage lifetime and mutation restrictions explicitly, including a safe constructed example where another alias changes a previously validated buffer. The full assessed work is {ref}`X-T67-004`.

Misconception: A view can become semantically invalid through a still-live mutable alias without any pointer dangling.

Evidence: Run adt.text and the Python strict UTF-8 differential oracle for all one/two-byte strings plus specified three/four-byte boundary samples. Kill overlong and surrogate acceptance mutants. Record that Python decoding is an independent implementation, not a proof of normalization or all higher-level text properties.

### T67.05 — Branded pool handles with checked generations

Separate nominal handle category, pool identity, slot generation and ownership; demonstrate why a C wrapper cannot create a compile-time fresh brand per runtime pool or enforce linear use.

A handle frompoolA is rejected bypoolB; release/reacquire invalidates the old generation; release atUINT_MAX retires its slot and reduces usable capacity to3.

Construction: Derive FREE/LIVE/RETIRED transitions and count available slots. Explain why copying a handle is permitted by C yet does not duplicate ownership. Pool objects must remain live at fixed addresses and cannot be reinitialized or reused while handles survive: pointer identity does not prevent ABA across object lifetimes. Compare PhantomData nominal/lifetime roles without claiming equivalent static checks. The full assessed work is {ref}`X-T67-005`.

Misconception: Generation wrap must have a policy; wrapping back to1 silently revalidates old handles.

Evidence: Run adt.brands and enumerate short acquire/release/get traces against an independent occupancy/generation model. Kill owner-check omission and generation-check omission independently. Compile a wrong-category handle probe; show that copying or explicitly constructing a valid public representation bypasses any unforgeability claim.

### T67.06 — Read-only strided views and ownership boundaries

Derive required backing extent from shape and strides, including empty shapes and overflow, and distinguish a read-only overlapping view from a mutable injective layout.

Backing[1,2,99,3,4],shape2x2,strides3/1 yields4 at(1,1) and needs5elements; capacity4fails. Shape0x3 is empty. Strides1/1 admit read-only overlap.

Construction: Prove multiplication and addition guards before computing the last element offset; explain why logical element count need not equal required span. Compare span contiguous access and mdspan layout_stride preconditions. Define when two logical indices alias and why a writable transfer needs stronger validation or an explicit alias contract. The full assessed work is {ref}`X-T67-006`.

Misconception: Read-only overlap and mutable uniqueness are different contracts.

Evidence: Run adt.views; enumerate small shapes/strides/capacities against a Python coordinate-set oracle. Kill row-major-assumption and missing-capacity-admission mutants. Audit zero/SIZE_MAX boundaries and distinguish arithmetic acceptance from existence of a real caller object of that extent.

### T67.07 — Recursive arena values and typed indices

Derive acyclicity from a topological child-index invariant and explain when a checked arena can support unchecked internal traversal without allowing later mutation to invalidate the proof.

CONST7,CONST9,ADD(0,1),root2 yields16. A self-child2 fails. UINT32_MAX+9 fails without changing prior output.

Construction: Prove by induction on node index that each value is available before its parent; separate index category from actual range validity. Give O(count)time/O(32)stack and compare a recursive tree that duplicates shared children. For validate-once extension, make the arena immutable or invalidate its certificate after every structural mutation. The full assessed work is {ref}`X-T67-007`.

Misconception: A validation certificate expires if clients mutate structural fields.

Evidence: Run adt.arena and independent postfix/tree evaluation cases. Kill forward-reference acceptance and arithmetic-overflow omission. Add unreachable malformed nodes, multiple roots, shared children, empty and maximum count, then record stack-use output.

### T67.08 — Lenses and prisms with falsifiable laws

Derive lens get-put, put-get and put-put laws and prism review/preview round trips; explain how lawful optics differ from arbitrary field mutation helpers.

Setting x of(1,2)to3 gives(3,2); setting it toitscurrent1 preserves bothfields. Preview(review(3))=3; preview(`EMPTY`)fails without publishing0.

Construction: Write each law as an executable predicate and derive which information an update may change. Compare the C functions with the inspected lens type laws; C types do not enforce those laws. Distinguish field equality from raw struct memcmp because padding need not encode semantic identity. The full assessed work is {ref}`X-T67-008`.

Misconception: A useful normalizing setter need not be a lawful lens.

Evidence: Run adt.optics:256combinations assess get-put/put-get/put-put and prism round trips. Kill the collateral-y-write and EMPTY-as-NUMBER mutants. Add composition of nested pairs, identify a law violated by a clamping setter, and explain why exhaustive small domains are not proof for arbitrary callback optics.

### T67.09 — Evolution-aware sums and lossless tolerant readers

Distinguish tolerance from permissiveness: an unknown noncritical alternative can be retained exactly, while malformed known alternatives and unknown required semantics must fail.

09 03 04 05 06 round-trips byte-for-byte;01 01 07 fails as malformed known data;80 00 fails as unsupported required semantics.

Construction: Define a sum of known-number, known-empty and unknown bytes; retain tag and payload even when semantics are unavailable. State lifetime, disjointness, maximum255payloadbytes and overflow-free size calculation. Compare binary unknown-field preservation with the inspected Protobuf guide and demonstrate a field-wise rebuilding path that loses unknown data. The full assessed work is {ref}`X-T67-009`.

Misconception: Round-trip bytes, not only recognized values.

Evidence: Run adt.evolution and construct a two-version relay trace. Kill unknown-payload-discard and malformed-known-acceptance mutants. Test all truncation points, trailing bytes, capacity shortages, zero-length unknown payload and borrowed-buffer mutation. Record which operations preserve unknown data and which deliberately reject it.

### T67.10 — Zero-copy packet view with precise error sum

Port the supplied census packet-view artifact to C while preserving its admitted wire states, error distinctions and borrowed-payload lifetime; identify guarantees supplied by the C API versus the compared language wrappers.

01 00 02 07 08 yieldskind1,length2,payload=input+3.02 00 00 isvalidack.01 00 01 07 08 islengtherror;02 00 01 07 isackerror;03 00 00 iskinderror.

Construction: Derive a state table for every failure stage and prove length-3 subtraction is reached only after header validation. No struct overlay, unaligned integer load, allocation or payload copy is permitted. Compare C tag/error conventions with census C++ variant/expected/span without treating the example as an authoritative language specification. The full assessed work is {ref}`X-T67-010`.

Misconception: Zero-copy removes a payload copy; it does not remove lifetime management.

Evidence: Run adt.packet and enumerate header/extent/tag combinations against the independent byte parser. Kill trailing-byte acceptance and nonempty-ack acceptance separately. Test all truncations and prior-output preservation, then integrate actual learner io.frame and bytes.cursor artifacts with recorded source identities. Public direct-parser anchors do not establish that integration.
