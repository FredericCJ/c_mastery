# Board qualification and capture protocol — not an observed run

This package is ready for a dedicated teaching board once its exact part, revision, clock tree, memory map, interrupt implementation and timer/trace route are supplied and checked against authoritative documents. MPS2 model register addresses must not be copied into an STM32 port. Authoring this protocol does not authorize flashing or host security changes. Use synthetic eight-byte payloads, a local probe/instrument and no external operational bus.

Before a physical run, archive the original target sources, every explicit runtime helper, build command, compiler version, ELF/map/disassembly, linker closure and source hashes. Document the board/MCU revision and relevant errata. Qualify privileged PRIMASK/BASEPRI access, implemented priority bits/grouping, timer clock and width, counter direction/reload semantics, timer interrupt W1C acknowledgement, interrupt/vector number, debug-halt behavior and writable memory/stack. Reserve queue storage with correct atomic alignment and whole-object lifetime. Disable unrelated configurable handlers only within the dedicated teaching firmware; name any NMI/fault/DMA/second-core participant that remains. No real application data is permitted.

Choose a free-running timer whose full wrap exceeds the complete experiment and whose frequency is independently checked against a known reference. Record its clock numerator/denominator and uncertainty, read latency and overflow limit. Configure a second owned timer for one event; prove status is acknowledged exactly once. If an external logic analyzer or oscilloscope is used, document model/firmware, sample rate, reference clock, trigger edge, probe loading, pin mapping and voltage compatibility. Capture both sides of any GPIO instrumentation and quantify its added stores/barriers; it is not identical to a timestamp read. Keep formatting and trace transmission outside measured handlers. Detect dropped trace records separately from queue drops.

Run the native boundary/negative controls before board execution. Then run actual nested mask0/1 and BASEPRI tests and record readback plus pending/active observations. Run both40-event workloads over equal800000 timer-tick windows with sequence IDs and the same queue contract. Record scheduled and actual trigger times, admission status, handler entry, before/after publication, exit and consumption. Keep raw traces for all80 events, including16 expected burst drops, and32 overhead brackets. The overhead bracket is a specified read/store sequence, not an exact per-event correction. Repeat with publication probes disabled, change compiler/optimization and retain the resulting images separately. A timer resolution too coarse to distinguish effects is an explicit measurement limitation, not zero cost.

Fill `fixtures/embedded/interrupt_handoff_capture.json`; replace its unexecuted placeholders, never the original template. Link each artifact by path and SHA256. Use `python tools/check_interrupt_handoff_capture.py <record.json> --root <capture-directory>` to validate the record. This checker validates supplied data/identities only: it cannot establish that a claimed physical observation happened. Synthetic self-tests are clearly labeled synthetic and never become physical receipts.

Acceptance: all declared build/clock/actor premises supported; exact event IDs/admission/drop counts; no missing/duplicate trace records; publication intervals ordered and no ambiguous full wrap; correct nested mask restoration; closure contains no forbidden runtime; raw evidence agrees with reported distributions. Report min/nearest-rank median/p95/max of interval bounds and both instrumented configurations. Reject an ISR that blocks on the interrupted foreground, an EN-only DMA quiescence assertion, a trace that omits drops, a stale image hash or an extrapolation of observed maxima into WCET. Board failures require a minimized event prefix, register/stack evidence and ownership/clock diagnosis before another run. Retain failed attempts.

External evidence remains separate: exact physical observations, instrument calibration, non-author review, independent learner integration and actual seven-day transfer attempts. The currently executed emulator and hosted/model campaigns satisfy only their explicitly named environments.
