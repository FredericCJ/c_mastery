# Contextual route semantic review

This revision separates catalog identities from encounter order and links every
registered objective to its current assessed units/exercises. The route merges
baseline and expansion work, gives artifact prerequisites an explicit producer
and version, and moves the compact algorithm vocabulary after C setup and bounds.
The seven T15 working cards that inherited a sorting-only challenge now have
project-specific changed conditions, with reversible public predecessor proofs.

The two pilot narratives reuse the existing byte-ring/framed-stream/SPSC and
TdTimer/resilience mechanisms. They explicitly distinguish perf ABI rings from
learner rings, and wheel precision from exact timer semantics. Context teaching
requires arguments rather than equating code with amortized, shortest-path or
probabilistic reasoning. The mechanism map names different later obligations.

Review limits remain explicit. The generated objective map is traceability, not a
claim that every old unit is pedagogically sufficient. Every explicit legacy successor binding is resolved criterion by criterion to its
public teaching: 1,708 criteria have current successor contracts, while 270 retain
their canonical criterion. Of those successor criteria, 1,678 replace predecessor
task prose and 30 T11 criteria retain the original work plus the explicitly
complementary freestanding-depth APIs. That additive disposition is authored in
the route source against the exact support record; an exact criterion match alone
does not erase the original tasks when the public contract preserves them.
Replacing criterion successors remove predecessor task and deliverable prose from the
active card; original project text becomes provenance. Explicit additive package
scopes remain additive. Each current contract appears once, with the retained
objective rubric and delayed assessment identities. Author closure claims never
become learner instructions. Context teaching is included in the card rather than
left as an unexplained path. The public validator checks
that these bindings resolve without exposing assessor content. This mechanical
resolution does not replace a non-author review of the substantive teaching. Independent transfer packages and real
learner performance must be assessed separately. Host author runs do not close
physical or independent-review obligations. These limits belong in the revision
ledger and may not be hidden by a route-integrity pass.

The deadline pilot now orders a bounded scan before the heap, indexed cancellation,
finite wheel and scalable native comparison. The graph-frontier adapter requires
its real solver, ring and heap producers. Sampling requires the SPSC publication
assessment while earlier PMU counting remains independent. These are typed route
requirements, not inferred availability of a reference implementation.

The final source-level trace found and corrected two ordering defects that the
original structural pass could not detect. The pointer successor now follows
T02 interface diagnostics, T03 object lifetime/alignment and the actual
X-T03-001 cursor assessment/export. Sampling and integrated PMU work now follow
completed framed-stream, nested-event parser, SPSC publication and deadline
comparison work. Earlier native counting explicitly uses supplied reference
adapters; it does not demand the learner's later service implementation.

The graph trace also found that conceptual producer acceptance did not provide
the exact CDCSR/CDRing/CDHeap/ad_bfs/ad_dijkstra imports. Five successor component
contracts now extend the active route, with unchanged API hashes and actual CLI
export/link support for unit and exercise producers. The graph consumer requires
those exact exports; old bounded container artifacts cannot substitute silently.
The public tests exercise export/link dispatch and compile a relocated synthetic
component. These plumbing fixtures are labelled synthetic, never learner evidence.
The graph API scope explicitly separates its actual CSR dependency from byte and
sorting dependencies in the shared T15 document.

This focused semantic trace covers the two pilots, graph-frontier imports and
the pointer/lifetime prerequisite chain. It does not establish a comprehensive
independent semantic review of every other successor's implicit prerequisites.

Embedded Markdown links are resolved relative to their original public document
before inlining, and learner workspaces copy the public link closure. Source and
destination directory symlinks reject before copying. Author tools, assessor
files, reviews, plans and research evidence cannot enter this closure; the exact
original EDU7 wire-format JSON is an explicitly named public contract exception.
Component imports bind the actual verified public-header content, including for
a self-consistent bundle that falsely claims the expected API hash.

Fresh-profile validation found 63 expansion introductions with no hard concept
gate: their peer-exercise/import metadata had omitted the baseline knowledge that
their own briefs assumed. Expansion entries now inherit their canonical parent
entry's upstream concepts, with provenance, without automatically requiring that
whole project or importing its binaries. Explicit contract groups add the named
array/span, invariant, AVL, stable-sort, grammar and systems mechanisms. The paired
statistics exercise follows its clock/measurement parent; native PMU permission
is not its prerequisite. All 238 exercises now have a real conceptual gate, and a
fresh profile offers only the basic C diagnostic and execution-model entries.

The checked-arithmetic and cursor producers retain their early positions without
requiring their own future exports. The three T56 portable core exercises retain
their explicitly separate kernel-adapter stages. B-tree split construction is
made an initial phase of the path-copy exercise rather than falsely inferred from
a generic choose-one advanced-structure heading. ACTIVE.md's exercise prerequisite
summary uses these route gates; it no longer repeats empty historical metadata as
the current readiness rule. These checks test readiness and source consistency,
not independent learner mastery of the prerequisites.

## contextual-v2: authored episodes and explicit encounter bindings

The v1 generator assigned encounter roles by slicing node order per project (the
first node was the introduction, the last node of each project a changed
assumption, the last two overall the transfer) and ignored the authored
encounter list, which was the same six labels for all thirteen mechanisms. It
ordered ready nodes by least-recently-used context, producing 1,957 context
switches in 1,982 transitions, and 1,976 of 1,983 `why_now` strings were generic.
Those defects made several roles false: the deadline scan preceded its own
"introduction", the ring transfer pointed at SPSC units and the dynamic-
programming transfer pointed at framing units. contextual-v1 is now frozen and
contextual-v2 replaces the inference with canonical source data.

The v2 source authors episodes for the compact foundation and the three
representative paths, plus graphs, hashing, allocation, balanced trees,
summaries, numerical kernels, callbacks, greedy/dynamic programming and
reclamation. Every encounter names node, objective, deliverable and a criterion
whose objective matches, and the validator rejects bindings that cannot be true.
The remaining nodes are unauthored project blocks; `contextual-v2.json`
`statistics` reports their count and the count of generic `why_now` texts.

Authoring against the actual criteria exposed defects that remain visible as
`missing` bindings rather than invented coverage:

- No criterion assesses `pf_ring_drain` (kernel-ABI ordering, wrapped records,
  loss accounting); the rings transfer at U-T43-09-03 is bound with that gap.
- LAB-EX-05 is catalogued under T15.09.a (greedy exchange) but implements 0/1
  knapsack, and it is a typed prerequisite of both units that derive the DP
  recurrence, so no DP implementation encounter follows the derivation.
- No node consumes an assessed summary, pool, tree/page index, reclamation or
  numerical component while asking for an unnamed selection under changed
  requirements; those independent transfers are missing.
- The ordered-search, stable-ordering, deadline and dispatch transfers are bound,
  but their exercises name the candidate structure; selection without a named
  structure exists only in the withheld assessor packets.

This review checked bindings against criterion text and lab contracts. It is an
author review, not an independent pedagogical review, and no learner has
attempted any episode.

The independent review of this batch found that editing the shared strand pages
would have changed every contextual-v1 card, because each card inlines its
context page. contextual-v2 therefore teaches from v2-only pages under
`routes/v2/`, and the frozen-predecessor list pins the v1 strand pages with the
v1 route, source and maps. The generator, the checker and the rename tool honour
that one list.
