## Problem

Implement constructors, transactional terminal substitution, a path interpreter and a memoized all-path summary with checked arithmetic and region-lifetime rules. The supplied public header fixes every operation and capacity; CONTRACTS.md specifies the complete input/output, state, ownership, callback, rejection and complexity requirements. Implement every named operation for this anchor. The fixture models and tests are supplied, but the independent Python implementation is a host oracle, not a target dependency. Expected concrete example: Emit7(Choose(Pure(-2),Pure(3))) bound through v -> Emit(v,Pure(2*v)) yields trace[7,-2], result-4 for answer0 and trace[7,3], result6 for answer1. Summary is paths2, emissions4, sum2.

Supply one plausible incorrect explanation and refute it with a defined local counterexample.
