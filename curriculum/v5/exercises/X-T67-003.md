# X-T67-003: Typed flag sets and reserved-bit admission

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: bytes.checked. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Construct ADFlags from uint32 raw input. Bits0,1,2 are independently allowed; zero is a valid empty set. Any other bit fails transactionally. Provide union/intersection operations in the learner extension and show that their closure depends on validated operands.

Concrete inputs and expected results: Inputs0 and7 succeed unchanged;8 andUINT32_MAX fail while preserving the prior ADFlags value.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.flags, fixtures/adt/PR-T67-03.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Distinguish a set of independent options from a mutually exclusive sum, and explain why reserved bits must be rejected or retained under a documented evolution policy rather than silently cleared. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Define the valid mask invariant raw & ~7 ==0, all eight admitted states and ownership-free value semantics. Explain integer promotions when complementing a narrow mask; use an explicit uint32 mask. A public struct can be forged, so only constructor-admitted values have the promised invariant. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.

## Deliverables

- D1: Distinguish a set of independent options from a mutually exclusive sum, and explain why reserved bits must be rejected or retained under a documented evolution policy rather than silently cleared.
- D2: Define the valid mask invariant raw & ~7 ==0, all eight admitted states and ownership-free value semantics. Explain integer promotions when complementing a narrow mask; use an explicit uint32 mask. A public struct can be forged, so only constructor-admitted values have the promised invariant.
- D3: Run adt.flags; exhaustively test0..255 and each single bit position. Reject the silent-mask mutant and empty-set rejection mutant. Show a newly reserved bit cannot be accidentally converted into success by masking.
- D4: Negotiate separate required and advisory bit sets between two schema versions. Preserve unknown advisory bits for forwarding while rejecting unsupported required bits, and prove the union operation cannot manufacture support. Complete all thirteen cost/enforcement dimensions with evidence or a mechanism-specific non-applicability.

## Verification

Run adt.flags; exhaustively test0..255 and each single bit position. Reject the silent-mask mutant and empty-set rejection mutant. Show a newly reserved bit cannot be accidentally converted into success by masking. Preserve predictions before execution, exact commands, source/input/toolchain identity and observed outputs. Explain independent-oracle assumptions and minimize disagreements. A supplied anchor or compiled mutant checks only its named property. Failure-side effects, ownership accounting and the required changed-condition result are pass/fail gates; finite tests cannot establish absolute mastery.

## Rubric

The metadata rubric maps each leaf to a distinct D1–D4 criterion. Require every criterion at level2 and at least two at level3 on independently attempted cases; record assistance. A violated ownership/failure contract, unsupported guarantee or incorrect exploitability claim fails regardless of performance. Passing only the public suite earns at most level1. Apply the shared six-dimension rubric as well.

## Hints

1. Write the set of all admitted bit patterns.
2. Complement the mask in its intended unsigned type.
3. A zero flag set is a boundary state, not automatically an error.
