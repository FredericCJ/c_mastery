# Find a machine instruction in the ELF file

## Prerequisites

Complete X-T07-001 before beginning.

## Environment

Use Linux x86-64 System V AMD64. From the exported workspace root run `python3 inspect_lab.py prepare --cc gcc`. Record the output directory, compiler version and manifest. The commands and answer-field conventions are in CONTRACTS.md.

## Problem

Find record_score in the hosted debug image. Predict how moving a section changes the relationship between a function address and a file offset. Use two independent views to identify its first eight bytes.

## Necessity

Decode the load, arithmetic or branch at the selected function. An output value by itself omits the evidence that connects this claim to a particular build.

## Reasoning

Read `readelf -hSW` and `readelf -Ws`. For a file-backed section compute sh_offset + (function_va − sh_addr). Read eight bytes there with `hexdump -s OFFSET -n 8 -C` and annotate the enclosing instructions from `objdump -d --disassemble=record_score`. Explain which register or flags an instruction reads and changes. An eight-byte window may end mid-instruction.

## Deliverables

- D1. Write your prediction before running the relevant inspection tools. Record the commands, file identities and observations in `answers/bytes.json`. Include `prediction`, `explanation` and the fields `elf_sha256`, `function_va`, `file_offset`, `first_8_hex`.
- D2. In your explanation, cite the bytes, instruction, header field or counter row supporting each inference in the reasoning exercise.
- D3. Repeat on the independently built optimized ELF. Describe a changed encoding or explain why the compiler retained it. Explain the consequence of applying the same formula to an unbacked section.

## Verification

Run `python3 inspect_lab.py check bytes --cc gcc`. For a hosted Clang build prepare and check with `--cc clang`. Preserve the manifest with the submission. A reviewer reads the written reasoning alongside the machine-checked observations.

## Rubric

- R1. Decode the load, arithmetic or branch at the selected function.
- R2. Locate the register operands and trace the first eight instruction bytes to their file positions.

## Hints

Start with the ELF class, machine and section index. Read byte pairs in file order, including on little-endian systems. Record integer addresses as decimal JSON numbers.

## Variants

V1 is a delayed independent transfer on a changed artifact, at least seven days after the first attempt. Derive the result from the supplied inputs and identify the evidence needed for each claim.

## Security

Use the supplied original program and locally generated files. Keep measured images, host details and observation logs in the local workspace.

## Validation

The checker compares selected artifact facts. The assessor separately evaluates the derivation, changed condition and whether an independent transfer took place.
