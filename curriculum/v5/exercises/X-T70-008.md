# X-T70-008: Shared text DAGs, editing alternatives and coordinate meaning

## Prerequisites

Bring pinned contracts and fresh recall for containers.array, memory.pool; prerequisite exercises: X-T70-006. Required knowledge includes C object lifetime, checked arithmetic, ownership, typed arrays and the selected source passages. The shared contract and modern-cost contract are explicit parts of this exercise. Existing project estimates describe author accounting; they impose no learner time ceiling.

## Environment

Use C17 hosted Linux with GCC and Clang, CMake and host Python. Record compiler/ABI versions, integer widths, sizeof/alignment and optimization. Mechanism code uses no library implementing the mechanism. Allocator callbacks are supplied dependencies with separate ownership. A strict freestanding port requires its own generated-code/link audit and is not established by the hosted run. Compare C11 draft/C17/C23 only where inspected normative evidence supports the claim; exact published C17 access remains a reference gap.

## Problem

Implement the DRope leaf/concat/flatten anchor with64 typed nodes, leaf length0–8 and maximum expanded length128. A rope is an ordered shared DAG: concatenating a root with itself must duplicate its logical bytes without mutating the shared leaf. Extend it with byte-index lookup and split, specifying allocation rollback and balancing separately. Implement two equal-byte-contract editing alternatives for a128-byte document: a gap buffer with explicit gap bounds and a piece table whose immutable original/add buffers are caller-owned and whose pieces are offset/length triples. Apply the same edit scripts to all three and a flat byte-list oracle. No Unicode scalar, grapheme or line-number equivalence is implied by byte offsets.

Supplied artifacts: labs/dod/include/dod.h, deliberately incomplete labs/dod/src/dod.c, executable anchors, fixture PR-T70-08.json and the shared CONTRACTS.md. Expected example: Leaves ab and cd concatenate to abcd; concatenating that root with itself flattens to abcdabcd while the ab leaf remains ab. Capacity7 rejects an8-byte flatten without touching the output canary or written. An empty leaf returns root0.

## Necessity

Ropes trade copying for metadata, traversal and retained sharing. Text-editing structures are not interchangeable until coordinate system, ownership, capacity, snapshot and failure contracts agree.

## Reasoning

T70.08.a: Prove ordered-DAG sequence semantics, cached length consistency and ownership of shared leaves; distinguish byte, codepoint, grapheme and line coordinates.

T70.08.b: Implement transactional leaf/concat/flatten and byte-index/split operations, including empty boundaries and shared subgraphs without cycles.

T70.08.c: Implement gap-buffer and piece-table editing with complete capacity and source-lifetime contracts; drive identical insert/delete scripts through all representations and an independent flat oracle.

T70.08.d: Investigate chain depth, rebalancing, fragmentation and retained backing storage using adversarial concatenation and edit locality; derive a balance criterion from the inspected rope paper without importing its measurements as this lab results.

T70.08.e: Transfer to UTF-8 scalar-index edits and invalid byte sequences. Define validation, coordinate conversion and snapshot ownership, then demonstrate a case where byte equality alone does not establish the requested text operation.

State preconditions, postconditions, representation invariants, resource ownership, failure publication and complexity. For each guarantee identify ISO C rules, diagnostics, runtime checks, external verification and programmer discipline separately. Include a minimal counterexample to an overstated equivalence with the corresponding language/library abstraction. Apply all13 dimensions in modern-cost-contract.md, recording genuine non-applicability with reasons and unavailable measurements as gaps.
