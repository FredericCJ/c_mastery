## Security

Target: the b5_request component in `labs/b05_depth` and the reap-while-cancel-pending variant you build, run on synthetic request metadata and events in a local process. No real device, block I/O or freed memory is involved.

Adversary: you choose the order of submit, cancel, completion and reap, including a late completion for generation 1, duplicate completions and repeated cancels. You do not control the generation counter or the ownership flags.

Violated property: the descriptor and buffer must stay owned until trusted completion; cancellation alone is not quiescence.

Evidence to capture: run `depth-tests request` (CTest `b05_depth.request`) on the correct build and record state and counters at each CHECK: after cancel `r.state == B5_CANCEL_REQUESTED` and `terminal_count == 0`; reap while cancel is pending returns B5_CONFLICT; the completion wins and `terminal_count == 1`; the duplicate completion returns B5_CONFLICT with `r.result == 2`; reap advances to generation 2; a stale generation-1 completion is B5_CONFLICT; and reap at UINT32_MAX ends in B5_RETIRED. Then build a variant in which reap succeeds from B5_CANCEL_REQUESTED and record the test failing with `DEPTH_CHECK:<line>:b5_request(&r, B5_REAP, 1, 0) == B5_CONFLICT`.

Impact class: demonstrated-invariant-violation, shown only by the reap-while-cancel-pending variant you build; the supplied test passes on a correct build and no supplied artifact demonstrates it. Memory is not actually freed or reused, so this is neither a sanitizer finding nor proved-impact.

Remediation: keep ownership until trusted completion and allow reap only in a terminal state. The regression test is the existing `b05_depth.request`; it must fail on your reap-while-cancel-pending variant and on a stale-generation-accepting variant, and pass on the repair.

Limitations: Only the b5_request metadata fields are modelled: no descriptor memory is freed, no device or DMA runs, and no use-after-free occurs; the quiescence event is trusted and not verified; adapter binding to real virtio evidence is outside this exercise.
