## Problem

Implement distinct evaluation and rendering dictionaries, borrowed function contexts, staged failures and one shared higher-order program without an interpreter library. The supplied public header fixes every operation and capacity; CONTRACTS.md specifies the complete input/output, state, ownership, callback, rejection and complexity requirements. Implement every named operation for this anchor. The fixture models and tests are supplied, but the independent Python implementation is a host oracle, not a target dependency. Expected concrete example: For capture2, the function maps x to x+2, the higher-order term returns5, and rendering is (((lambda x.(x+2)) 1)+2). Evaluation calls its builder at application; rendering calls it at lambda construction.
