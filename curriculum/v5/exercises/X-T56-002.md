## Problem

Implement sd_load/clone/write/release from CONTRACTS.md using the 16 actual backing frames. Load a 130-byte sequence 1..130 with fail_after=0,1,2 and require no new owned references or output publication. Repeat while a preexisting image holds a frame. On success the third frame starts129,130 then62 zero octets. Clone with one thread, mutate child offset0 to99, and require parent1; deny allocation first and require all ownership unchanged. Reject kind1/2 and threads2 before modifying any earlier page. Fill all16 frames and prove exhaustion does not damage owners. Derive and implement the kernel adapter deliverable below.
