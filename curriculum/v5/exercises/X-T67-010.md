# X-T67-010: Zero-copy packet view with precise error sum

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: bytes.cursor, bytes.checked, codec.records, io.frame. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Implement ad_packet for [kind:u8,length:u16 big-endian,payload]. Kind1 data accepts any declared payload includingempty;kind2 acknowledgement requireszero. Check header first, then kind, exact extent, then ack constraint. Return distinct ADPacketError values and publish ADPacket only on success; keep payload pointing into stable caller backing. Compose the parser with the retained io.frame/cursor interfaces via a learner adapter and reject fragmentation until a complete frame is available.

Concrete inputs and expected results: 01 00 02 07 08 yieldskind1,length2,payload=input+3.02 00 00 isvalidack.01 00 01 07 08 islengtherror;02 00 01 07 isackerror;03 00 00 iskinderror.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.packet, fixtures/adt/PR-T67-10.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Port the supplied census packet-view artifact to C while preserving its admitted wire states, error distinctions and borrowed-payload lifetime; identify guarantees supplied by the C API versus the compared language wrappers. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Derive a state table for every failure stage and prove length-3 subtraction is reached only after header validation. No struct overlay, unaligned integer load, allocation or payload copy is permitted. Compare C tag/error conventions with census C++ variant/expected/span without treating the example as an authoritative language specification. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
