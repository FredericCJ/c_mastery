# X-T15-010: Thompson closure, whole/search semantics and bounded subset construction

## Prerequisites

Study T15.14 and PR-T15-09, T03 array/object lifetimes and T14 stack/set representations. Bring a hand trace of the shared grammar, bounds tests and a list of ordinary versus malformed inputs. LR additionally needs least fixed points and FIRST/FOLLOW; regular expressions need finite-state machines; Pratt needs expression trees; scannerless work needs rollback and three-result recognition. No unlisted accepted artifact import is required.

## Environment

The explicit [parsing depth contract1](../../../labs/parsing_depth/CONTRACTS.md) supplies the full typed API, exact languages, capacities, dependencies, ownership, admission/failure semantics and local security scope. Implement the supplied compiling `src/parsing.c` scaffold. The C mechanism cannot delegate to a mature parser library. Host independent oracles remain separate. ISO C type checks do not establish the semantic grammar/table or pointer-lifetime preconditions.

## Problem

Compile the explicit a/b/empty regular-expression grammar into typed NFA states, then implement whole-input and substring search. Derive epsilon closure that terminates on nullable cycles. Implement the delayed bounded DFA subset table with unchanged-output capacity failure and an explicit NFA fallback choice. The shared pattern (a|b)*abb, a**, (~|a)* and bytes outside a/b distinguish semantics. No regex library may perform the C mechanism.

## Necessity

Naive backtracking or duplicate active paths can grow dramatically even for a regular language. Nullable repetition can loop without a visitation invariant. A deterministic table trades construction/storage for repeated recognition, and capacity failure must not silently change the language. Regular-language matching is not equivalent to engines with backreferences.

## Reasoning

Prove fragment start/end meaning, epsilon-closure termination, current-state-set correspondence after each input byte and search restart semantics. Derive subset transition equivalence and exponential worst-case state growth. Account for pattern depth, typed-state capacity, worklist maximum, copied pattern representation and exact failure publication. Bound O(nS) simulation and table-build work without pretending fixed constants remove the mechanism. Explain a plausible false claim that every path must be executed independently. Give the smallest concrete counterexample to one plausible incorrect explanation. Separate ISO C rules, the teaching language/grammar, compiler support and programmer-maintained invariants. State every pre/postcondition and no-publication failure boundary.
