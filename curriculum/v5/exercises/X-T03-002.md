# X-T03-002: Representation versus wire encoding

## Prerequisites

Complete X-T02-001, X-T04-001 and X-T03-001. Bring typed-expression reasoning and checked-size tests. Read T03.02, T03.03 and T03.08. Know unsigned byte extraction and borrowed input lifetimes; no serializer is imported.

## Environment

Apply [shared contract v1](shared-contract.md). This concrete wire format requires `CHAR_BIT==8`, `uint16_t`, `uint32_t` and `int32_t`; fail compilation with an explicit capability diagnostic if absent. That is a declared target restriction, not a universal ISO guarantee. Wire signed values use a two's-complement mathematical encoding; the codec must derive values arithmetically and avoid out-of-range unsigned-to-signed conversion.

## Problem

Implement `fd_encode(FDRecord,out,capacity)` and `fd_decode(wire,length,out)`. A record has flags, count and value. The wire is exactly eight octets: byte 0 version 1; byte 1 flags limited to mask 0x03; bytes 2–3 count in big-endian order; bytes 4–7 signed 32-bit value represented modulo 2^32 in big-endian order. Count is metadata here, not an appended payload length. Invalid flags, version or length reject. Encoding capacity must equal 8, not merely exceed it. Decode input bytes and output object must be disjoint live objects. All rejected calls preserve output bytes/field values. Null required pointers reject.

Derive and check the vectors `{flags=3,count=258,value=-2}` to `01 03 01 02 FF FF FF FE`, and `{0,0,0}` to `01 00 00 00 00 00 00 00`. Reuse the checked-extent and cursor implementations through explicit calls before byte decoding. Use byte operations, not a cast, packed structure, `memcpy` serialization or network-byte-order library. Decoding must accept a valid record at an unaligned address within a real byte array.

Separately inspect a live FDRecord's size, alignment, offsets and object bytes through character access. The observation record is not the wire representation.

## Necessity

Raw structure dumps mix ABI layout, padding, endianness and value representation with a protocol. A successful same-host round trip can conceal symmetric encoder/decoder defects. Arbitrary wire bits do not automatically form a valid aligned typed object.

## Reasoning

Give an abstraction function from the eight bytes to mathematical fields, and prove every shift/multiply uses an adequate unsigned type. Explain how the high-bit-set signed range is decoded using only representable signed intermediates. Do not negate `INT32_MIN`. Compare object equality, field equality and wire equality with their assumptions.

The input remains borrowed for the call, and outputs publish only after complete validation. Bound work by eight-byte processing and O(1) temporary storage. Explain which properties ISO C enforces, which the static assertions enforce, and which are application constraints. An ABI layout observation does not change the fixed wire order.

## Deliverables

- **D1:** wire algebra, representation/field equality table, range proof and actual layout observations.
- **D2:** codec and a consumer using a deliberately unaligned but valid byte-array window.
- **D3:** independently calculated vectors, round-trip/metamorphic checks, rejection preservation and a symmetric-bug counterexample.
- **D4:** reversed-order codec variant, cost/dependency comparison and portability report.

## Verification

Run `foundation_depth.codec`. Test both signed endpoints, -1, 0, 1, every flag 0–255, count 0 and UINT16_MAX, each length 0–9, null pointers and all truncation prefixes. For valid inputs verify decode(encode(record)) memberwise. Independently verify exact wire vectors; round trips alone are insufficient. Flip each reserved flag bit and alter version. Check every output byte/member remains unchanged on rejection.

Generate wire values with an independent mathematical host encoder; compare canonical outputs and minimize discrepancies. Kill a compiling pair of encoder/decoder mutants that both reverse count order using an independently fixed vector. Analyze a cast-based decoder defect without executing invalid typed access. Observe generated code only for valid implementations with equivalent contracts.

## Rubric

The objective criteria assess object observations, portable arithmetic, equality and access type separately. A working host-only round trip earns at most 1 for correctness. A packed-structure solution fails the first-principles and portability contract even if its current bytes match. Level 3 revises wire order or target assumptions while preserving the proof.

## Hints

1. Write the eight positions on paper and calculate a negative value's wire integer mathematically.
2. Build an unsigned wire accumulator, then split the representable signed ranges before conversion.
3. Find a test that two implementations sharing the same endian mistake cannot both satisfy.

## Security

Only synthetic bytes and local outputs are processed. Malformed wire input is admitted as data and must reject safely; forged pointers are outside the callable contract. No assertion of exploitability follows from an invalid-cast example.
