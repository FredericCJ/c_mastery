# Recompute a PMU dossier and trace a wrapped sample

## Prerequisites

Complete X-T44-002 before beginning. Bring the ring publication trace from U-T43-09-03.

## Environment

Use the extracted workspace and Python 3. The raw dossier, runner and measurement gates are supplied under `labs/`. The original observation identifies its AMD x86-64 host. No local compiler, PMU or perf permissions are required for replay.

## Problem

Replay the shipped layout experiment offline. Predict which gate fails first if a member has zero running time. Then hand-trace a 12-byte committed record in a 16-byte ring beginning at absolute tail 28 with published head 40.

## Necessity

Recompute count validity and paired comparisons from the dossier's raw rows and calibration. An output value by itself omits the evidence that connects this claim to a particular build.

## Reasoning

Use `native.py report` on the shipped replay and independently compare group IDs, enabled and running time on one paired observation. Explain the denominator and order in each pair. Compute the wrapped header's first physical byte, the next absolute tail and both pieces of the header. State when the consumer may publish the new tail and what can be inferred about lost samples without an explicit count.

## Deliverables

- D1. Write your prediction before running the relevant inspection tools. Record the commands, file identities and observations in `answers/replay.json`. Include `prediction`, `explanation` and the fields `report_sha256`, `pairs`, `interpretation`, `wrapped_sample`.
- D2. In your explanation, cite the bytes, instruction, header field or counter row supporting each inference in the reasoning exercise.
- D3. On a scratch copy, set one running time to zero. Recompute its acquisition or scheduling gate and bound the resulting claim. Inspect the dossier's provenance before assigning any microarchitectural cause.

## Verification

Run `python3 inspect_lab.py check replay --cc gcc`. Retain the exact report with the submission. A reviewer reads the written reasoning alongside the machine-checked observations.

## Rubric

- R1. Recompute count validity and paired comparisons from the dossier's raw rows and calibration.
- R2. Trace a split sample header, monotonic head/tail publication and the meaning of an unavailable loss count.

## Hints

Keep absolute positions while deriving availability. Apply a ring mask only when indexing physical storage. For grouped counts, require matching events and positive running time before estimating scaled values.

## Variants

V1 is a delayed independent transfer on a changed artifact, at least seven days after the first attempt. Derive the result from the supplied inputs and identify the evidence needed for each claim.

## Security

Use the supplied original program and locally generated files. Keep measured images, host details and observation logs in the local workspace.

## Validation

The checker compares selected artifact facts. The assessor separately evaluates the derivation, changed condition and whether an independent transfer took place.
