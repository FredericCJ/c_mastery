# X-T67-004: UTF-8 smart constructors and validated borrowed text

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: bytes.cursor, bytes.checked. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Implement ad_text over at most65535 bytes. Return a borrowed immutable pointer/length and Unicode scalar count. NULL is permitted only for length0. Reject truncated continuation sequences, stray continuations, overlong forms, surrogates and scalars aboveU+10FFFF. No normalization, grapheme segmentation or allocation is performed. Failure leaves output unchanged.

Concrete inputs and expected results: 41 E2 82 AC F4 8F BF BF is8bytes/3scalars; C0 80 and ED A0 80 fail; empty NULL input succeeds with0scalars; prefix41 E2 82 fails.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.text, fixtures/adt/PR-T67-04.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Derive a UTF-8 validation predicate from RFC3629 and explain why successful construction proves byte encoding only while the backing bytes remain live and unchanged. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Track input position and remaining continuation count without forming an out-of-range pointer. For each sequence derive minimum scalar value and maximum scalar value; compare scalar count with byte count. State storage lifetime and mutation restrictions explicitly, including a safe constructed example where another alias changes a previously validated buffer. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.

## Deliverables

- D1: Derive a UTF-8 validation predicate from RFC3629 and explain why successful construction proves byte encoding only while the backing bytes remain live and unchanged.
- D2: Track input position and remaining continuation count without forming an out-of-range pointer. For each sequence derive minimum scalar value and maximum scalar value; compare scalar count with byte count. State storage lifetime and mutation restrictions explicitly, including a safe constructed example where another alias changes a previously validated buffer.
- D3: Run adt.text and the Python strict UTF-8 differential oracle for all one/two-byte strings plus specified three/four-byte boundary samples. Kill overlong and surrogate acceptance mutants. Record that Python decoding is an independent implementation, not a proof of normalization or all higher-level text properties.
- D4: Add an incremental decoder across chunks with at most3retained bytes and finalization. Test every split of each boundary sequence, cancellation that drops pending bytes, and a copying owner that can preserve validation under caller mutation. Complete all thirteen cost/enforcement dimensions with evidence or a mechanism-specific non-applicability.
