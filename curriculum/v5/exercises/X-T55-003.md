# X-T55-003: Epoch cohorts: quiescence, earliest reuse and memory pressure

## Prerequisites

Bring X-T55-002 core, learner container adapter and retention traces. Read PR-T55-07, Crossbeam Pointers/Pinning/Garbage and Michael retention discussion. Know immutable publication, grace periods, wraparound and data races. Crossbeam is comparison material, not a permitted implementation library.

## Environment

C17 and the parent dependency profile remain in force. The anchor uses Linux x86-64, GCC/Clang, CMake and pthreads for host verification only. No libc mechanism implementation, ready-made arena/once/reclamation library, libatomic or hidden helper may enter a strict freestanding target. Record compiler/flags, data model, alignment, atomic lock-free properties, undefined symbols and disassembly. Source-language/library comparisons have their own cited contracts, not additional ISO C guarantees. N1570 is a C11 draft; exact C17 remains an access gap.

## Problem

Implement the serialized two-participant/three-node MBEpoch tracker. At epoch1 enter reader0, retire node0, advance to2, then attempt another advance: BUSY until reader0 leaves. Advance to3 and collect exactly1. Distance1 never collects even with no active readers: this selected policy requires distance2. A reader entering the current cohort permits the first advance. Epoch3 reports FULL rather than wrapping. Add a synchronized adapter to the same learner append/read/remove structure and compare a paused reader0 while the writer removes all three nodes.

Supplied artifacts: `labs/modern_bridge/include/bridge.h`, compiling unsolved `src/bridge.c`, `tests/tests.c`, `fixtures/modern_bridge/cases.json` and the incorporated `labs/modern_bridge/CONTRACTS.md` version1. The contract defines representation, operations, preconditions, error precedence, ownership, finite limits and complexity. Preserve the interface. Target adapters remain separate learner sources; retain imported learner source hashes rather than copying assessor code.

## Necessity

A grace-period label does not identify readers that can still observe a retired node. A counter alone protects no access; silently deleting an active participant manufactures quiescence. A safe epoch scheme may retain memory indefinitely behind a stopped reader.

## Reasoning

For each node enumerate possible observers, entry epochs, required quiescent boundaries and first policy-admitted reuse. Distinguish conservative two-advance policy from theoretical earliest reuse under stronger knowledge. Subtraction is safe here because epochs never wrap. Plain MBEpoch fields cannot be raced. Derive real entry-before-access and remove-before-grace ordering and map synchronization to C and the target. Compare Crossbeam Guard library protocol with explicit C discipline; no borrow checker/collector is present. Bounded storage can fail despite nonblocking unrelated operations.

For each operation state pre/postconditions, invariants, ownership and failure preservation. Assign guarantees to ISO C, compiler/ABI contract, runtime checks, external verification or caller discipline. Supply one plausible incorrect explanation and minimal counterexample. Complete the13-dimension modern cost review, with justified non-applicability; compare equal correctness and ownership contracts.
