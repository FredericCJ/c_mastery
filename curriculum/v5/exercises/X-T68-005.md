## Problem

Implement a _Generic receiver dispatcher selecting functions for uint32_t* and const uint32_t*. The mutable receiver returnsvalue+100, const receiver returnsvalue+200, using modulo arithmetic; neither modifies the pointed value. mp_generic_receivers invokes both through pointer-producing expressions and reports exactlytwoevaluations. Unsupported receiver categories receive a compile-time diagnostic; there is no default erased fallback.

Concrete inputs and expected results: Mutable7 and const9 produce316 with2evaluations and unchanged pointees. Selecting the mutable policy for the const receiver produces the wrong semantic marker even if a cast lets it compile.

Supplied artifacts: labs/metaprog/include/metaprog.h, compiling unsolved src/metaprog.c, CTest metaprog.generic, fixtures/metaprog/PR-T68-05.json, and the shared contracts. State every additional backend assumption before running it.

The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.
