## Problem

Implement sd_channel_init/grant/send/receive/close/reopen. Queue bytes{1,0,255}, attempt receive through SEND-only rights, a too-small destination and a validator that denies the whole span; each must preserve the message and caller canaries. Then close, drain the exact bytes, return CLOSED on empty and reject an old capability after reopening. Fill both slots; send zero bytes with NULL; retire an epoch at UINT32_MAX without wrap. Derive a copyout proof that remains valid between validation and copy; a callback that merely checks a transient page table does not satisfy it.
