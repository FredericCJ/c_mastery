# X-T67-007: Recursive arena values and typed indices

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: . Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Implement ad_eval for1..32ADNodes. Kind0 is uint32 literal; kind1 adds two child indices, each strictly less than the current node index. Validate every node, even if unreachable from root. Root must be in range. Addition is mathematical uint32 with overflow rejection, output unchanged on failure. Use iterative evaluation and fixed32word scratch storage, no recursion or library graph engine.

Concrete inputs and expected results: CONST7,CONST9,ADD(0,1),root2 yields16. A self-child2 fails. UINT32_MAX+9 fails without changing prior output.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.arena, fixtures/adt/PR-T67-07.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Derive acyclicity from a topological child-index invariant and explain when a checked arena can support unchecked internal traversal without allowing later mutation to invalidate the proof. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Prove by induction on node index that each value is available before its parent; separate index category from actual range validity. Give O(count)time/O(32)stack and compare a recursive tree that duplicates shared children. For validate-once extension, make the arena immutable or invalidate its certificate after every structural mutation. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
