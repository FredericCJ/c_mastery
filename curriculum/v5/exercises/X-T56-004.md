## Problem

Implement sd_files_init/open/dup/seek/read/close over entries alpha="0123456789" and empty={NULL,0}. Two opens start independently: reads3 and4 yield012 and0123. Duplicate the first handle; reading2 through its duplicate yields34 and reading1 through the original yields5. Denied read2 must leave that shared offset6 and output unchanged; the next read1 yields6. Seek end-1 then read3 returns9 only, and EOF permits NULL with length0. Reject negative/out-of-range seeks, ../alpha, duplicate names, stale closes, exhausted handles and generation wrap. Borrowed archive bytes must remain live until the last description closes.

## Necessity

The retained CMK_BOOT_FILE syscall copies an entire named archive entry. It has no per-open offsets or duplicate-description semantics. Tests of whole-file bounds cannot establish these distinct lifetime and offset properties. A complete-span preflight must precede both copy and offset advancement.
