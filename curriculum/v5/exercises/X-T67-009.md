# X-T67-009: Evolution-aware sums and lossless tolerant readers

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: codec.records, bytes.cursor. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Implement original teaching TLV [tag:u8,length:u8,payload]. Tag1 has exactly2payloadbytes,tag2 has0; tags3..127 are unknown advisory variants retained as borrowed bytes;0 and128..255 fail. Require exact input extent and lossless re-encoding. Write into disjoint caller storage only after complete capacity validation, with used/output unchanged on failure. This is not a Protobuf-compatible wire implementation.

Concrete inputs and expected results: 09 03 04 05 06 round-trips byte-for-byte;01 01 07 fails as malformed known data;80 00 fails as unsupported required semantics.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.evolution, fixtures/adt/PR-T67-09.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Distinguish tolerance from permissiveness: an unknown noncritical alternative can be retained exactly, while malformed known alternatives and unknown required semantics must fail. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Define a sum of known-number, known-empty and unknown bytes; retain tag and payload even when semantics are unavailable. State lifetime, disjointness, maximum255payloadbytes and overflow-free size calculation. Compare binary unknown-field preservation with the inspected Protobuf guide and demonstrate a field-wise rebuilding path that loses unknown data. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
