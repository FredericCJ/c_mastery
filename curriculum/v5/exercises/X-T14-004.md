# X-T14-004: Ordered segment aggregation with affine lazy maps

## Prerequisites

Read PR-T14-09 and the applicable T14/T15 module teaching. Bring your own array/bounds tests and invariant notebook; no unlisted accepted artifact import is required. ## Problem

Implement a fixed-capacity range index over residues modulo65521. Return all four fields of the ordered polynomial aggregate, and apply affine maps to half-open ranges. Use [1,2,3] and the exact examples in the shared contract as hand calculations. Then compose x->2x+1 followed by x->3x+4 on overlapping proper subranges; include assignment a=0. Queries must not mutate the object. No external segment-tree implementation or hashing library may perform this mechanism.

## Necessity

A range-sum example hides reversal because addition commutes. This aggregate exposes order errors, while affine tags expose wrong temporal composition. Assignment cannot be encoded by treating zero as an absent-tag marker. Algebraic laws, not a generic tree heading, justify lazy propagation.

## Reasoning

Prove identity and associativity by interpreting aggregates as sequences. Derive mapping over concatenation and newer-after-older affine composition. State exactly which stored aggregate already includes which pending tag; derive read-only query carry order. Bound intermediate uint64 products and node indexes. Show why a constant-sized algebraic operation is required for the quoted logarithmic operation cost. Explain why equal polynomial residues do not prove equal text. Include one plausible incorrect explanation and its smallest counterexample. Separate mathematical proof, ISO C guarantees, compiler diagnostics, dynamic checks and caller discipline. Fixed bounds make experiments tractable; they do not excuse a false general complexity claim.
