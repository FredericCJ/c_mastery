# X-T76-001: Positioned event logs and persistent snapshot roots

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: persist.hamt, codec.records, storage.pages, testing.faults. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [replicated/CONTRACTS.md](../../../labs/replicated/CONTRACTS.md).

## Problem

Implement RPLog and rp_log_init/append/get. The original in-memory log contains at most16 events (position1..16,key0..31,int32 value) and17 snapshot roots. Each append first updates the imported persist.hamt arena, then publishes the event and root together. get(position,key) queries the exact retained prefix; position0 is empty. Invalid key/position, log full and injected HAMT allocation failure preserve published state and output. Replay an admitted prefix into a fresh fixed-address arena; values are latest event payload per key, not accumulated balances. No filesystem durability is implied.

Concrete inputs and expected results: Append(3,7),append(3,9): prefix1 returns7 and prefix2 returns9. Inject each allocation ordinal1..3 on the next append: count stays2, used count is restored and prior roots still resolve. The17th append returns RP_FULL without consuming nodes.

Supplied artifacts: labs/replicated/include/replicated.h, compiling unsolved src/replicated.c, CTest replicated.log, fixtures/replicated/PR-T76-01.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Distinguish immutable event history, a current projection, a retained snapshot root and durable storage. Derive why replay requires event-version and external-query assumptions, not merely a list of bytes. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.
