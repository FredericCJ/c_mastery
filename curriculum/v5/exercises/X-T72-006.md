## Security

Target the combinator parser `co_parse` in `labs/coroutines` over a bounded `struct co_parser` DAG, using only synthetic values. No network service or hardware is involved.

- Adversary: chooses the input bytes, the DAG within the node limit (including CO_MANY over an empty node) and the visit budget. It cannot supply an unbounded grammar or change the DAG during a parse.
- Violated property: termination within the budget (a nullable repetition must not loop) and parse correctness (a failed alternative restores the cursor).
- Boundary: in-process host model; harmless success is the illegal state change or counter recorded by the harness, never a crash left running.
- Evidence to capture: run `coroutines.parser` (`ac` ends at 1, `ab` at 2, `x` is CO_NO_MATCH with end 91, budget 0 is CO_RANGE with steps 0, many over empty is CO_STATE with end 91). Build a variant without the progress check or without rollback as `labs/coroutines/CONTRACTS.md` asks, run only under a finite budget, and record steps and end.
- Impact class: demonstrated-invariant-violation, from the learner-built defective variant only (no flawed variant is supplied and the supplied test passes on a correct build, so no supplied artifact demonstrates it); not a crash, sanitizer finding or undefined behaviour, and not a proved impact.
- Remediation and regression: reject nullable repetition, charge visits before work and roll back the cursor; `coroutines.parser` must fail the variant.
- Limitations: rollback covers the cursor only, not allocations or other action effects.
