# Resolve a cross-object call and account for the loaded image

## Prerequisites

Complete X-T08-001 before beginning.

## Environment

Use Linux x86-64 System V AMD64. From the exported workspace root run `python3 inspect_lab.py prepare --cc gcc`. Record the output directory, compiler version and manifest. The commands and answer-field conventions are in CONTRACTS.md.

## Problem

Explain how the call to record_score acquires a destination and where record_calls gets its initial value. Predict which addresses will change between an object, the linked PIE and a running process.

## Necessity

Resolve the caller's relocation against the provider definition. An output value by itself omits the evidence that connects this claim to a particular build.

## Reasoning

Use `objdump -dr driver.o` with `readelf -Wr driver.o` to locate the field and name its relocation. Show the addend and place for this architecture. Disassemble main in the linked image. In GDB, stop in main, record `p/x &record_score`, and subtract the symbol value to derive the load bias. Compare the RW LOAD's file and memory lengths and `.bss` section type. Explain who zeroes that memory for the hosted process.

## Deliverables

- D1. Write your prediction before running the relevant inspection tools. Record the commands, file identities and observations in `answers/linking.json`. Include `prediction`, `explanation` and the fields `elf_sha256`, `relocation_offset`, `relocation_type`, `bss_type`, `rw_file_size`, `rw_memory_size`.
- D2. In your explanation, cite the bytes, instruction, header field or counter row supporting each inference in the reasoning exercise.
- D3. Rebuild in another scratch directory with a different optimization level. Derive the new site and bias afresh. Explain why zero-filled storage cannot in general be recovered by slicing that many bytes from disk.

## Verification

Run `python3 inspect_lab.py check linking --cc gcc`. For a hosted Clang build prepare and check with `--cc clang`. Preserve the manifest with the submission. A reviewer reads the written reasoning alongside the machine-checked observations.

## Rubric

- R1. Resolve the caller's relocation against the provider definition.
- R2. Relate linked address formation, PIE load bias and zero-filled storage to the process image.

## Hints

An ET_REL relocation offset is relative to its target section. Segment fields describe what the loader maps. Use section and program headers side by side.

## Variants

V1 is a delayed independent transfer on a changed artifact, at least seven days after the first attempt. Derive the result from the supplied inputs and identify the evidence needed for each claim.

## Security

Use the supplied original program and locally generated files. Keep measured images, host details and observation logs in the local workspace.

## Validation

The checker compares selected artifact facts. The assessor separately evaluates the derivation, changed condition and whether an independent transfer took place.
