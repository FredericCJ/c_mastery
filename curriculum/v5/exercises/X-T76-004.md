# X-T76-004: Join-semilattice counters and deterministic registers

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: codec.records, io.frame. Do not import an assessor implementation.

## Environment

Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [replicated/CONTRACTS.md](../../../labs/replicated/CONTRACTS.md).

## Problem

Implement RPPN with3 positive and3 negative uint32 components, checked local increments and int64 query sum(P)-sum(N). Merge by componentwise maximum, allowing self-merge. Implement RPRegister merge by lexicographic(timestamp,replica0..2); identical identity with different payload is RP_CONFLICT. A canonical initial register is(0,0,0), and generated writes use positive timestamps. Inputs must derive from one writer per replica identity; public fields are not Byzantine proofs.

Concrete inputs and expected results: Replica0 adds5; replica1 subtracts3. Merge yields2 and repeating the same merge remains2. Register(7,0,1) joined with(7,2,9) chooses9; another payload at(7,2) is a conflict. Adding UINT32_MAX to component5 fails unchanged.

Supplied artifacts: labs/replicated/include/replicated.h, compiling unsolved src/replicated.c, CTest replicated.counters, fixtures/replicated/PR-T76-04.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Derive convergence from explicit componentwise joins and globally unique writer identities, and distinguish state merge from replaying operations. A last-writer register resolves an order chosen by the protocol, not necessarily real-time recency. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Prove idempotence, commutativity and associativity on admitted compatible states, plus inflation of each grow-only component. Explain why sum of received states double-counts retransmission, why finite overflow must reject, and why a reused writer identity with forked state violates the ownership model. For registers identify conflict cases outside the unique-event assumption and the total-order tie rule. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
