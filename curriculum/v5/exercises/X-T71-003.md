## Security

Target `pt_session_step` and the in-process two-endpoint driver in `labs/protocols`, using only synthetic values. No network service or hardware is involved.

- Adversary: chooses the ordered (sending role, tag) pairs, including wrong direction, wrong tag, a replayed message and any step after BYE. It does not control the phase table, scheduler or transport.
- Violated property: protocol integrity: an endpoint advances only on the tag and direction its phase admits, remaining decreases once per ACK, and a terminal session never progresses.
- Boundary: in-process host model; harmless success is the illegal state change or counter recorded by the harness, never a crash left running.
- Evidence to capture: run `protocols.session` (every role and remaining 0..8: wrong-side HELLO is PT_STATE with phase 0, DATA/ACK keep remaining exact, BYE reaches phase 5 and a second BYE is PT_STATE). Add a wrong-tag case, then build a defective variant (for example one skipping the direction check) as `labs/protocols/CONTRACTS.md` asks, and record its input sequence and the illegal transition.
- Impact class: demonstrated-invariant-violation, from the learner-built defective variant only (no flawed variant is supplied and the supplied test passes on a correct build, so no supplied artifact demonstrates it); not a crash, sanitizer finding or undefined behaviour, and not a proved impact.
- Remediation and regression: reject before any state change and keep BYE absorbing; `protocols.session` plus the wrong-tag case must fail the defective variant.
- Limitations: a lost message or an endpoint that is never scheduled still deadlocks matching automata; C tags do not inherit the guarantees of a typed session language.
