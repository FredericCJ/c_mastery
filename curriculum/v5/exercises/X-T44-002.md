# Reconcile GDB observations with a stripped Ghidra decompilation

## Prerequisites

Complete X-T09-001 before beginning.

## Environment

Use Linux x86-64 System V AMD64. From the exported workspace root run `python3 inspect_lab.py prepare --cc gcc`. Record the output directory, compiler version and manifest. The commands and answer-field conventions are in CONTRACTS.md.

## Problem

Predict the arguments and return value of the first call. Compare an instruction breakpoint in the debug and optimized images. Investigate a separately stripped copy in Ghidra CodeBrowser and reconstruct its semantics from call sites, data references and the decompiler.

## Necessity

Explain a source-level observation that changes under optimization using stopped instructions. An output value by itself omits the evidence that connects this claim to a particular build.

## Reasoning

In GDB break at `*record_score`, record the incoming integer registers, then use `finish` and record the return register. Compare source stepping, line mappings and local availability under -Og and -O2. In CodeBrowser import `stripped`, enable analysis, find the computation by following main's caller/callee graph, rename the function, and write a function plate comment explaining its branch and counter side effect. Run ExportInspection.java from the Script Manager at that function.

## Deliverables

- D1. Write your prediction before running the relevant inspection tools. Record the commands, file identities and observations in `answers/debugger.json`. Include `prediction`, `explanation` and the fields `debug_args_and_return`, `optimized_args_and_return`, `annotation`.
- D2. In your explanation, cite the bytes, instruction, header field or counter row supporting each inference in the reasoning exercise.
- D3. Use a different compiler and reassess the argument registers and the decompiler's inferred types. Identify one property the snapshot or pseudocode alone leaves uncertain. Include matching hashes for the debug, optimized and imported images.

## Verification

Run `python3 inspect_lab.py check debugger --cc gcc`. For a hosted Clang build prepare and check with `--cc clang`. Preserve the manifest with the submission. A reviewer reads the written reasoning alongside the machine-checked observations.

## Rubric

- R1. Explain a source-level observation that changes under optimization using stopped instructions.
- R2. Match a renamed stripped function and decompiler annotation to the exact measured image and ABI observations.

## Hints

Pair the stripped and optimized executable by normalized function RVA and file identity. A symbol name remembered from the debug variant is insufficient evidence of what the stripped function does.

## Variants

V1 is a delayed independent transfer on a changed artifact, at least seven days after the first attempt. Derive the result from the supplied inputs and identify the evidence needed for each claim.

## Security

Use the supplied original program and locally generated files. Keep measured images, host details and observation logs in the local workspace.

## Validation

The checker compares selected artifact facts. The assessor separately evaluates the derivation, changed condition and whether an independent transfer took place.
