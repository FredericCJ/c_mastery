## Problem

Implement the fused contiguous-key nonnegative-sum query, an unfused scan/filter/group operator chain and a bounded push adapter with identical error and order contracts.

The complete representation, operations, input bounds, state transitions, ownership, callback rules, failure behavior and output contract are supplied by the shared contract. Concrete inputs and independent expected result: Rows(1,-1),(1,3),(1,4),(2,-8),(3,5),(4,6) produce(1,7),(3,5),(4,6). A first next stops at index3 and cannot consume group3.

Supplied artifacts are labs/coroutines/include, labs/coroutines/src, the coroutines.dataflow CTest and fixtures/coroutines/PR-T72-02.json. Implement the mechanism from permitted primitives. Complete the required alternative/integration as well as this bounded executable anchor.

## Necessity

Explain open/next/close and group-boundary ownership in a pull dataflow plan; distinguish iterator backpressure from unbounded eager materialization. A passing nominal example does not assess the two independent misconception controls or the changed-condition obligations.

## Reasoning

Write valid states and transition pre/postconditions before code. State precisely what is guaranteed by ISO C, compiler diagnostics, runtime checks, the ABI, external verification and programmer discipline. Explain open/next/close and group-boundary ownership in a pull dataflow plan; distinguish iterator backpressure from unbounded eager materialization. Account for ownership during partial progress and cleanup, not just successful returns. Derive operation and storage bounds for this model, and supply a counterexample to an overstated language-equivalence claim.
