# X-T76-007: Merkle commitments and bounded anti-entropy

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: codec.records, io.frame. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [replicated/CONTRACTS.md](../../../labs/replicated/CONTRACTS.md).

## Problem

Implement local SHA-256 for byte lengths0..65 directly from RFC6234 equations, and RFC9162-style Merkle roots over0..8 uint32 leaves encoded big-endian. Empty root is SHA256(empty), leaf is SHA256(00||four bytes), internal node is SHA256(01||left||right), split at largest power of two strictly below count. Implement recursive equal-subtree skipping and return a bitmask of differing leaf positions for equal-length trees. No target hash library, network service or certificate-transparency implementation may replace these mechanisms.

Concrete inputs and expected results: SHA256(empty)=e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855. Trees[1,2,3] and[1,2,9] differ only at bit2 (mask4); empty trees give mask0. Compare every count0..8 with a separately implemented Python hashlib construction.

Supplied artifacts: labs/replicated/include/replicated.h, compiling unsolved src/replicated.c, CTest replicated.merkle, fixtures/replicated/PR-T76-07.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Derive a domain-separated Merkle root for an exact ordered leaf sequence, distinguishing hash equality under a collision assumption from identity authentication, availability or a proof that arbitrary bytes are well formed. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Derive padding across55/56/63/64/65-byte boundaries, uint32 modular arithmetic, round constants and endian conversion. Prove the tree shape for non-power-of-two counts and that a subtree comparison is meaningful only with the same position/range/domain. Account for hash collision and corrupt-peer assumptions; a matching root alone authenticates no sender and guarantees no retrievability. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
