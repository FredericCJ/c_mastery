# X-T42-004: Descriptor incarnations across stale events and interest changes

## Prerequisites

Complete parent teaching and retain explicit source/contract identities for reused learner integer, parser, clock and event components. C17 object lifetime, bounds and failure publication are prerequisites. The assessor implementations are excluded from learner exports.

## Environment

Use the compiling learner scaffold and shared CONTRACTS.md. Core code uses type/limit headers only; no existing parser/calendar library implements the studied mechanism. Host Python, sanitizers and socket/retained-component verification are separate dependencies.

## Problem

Implement the four-slot HDPool. Admit11..14, reject15 without taking ownership; close one handle and reuse its same fd with a new generation. Replaying the old readable event and old close must be STALE with unchanged outputs. Exercise generationUINT32_MAX retirement, duplicate live fd, unverified flags and READ/WRITE/HUP/ERROR interest masks. The supplied local socketpair adapter sets/verifies flags and uses dup2 only on its just-released owned descriptor to demonstrate actual integer reuse.

## Necessity

An fd value alone is not a stable connection identity, and writable readiness without queued work can spin. Generations reject queued identities but do not revoke raw pointers or cancel already executing callbacks; quiescence remains an adapter precondition.

## Reasoning

An fd value alone is not a stable connection identity, and writable readiness without queued work can spin. Generations reject queued identities but do not revoke raw pointers or cancel already executing callbacks; quiescence remains an adapter precondition. Prove pre/postconditions, input/output separation, invariant preservation, failure publication and costs. Separate C17 arithmetic/lifetime guarantees from original policy, RFC semantics, Linux behavior and programmer discipline. C2x syntax probes are not semantic equivalence evidence.

## Security

Use only original local teaching C, synthetic request spans and owned local socketpairs. The adversary controls inputs/event order inside live storage. A harmless success is wrong local framing status or wrong incarnation dispatch. State each exposing transition and prerequisites, compare corrected code and regressions, and retain caller lifetime/clock trust limits. No remote endpoint, production system, external packets, host security setting changes or flashing. A crash or status mismatch is not arbitrary code execution or a demonstrated proxy attack.
