# X-T67-002: Newtypes and checked dimensional conversions

## Prerequisites

Complete the earlier domain projects and retain the named prerequisite artifacts with their contracts, ownership ledger and tests. Required learner artifacts: bytes.checked, parser.integer. Do not import an assessor implementation.

## Environment

Implement mechanisms locally using declared typed storage/callbacks; hosted harness and diagnostic runtimes are separate. See laboratory contract for exact dependencies. Use C17 with extensions disabled and warnings treated as errors. A diagnostic extension is identified explicitly and does not become an ISO guarantee. The full platform, pointer, callback and concurrency preconditions are in [adt/CONTRACTS.md](../../../labs/adt/CONTRACTS.md).

## Problem

Implement ad_milliseconds(ADSeconds,ADMillis*). Conversion succeeds exactly for seconds<=UINT32_MAX/1000, with exact multiplication and unchanged output otherwise. Separate nominal dimensional distinction from runtime range validation. Add diagnostic probes for passing ADMillis to the ADSeconds parameter and for the unsafe typedef-only alternative.

Concrete inputs and expected results: 42seconds becomes42000milliseconds;4294967seconds becomes4294967000;4294968seconds fails without modifying output;zero succeeds.

Supplied artifacts: labs/adt/include/adt.h, compiling unsolved src/adt.c, CTest adt.quantities, fixtures/adt/PR-T67-02.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Explain why two distinct struct wrapper types reject accidental argument substitution while two typedef names for uint32_t do not; derive the exact safe seconds-to-milliseconds domain. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Derive the division-before-multiplication admission test and show that the largest accepted seconds value maps below UINT32_MAX. Compare the inspected C++ duration_cast ratio formulas; static_cast or a distinct duration type does not itself establish arbitrary destination representability. Specify round/truncate behavior before adding fractional units. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.

- D1: Explain why two distinct struct wrapper types reject accidental argument substitution while two typedef names for uint32_t do not; derive the exact safe seconds-to-milliseconds domain.
- D2: Derive the division-before-multiplication admission test and show that the largest accepted seconds value maps below UINT32_MAX. Compare the inspected C++ duration_cast ratio formulas; static_cast or a distinct duration type does not itself establish arbitrary destination representability. - D3: Run adt.quantities and reject wrong nominal type in a separate compilation. Kill missing-range-check and wrong-scale mutants, then test both sides of the quotient boundary. Show an explicit cast or field extraction bypass and identify programmer discipline rather than claim unforgeability.
- D4: Introduce signed microseconds and rational tick periods with a nonintegral ratio. Implement checked conversion with explicit rounding toward zero and a loss-of-precision result; derive bounds without a wider integer type. Complete all thirteen cost/enforcement dimensions with evidence or a mechanism-specific non-applicability.
