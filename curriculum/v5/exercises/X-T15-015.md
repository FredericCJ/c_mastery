# X-T15-015: Document algebra, continuation-sensitive grouping and AST-preserving formatting

## Prerequisites

Know typed arrays, half-open ranges, staged publication, source offsets and syntax/semantics separation. Recovery and formatting require your completed X-T15-012 implementation and its exact PdTree contracts. Bring grammar traces, failure snapshots and the public `parsing_depth` workspace; dependency import is explicit. Template evaluation additionally needs lexical scope and bounded graph traversal. No library implements the new mechanism for you.

## Environment

The explicit [text-composition contract1](../../../labs/text_composition/CONTRACTS.md) gives all input types, operations, exact grammar, capacities, ownership, failure/resource and local security rules. Implement `src/text.c`; configure the actual prerequisite workspace with CMASTERY_PARSING_DEPTH_ROOT. Host tools and models remain outside the target component contract. Inspect dependency identity and emitted resource costs; no runtime absence or language-level safety follows from the API spelling.

## Problem

Implement typed NIL/TEXT/LINE/CAT/NEST/GROUP documents and the specified bounded layout interpreter. Include the pending continuation when choosing flat groups. Implement tc_expression_doc over an actual successful PdTree and reparse every width to the same syntactic tree, even when evaluation overflows. At width4, group(nest(2,a LINE b)) CAT zzz must emit a newline and two spaces; width6 can flatten it.

## Necessity

Concatenating preformatted strings loses grouping and indentation semantics. A group that fits alone may overflow when followed by unbreakable text. Equal evaluated values do not prove that formatting preserves syntax, and an acyclic shared DAG can unfold to far more work than its unique node count.

## Reasoning

Derive the CAT unit/associativity, flattening and nesting laws, and the explicit pending-frame invariant. Explain the precise greedy probe rule and why it is not a claim of global optimality or a lazy language implementation. Prove failure atomicity and termination under node/fuel/output bounds, including cumulative nesting and repeated DAG references. For expression formatting preserve operator kinds and child structure, not source offsets or merely values. Supply pre/postconditions, loop/stack invariants, ownership, failure and complexity arguments. Classify guarantees supplied by ISO C, diagnostics, runtime checks, external models and caller discipline separately.

- D1: Representation/grammar derivation, inspected-source comparison, exact invariant and a plausible wrong explanation with a counterexample.
- D2: Original C mechanism and actual prerequisite binding, resource/stack/work ledger, staged output and cleanup argument.
- D3: Independent oracle, complete concrete inputs/results, boundary/failure preservation snapshots and two causal semantic mutants.
- D4: Named delayed transfer implementation and predictions, changed assumptions, equal-contract comparison and evidence limits.

## Verification

Force a cyclic/forward child, oversized indentation, low fuel and output exhaustion. Kill ignore-continuation and lose-nesting mutants separately. Retain a simple reference and explain both unbreakable overflow and repeated-lookahead resource costs. Run GCC/Clang debug, optimized and sanitizer profiles; retain exact commands, raw outputs and source hashes. Public `text_composition.layout` must reject the compiling incomplete scaffold with TC_ASSERT. Passing public examples without D1/D4 is insufficient. The private oracle uses a different model and the reference campaign checks mutation sensitivity.
