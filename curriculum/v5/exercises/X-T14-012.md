# X-T14-012: Live-universe bitmap queries and nullable logic

## Prerequisites

Complete X-T04-001 and bring your original unsigned bit tests and array mutation notebook. Know stable identities, sorted lists, bounds, lifetimes and loop invariants. Read the exact inspected passages and shared contract. The three index exercises use one data representation; later composition imports your completed components explicitly, while author validation uses identified private references.

## Environment

Use the JSON C17 profile and actual recorded toolchains. Core code may not call database, search or bitset libraries. The shared contract specifies allowed original compiler helpers and separates host-side verification. Compiler-generated objects and linked images must be inspected. Changing C edition does not enforce index consistency, snapshot identity or lifetime safety; any C23 comparison must name the exact changed language rule rather than claim automatic protection.

## Problem

Implement qi_build, qi_replace and qi_terms for the32-slot shared row model. Track live identities and one incidence mask per term. Replacing row7 must remove its former term bits; deleting a row must exclude it from every complement. Empty required/forbidden sets select exactly live rows. Supply a dense-versus-sparse representation/cost comparison without using a bitset library.

The supplied query.h, unsolved src/query.c, public tests, driver and cases.json establish concrete inputs and outputs. Incorporate every representation, failure-priority, alias/lifetime and size rule in labs/corpus_query/CONTRACTS.md. Preserve the common APIs so the final composition calls the actual earlier mechanisms.

## Necessity

Machine-word NOT has a larger universe than live rows. Stale incidence bits survive ordinary insertion-only tests, and nullable truth is not two-valued Boolean complement. Provide a plausible incorrect explanation and a minimal falsifying input.

## Reasoning

Derive the specific invariant and operation proof in the shared contract, including empty and maximum states, stable row ownership and output unchanged on rejection. Show which assumptions are enforced by ISO C, diagnostics, runtime checks or caller discipline. Give the exact cost model with N rows,T terms,L positions and group size. Keep candidate filtering distinct from final predicate truth. Revisit the argument for nullable values, deletion and changed assumptions in D4.

## Deliverables

- D1: Representation diagrams, pre/postconditions, proof and counterexample with inspected source locators.
- D2: Original implementation and mutation traces, build/dependency manifests, actual object/link audit and stack/storage accounting.
- D3: Independent raw-row model, positive and negative inputs, failure-state comparisons, two discriminating compiled mutants for this anchor, and measured equivalent-contract workloads.
- D4: Named delayed implementation and integration, changed-condition proof, independent comparison and resource explanation.

## Verification

Use the public bitmap anchor and all shared procedures. The independent oracle scans raw rows and token sequences rather than reconstructing the index under test. Record exact seed731207 and explored bounds from the current campaign. Test empty/full word width, dead/null rows, replacement removing old facts, repeated tokens, interval boundaries and errors relevant to this mechanism. Run GCC/Clang debug, release and ASan/UBSan, require each compiled mutant to fail its own QI_CHECK, and verify the unsolved exported scaffold compiles before semantic rejection. Keep exact source hashes and raw results. Finite cases do not establish universal correctness.
