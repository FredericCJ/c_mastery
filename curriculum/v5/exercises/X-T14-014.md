## Problem

Build four-slot zone summaries and implement inclusive qi_range. Query[4,4] must retain a group whose minimum is4. A group with only0 and10 is a candidate for[5,5] but supplies no result. Compare sorted and permuted row orders with the same values; inspect actual groups/rows counters. Null-only and deleted groups must not produce values.

The supplied query.h, unsolved src/query.c, public tests, driver and cases.json establish concrete inputs and outputs. Incorporate every representation, failure-priority, alias/lifetime and size rule in labs/corpus_query/CONTRACTS.md. Preserve the common APIs so the final composition calls the actual earlier mechanisms.

## Necessity

A summary overlap is necessary, not sufficient. A stale narrow interval silently drops legitimate results after replacement; a stale wider interval only increases work. These defects cannot be assessed by ordinary container lookup. Provide a plausible incorrect explanation and a minimal falsifying input.

## Reasoning

Derive the specific invariant and operation proof in the shared contract, including empty and maximum states, stable row ownership and output unchanged on rejection. Show which assumptions are enforced by ISO C, diagnostics, runtime checks or caller discipline. Give the exact cost model with N rows,T terms,L positions and group size. Keep candidate filtering distinct from final predicate truth. Revisit the argument for nullable values, deletion and changed assumptions in D4.
