## Problem

Implement RPState{tick0..8,position0..15,score0..65535,random:uint32}. rp_step consumes movement-1/0/1, wraps position on a16cell ring, advances LCG random=random*1664525+1013904223 modulo2^32, adds(random&3) with checked score limit and returns RPEffect{tick,score} as data. No clocks,I/O,allocation or callbacks occur in the reducer. rp_replay stages at most8 steps and effects, preserving outputs on failure. Restore the state before a changed input and replay the suffix; compare with a fresh fold of corrected inputs. rp_checkpoint composes two actual HAMT updates for position/score under one root publication and injects failure at each of6allocation ordinals; it is a projection checkpoint, not the full replay snapshot (tick/random remain in the explicit RPState snapshot).

Concrete inputs and expected results: Initial(0,0,0,1),movement-1 gives position15,random1015568748,score0; next movement1 gives position0,score3. Eight inputs[1,1,0,-1,1,0,1,-1] produce score12. Replacing input4 with1 and replaying from the prior snapshot equals a fresh corrected fold. All six checkpoint failure cuts preserve the published root and used count.

Supplied artifacts: labs/replicated/include/replicated.h, compiling unsolved src/replicated.c, CTest replicated.replay, fixtures/replicated/PR-T76-09.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Implement the T20.03 functional-core boundary: explicit state and recorded input produce new state and effect requests, while an adapter owns effects. Demonstrate rollback equivalence without replaying externally visible effects or claiming that ordinary C enforces purity. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Prove determinism from complete state/input and defined unsigned arithmetic. Identify every effect boundary and distinguish speculative requests from committed presentation. Derive rollback of the HAMT used cursor after a failed second update while preserving old reachable roots; staged unreachable arena cells and allocation counters may differ. All arena users must be quiescent during the transaction, and roots from unpublished intermediate updates must never escape. Score overflow or invalid movement must not partially publish a state/effect. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
