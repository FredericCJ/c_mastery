## Problem

Implement MPKey equality overx,y only; cache is explicitly nonsemantic. Hash canonical little-endian64bit words forx theny with the supplied specified FNV-1a recurrence, not native struct bytes. Implement mp_find_counterexample for pure MPProperty over bounded pairs0..bound, bound<=255: deterministic lexicographic enumeration, first failing input, then decrement-one-coordinate shrinking while failure persists. Return1with locally minimal witness,0if all admitted pairs pass,-1on invalid property/bound; no failure output publication for0/-1.

Concrete inputs and expected results: Keys(1,2,cache0) and(1,2,cache9) compareequal and hash equally; (1,3,0) differs. Propertyx+y<5 over0..8 yields a failing pair ofsum5. Reflexivity finds no failure in the bounded domain.

Supplied artifacts: labs/metaprog/include/metaprog.h, compiling unsolved src/metaprog.c, CTest metaprog.laws, fixtures/metaprog/PR-T68-07.json, and the shared contracts. State every additional backend assumption before running it.

## Necessity

Explain the equality-implies-equal-hash law, why cached/nonsemantic fields must be excluded consistently, and what deterministic generation plus shrinking establishes and leaves unproved. The misconception and changed-condition case below are separately assessed; ordinary successful execution alone does not cover them.

## Reasoning

Prove reflexivity/symmetry/transitivity obligations separately from hashing and collisions. Specify FNV parameters and unsigned64 wrap; this is not a cryptographic integrity claim. The shrinking order finds a local minimum under decrement moves, not necessarily a globally simplest witness for arbitrary nonmonotone predicates. Callback/context must remain live, deterministic and side-effect controlled. Give the abstraction function, admitted states, pre/postconditions, ownership graph, failure effects and complexity before implementation. Identify the enforcement boundary of every safety claim using the shared modern-cost contract. Distinguish an invalid caller object from an operational failure admitted by the API.
