## R1 — representation and admission
At ISN0xfffffff0 a copied50-byte send commits NXT34. A refused51-byte send under rwnd50 and a refused lower copy leave output sequence123 untouched. ACK35 lies one byte beyond NXT and cannot retire flight. The struct owns no application buffer: the copy adapter must already own bytes and retain them until acknowledgement. A list of outstanding segments is a valid alternative if cumulative advancement, retransmission identity and resource bounds agree. A candidate that increments NXT before refused admission fails even if a later retry accidentally restores byte count. Inspect API preconditions as well as tests: nonnull live pointers, no aliasing outputs and serialized access are programmer obligations.

## R2 — growth
For n<=MSS, partition n new bytes into any composition. Sum min(part,MSS)=n, so final slow-start cwnd=2n regardless of the4095 partitions tested. Mutant4 adds MSS on every ACK and reaches5100 rather than150 after fifty1-byte ACKs with initial100. A congestion-avoidance full-window acknowledgement permits one MSS increase independent of partition; the672 oracle cases compare aggregate totals, not a second transition implementation. Larger cumulative ACKs in slow start need not equal per-segment growth: the MSS cap is intentional. Clamp at NR_LIMIT; old credit is less than cwnd and new distance<=65535, so addition stays below2^32. Derive the guarantee under valid-state invariants, not arbitrary field corruption.

## R3 — losses and duplicate ACKs
With cwnd800 but rwnd/actual flight400, threshold200 and recovery cwnd500 follow; using cwnd gives400/700 and is wrong. A changed advertised window and payload-bearing ACK are not qualified duplicates. Cap extra inflation at the original ceiling(flight/MSS), so this trace reaches600 then stops despite twenty extra duplicates. Alternating window updates and duplicate ACKs must not reset the inflation budget; a separate recovery_used counter preserves this invariant. This regression caught the first implementation's reuse of the resettable duplicate counter. New ACK deflates to200. Multiple-loss simulation must fast-retransmit block8 but wait for a timer for block10 under Reno; assuming one fast retransmission repairs every hole is false. A40ms reorder of block8 creates duplicate ACKs and a spurious retransmission with zero drops. Thus duplicates are evidence for a conservative action, not proof of loss. Repeated timeout at the same UNA holds threshold even if intervening recovery permitted more flight; a new ACK starts a new episode. Alternatives using NewReno may be explained but must be separately specified and compared, not silently substituted for required Reno behavior.

## R5 — executable composition and transfer
The simulator links actual NiParse/SChecksum rather than mocks. It parses each queued packet, verifies payload patterns, stores actual out-of-order bytes and emits cumulative ACKs from the receiver's contiguous prefix. Its ACK envelope deliberately retains one synthetic address orientation to reuse a single bounded parser configuration; it is not a bidirectional full TCP wire endpoint. It assumes an already established flow; SYN/FIN/RTT estimator and driver are assessed in preceding labs. Compare the input contracts explicitly before claiming reuse. The lower-copy boundary precedes bottleneck drop; changing a post-copy drop into BUSY would incorrectly erase flight and alter congestion behavior.

## R6 — cost, fairness and adversarial analysis
The finite pilot results are not hardcoded oracle truth. Required relations are exact byte totals, sent packets=128+fast+timeout retransmits, single loss fast/no timeout, multiple loss fast+timeout, reordering fast/zero drops, delayed receiver fewer ACKs/slower clean completion, and symmetric results after renaming flows plus reversing priority. Compute finite-horizon fairness from delivered bytes at100ms. Equal finished workloads always give1 and therefore measure the workload specification rather than fairness. Derive core O(1) work and sizeof state from each ABI; simulator uses explicit bounded event/packet/receiver arrays and O(EVENTS) scanning per tick, so simulated time is not measured CPU throughput. Actual ELF imports, call graph and stack reserve support only the CPU harness and named profiles.

Nine compiled controls:1 ignores rwnd;2 halves cwnd instead of flight;3 counts nonqualifying ACKs;4 inflates on ACK division;5 allows unlimited duplicate inflation;6 re-halves repeated timer expiry;7 omits idle collapse;8 includes Limited Transmit bytes in fast threshold;9 replenishes the recovery budget on a window update. Each must reach the intended public assertion; build failures earn no semantic credit. The local adversarial cases affect only an original numeric controller, with no real packets, accounts or external targets. Corrected inflation is still not authentication, Byzantine tolerance, universal congestion fairness or a full compliant TCP implementation.
