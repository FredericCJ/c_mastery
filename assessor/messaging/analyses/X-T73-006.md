# X-T73-006 assessor technical analysis

SC establishes a total order for bottom publication and top arbitration. Atomic slots avoid a C data race when a losing thief reads a slot later reused by the owner; the failed CAS prevents publication. The no-wrap bound prevents ABA of numeric positions. Pointer payloads introduce a separate object lifetime obligation even if slot loads are atomic. Paper proof assumptions must be matched, not inherited by name.

## Delayed case X-T73-006-DELAYED

Weaken SC to acquire/release/fences one edge at a time, deriving a C memory-model argument and model-checker counterexamples before benchmarking. Delayed assessment changes payloads to pointers and permits array growth: add a reclamation scheme and prove a losing thief cannot dereference freed storage.

Require the revised contract, minimal counterexample, implementation/trace and cost evidence before feedback. Assess the invariant under the new assumptions, not just output similarity. Pause a thief after loading the old array pointer, let the owner grow and retire that array, then resume the thief. Retaining only task objects fails to retain the array. Require an epoch/hazard/owner-quiescence argument for both levels and distinguish allocator reuse from index wrap.

## Limits

## Retained pointer lifetime successor

The queue mutex protects acquisition of both old-array and payload references.
Each speculative thief holds one of each before unlocking; a successful claim
transfers the queue's existing payload reference to the caller and releases only
the speculative reference. A losing thief releases both without output. Growth
transfers the current-array ownership to a new allocation but does not duplicate
any queued payload token. The paused-thief test proves the actual old array stays
allocated across growth and that the winner's payload drop does not destroy a
payload still retained by the loser. Both omissions have compiled controls whose
counter assertions fire before a stale pointer dereference.

The owner final-pop case must advance top as well as bottom. Otherwise the owner
could remove the sole payload, push another at the same logical index, and let a
paused thief falsely claim its former speculative object. Array-slot equality
checks alone do not provide a general reclamation scheme. Review the monotonic
index and no-wrap preconditions independently of mutex exclusion. Destruction
refuses while a speculative thief is active; external admission closure remains
necessary before a successful destroy. Returned payload tokens may outlive the
queue, so allocator/callback context lifetime belongs in the caller contract.

The seven-reference test changes the actual implementation limit to7 and reaches
the refusal and final-release boundaries; it is not a mocked count comparison.
The default remainsUINT_MAX. The independent deque oracle checks5,464 histories
including allocation refusal, growth and mixed-end consumption. Native thousand-
payload contention checks exactly-once drops. This is a deliberate mutex-based
reference acquisition/retirement design: blocking and retained memory under a
stalled owner are costs, not lock-free progress guarantees.
