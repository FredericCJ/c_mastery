# X-T73-001 assessor technical analysis

The parent owns slot allocation; successful pthread_create admits exactly one child. Join creates the lifetime boundary before parent context release, and pthread_join makes the child result observable. Failure order is deliberately independent of scheduling. The work.pool adapter must not retain a second ambiguous owner. A nested scope can propagate cancellation safely but cannot promise prompt return if a descendant ignores checkpoints.

## Assessment boundaries

The assessor implementation is messaging.c in this separate directory tree. Review D1–D4 individually against the metadata rubric. ## Delayed case X-T73-001-DELAYED

Add nested nurseries with a parent deadline: propagate cancellation down while joining upward, retaining contexts until every descendant is quiescent. Delayed assessment supplies two failures racing in different orders; keep deterministic creation-order reporting while preserving both errors in a bounded aggregate.

Require the revised contract, minimal counterexample, implementation/trace and cost evidence before feedback. Assess the invariant under the new assumptions, not just output similarity. An early return after child1 fails violates context lifetime even if tests rarely schedule the remaining child.
