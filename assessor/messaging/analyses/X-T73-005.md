## Actual two-level actor adapter

`followthrough/supervisor.c` stages the original supervisor plan and executes it
against sixteen actual owning actors plus fallible resource callbacks. Quiescence
is checked before publishing a budget or action. Resource liveness is separate
from actor liveness: a failed handler already marks its actor dead, but its
resource must still be closed. Drop queued owners before closing that resource.

The local partial-start failure first tears down the whole branch, including
already restarted children, then consumes a parent restart opportunity. Forward
parent construction ensures child index1 cannot observe stopped index0. Successful
parent reconstruction resets only the child's budget. If the parent also fails,
the whole tree closes after reverse cleanup rather than returning with live
unowned instances. A parent failure must not be hidden by a failed-status return;
tests and the cleanup mutant check actual resource state and create/free counts.
The independent oracle models live-node sets and constructor-failure masks for
3,072 combinations, not by calling the C planner. Sequential transition coverage
is not a proof of arbitrary scheduler behavior or callback correctness.

This analysis records the technical solution and expected reasoning, not learner performance or a non-author review. Public-source comparisons are restricted to the registered inspected passages.
