# X-T73-007 assessor technical analysis

Snapshot-relative version checks prevent a transaction from consuming a value committed after its start. Commit validates reads while holding its own write locks, using saved unlocked versions for those cells. Atomic SC payloads avoid importing the paper pseudocode as racy C. All data remains live for the store lifetime, deliberately leaving arbitrary reclamation outside this proof. An abort can consume a timestamp but cannot publish buffered values.

## Assessment boundaries

The assessor implementation is messaging.c in this separate directory tree. Review D1–D4 individually against the metadata rubric. The deliberate SC_MUTANT values 7 and 17 targets the transactions anchor; require its named semantic assertion, not a compiler failure, timeout or unrelated crash. Additional independent tests remain mandatory.

## Delayed case X-T73-007-DELAYED

Introduce a retryable callback with a synthetic log effect: stage it for commit or supply compensation rather than replaying it blindly. Delayed assessment allows dynamically allocated nodes and privatization; show why the fixed-cell proof says nothing about reclaimed node lifetime and design a compatible reclamation protocol.

Require the revised contract, minimal counterexample, implementation/trace and cost evidence before feedback. Assess the invariant under the new assumptions, not just output similarity. Have a transaction load a node address, another remove and free it, then the first inspect its fields. Rechecking a version after dereference does not repair the lifetime violation. The revised protocol must retain the node before dereference and revalidate the relation that made it reachable.

## Limits

This analysis records the technical solution and expected reasoning, not learner performance or a non-author review. Public-source comparisons are restricted to the registered inspected passages. Tests, sanitizers and bounded models do not prove arbitrary lifetimes, interleavings or environments correct.
