# Assessor analysis: PR-T57-07

Kernel control interfaces outlive one process build. Parsing native structs imports alignment, padding and pointer-size assumptions into the interface. A version and exact-length rule let incompatible messages fail before changing state.

Demonstrate exact-length admission and byte-order independence; distinguish ABI versioning from ISO C object representation and kernel/user pointer validation.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: Repair acceptance of a mismatched embedded length and a cast of unaligned user bytes to a native struct. A correctly decoded version does not authorize an operation.

Require the learner to derive 4660 from the fixture inputs independently. Stage every field and publish the result only after all checks.

Transfer answer obligations: Add a version2 optional field while preserving version1 bytes; compare strict rejection, ignorable extensions and per-operation authorization with adversarial tails.

Actual guest module build/load/unload, concurrent open/remove traces, allocation-fault injection and lockdep/KASAN observations remain mandatory target evidence; host model tests do not satisfy them.
