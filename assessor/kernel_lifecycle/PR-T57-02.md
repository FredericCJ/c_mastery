# Assessor analysis: PR-T57-02

A user copy may stop before transferring the requested span. Its result is a count of bytes not copied in kernel APIs, while a read/write method typically reports completed bytes or an error. Translate between these contracts without treating a user address as a trusted C pointer.

State ownership of unread input, modified prefix and untouched suffix. Explain why a partial-copy return cannot be reused as a negative errno and why cap admission precedes copying.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A faulty wrapper returns the requested count after a partial copy and exposes stale bytes. Demonstrate the stale sentinel in the original local teaching endpoint without touching other processes.

Require the learner to derive 2 from the fixture inputs independently. Completed bytes equal requested minus bytes-not-copied in the guest adapter, with zero-progress error policy stated.

Transfer answer obligations: Change the ABI to all-or-nothing record publication using private staging; inject a fault after a valid header and show no record becomes visible.

Actual guest module build/load/unload, concurrent open/remove traces, allocation-fault injection and lockdep/KASAN observations remain mandatory target evidence; host model tests do not satisfy them.
