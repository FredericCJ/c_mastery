# PR-T51-05 reference and discriminators

Assessor only. CMX is an actual imported implementation and remains unchanged. The successor implements the application predicate loop and request ledger rather than replacing it with a synthetic queue model.

T51.05.a: a signaled waiter can be in mutex reacquisition while the current owner consumes the only item. After ownership arrives, count is zero. The correct request re-enrolls; the single-if mutant consumes a nonexistent item and corrupts the unsigned count/ledger before the harness stops at its intended assertion. The model is serialized and performs no native racing access. With three waiters and one item, only the first claim succeeds and the other two rewait. A pulse without a waiter creates no retained permit.

Do not classify every signal-before-update ordering as wrong. The test pulses while the correct mutex remains owned, observes the waiter in reacquisition, and then changes the predicate before releasing. That signal is useful even though it preceded the state store. A valid proof is about the exclusion/enrollment boundary and eventual recheck, not statement order alone.

T51.05.b: CMX relock sets the associated mutex as the wait object, preserves the selected terminal result in `pending`, and uses an infinite reacquisition deadline. Thus deadline5 can select TIMEOUT while the operation cannot finish at99. Returning TIMEOUT before ownership is restored breaks the wait contract even if no item is lost. Close/cancel follow the same rule. Destroy refusal is the chosen answer to the changed-condition destruction request; no freed control is dereferenced and no successful destruction is reported. The matching-mutex check is stronger than checking that the caller owns some mutex.

T51.05.c: accepted counts commit, claimed counts a received value held in a DONE request, and consumed counts result publication. Result output is not retained. Single signal on a shared condition may select the wrong predicate: a waiting producer is older than a waiting consumer even though only an item, not space, is available. The locked-begin entry creates this concrete schedule atomically using the original release/enroll operation. The single-signal comparison intentionally demonstrates a stalled eligible waiter; the broadcast reference and explicit rescue both preserve the same values and ledger. This is a liveness discriminator rather than a checksum-only test.

Shutdown closes admission and the actual condition but retains queued/claimed values; a blocked producer of9 has no accepted receipt, and later consumers drain7,8 before empty CLOSED. Pending operations must complete and results must be consumed before destruction. The reference's wrapper is externally serialized. It is not a proof that the raw CMX state is safe for arbitrary native threads or interrupt callers. A Cortex-M4 run establishes target execution/dependency closure of the selected state transitions, not context switching, physical performance or all schedules. Independent learner and reviewer gates remain open.
