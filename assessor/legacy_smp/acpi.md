# T53.01 assessor argument

`acpi.c` commits a zero-initialized local topology only after the complete
declared table validates. Decode each integer from bytes before arithmetic.
The loop checks remaining bytes before the header, nonzero validated advance
before field access, then exact known record size. Distinguish malformed length
from empty enabled inventory and unsupported profile. Unknown length-valid
records can be ignored; a malformed unknown record cannot.

The sparse fixture's result is `(UID10,APIC0),(UID11,APIC2),(UID13,APIC6)`;
UID12/APIC4 is disabled. Dense array indices are0,1,2. OnlineCapable without
Enabled does not add an active CPU. For type9, values such as `0x12345678` and
`0xabcdef01` must survive byte decoding. A valid 32-bit representation alone
does not authorize that ID as a selected processor's interrupt destination.

The root adapter validates region disjointness and overflow before mapping.
Subtraction after `address>=base` avoids overflowing address+length; only then
may a range offset become a C pointer offset. A full header mapping does not
prove a full table mapping. The RSDP, root and child checksums are distinct.
Every referenced child is validated before final MADT publication, and repeated
MADTs refuse rather than selecting an arbitrary winner. An unknown or missing
mapping is an error, never permission to dereference the numeric address.

Assess `.a` against the identity/profile proof and wide-ID control; `.b` against
all truncations, root/high-address/overlap checks, unchanged prior output and
the same independent bytes executed as big-endian ELFv2; `.c` against actual
six boot captures and the separate host/root/guest causal claims. The Python
oracle shares the explicit contract but no C decoder. Its finite1957 rows and
the guarded spans are falsification evidence, not a proof of arbitrary input.

Controls1–4 respectively ignore checksum, uniqueness, high identity bits and
structural length refusal. Each compiles and reaches a precise assertion.
Reject crashes, sanitizer diagnostics, failed translations and generic errors.
The public code intentionally returns INVALID; never complete that scaffold
while recording assessor evidence.

The explicit PPC launcher needs a32-byte aligned frame and r12 pointing to
the callee's global entry. The first crude pilot used deprecated linker-path
syntax under `-Werror` and failed translation; a stale previous executable was
then accidentally invoked by the exploratory one-liner. That invocation is not
new evidence. The maintained producer gates execution on a successful build
in a fresh private directory and uses `--ld-path=`. No pilot is a final receipt.

Root/type9 normative ACPI6.6 passages remain inaccessible. Inspecting actual
ACPICA structs supports layout provenance but not full OS/platform compliance.
The retained CMK root walk still relies on its declared physical-range mapping;
host checked regions do not retroactively prove that assumption. The q35 change
adds an MCFG child and changes FACP size in the actual observed configuration;
do not predict universal firmware inventory from these six samples. Capture
instrumentation walks all children for bytes before the retained selection and
stops before AP startup. Physical timing, arbitrary firmware, independent
human assessment and delayed learner performance remain separate work.
