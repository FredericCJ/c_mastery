# Memory clinic assessor analysis

This analysis is withheld from learner exports. It evaluates the exact original PR-T03-05 criteria and their delayed variants, not a replacement exercise. Use the shared public contract and source-bound campaign rather than copying expected terminal text into an acceptance receipt.

## T03-14-a

Automatic escape ends the local object's lifetime before dereference; making the pointer global or volatile does not extend it. Return a copied value or transfer a separately allocated owner with explicit cleanup. Double free violates the allocation library contract even if the numerical address repeats. Consume the unique handle before invoking release; a repeated API release must reject without invoking the callback. The old pointer is not a valid instrument for checking whether storage still exists after actual free. Snapshot the value while alive instead. Overlapping memcpy violates its range precondition; the imported fd_move implementation chooses direction within one admitted array and preserves the source snapshot. Merely replacing the allocator with a quarantine can hide the physical fault while leaving an application ownership violation.

The positive original trace rejects events2/3 through live control state, avoiding UB. Four deliberately invalid child cases are separate diagnostic observations. A report describes a tested violation; neither its absence nor a successful process termination proves semantics. Five safe compiled semantic mutants distinguish wrong snapshot, accepted duplicate release, ignored member identity, wrong overlap direction and lost retain accounting. A sixth deliberately racy mutant belongs only in the instrumented isolated target.

Delayed variant: a worker owns a counted reference before creation. Creator drop changes2→1; paused worker's add/read happens while storage lives; worker drop1→0 releases once. After join there is no actor left to touch the mutex and destruction is legal. In the parallel test, both owners remain live while they each add10000. The same mutex serializes both count and value. An atomic count alone would not make non-atomic payload increments safe. The serial version of the race mutant has no simultaneous conflicting accesses, so a clean TSan run there does not validate its general API.

## T03-14-b

For the noninitial member, construct its address from the live whole object's character representation, offset and actual member type. This direction stays within the whole object. Compare the supplied candidate before accepting; an unrelated same-typed member remains a distinct object even if the type matches. Const is preserved in every intermediate pointer and the output is a value copy. Subtracting offsetof from arbitrary int pointers does not establish the existence, bounds, lifetime or provenance of a containing McContainer. Treating this as a generic portable container_of proof is a level1 error.

Delayed variant: McFirst begins with int first. N1570 6.7.2.1p15 supplies the particular initial-member converse conversion after the actual containing object is established. Static offset zero is necessary evidence here but does not manufacture an object around every int at that address. Check foreign live objects without ever casting and reading a fabricated owner. A caller-supplied whole-object identity is a precondition, not an unforgeable capability.

## T03-14-c

Require a separate falsification claim for each repair. Snapshot correctness still assumes the source is live during copying: early concurrent release would break it, hence the shared borrow control. Unique release assumes unforgeable-by-discipline ownership: copying a public control is not retain. The quarantine allocator leaves the physical allocation live after logical release, giving a defined access that ASan cannot reject as heap-use-after-free; API refusal remains the relevant oracle. The actual free variant does end lifetime. The overlap direction control detects a wrong forward copy for rightward overlap; do not mistake leftward-only tests for coverage. Container checks do not validate arbitrary addresses; foreign live candidate rejection targets the specific false equivalence without invoking invalid-pointer UB.

Changing O0/O3 and compiler may alter emitted accesses or instrumentation; only actual reports count. The deliberately invalid source uses a compiler noinline attribute and volatile publication to retain the selected lifetime accesses, but its undefined values remain unusable as oracles. The first actual campaign found GCC O3 did not report the direct constant-size overlapping copy, despite `-fno-builtin-memcpy`; that failed attempt is retained. Generated code had no memcpy call. A volatile indirect function pointer preserves a library boundary for a second version of the same fault. Require actual retained assembly and per-case observations instead of claiming every build diagnoses the direct version. Shared reference accounting without a payload lock passes a serial history while the overlapping history gives a real TSan data-race report. A completed concurrent test cannot prove all interleavings, cancellation behavior, robust recovery or scheduler bounds. Those remain outside the stated model.

Independent assessment must produce the changed conditions after the canonical seven-day interval. The author campaign is finite evidence for the supplied implementation, not an independent assessor or a learner mastery record.
