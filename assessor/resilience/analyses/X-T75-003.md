# X-T75-003: assessor technical analysis

Do not include this file in learner packages.

The reference stores absolute due values so each fourth tick can revisit a bucket without early delivery. Removing a timer saves next before unlinking and increments generation; no callback can mutate traversal in this anchor. Slot selection is O(capacity), unlike O(1) free-list variants. Hierarchical cascades need special care at exact fine-wheel boundaries and zero residual delay. Withheld case schedules into the same bucket while an expiry callback executes; require a detached ready list or an explicit reentrancy prohibition.

Independent expected example: At now0 a delay5 timer maps to bucket1 but must not fire at tick1; it fires exactly at5. Cancelling generation1 then reusing that slot at generation2 makes the old ID STALE. Simultaneous due timers all appear in the returned mask, without invoking callbacks during linkage traversal.

Assessment boundaries: Use an independent sorted map of absolute due times, not another wheel. Exhaust pairs of due1..16 and every cancellation point; verify back-links after each step. Add a delayed-clock jump that crosses three revolutions and either process all missed ticks or specify a bounded late-fire policy. Record the selected scheduler decision before measurement; historical paper VAX numbers are source observations only.
