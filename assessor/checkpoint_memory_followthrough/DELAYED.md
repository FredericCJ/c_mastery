# P1 sealed changed-condition administration

Retain each exact `-DELAYED` identifier and minimum_days=7 from the parent cards.
Author readiness is immediate; actual learner evidence requires the elapsed interval
and an unaided attempt. Seal source hashes, permitted artifacts, assistance log,
predictions and the assessor identity before releasing these conditions. Do not
give this analysis or the reference implementation to the learner.

| Objective | Released change | Discriminating result and assessment |
|---|---|---|
| T14.01.c | Use allocated records instead of a declared array | Typed initialization and deallocation arguments change; merely aligning byte storage does not suffice. Require exact ownership transitions and two backing releases. |
| T14.05.c | Linked queue with bounded nodes and midway exhaustion | Fail node acquisitions1–4: accepted0–3, no unqueued record leak, no replay of prefix. |
| T16.02.a | Required alignment exceeds supplied base guarantee | Refusal before mutation; neither a mask nor a successful host address observation proves a stronger caller guarantee. |
| T18.04.b | Callback completes after cancellation | Queue removal/cancel leave callback pin; stale/nonquiescent completion cannot reset; matching completion releases once. |
| T18.04.c | Move backing while keeping handles | Fail relocation allocation, refuse with pins, then retain handle/value after success; invalidate raw borrows and never inspect expired pointer values. |
| T13.01.c | LTO and stack protection | Reinspect generated helpers and resolved providers; fail closed for unprovided stack protection or hidden effects. Native inspection-only images are not executed. |
| T16.14.b | Capacity2, unchanged four-record input | Admit2 and retain refused suffix; resource counts and data match the same workload. |
| T16.14.c | Change fixed-capacity record-size distribution | Predict all1/all16/mixed admission and storage before measuring; distinguish logical release, retained backing, metadata and unequal accepted work. |
| T21.04.b | Async unregister; later actual OwOwner adaptation | Pending owner cannot be reclaimed; stale ack does nothing; matching ack releases once; quantify control bytes/callbacks and name nonfailing/nonreentrant assumptions. |

Score each criterion independently using levels0–3 in the retained card. A level2
reference demonstration is not level3 evidence. Require a new rationale and actual
artifacts for the changed condition; code copied from this package does not establish
independent transfer. Record failures, hints used, retries and residual limitations.
No physical board or external technical review is inferred from this administration.
