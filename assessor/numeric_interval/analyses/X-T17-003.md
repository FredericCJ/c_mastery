## R1: what is bounded

The interval represents all real values between endpoints, not a distribution or just the finite grid. Independent subtraction of [-1,1] from itself gives [-2,2]; the shared-variable expression x-x is0. A dedicated square can use correlation and has minimum0 when the input crosses zero. This is why multiplying endpoint pairs is sound for independent operands but unnecessarily wide for x*x. The numerical calculation cannot repair an incorrect physical bound. ## R2: arithmetic and failure proof

All admitted int32 products are at most2^62, ratio/scaling numerators at most2^47, so no INT64_MIN/-1 overflow occurs. Addition/subtraction fit int64 before range admission. Negative signed shifts are unnecessary. Evaluate four corner products/quotients; divisor exclusion of zero makes the quotient extrema finite. For square, check whether zero belongs before choosing minimum endpoint square. Stage both endpoints and publish only when both fit. Output aliasing is safe because operands are by-value snapshots; arbitrary invalid pointers remain outside the preconditions.
