## Worked semantics and invariants

For `abcabcd`, after `abc` the remembered span is `[0,3)` with mask5. Continue through the nonaccepting repeated-prefix states; `d` finally reaches the rule1 state at7. Emit `[0,7):1`. For `abcabc`, EOF at6 is not accepting: emit `[0,3):0`, restart at3 and emit `[3,6):0`. Rollback count is3 and baseline transitions9. `dabc` becomes `[0,1):1,[1,4):0`. `abcx` reports NO_MATCH at3 and publishes no prefix even though a first token was privately recognized. At capacity1, `abcabc` reports RANGE at3 with both token/cost outputs intact. At the same capacity, `abcx` remains NO_MATCH: recognition precedes the output-capacity check. Empty input is successful and never emits a zero-length token.

At loop entry, `q` is the state reached by the input slice `[begin,pos)`; `last` and `mask` record the most recent accepting configuration since `begin`. Acceptance can update these only after consuming input because start acceptance was rejected. At stopping, every longer reachable prefix was either examined unsuccessfully or lies behind a sound failed-configuration certificate. Choosing the lowest acceptance bit only after the length decision proves the priority order. A successful token strictly advances `begin`; bounded indices and validated transitions prove memory accesses within the admitted objects, not validity of arbitrary caller pointers.

For mode1, the stack records traversed configurations since the most recent acceptance. On reaching a nonaccepting terminal/dead/known-failed configuration, walk the stack backward and mark each nonaccepting pair. Its only possible continuation for this fixed input leads to the already proved failure. Stop before an accepting predecessor, since it is itself a possible longest endpoint. A repeated known failure cannot exclude a new accepting prefix; no acceptance existed along the certified suffix. Clearing the table for every call is essential: appending `d` to `(abc)^85` converts the previous failed search into one256-byte token. Changing state6's accepting mask to8 makes the255-byte prefix one rule3 token. Reusing failed pairs in either case would be unsound.

The scalar recurrence for the baseline is `T(k)=3k+T(k-1)`, yielding10965 transitions at85. On the supplied family mode1 must produce identical85 tokens with fewer than765 transitions and nonzero memo stops/marked pairs. This measured bound applies to that fixture. The general proof uses the finite-state failed-pair charging argument, with a conservative `O(Q²n)` bound and fixed-Q linear dependence. A statement that simply counts DFA transitions as one per source byte ignores rescanning; a claim of `O(n)` uniformly independent of Q also omits the table/state factor. The implementation's workspace is bytes plus stacks, not the paper's ideal bit table. Host ticks, staging storage and target stack frames measure different resources.

## Discriminating failures and repair

Six original compiling mutants independently select the first acceptance, select the highest rule bit, publish a partial prefix before a later error, skip remaining input after one token, retain stale failed-pair entries, or ignore memo hits. The three anchors target them in pairs. Mutation acceptance requires a semantic MM_CHECK failure; an inability to compile is not a semantic kill. The memo mutant deliberately starts with all scratch entries set, so its failure is deterministic and does not read uninitialized memory. The oracle uses independent Python regex full matching over every possible candidate endpoint and then orders candidates by longest end/earliest rule. It does not repeat the C DFA transition algorithm.

Plausible wrong explanations: “DFA means linear scanner” fails on the quadratic witness; “earlier rule always wins” fails on seven-byte `abcabcd`; “a failed state remains dead” fails after appending `d`; “rollback only changes the cursor” ignores the required output transaction; “the adapter proves all regex engines equivalent” ignores the prior bounded binary grammar and nullable rejection. Correct alternative implementations include storing a vector of accepting positions, a backwards dynamic-programming suffix table, or generated per-state code, provided their exact semantics, bounds, failure transaction, actual prerequisite adapter and measured cost model hold. An alternative performance proof must justify its own algorithm rather than cite this reference's proof.
