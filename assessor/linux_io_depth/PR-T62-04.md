# Assessor analysis: PR-T62-04

File descriptors and request slots can be reused while old completions are still queued. An identity must distinguish the current operation from a prior occupant. Completion publication and payload release need a single terminal owner.

Prove each target completion is consumed once and cannot authorize release of another generation. State finite-generation exhaustion policy and metadata versus payload lifetime.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: The mutant ignores generation and lets a stale completion finish a new request. Demonstrate harmless wrong-result publication using two synthetic requests, not another process’s data.

Require the learner to derive 0 from the fixture inputs independently. Retain payload until a terminal event for the same generation is processed.

Transfer answer obligations: Add multishot operations where nonterminal completions retain ownership; derive terminal recognition and buffer recycling from the actual opcode flags.

Actual epoll, eventfd/timerfd/signalfd, io_uring feature/error paths, splice/sendfile and fsync/rename observations are required; unavailable kernel features are explicit gaps and never simulated passes.
