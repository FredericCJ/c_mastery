# Assessor analysis: PR-T62-03

Shared rings combine modular counters with a bounded live distance. Masking an index hides overflow of occupancy if the producer ignores the consumer position. Ordering the payload and tail publication is a separate obligation.

Derive the bounded-distance interpretation under counter wrap. Separate single-producer ownership, ring-slot lifetime and payload-before-tail publication.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A producer masks tail and overwrites a still-owned full slot. Adding a barrier cannot repair missing capacity admission.

Require the learner to derive 2 from the fixture inputs independently. Acquire the peer position, fill owned storage, then publish the tail with the required ordering.

Transfer answer obligations: Add multiple producers or change queue depth away from a power of two; redesign reservation and indexing rather than reusing the single-owner mask proof.

Actual epoll, eventfd/timerfd/signalfd, io_uring feature/error paths, splice/sendfile and fsync/rename observations are required; unavailable kernel features are explicit gaps and never simulated passes.
