# Private cohort analysis

The precursor per-dispatch ledger postpones each execution unit by P from
service. This cohort model instead keeps the eligibility/activation distinction
through preemption. It intentionally does not use a single `remaining` amount
as a sufficient description of all ages.

For the supplied premature-replenishment witness, two units activate40 and18
returned units activate50. The server consumes one old unit at40, another at51,
then18 newer units52..69. Only the old two return90; the others return100.
The lower-priority job therefore completes99. The original flawed specimen
relabels all20 as activated40, returns them90 and delays the victim to117.
The public trace oracle checks all choices and capacities, not only endpoints.

For the overrun witness, borrowing one not-yet-eligible unit advances its next
reservation from20 to40. There are still four unit identities; a clamp-to-zero
display would hide that obligation while manufacturing a fifth future unit.
Compensation does not erase the first overrun's elapsed interference. A bounded
model must not masquerade as a working physical enforcement mechanism.

Every mutation in the reference is intentionally selected by SU_MUTANT. The
proper implementation stages all state and publishes only after checked time,
counter and admission conditions. Early publication fails even if the eventual
return code is correct. Inactive anchor normalization was corrected after the
independent-history pilot exposed a representation mismatch; only subsequent
source-current observations support the final implementation.

The unit algorithm is an original finite derivation with deliberately explicit
late-time behavior. It is not a literal implementation of either the disputed
1989 SpSL formulation or the RTAS2010 aggregated pseudocode. That pseudocode
contains apparent field/index/reset ambiguities, and the revised2011 full
algorithm was not available for inspection. Keep that source gap visible.
