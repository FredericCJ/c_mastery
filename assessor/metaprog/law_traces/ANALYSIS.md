# T68.07 assessor analysis

The owner stages its allocation and copy before invoking the old matching
release. A nonfailing/nonreentrant callback premise is essential. Empty content
owns a real one-byte allocation; an empty control owns nothing. Drop detaches
the owner before releasing, but that does not grant general reentrant use.

Equality is equality of canonical byte sequences, giving the three equivalence
laws. Hashing uses the same sequence and its explicit length. Cache and native
padding are excluded. A quiet hash-law test cannot establish transitivity, and
hash collisions do not imply key equality. ASCII folding/space normalization is
an explicit bounded text model, not Unicode normalization or locale-sensitive
case conversion. Rust automatic derives include the fields; a custom semantic
contract needs consistent custom equality/hash.

The adapter validates the complete correct-model trace before allocating,
including scheduled failed SET behavior and the suffix. An actual wrong
implementation can diverge, but the history was admitted by its reference
preconditions. It retains the first class and cleans the owned blocks. A host
failure outside fail_at is unavailable evidence, not an expected defect.

Every accepted shrink step decreases count+value codes+failure ordinal. At
termination every declared immediate move either violates admission or fails
to retain the same class. This is a local-minimum result. The nonmonotone
constant-equality/two-class-hash example supplies a smaller disconnected witness.
Even a valid history with a different CALLBACK failure is not a retained HASH
witness. A host NOMEM candidate must abort unchanged rather than silently certify
minimality; the actual linker-wrapper experiment tests that correction.
