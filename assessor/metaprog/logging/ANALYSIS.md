# Assessor: T68.04 typed logging and optional metadata

R1: with one argument, append error,log4,log3,log2,ONE,unused to the
five-position selector: NAME is ONE and unused fills its ellipsis. Four
arguments select log4; five select the zero-parameter error declaration and
cannot legally pass the logger arguments. Argument substitution does not
evaluate the fields discarded by selector expansion. The selected call
contains each field and sink once. Function arguments do not gain a prescribed
relative order. The duplicate-one mutant uses a comma expression, so its
extra effect is a defined and observable violation rather than an undefined
test oracle. Original MOD7 and MOD8 independently test duplicate numeric
evaluation and the explicit zero identity.

R2: `MPL_LOG(s)` omits the variable argument, while `MPL_LOG(s,)` supplies an
empty token argument that leaves a missing typed expression. Both must fail
this interface. The explicit LOG0 form appends an empty record. The site
compound literal needs a second pair of parentheses across nested macro
argument recognition. A bare integer cannot initialize a structure parameter;
that constraint is different from the allowed conversion of3.5 to uint32 in
the number constructor. A separate warning-policy probe records rejection
of the literal by Clang with warnings as errors, while a nonconstant numeric
input is accepted in both strict profiles. C2x/C++20 VA_OPT observations do not expand the C17
contract, and N3033 is a proposal rather than either published standard.

R3: shape/control/full admission precede payload reads. A record is staged
from zero-initialized local storage, validated field by field and then copied
into the next slot, followed by count publication. Unknown later tag,
oversized binary extent or unterminated bounded filename does not modify
the sink. Copying source bytes and filenames lets their storage change after
return; the output does not contain a borrowed pointer. Padding bytes are
not serialized or compared across independent values. Failure byte snapshots
compare one live object's representation before/after no permitted writes.

The Python oracle models statuses and logical fields, using a finite trace
digest rather than C struct layout. It includes all short products of seven
field classes, boundary control/site cases and deterministic larger random
records. This is independent algorithmic expected evidence, not independence
of reviewer or completeness of the C abstract-machine state space.

R4 / held delayed prompt: a consumer now requires caller source metadata,
an embedded-zero binary field and a number, while a full sink refuses a
call whose three field expressions each increment a distinct counter.
Predict sink bytes, exact counters and data lifetime before implementation.
Then remove metadata and change the filename to a256-byte unterminated
array, using the direct typed wrapper. The intended answer keeps all sink
bytes on refusal while the already evaluated counters remain incremented;
the copied successful binary payload is unaffected by later source changes.
The existing author cases implement these changed mechanisms, but the actual
delayed learner must produce fresh reasoning and artifacts unaided.

Mutants1..6 duplicate one field evaluation, publish count before invalid
field rejection, replace the zero-field record with one number, omit copied
tail bytes, omit source line, and accept full sink respectively. Mutants7/8
are actual retained numeric producer controls. Every rejection must be an
ordinary named assertion, not a signal, failed build or sanitizer event.

Costs: direct and macro logging feed the exact same typed writer and record
contract; samples may differ from noise or compilation. Common staging can
produce compiler memcpy/memset helpers even though source uses assignments
and loops. Those are reported as host link costs, not claimed freestanding
absence. Public pointer/disjointness/serialized-caller premises are necessary;
there is no concurrent log publication, arbitrary variadic type safety,
wire serialization or general format-string checking.
