# T68.08 technical analysis and sealed assessment

The program stores a copied source and descriptors, avoiding a format-string
borrow across preparation. Brace escapes consume two bytes and emit one;
placeholders consume four and emit at most16. Thus128 bounds any parse-produced
32-byte program. Check kinds independently of the grammar. _Generic chooses a
function designator and the argument appears once in the executed call; it is
not compile-time parsing or borrow checking. C++ experiments test stronger
literal compatibility separately from runtime vformat failure.

Stage preparation before sink admission. Decimal conversion uses the actual
retained primitive, preserving its ten-digit/zero contracts. Span strings are
explicit extents, unlike the retained zero-terminated text precondition. An
embedded zero is copied, not treated as a terminator. A copied program is safe
only under its unmodified parsed-program premise; public C fields are forgeable.

For valid writer reports, external output equals message[0:offset] until a
terminal error/cancel, and later terminal calls invoke nothing. IO status is
independent of accepted count, so ERROR accepting the entire suffix still
reports IO. A protocol-invalid report invalidates the external-prefix theorem;
record uncertainty and never retry. External output is not rolled back by an
unchanged or stopped C control. Arbitrary zero-progress AGAIN prevents a global
termination bound. The local nonblocking pipe experiment supplies real EAGAIN,
short accepted writes and cancellation while keeping both owned ends live;
it does not imply arbitrary devices have the same contract.

Controls1..6 accept incomplete braces, omit kind validation, advance sink used
on FULL, omit retry-offset progress, lose accepted progress on ERROR, and write
after cancellation. Controls7/8 compile retained MOD15/16. They fail ordinary
assertions rather than relying on memory corruption or sanitizer termination.
The independent Python grammar is regex-token based and substitutes Python
decimal strings; stream histories use a separate immutable prefix model.

Sealed delayed case: choose repeated placeholders with embedded-zero spans and
escaped braces, then a writer schedule AGAIN0, OK1, AGAIN1, ERROR accepting the
entire remaining suffix. Require exact prefix/call evidence and permanent IO,
not DONE. Change the schedule to an impossible accepted count and require an
explicit loss of the exact-prefix claim; a retry must be rejected. Supply a
different malformed grammar and one unused argument with an invalid category,
requiring separate grammar and all-argument admission reasoning. All mechanisms
are supported by the supplied implementation; the exact schedule is held for an
unaided delayed attempt. Assess all original R1-R4 independently. Source review
and finite author executions are not independent human assessment or mastery.
