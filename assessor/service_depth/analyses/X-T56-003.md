# X-T56-003 assessor analysis

Keep outside learner publication.

A denied RECEIVE right is a local authorization failure, with no queue mutation. CHANNEL2 removes that right check and exposes the synthetic bytes through SEND-only metadata. CHANNEL dequeues before validation and loses the message after SD_COPY. Correct receive first validates capability, size and stable output extent, then copies and publishes exactly once. Closed queues drain; epoch increment rejects old capabilities, and UINT32_MAX retirement is intentionally a state-changing FULL result. A forged SDCap could forge rights in this C model, which is why the real adapter must resolve a protected handle table. Plain C fields and one callback offer neither atomicity nor userspace memory pinning. A crash/sanitizer report is not the demonstrated property; the deterministic byte disclosure/lost message is.

## Integration boundary

D2 adapter: extend a learner-owned syscall ABI with explicit span length and protected endpoint lookup. Resolve SEND/RECEIVE/CLOSE rights in kernel storage, pin or otherwise stabilize the entire output extent, and only dequeue after successful complete copy. Define wake/cancel ordering under the existing kernel lock and retain queued ownership after peer death. Execute isolated sender/receiver programs in a disposable VM, including a span crossing an unmapped page. The portable callback only models that stable-copy premise.

## Independent assessment

V1 after7days: permit partial copy progress and redesign the message/offset/result contract so retry cannot duplicate or drop bytes. V2: a sender dies while blocked and an endpoint slot is recycled before a delayed wake; implement incarnation-aware enrollment and prove who releases each reference.
