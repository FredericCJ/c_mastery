# Assessor analysis: PR-T58-07

Page permission bits are not sufficient by themselves: access type, current privilege and supervisor user-memory policy participate in the decision. Execute permission must not silently become write permission.

Derive each access decision before dereferencing and identify omitted page-walk obligations: validity, canonical address, superpage alignment, access/dirty updates, translation synchronization and fault cause.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: Repair a supervisor execute path that assumes SUM permits executing user memory. A model allow decision never grants C pointer provenance or physical access.

Require the learner to derive 1 from the fixture inputs independently. Supervisor user-page execution remains denied even when data access is enabled.

Transfer answer obligations: Implement a bounded three-level page-table walker with synthetic tables, then compare RV64 Sv39 and the selected Arm translation regime; inspect their full manuals and record unresolved differences.

Actual cross-linked image runs, hostile-register context tests, trap return and two-address-space translation observations in both dedicated guests are mandatory; model tests are not a complete OS port.
