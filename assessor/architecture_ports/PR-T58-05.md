# Assessor analysis: PR-T58-05

Instruction immediate fields are bit patterns interpreted with ISA-specific sign extension. An unsigned C shift implements bit extraction; a shift of a negative signed C operand has different rules. Alignment and range checks precede truncation.

Derive sign-extension using unsigned extraction and subtraction in a range representable by int. Separate field representability, target instruction alignment and linker relaxation.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: Truncating an odd branch displacement silently redirects execution. A range-only check is insufficient; a passing assembler can still hide linker-added veneers.

Require the learner to derive -1 from the fixture inputs independently. Validate alignment before masking or truncating.

Transfer answer obligations: Encode RV B/J immediate bit scattering and compare with an independent assembler, then force an out-of-range AArch64 call and inspect its veneer clobbers.

Actual cross-linked image runs, hostile-register context tests, trap return and two-address-space translation observations in both dedicated guests are mandatory; model tests are not a complete OS port.
