# Assessor analysis: PR-T58-02

An ordinary call promises selected registers survive, not every machine register. AArch64 x18 is platform-specific; treating it as universally scratch or saved is not portable. A trap may interrupt a caller with temporaries still live.

Identify which owner saves each register and why the return-address register needs protection in nonleaf callees despite its caller-saved classification.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A context port omits SP or assumes Arm x18 is a temporary everywhere. Explain a source-level test that can pass while this latent ABI violation remains.

Require the learner to derive 12 from the fixture inputs independently. Compare register sets from both ABIs and declare platform-reserved state explicitly.

Transfer answer obligations: Add floating-point state and compare only low64 preservation of selected AArch64 SIMD registers against full vector context requirements.

Actual cross-linked image runs, hostile-register context tests, trap return and two-address-space translation observations in both dedicated guests are mandatory; model tests are not a complete OS port.
