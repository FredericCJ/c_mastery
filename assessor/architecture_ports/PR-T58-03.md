# Assessor analysis: PR-T58-03

A function with nine integer arguments crosses the register-to-stack boundary on both selected64-bit ABIs. Testing only two arguments hides stack-offset and alignment errors. Aggregate and variadic arguments require different classifiers.

Derive the first stack argument relative to entry SP; distinguish entry-SP offsets from offsets after the callee allocates its frame.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A callee reads the ninth argument one slot above its defined location. All eight-register tests pass; the hostile ninth argument must falsify it.

Require the learner to derive 8 from the fixture inputs independently. Classify language values before assigning ABI locations.

Transfer answer obligations: Return a large aggregate through a hidden result pointer and show why this scalar classifier cannot simply shift the same table on every ABI.

Actual cross-linked image runs, hostile-register context tests, trap return and two-address-space translation observations in both dedicated guests are mandatory; model tests are not a complete OS port.
