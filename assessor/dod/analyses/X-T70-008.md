Concatenation creates a parent referring to older nodes, so indices impose an acyclic construction order. Flatten recursively traverses each edge occurrence: deduplicating visited nodes would incorrectly turn abcdabcd into abcd. Capacity is checked from cached length before writes. Repeated append creates linear depth absent balancing; the paper uses a length/depth relation motivated by Fibonacci growth. A piece table retains source buffers and may keep a large deleted original alive; a gap buffer moves bytes near the edit point and has no automatic persistent snapshots. Withheld transfer: insert a multi-byte scalar across a leaf boundary, then delete by scalar index; require decoding across boundaries and a policy for malformed input.
