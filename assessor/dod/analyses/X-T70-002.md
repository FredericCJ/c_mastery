# X-T70-002: assessor technical analysis

Do not include this file in learner packages.

An inline/heap discriminator can be heap!=NULL; local storage is selected at access time, avoiding a self pointer during move. Append admits max length by subtraction, grows geometrically, copies and publishes last. The only calls that may fail occur before release; destructor callbacks are no-fail. The reference can transfer heap without copying, but inline move copies bytes and empties the source. Empty destination is required to avoid destroying an unrelated value. Withheld transfer: a capture holds a pointer to one of its own fields. Require a relocation callback or prohibit that capture; byte copying does not repair the pointer. The fixed-capacity alternative has a different failure contract and cannot be called a free optimization.

Independent expected example: Appending16 bytes performs no allocation. A failed17th byte preserves length16 and all bytes. Successful spill followed by move leaves the source empty and transfers exactly one allocation. Truncating to8 and compacting frees that allocation once; resetting both owners performs no second free.

Assessment boundaries: Run an operation-model generator over append lengths0,1,15,16,17,127,128,129; truncate, compact, move and reset. Preserve operation traces and independent byte-list state. Inject allocator failure at every spill and verify live allocation ownership, exact release counts and output state separately from callback instrumentation. Compile without a container/string library. Record sizeof/_Alignof on each available target. The header intentionally exposes fields for teaching, so forged state is outside the checked API contract and must be discussed.

Score each objective using its exact criterion in the brief. Public reference success does not validate the learner extension or delayed assessment. Retain a separate attempted counterexample, failed mutant, cost explanation and assistance log for each objective.
