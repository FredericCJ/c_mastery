# Region-cohort assessment analysis

The baseline MBRegion is reused exactly. Its high-water persists across reset, its declared byte array remains character storage, and its callbacks cannot fail. Four alignment32 typed objects live in BfCohort outside that byte array. Batch parsing copies the wire first and decodes fields into those actual objects. Successful registration changes cleanup ownership; a FULL registration leaves the just-opened resource outside the region, requiring manual close before reset of earlier resources. Capacity reservations force the actual provider's registration failure at each ordinal. Pre-admission malformed input is unchanged; admitted construction failure consumes a generation and performs cleanup. These failure contracts must not be conflated.

A slice with begin3 requires padding from3+cursor, not cursor. The independent arbitrary-precision oracle deliberately derives absolute aligned candidate positions, then tests containment in the original array. Numerical base alignment still depends on the caller's actual aligned backing. Three separate MB owners make selective child reset precise; a whole-tree operation invalidates all three. No callback may reenter another tree operation, so the wrapper does not pretend to implement a transactional distributed cleanup.

Growth retains tails and never relocates old chunks. A failed acquire happens before metadata publication, while the external provider's attempt counter is allowed to advance. Reserved capacity includes all chunks, not just requested bytes. A prior span remains alive through later growth but not reset. Typed upstream allocations have a matching release; the initial chunk is caller-owned. The independent history model uses a list of mathematical consumed prefixes and bounded failure ordinals, separate from the C callbacks.

The delayed region is an explicit consumer of the prior retained-cleanup BfArena. Keeping the root after cleanup failure preserves allocation authority; a done flag prevents successful cleanup from running twice. Success establishes a new root until the finite mark supply is exhausted. Allocation-ID exhaustion is independent and does not prevent cleanup. The changed64-byte representation must be counted rather than called cost-equivalent to32-byte MBRegion. Caller lifetime/no-copy/normal-return premises remain essential.

R1-R5 need distinct evidence and independent delayed derivation. Finite enumeration, a quiet sanitizer, source comparison and actual emulator execution each have different limits. None provides physical timing, access to exact published C17/C23, independent human review, or learner mastery.
