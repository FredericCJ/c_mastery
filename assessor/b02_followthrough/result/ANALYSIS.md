# Withheld result analysis

Constructors must select both the discriminant and the corresponding active field. Check the tag before reading the field in a mutant test so a tag/member mistake is rejected without interpreting an invalid pointer. Numeric magnitude is safe only after the -9999 lower bound; the original B02 implementation stages the decimal then performs capacity admission. The output sentinel is not a string: all eight bytes and the unchanged count matter on failure.

Ownership is a single linear obligation in the API, not in the C type system. Clone publishes after allocation/copy. Moving or taking does not destroy: it transfers callback/context/pointer/length and empties the source. Emptying before release prevents a successful drop from remaining an apparent owner, but the no-reentry premise still applies; it is not a general reentrant callback guarantee. The static test allocator stops the moved-source mutants before a repeated actual free; a separate successful malloc/free path confirms real allocation and one release. Null nonempty input, allocation refusal, nonempty destination and repeated empty cleanup distinguish admission from consumption.

The old object is intentionally a complete working version1 consumer supplied to the learner. The new implementation is not supplied. Building the old source once without result.h demonstrates that a new wire sender must respect the consumer's protocol, not that enum growth automatically preserves C ABI. Both version2 and version1/tag3 must be rejected by old code. Signed decoding uses -1-(UINT32_MAX-raw) for the negative half; the subtraction fits INT32_MAX before conversion. This makes every raw signed32 payload mathematically defined before the explicit narrow numeric-domain rejection.

The independent host oracle uses integer text formatting and signed integer byte conversion rather than reproducing the decimal reversal or C shift loop. All 279,986 numeric/tag/capacity cases and 80,512 wire cases are expected from those independent operations. The source-only counterexamples remain important: a copied dangling descriptor, forged active field and shallow owner copy are outside valid API use, and warnings do not close those gaps.

For changed conditions require a new alternative to be encoded explicitly, old-code rejection unchanged, and new-code interpretation checked before publication. Accept no claim that an ordinary switch must be exhaustive. GCC/Clang diagnostic outputs are bounded implementation observations; a complete positive control and unsigned-tag non-diagnostic counterexample distinguish syntax admission from sum-type enforcement. Independent assessment remains unperformed by author campaigns.
