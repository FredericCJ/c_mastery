# Assessor analysis: PR-T60-02

Precedence determines the tree, not execution order of arbitrary C side effects. The subset has pure expressions, so its tree can be lowered directly to a stack IR while retaining an independent tree derivation.

Prove each parser level consumes its grammar production or rejects, and derive linear token work with bounded recursion. Explain why no partially constructed IR is publishable.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A parser accepts the valid prefix2 of2? and silently drops the error. Another implements2+3*x as(2+3)*x. Separate tokenization, grouping and lowering defects.

Require the learner to derive 14 from the fixture inputs independently. Require the final cursor to equal the bounded source extent.

Transfer answer obligations: Add subtraction and left associativity, then introduce a side-effecting call and state which source sequencing must be preserved rather than inferred from precedence.

Execute emitted x86-64 code against an independently compiled C oracle, execute Thumb output in a dedicated emulator, and complete changed-condition extensions. Public IR anchors do not certify a general C compiler.
