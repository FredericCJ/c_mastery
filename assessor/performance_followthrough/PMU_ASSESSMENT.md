# Withheld PMU transfer and diagnosis assessment

Keep this file in the assessor package. Give the learner only the workload and
requirements selected below; do not name the data structure or provide this analysis.

Prerequisite receipts must establish accepted-prefix parsing, bounds/lifetime,
typed storage, cleanup and synchronization. Merely exporting a ring artifact
does not establish mastery. Record missing prerequisites before intervention.
Use a new problem instance after the existing minimum-seven-day delay and retain
all assistance, failed approaches and revised hypotheses. Do not fabricate runs.

1. Give a source of variable-size telemetry records, one bounded receiver, a
   producer that cannot block and an occasional slow consumer. Require explicit
   loss, cancellation and recovery semantics. After the initial design, replace
   producer memory with kernel-owned metadata and independently published records.
   Assess whether the learner notices the new ABI and ordering contract rather
   than copying the earlier queue representation. Inject a split header, a lost
   record and an invalid length. Require the exact consumed prefix and recovery
   decision, not only a final count.
2. Give two workloads with equal semantic results and similar retired instruction
   counts but different cycle distributions. Retain raw groups and change the
   working set and layout independently. Ask for competing frequency, locality
   and interference explanations, the strongest supported conclusion and the next
   discriminating observation. Correct refusal to choose a cause is preferable
   to inventing cache evidence. Provide an event-open denial or zero-running
   record in one condition and verify it does not enter a ratio as zero.
3. Give a publication API whose final directory synchronization fails after the
   rename. Ask what the consumer sees, which resources remain owned, and which
   durability statement is still justified. A learner who says all changes were
   rolled back has misunderstood the transition even if the happy path passes.

Use an observation form with participant pseudonym, date, task revision/source
hashes, prior receipts, unaided predictions, first implementation, failed cases,
assistance timestamps, changed-condition response, selected/rejected alternatives,
interpretation limits and assessor rationale. Preserve original attempts.

Rubric: 0 absent/wrong; 1 imitated nominal flow; 2 independently justified contract
and correct bounded implementation; 3 successful unaided transfer plus diagnosis
of a counterexample to the previous argument. Score acquisition, parsing,
ownership, reasoning and hardware interpretation separately. Reconcile imitation,
unstated prerequisites and mistaken contracts against raw observations; do not
average a false hardware claim into a passing score. Independent assessment and
educational effectiveness remain unobserved until real participant evidence exists.
