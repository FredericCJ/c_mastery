# Assessor analysis: PR-T64-02

A small rational model separates a rounding rule from the current floating-point environment. It provides independently computable half-way cases for checking target conversions and changed rounding modes.

Derive nearest-neighbor intervals and parity at exact ties. Prove remainder doubling is avoided by comparing r with denominator-r, and explain the negative sign symmetry.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: The mutant rounds every tie away from zero. A test corpus containing only odd lower endpoints misses the defect; a changed rounding mode cannot be assumed to affect every compiler-folded expression.

Require the learner to derive 2 from the fixture inputs independently. First compute quotient/remainder; increment only above half or at half with odd quotient.

Transfer answer obligations: Compare the rational oracle with volatile double operations under each available fenv rounding mode, retaining compiler flags and FENV_ACCESS support limits. Distinguish conversion behavior from arithmetic rounding.

Required extension evidence includes scalar versus explicit-vector differential tests, emitted assembly and target feature checks, fast-math counterexamples, reproducible resource/timing experiments and changed-size/data-layout transfer. Portable core tests alone do not establish SIMD execution or a performance advantage.
