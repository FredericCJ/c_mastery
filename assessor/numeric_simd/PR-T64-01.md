# Assessor analysis: PR-T64-01

Fixed-point multiplication changes scale twice: the product has twice as many fractional bits, and rounding precedes a checked narrowing. Saturating after a signed overflow is not a repair.

Derive the product scale and prove int32_t multiplication and negation bounds before implementing absolute value. Separate saturation policy from the rounding rule.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: The mutant truncates toward zero, failing positive and negative half-way cases. A signed right shift is not a portable replacement for the specified rounding rule.

Require the learner to derive -1 from the fixture inputs independently. Round a nonnegative magnitude, restore the sign and clamp before narrowing.

Transfer answer obligations: Change to Q3.12 and compare wrap, saturate and error-return APIs. Derive a dot-product accumulator width from maximum length instead of copying the Q1.15 constants.

Required extension evidence includes scalar versus explicit-vector differential tests, emitted assembly and target feature checks, fast-math counterexamples, reproducible resource/timing experiments and changed-size/data-layout transfer. Portable core tests alone do not establish SIMD execution or a performance advantage.
