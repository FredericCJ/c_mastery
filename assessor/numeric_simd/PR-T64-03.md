# Assessor analysis: PR-T64-03

A product can fit its type while a sum of many products overflows. An exact integer reference is valuable for validating vector rearrangement because addition order then does not alter the specified result.

Derive the maximum positive and negative product and n-times-product bound. Explain which intermediate width is required before multiplication and before addition.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: The mutant narrows the completed sum to32 bits. On a target with a different conversion behavior, report implementation-defined narrowing separately from the violated mathematical output contract.

Require the learner to derive 3221225472 from the fixture inputs independently. Widen an operand before multiplication and retain the wide accumulator.

Transfer answer obligations: Vectorize into several wide partial sums and compare exact results for every tail length. Change n beyond the proved bound and design checked partial accumulation without silently weakening exactness.

Required extension evidence includes scalar versus explicit-vector differential tests, emitted assembly and target feature checks, fast-math counterexamples, reproducible resource/timing experiments and changed-size/data-layout transfer. Portable core tests alone do not establish SIMD execution or a performance advantage.
