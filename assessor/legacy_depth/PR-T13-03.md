# PR-T13-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1307a"></a>

## T13.07.a

State scoping is a contract property, not a consequence of one thread-local variable. A deterministic generator still needs an ownership protocol when shared.

Withheld discriminator: Replace global rand with an explicit per-instance generator and revisit reproducibility and sharing. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1307b"></a>

## T13.07.b

This can fail without threads, so a mutex alone may conceal rather than solve the borrowed-result lifetime problem. Explicit operation-local storage changes the representation contract.

Withheld discriminator: Allow same-instance callback reentry and test whether the proposed storage ownership still holds. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1307c"></a>

## T13.07.c

A snapshot is incomplete if it omits state that changes observable behavior. Reset and reproducibility are related but distinct: restoring internal state cannot reproduce uncontrolled external inputs.

Withheld discriminator: An external clock or callback influences output; separate replay inputs from hidden environmental dependence. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1308a"></a>

## T13.08.a

Composition needs its own invariant. GNU safety annotations are implementation documentation and preliminary labels are not unconditional future promises.

Withheld discriminator: Compose two individually thread-safe operations into check-then-act and construct an intervening-call trace. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1308b"></a>

## T13.08.b

An ISR is governed by architecture, compiler and board contracts as well as C. A host mutex or signal analogy does not establish those rules.

Withheld discriminator: Allow nested interrupts that share the buffer and design an ownership/publication policy before claiming safety. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1308c"></a>

## T13.08.c

A loop bound bounds only iteration count. A real time bound composes per-step costs, interference and cancellation behavior.

Withheld discriminator: The callback can block indefinitely on its first call; specify timeout/cooperative cancellation or reject the backend. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
