# PR-T45-08 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4508a"></a>
## T45.08.a

A tagged representation needs a valid tag-to-payload relation. Initializing every byte is neither necessary nor sufficient for every abstraction invariant.

Expected relation: Publication requires all designated fields and invariants; all-zero object bytes are not assumed universally valid pointer/float representations.

Withheld transfer discriminator: Use a tagged union whose inactive member need not be initialized and specify legal reads.

<a id="t4508b"></a>
## T45.08.b

Origin tracking can be approximate and instrumentation incomplete. An observed report supports its exercised scope; absence does not prove initialization everywhere.

Expected relation: The source-level obligation is identified before the consuming branch; detector propagation behavior remains a tool model, not a language permission.

Withheld transfer discriminator: Use an uninstrumented library boundary and state what initialization evidence is lost.

<a id="t4508c"></a>
## T45.08.c

A portable wire format needs explicit sizes, byte order and version rules. Native layout and representation bytes cannot be imported silently.

Expected relation: Equivalent semantic fields compare equal regardless of supplied nonsemantic bytes; failures publish no active object; serialization is deterministic by contract.

Withheld transfer discriminator: Add a versioned optional field and specify absent/default semantics.
