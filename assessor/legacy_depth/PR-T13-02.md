# PR-T13-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1303a"></a>

## T13.03.a

Per-function reporting describes a compiler artifact, not source-independent total stack. A dynamic report without bounded includes only its bounded portion.

Withheld discriminator: Enable inlining/LTO and compare both the report and generated call graph for the exact build. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1303b"></a>

## T13.03.b

A high-water observation is a lower bound on the maximum of all possible runs under the model, not a universal upper bound. Stack painting itself needs a defined target mechanism.

Withheld discriminator: Insert a rare error callback not taken by the initial workload and re-evaluate the bound. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1303c"></a>

## T13.03.c

The arithmetic is independent expected evidence; actual frame sizes, hardware exception frames and nesting masks need target inspection. No interrupt experiment or board claim is implied.

Withheld discriminator: Use a dedicated interrupt stack and derive two separate budgets instead of one sum. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T13.04.a

The reentry creates a self-dependency even with one thread. An unknown allocator or locale implementation cannot be labeled lock-free from interface spelling.

Withheld discriminator: Make the callback call back into the wrapper while the outer operation owns a nonrecursive lock. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1304b"></a>

## T13.04.b

Timing is contingent on scheduling and clock quality. A try-lock removes a wait policy only if all transitive work is also bounded and failure is handled.

Withheld discriminator: Replace the mutex with try-lock and specify the new visible failure contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1304c"></a>

## T13.04.c

A timeout is evidence of noncompletion in that run, not a full deadlock proof. The graph and ownership argument explain the mechanism and repair.

Withheld discriminator: Permit nested calls with separate instance state and prove whether any shared backend lock still forms a cycle. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T13.05.a

State transition coverage matters more than timing averages. A failure path may allocate/free and retry later, so first successful call differs from first attempted call.

Withheld discriminator: Introduce initialization failure followed by retry and distinguish permanent failure from retryable state. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1305b"></a>

## T13.05.b

Startup, loader, allocator and locale activity can overlap. An experiment must isolate boundaries; no required allocation count is portable across libraries.

Withheld discriminator: Change locale after warmup and determine which initialization assumptions are invalidated. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1305c"></a>

## T13.05.c

Reset is a lifetime transition. Quiescence and outstanding references must be resolved before storage release; process freshness does not itself establish external-service freshness.

Withheld discriminator: A callback retains a cache pointer across reset; revise the protocol or reject the lifecycle. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
