# PR-T45-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4502a"></a>
## T45.02.a

The caller still owes valid live storage. Scalar checks do not prove arbitrary pointer extent, lifetime or synchronization.

Expected relation: Negative and beyond-one-past indices reject before conversion/pointer formation; one-past with zero access follows the parent contract; NUL space is reserved.

Withheld transfer discriminator: Introduce a subview with independent logical length and shared backing capacity.

<a id="t4502b"></a>
## T45.02.b

A binary span is not a C string. Reusing a string helper can silently truncate data or impose an unwanted terminator rule.

Expected relation: The analysis rejects invalid formation where the C rule requires it; a bounded scan never reads the first absent byte; embedded NUL follows the publication contract.

Withheld transfer discriminator: Use a length-delimited binary payload that legitimately contains zero bytes.

<a id="t4502c"></a>
## T45.02.c

Overlap changes the implementation proof and can expose partial mutation. A new contract needs an independent oracle rather than inheriting disjoint-copy evidence.

Expected relation: Rejected checked operations preserve all observable state; the logical-cell mutant is rejected independently of addressability.

Withheld transfer discriminator: Allow overlapping source/destination under a newly versioned move contract and derive staging direction.
