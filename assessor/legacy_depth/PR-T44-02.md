# PR-T44-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4403a"></a>
## T44.03.a

Reduction is relative to the predicate. A coarse crash predicate can minimize to a different defect and invalidate the claimed diagnosis.

Expected relation: Only the selected symptom under matching identity is FAIL; unstable or unrelated outcomes are UNRESOLVED and never establish preservation.

Withheld transfer discriminator: Introduce a schedule seed and make replay identity include it.

<a id="t4403b"></a>
## T44.03.b

A reducer is not an oracle. Grammar-aware reduction changes the candidate space and minimality relation, which must be stated.

Expected relation: Returned candidates retain FAIL, order and grammar; budget exhaustion is explicit and cache keys include input plus replay identity.

Withheld transfer discriminator: Use a grammar-aware tree reducer and explain which reductions it can now express.

<a id="t4403c"></a>
## T44.03.c

No single deletion preserving FAIL does not mean every token caused the program defect. Reduction localizes an input, while code-state analysis establishes the repair.

Expected relation: The candidate is one-minimal under the declared predicate but size3 exceeds the global size2; unresolved outcomes limit causal interpretation.

Withheld transfer discriminator: Change allowed reduction from one deletion to two deletions and recertify minimality.
