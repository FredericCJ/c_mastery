# PR-T45-06 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4506a"></a>
## T45.06.a

Rollback cannot reclaim a resource whose ownership was transferred successfully. The transfer boundary needs its own commit semantics.

Expected relation: Every acquired resource is released once in dependency order or explicitly transferred; unacquired resources are never released; failed construction publishes nothing.

Withheld transfer discriminator: Transfer one child resource to another owner before parent failure.

<a id="t4506b"></a>
## T45.06.b

A reference-counted cycle and a tracing collector have different reclamation behavior. The graph model must identify which mechanism is being assessed.

Expected relation: Reachability and retention budgets are separate; cycle and conservative-root assumptions are explicit; no graph label is promised as a native detector string.

Withheld transfer discriminator: Add weak edges and recompute strong reachability.

<a id="t4506c"></a>
## T45.06.c

Exactly-once release and bounded retention are related but different. Reclamation delays must be included in the resource model.

Expected relation: Every cycle returns to its declared baseline; transient peaks and retained budget are checked at each boundary; first cause survives cleanup failure.

Withheld transfer discriminator: Let destruction be deferred until readers leave an epoch and update the retained-byte bound.
