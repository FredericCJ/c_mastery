# PR-T15-08 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1512a"></a>

## T15.12.a

Wire signed representation is a chosen protocol,not a host assumption. Avoid misaligned typed casts and invalid signed conversions.

Withheld discriminator: Decode on a host with different endian/alignment and compare the value proof. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1512b"></a>

## T15.12.b

Compatibility depends on semantics and framing,not simply accepting more bytes. Unknown critical state cannot be silently discarded.

Withheld discriminator: Add length-delimited optional fields and define skip/critical-extension rules with bounded work. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.12.c

A CRC is linear error detection under specified conventions. A matching checksum does not authenticate a sender or prevent deliberate modification.

Withheld discriminator: Change reflection/init parameters and show why the prior vector no longer certifies the new variant. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.13.a

Framing and payload validation are distinct. A length prefix must be admitted before reserving or indexing payload storage.

Withheld discriminator: Use an escaped delimiter protocol and derive the new state needed when escape ends a chunk. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1513b"></a>

## T15.13.b

Backpressure is an ownership state,not just a return code. Reusing a pending buffer before acknowledgement violates the borrow contract.

Withheld discriminator: The consumer retains a borrowed frame until acknowledgement; define storage lifetime and cancellation. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1513c"></a>

## T15.13.c

No-progress loops can occur with valid pointers and fixed storage. Recovery must have a decreasing input/work budget and cannot assume a future delimiter will arrive.

Withheld discriminator: Permit nested frames with depthlimit3 and derive independent byte/depth budgets. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
