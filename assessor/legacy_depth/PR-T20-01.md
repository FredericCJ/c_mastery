# PR-T20-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2001a"></a>
## T20.01.a

Cohesion and hidden decisions are assessed through actual change experiments. A zero-copy path may couple lifetimes even when include dependencies remain acyclic.

Expected relation: The change-impact table names the decision hidden by each module and demonstrates which clients avoid change; no universal best decomposition is claimed.

Withheld transfer discriminator: Introduce zero-copy transport that retains a storage view and revise the ownership boundary.

<a id="t2001b"></a>
## T20.01.b

An opaque void pointer may hide syntax while still imposing undocumented platform semantics. The port must expose timing, failure and lifetime behavior explicitly.

Expected relation: The repaired public core header needs no OS/vendor representation; dependent consumers compile under the declared primitive profile.

Withheld transfer discriminator: Add asynchronous completion and represent retained buffer ownership without exposing an OS request object.

<a id="t2001c"></a>
## T20.01.c

A cycle in callbacks can be legitimate but needs bounded recursion/lifetime rules. Topological source layout cannot establish those dynamic properties.

Expected relation: Both graphs are recorded; the repaired compile boundary is acyclic while runtime callback relationships have explicit reentry/ownership rules.

Withheld transfer discriminator: Introduce a plugin registry and separate registration-time from execution-time dependencies.

<a id="t2002a"></a>
## T20.02.a

Two policies can have identical depths and incompatible ownership behavior. Verify identity and release accounting independently.

Expected relation: Reject-newest retains[A,B] with C still caller-owned; drop-oldest retains[B,C] and releases or returns A according to the explicit contract.

Withheld transfer discriminator: Add priority admission and define starvation and release obligations without rewriting the ring mechanism.

<a id="t2002b"></a>
## T20.02.b

A fake clock enables tests but cannot prove an actual hardware timer's behavior. Keep adapter validation and model reasoning separate.

Expected relation: Each injected effect obeys stated units, retention and failure rules; a nonmonotonic clock cannot silently satisfy a monotonic deadline contract.

Withheld transfer discriminator: Replace periodic polling with event notifications and derive subscription/cancellation lifetime rules.

<a id="t2002c"></a>
## T20.02.c

Changing the policy pointer cannot invalidate an in-flight operation's captured contract. The chosen replacement protocol must preserve its old resources until completion.

Expected relation: The report identifies actual code/dependency differences and preserved behavior; runtime policy state has an owner and valid lifetime.

Withheld transfer discriminator: Permit runtime replacement while a request is pending and define quiescence or version pinning.

<a id="t2003a"></a>
## T20.03.a

Purity concerns dependence and effects, not absence of useful state. An explicit state argument can support deterministic transitions while an implicit global undermines replay.

Expected relation: The fixture produces[2,6,10]; overflow reports failure without invalid signed evaluation or partial publication; repeated identical inputs agree.

Withheld transfer discriminator: Change the transform to a stateful window sum and make all retained state explicit in the replay record.

<a id="t2003b"></a>
## T20.03.b

A pure reducer is not a distributed transaction. The repair's duplicate suppression scope and persistence assumptions must be stated and tested.

Expected relation: The trace distinguishes decision, invocation, external commit and acknowledgment; an ambiguous result remains explicit.

Withheld transfer discriminator: Add a durable outbox or idempotency key and define the exact recovery contract it provides.

<a id="t2003c"></a>
## T20.03.c

The finite sum is1+3+9+27+81. Exhaustiveness applies only to this bounded model and its assumptions, not to every C execution.

Expected relation: 121 input sequences cover the selected finite transform domain; they do not establish physical device, OS timing or general integer-range correctness.

Withheld transfer discriminator: Replace exact enumeration with a property test over full-range values and explain shrinking and coverage limits.

<a id="t2004a"></a>
## T20.04.a

A file write, durable commit and device acknowledgment are different events. Signatures alone cannot encode the distinction.

Expected relation: The conformance table rejects at least one unit, timing, progress or retention mismatch before composition.

Withheld transfer discriminator: Replace stable storage with a volatile resettable medium and revise durability/recovery claims.

<a id="t2004b"></a>
## T20.04.b

Independently authored paths can still share a mistaken contract. Require a separately derived expected trace and exact environment evidence.

Expected relation: The scripted/Linux adapters produce their declared traces; board compile success is not a physical result and remains separately labeled.

Withheld transfer discriminator: Replace the Linux file source with a nonblocking short-read stream and reuse protocol tests.

<a id="t2004c"></a>
## T20.04.c

A semantically valid adapter must preserve observable partial progress and failure behavior as well as eventual payload.

Expected relation: Record values agree after complete assembly; a deferred retain contract cannot replace a synchronous borrow contract without an adapter or API change.

Withheld transfer discriminator: Permit cancellation after one chunk and define whether the partial record survives a retry.
