## Withheld executable formatting control

The original target lives in `fixtures/legacy_depth/format_authority.c`. `assessor/legacy_depth/security_format.c` supplies the repair and `security_format_test.c` checks the independent contract. Run `python3 assessor/legacy_depth/verify_format_demo.py` on Linux or through WSL. The compiler command includes C17 and warning errors. The flawed call consumes a correctly typed live int pointer: `%n` stores zero because no characters preceded it. This is defined behavior that violates the application property that rendering cannot modify the marker. The trusted `%s` repair returns two, preserves marker 77, and prints `%n`; capacities 1, 2 and 3 verify truncation separately. This proves neither arbitrary-address write nor code execution. A platform policy may reject a writable format containing `%n`; that is a changed condition to investigate without disabling host policy.

The initial author run failed on an overlong test initializer under warning-as-error; the preserved initial failure receipt is not a semantic kill. After correcting that initializer, all six original/repair runs passed. The receipt covers only this example and is not learner assessment or independent review.
