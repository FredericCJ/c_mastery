# PR-T09-02 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0904a"></a>
## T09.04.a — Relate relocation entries to unresolved address computations.

The synthetic expression is-20; real relocation semantics must be selected by its actual type, field location and addend representation.

Reject superficial reasoning: A relocation is merely copying a symbol address into bytes.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A relocation is merely copying a symbol address into bytes.

Delayed assessor check: Use a REL object where the addend is stored in the relocated bytes and explain the changed decoder obligation.

<a id="t0904b"></a>
## T09.04.b — Compare absolute, PC-relative, and selected architecture relocations.

The formulas and signedness differ; a load-base change affects an absolute address differently from an intra-image relative displacement.

Reject superficial reasoning: Absolute and PC-relative relocations differ only in field size.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Absolute and PC-relative relocations differ only in field size.

Delayed assessor check: Move the target symbol to another load region and identify which relative assumptions no longer hold.

<a id="t0904c"></a>
## T09.04.c — Diagnose relocation overflow and incompatible relocation models.

-20 fits and236 does not; equal low bytes do not imply equal relocation meaning. Distinguish intended overflow diagnostics from unrelated link failure.

Reject superficial reasoning: Truncating to the field width is a valid overflow policy.

Discriminator: The two values encode the same low byte EC but only -20 is in [-128,127]. A decoder that accepts236 after truncation erases the very overflow being assessed; a wider intermediate or independent integer arithmetic must precede encoding.

Delayed assessor check: Change the relocation's signedness or code model and derive a new admissible interval before altering flags.

<a id="t0905a"></a>
## T09.05.a — Compare PIC, PIE, non-PIE, and static relocation assumptions.

Position independence, executable role and runtime linkage are separate dimensions; actual metadata and address formation substantiate each claim.

Reject superficial reasoning: PIC, PIE and static linking are interchangeable properties.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: PIC, PIE and static linking are interchangeable properties.

Delayed assessor check: Build a supported static-PIE variant and locate its self-relocation owner rather than assuming no loader means no relocations.

<a id="t0905b"></a>
## T09.05.b — Inspect address formation and indirection in generated code.

Visibility and binding can change indirection or relaxation; final code is the artifact being executed. Source-level operation count is not a dynamic instruction count.

Reject superficial reasoning: Every source address operation requires the same indirection sequence.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every source address operation requires the same indirection sequence.

Delayed assessor check: Hide an export or change interposition policy and explain which optimization becomes valid.

<a id="t0905c"></a>
## T09.05.c — Identify relocation costs and restrictions in the selected environment.

Static counts and dynamic costs are different observations; relocation type, loader behavior and shared pages affect cost. Equivalent behavior is required for comparison.

Reject superficial reasoning: More relocation records necessarily imply proportionally slower startup.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: More relocation records necessarily imply proportionally slower startup.

Delayed assessor check: Change only eager/lazy binding and separate work moved to first call from work eliminated.
