# PR-T44-08 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4410a"></a>
## T44.10.a

Frame validity depends on architecture and active configuration. An imprecise fault may not identify the responsible instruction even with a valid frame.

Expected relation: The original frame base/vector results hold under the stated model; unsupported/truncated frames remain undecoded, not guessed.

Withheld transfer discriminator: Add alignment padding with an explicitly inspected target contract.

<a id="t4410b"></a>
## T44.10.b

MMIO and independently running devices have target contracts beyond ISO C. Host mutexes and debugger stops do not automatically establish device quiescence.

Expected relation: The first invalid ownership event is CPU reuse before stop acknowledgment; invalid fault-address flags prevent using stale addresses.

Withheld transfer discriminator: Move the model to a cached MCU and list the added visibility obligations.

<a id="t4410c"></a>
## T44.10.c

Generation rejection protects logical identity, but actual DMA cessation and memory visibility require the selected hardware protocol.

Expected relation: Early writes reject; one terminal transition returns ownership; reset requires an explicit quiescence contract and target evidence remains separate.

Withheld transfer discriminator: Add a late completion from the pre-reset generation.
