# PR-T11-05 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t1109a"></a>
## T11.09.a — Check undefined symbols, linked objects, and dynamic dependencies.

Undefined, dynamic and statically resolved dependencies require different evidence; the existing visible audit must be supplemented with origin/map checks for the last case.

Reject superficial reasoning: No undefined symbols means no forbidden code was linked.

Discriminator: A final fully linked original object can contain forbidden_helper while nm -u is empty and no DT_NEEDED exists. The new control therefore needs map/origin evidence; merely replaying the existing unresolved-object negative case does not assess this leaf extension.

Delayed assessor check: Strip symbols from an original artifact and fail closed or use a documented alternative rather than infer an empty dependency set.

<a id="t1109b"></a>
## T11.09.b — Inspect final disassembly for compiler helpers and instrumentation.

Inlining, static resolution and indirect calls can hide names; an auditable allowlist needs a declared analysis boundary and unresolved uncertainty.

Reject superficial reasoning: A final symbol-name search is a complete semantic dependency proof.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A final symbol-name search is a complete semantic dependency proof.

Delayed assessor check: Enable LTO and show how origin records and final code evidence change when the helper is inlined.

<a id="t1109c"></a>
## T11.09.c — Compare audits across optimization, compiler, and configuration changes.

Each source/configuration/binary tuple has a separate receipt; negative controls must fail for the intended dependency property, not a missing executable.

Reject superficial reasoning: A passing representative build licenses all optimization and compiler variants.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A passing representative build licenses all optimization and compiler variants.

Delayed assessor check: Change the allowlist and demonstrate which prior receipts become stale even when source bytes are unchanged.
