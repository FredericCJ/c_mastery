# PR-T46-08 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4608a"></a>
## T46.08.a

The marked-set invariant bounds work despite cycles. Weak edges change reachability semantics and require a separate phase/policy.

Expected relation: Only live initialized locations contribute roots; each object is enqueued once; aliases do not overflow the object-count worklist.

Withheld transfer discriminator: Add weak references under a new contract and separate tracing from weak processing.

<a id="t4608b"></a>
## T46.08.b

Precise roots must cover all live temporaries across every allocating call. This is programmer discipline in C unless external tooling verifies the convention.

Expected relation: Both operands survive collection; failed root admission restores the prior root count and publishes no parent; the missing-root mutant fails.

Withheld transfer discriminator: Add a helper that allocates between computing the two operands.

<a id="t4608c"></a>
## T46.08.c

Incremental mutation invalidates the original static graph assumption. A barrier and phase invariant are new mechanisms, not a scheduling tweak.

Expected relation: No failed collection sweeps; retry clears marks; stale references reject after actual reclamation; stop-the-world latency remains unbounded by guest fuel.

Withheld transfer discriminator: Introduce incremental marking and derive the write barrier required during mutation.
