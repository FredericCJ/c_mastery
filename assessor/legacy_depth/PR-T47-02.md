# PR-T47-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4702a"></a>
## T47.02.a

Associativity changes traffic,not the no-steal invariant. Sharing a buffer between clean cache and dirty scratch would require a new ownership proof.

Expected relation: Only matching physical tags hit; no uncommitted node reaches the clean backend cache; memory categories are distinct.

Withheld transfer discriminator: Use a two-way cache and compare replacement policy without changing transaction ownership.

<a id="t4702b"></a>
## T47.02.b

Cache coherence is part of storage correctness. A correct tree lookup over stale bytes still returns the wrong committed value.

Expected relation: Both publication and checkpoint transitions preserve the latest committed logical map; each missing-invalidation mutant is distinguishable.

Withheld transfer discriminator: Reuse a physical page after deletion and add generation to the cache identity analysis.

<a id="t4702c"></a>
## T47.02.c

A direct-mapped conflict workload can defeat apparent locality. Finite traffic counts do not establish latency or physical I/O size.

Expected relation: The trace predicts exact logical read counts; native device traffic remains a separately observed or unavailable quantity.

Withheld transfer discriminator: Run a scan larger than the cache and compare with a point-lookup workload.
