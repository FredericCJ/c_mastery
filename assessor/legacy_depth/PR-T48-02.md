# PR-T48-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4802a"></a>
## T48.02.a

Unknown tags may be skipped only after their extents validate. Compatible extended records are not an excuse to skip minimum-stride checks.

Expected relation: Offset8 plus size21 advances to32; malformed raw or rounded extents refuse before reading or publishing fields.

Withheld transfer discriminator: Use a buffer whose valid total size ends exactly on a tag boundary.

<a id="t4802b"></a>
## T48.02.b

The reservation policy is a teaching allocator rule, not an inferred universal firmware ordering rule. Exact endpoint rounding determines ownership.

Expected relation: Reserved overlap always wins; no partially reserved frame is returned; permutation preserves the final free set.

Withheld transfer discriminator: Move the module into a formerly free interval and recompute capacity.

<a id="t4802c"></a>
## T48.02.c

The contract must state output semantics on error. Bounds checking and transactionality are separate obligations.

Expected relation: All malformed cases reject; the caller-visible result follows one explicit unchanged-or-cleared contract, with no mixed partial result.

Withheld transfer discriminator: Add a validated optional tag without making required-tag absence acceptable.
