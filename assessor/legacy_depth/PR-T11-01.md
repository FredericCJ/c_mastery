# PR-T11-01 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t1101a"></a>
## T11.01.a — Separate hosted, freestanding, libc-free, allocation-free, and custom-startup requirements.

Each label refers to a different requirement and boundary; a no-libc process can use OS services and a freestanding component can be tested by a hosted harness.

Reject superficial reasoning: These labels are synonyms and follow from omitting stdlib.h.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: These labels are synonyms and follow from omitting stdlib.h.

Delayed assessor check: Add an allocating callback behind an otherwise allocation-free interface and explain which claim becomes conditional.

<a id="t1101b"></a>
## T11.01.b — State whether restrictions apply to component or entire executable.

Component and executable claims have different scopes; link commands and origins must establish the selected boundary. Target code may not delegate its mechanism to the oracle.

Reject superficial reasoning: A forbidden routine anywhere in the test process invalidates component isolation, or conversely host success proves whole-image isolation.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A forbidden routine anywhere in the test process invalidates component isolation, or conversely host success proves whole-image isolation.

Delayed assessor check: Move the primitive into a no-libc executable and rebuild the complete closure rather than reuse the host receipt.

## T11.01.c — Enumerate headers, libraries, runtime helpers, syscalls, and allocation sources.

Generated code and transitive callees can add requirements; unknown callback behavior remains conditional. The manifest must distinguish declaration availability from implementation linkage.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A textual search for malloc and includes discovers every dependency.

Delayed assessor check: Introduce a function-pointer callback supplied by another learner component and bind its own accepted contract explicitly.

## T11.02.b — Distinguish -nostdlib, -nodefaultlibs, and -nostartfiles experimentally.

The options affect different link-input categories; unresolved helper or startup references need an explicit resolution/exclusion decision. Missing tool installation is not an intended failure.

Reject superficial reasoning: All three exclusion options remove identical inputs.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: All three exclusion options remove identical inputs.

Delayed assessor check: Supply one local byte helper explicitly under -nostdlib and prove no unrelated library enters through the link line.

## T11.02.c — Treat header-search restrictions as a separate build dimension.

Headers can be available without linking their library; restricting search does not remove implicit compiler support. Preserve required compiler-provided types deliberately.

Reject superficial reasoning: Header restrictions are equivalent to runtime-library restrictions.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Header restrictions are equivalent to runtime-library restrictions.

Delayed assessor check: Create a target sysroot with different stdint definitions and reject a host-header leak using a measured type manifest.
