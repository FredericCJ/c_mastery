# PR-T47-12 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4712a"></a>
## T47.12.a

An integer API can still perform persistent effects. Capability restriction and idempotence are separate contracts.

Expected relation: Each layer's status remains attributable; denied services have no side effects; uncertain commit requires recovery.

Withheld transfer discriminator: Add a read-modify-write service with operation IDs and reconciliation.

<a id="t4712b"></a>
## T47.12.b

A common C signature does not imply equivalent semantics. The adapter is part of the proof and requires its own failure tests.

Expected relation: The adapter preserves page identity and exclusive ownership; short/error/device-completion behavior is explicit; actual guest execution is recorded separately.

Withheld transfer discriminator: Replace the device with asynchronous queued I/O and derive buffer retention/cancellation rules.

<a id="t4712c"></a>
## T47.12.c

Compensation is another operation that can fail; it is not automatic rollback of an already durable transaction.

Expected relation: Recovered value determines the outcome under the operation contract; no mixed map or blind retry is accepted.

Withheld transfer discriminator: Transfer the protocol to a two-step application workflow with compensation.
