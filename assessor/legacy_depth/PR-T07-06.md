# PR-T07-06 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0712a"></a>
## T07.12.a — Control timestamps, paths, generated identifiers, and archive ordering.

Path mapping does not normalize arbitrary generated timestamps or inputs; each source of variation needs a justified policy. Do not erase meaningful provenance to force equality.

Reject superficial reasoning: One prefix-map option makes every build reproducible.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: One prefix-map option makes every build reproducible.

Delayed assessor check: Use a deterministic archive ordering policy and show whether changing object order still changes semantics or only representation.

<a id="t0712b"></a>
## T07.12.b — Compare output hashes and explain unavoidable variability.

Behavioral equivalence, code identity and whole-file identity are different claims; only a fully declared identical-input experiment supports the latter.

Reject superficial reasoning: Equal output or equal .text implies identical complete artifacts.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Equal output or equal .text implies identical complete artifacts.

Delayed assessor check: Introduce a nondeterministic generated table whose entry order affects lookup semantics and show normalization would hide a real defect.

<a id="t0712c"></a>
## T07.12.c — Record compiler, linker, source, configuration, and dependency provenance.

The record is a reproducibility claim with a specific input boundary, not proof of trusted provenance or universal equivalence.

Reject superficial reasoning: An output hash alone states how an artifact was produced.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: An output hash alone states how an artifact was produced.

Delayed assessor check: Reproduce using a different compiler release and report semantic agreement separately from byte identity.
