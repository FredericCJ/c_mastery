# PR-T46-06 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4606a"></a>
## T46.06.a

Short-circuiting changes which effects execute. Treating it as eager arithmetic evaluation changes the language semantics.

Expected relation: Targets land on valid instructions in the same function; both arms leave one expression value; loop backedges preserve height.

Withheld transfer discriminator: Add short-circuit Boolean operators and derive their distinct stack equations.

<a id="t4606b"></a>
## T46.06.b

A new nonlocal control construct affects stack cleanup, roots and resource ledgers. It cannot be implemented safely by jumping to an arbitrary host label.

Expected relation: Integer conditions reject; one if arm executes; set returns its assigned value; do discards the first result and while discards body values.

Withheld transfer discriminator: Introduce a break expression with a value and specify its effect on joins.

<a id="t4606c"></a>
## T46.06.c

Fuel is part of the execution contract. Compiler changes can alter the amount required even when source results are equivalent.

Expected relation: Fuel counts dispatches; the finite program completes only with sufficient budget; the infinite loop stops with FUEL and unchanged result output.

Withheld transfer discriminator: Change lowering to reduce opcode count and reassess fuel compatibility.
