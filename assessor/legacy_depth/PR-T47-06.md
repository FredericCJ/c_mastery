# PR-T47-06 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4706a"></a>
## T47.06.a

Adding readers changes visibility and lifetime rules. The existing serialized proof cannot be reused as a concurrency proof.

Expected relation: The complete memory bound includes every category; no reader concurrency is implied; backend writes before commit are restricted by protocol.

Withheld transfer discriminator: Design snapshot readers and list the additional version/reclamation machinery.

<a id="t4706b"></a>
## T47.06.b

Savepoints require a finer rollback boundary and resource accounting. A single active flag does not encode the required history.

Expected relation: Input rejection preserves staged earlier work; capacity exhaustion aborts the transaction; committed state remains unchanged before publication.

Withheld transfer discriminator: Introduce a savepoint and specify its bounded undo representation.

<a id="t4706c"></a>
## T47.06.c

Shared caches introduce identity and synchronization obligations. A handle-local invalidation proof does not cover another handle's cached state.

Expected relation: The first unauthorized visibility transition is identified and repaired; committed reads cannot observe transaction-private bytes.

Withheld transfer discriminator: Add a cache shared by two store handles and reassess serialization assumptions.
