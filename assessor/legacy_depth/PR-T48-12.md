# PR-T48-12 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4812a"></a>
## T48.12.a

Portable semantics require explicit integer, storage and callback assumptions. Equivalent output on one input is insufficient to establish identical implementations.

Expected relation: Only adapter and target build choices differ; the result relation and bytecode identity match.

Withheld transfer discriminator: Load bytecode from a checked archive span and reject a truncated image before running.

<a id="t4812b"></a>
## T48.12.b

Compiler stack reports need call-graph and recursion assumptions. Moving storage changes reentrancy and ownership even when outputs remain equal.

Expected relation: Every linked helper has an owned allowed implementation; separate stack and static budgets fit the selected process layout under stated bounds.

Withheld transfer discriminator: Tighten the user stack and move suitable scratch to caller-owned static storage with a nonreentrancy contract.

<a id="t4812c"></a>
## T48.12.c

Resource counters bound only their defined units. A blocking or unbounded callback invalidates a wall-time claim even with one permitted call.

Expected relation: The successful case consumes one allowance; zero allowance yields CVM_HOST_BUDGET with no callback; error propagates distinctly.

Withheld transfer discriminator: Use a callback that consumes a bounded internal loop and derive a combined service bound.
