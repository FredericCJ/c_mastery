# PR-T44-06 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4408a"></a>
## T44.08.a

A cursor is both a count and a position in the source representation. Vectored I/O needs a checked mapping between those views.

Expected relation: Offsets are cumulative, no byte repeats or disappears, impossible adapter counts reject, zero/EOF have operation-specific results.

Withheld transfer discriminator: Transfer to scatter/gather buffers with zero-length segments.

<a id="t4408b"></a>
## T44.08.b

An errno wrapper cannot be applied blindly to direct-status functions. Resource tests remain confined to owned descriptors and finite child processes.

Expected relation: Original ENOSPC survives logging EIO; signal disposition controls the observable path; per-process EMFILE is distinct from system-wide exhaustion.

Withheld transfer discriminator: Use a pthread API returning a direct error number and adapt the wrapper.

<a id="t4408c"></a>
## T44.08.c

The wrapper must follow the selected OS contract. A runtime integer equality cannot establish that a reused descriptor denotes the old resource.

Expected relation: The Linux model retires the old descriptor once; generation2 remains untouched. Record the different POSIX edition contract as a portability obligation.

Withheld transfer discriminator: Design an adapter with explicit close-policy selection and test both modeled contracts.
