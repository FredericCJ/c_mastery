# PR-T20-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2006a"></a>
## T20.06.a

A scheduling model is conditional analysis. Real measured latencies require recorded clocks, load and target execution; neither substitutes for the other.

Expected relation: Every completion bound follows stated scheduling/preemption/service assumptions; two workers on one core do not create two cores.

Withheld transfer discriminator: Add blocking I/O that can overlap computation and revise the model's useful concurrency.

<a id="t2006b"></a>
## T20.06.b

The recurrence is accepted=min(arrivals,capacity-pending), service=min(pending+accepted,budget). Identity traces additionally verify that rejected items remain caller-owned.

Expected relation: Original processed[2,2,2],dropped[0,0,0],pending[1,0,2]; overload processed[2,2,2],dropped[1,0,1],pending[2,0,2].

Withheld transfer discriminator: Move service before enqueue and recompute both traces and latency interpretation.

<a id="t2006c"></a>
## T20.06.c

Do not invent a worst-case execution time from mean measurements. Analytical and empirical claims retain separate assumptions.

Expected relation: The decision includes an admissible workload model and overload policy; overload outside it is explicit rather than hidden by queueing.

Withheld transfer discriminator: Introduce a blocking callback with unbounded duration and identify which guarantee becomes impossible without changing the contract.

<a id="t2007a"></a>
## T20.07.a

Hierarchy may reduce repeated transitions but must preserve observable ordering. It cannot erase intermediate resource obligations.

Expected relation: Every combined state names the unique owner and allowed next events; impossible combinations reject or remain unreachable by proof.

Withheld transfer discriminator: Add a supervisor restart state and distinguish child incarnation from logical request identity.

<a id="t2007b"></a>
## T20.07.b

A bounded queue creates a progress obligation for control events. Reserving capacity, synchronous acknowledgment or another explicit policy is needed when ordinary work fills it.

Expected relation: Each admitted trace has one terminal owner; stale events cannot act on a new request; overflow has a declared retry/failure result.

Withheld transfer discriminator: Make cancellation acknowledgment itself a queued event and prove a full queue cannot strand cleanup forever.

<a id="t2007c"></a>
## T20.07.c

A logical ordering argument does not remove C data races. A multi-thread variant needs both memory-model synchronization and protocol ordering.

Expected relation: Independent permutations preserve observations; dependent permutations either satisfy the stated serialization or expose a minimized counterexample.

Withheld transfer discriminator: Replace serialized callbacks with multiple producers and derive the synchronization needed before C-level execution is legal.
