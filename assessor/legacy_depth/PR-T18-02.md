# PR-T18-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1803a"></a>
## T18.03.a

ISO C assignments do not enforce move-only types. Shared ownership requires a separate counting or reachability protocol and does not provide data synchronization.

Expected relation: Borrowers release nothing; transfer clears the old logical owner; weak access does not by itself keep storage alive.

Withheld transfer discriminator: Replace the single owner with an acyclic parent-child tree and then introduce a cycle; identify which release proof fails.

<a id="t1803b"></a>
## T18.03.b

A ledger must record the actual side-effect boundary. A lost acknowledgment may require recovery rather than blind rollback; exact-once release is not inferred from one success trace.

Expected relation: Every acquired resource has exactly one eventual release or explicit transferred owner; never-acquired resources have zero releases.

Withheld transfer discriminator: Make registration acquisition succeed while its acknowledgment is lost and add an ownership query or idempotency protocol.

<a id="t1803c"></a>
## T18.03.c

SQLite finalization reports evaluation status while deleting the statement. Other resource contracts may differ; wrappers must retain that distinction rather than retry every error.

Expected relation: Each resource has an explicit post-close owner state; a reported cleanup error does not automatically authorize retry.

Withheld transfer discriminator: Add a close operation whose failure leaves ownership intact and compose it with one whose error still consumes ownership.

<a id="t1804a"></a>
## T18.04.a

A generation check can reject a stale logical request only while the object containing the generation is still alive. It cannot make a freed context safe to inspect.

Expected relation: Context remains live through the final callback and any promised quiescence acknowledgment; removing a registry entry alone is insufficient.

Withheld transfer discriminator: Allow callbacks to schedule another callback and derive whether quiescence includes that queued descendant.

<a id="t1804b"></a>
## T18.04.b

The contract may conservatively invalidate more than addresses physically move. A stale view must not read owner metadata after owner destruction; the external owner-lifetime obligation remains.

Expected relation: Each operation has an explicit epoch effect; failed append preserves views under the chosen transactional policy; SQLite borrows obey their own operation-specific contract.

Withheld transfer discriminator: Permit nonmoving value updates while structural mutation invalidates iterators; split the epoch policy and test both classes.

<a id="t1804c"></a>
## T18.04.c

Retirement exchanges capacity for permanent stale-token rejection within this model. Generation equality does not establish concurrent lifetime safety or prevent forged tokens without an authority boundary.

Expected relation: A stale handle never becomes valid again under retirement; allocation eventually reports exhaustion rather than wrapping.

Withheld transfer discriminator: Change to a bounded epoch lease with an explicit maximum retention interval and derive the conditions needed to permit reuse.
