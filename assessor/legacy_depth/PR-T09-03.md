# PR-T09-03 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0906a"></a>
## T09.06.a — Trace interpreter selection, dependency discovery, and symbol lookup.

Each dependency has its own resolution; failure must name the missing object. Local process environment changes do not establish universal search behavior.

Reject superficial reasoning: Finding the first plugin proves its entire dependency closure is present.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Finding the first plugin proves its entire dependency closure is present.

Delayed assessor check: Relocate the plugin and its dependency together and justify an origin-relative policy without private build paths.

<a id="t0906b"></a>
## T09.06.b — Inspect GOT, PLT, binding behavior, and symbol interposition.

Visibility, lookup scope and binding policy can redirect the toy call; numeric output alone does not identify the selected symbol origin.

Reject superficial reasoning: A symbol's source definition uniquely fixes every dynamic call target.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A symbol's source definition uniquely fixes every dynamic call target.

Delayed assessor check: Hide the symbol or bind it locally and explain which interposition expectation changes.

<a id="t0906c"></a>
## T09.06.c — Compare startup and lazy-resolution behavior without assuming universality.

The declared loader may defer function resolution; data relocations and other loading work remain immediate. Unsupported lazy behavior must be reported, not guessed.

Reject superficial reasoning: Lazy mode postpones resolution of all symbols including data.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Lazy mode postpones resolution of all symbols including data.

Delayed assessor check: Replace the missing function reference with a data reference and predict the changed load-time outcome.

## T09.07.b — Locate initialization/finalization arrays and their execution mechanisms.

## T09.11.c — Compare source compatibility with binary compatibility.

Source, symbol and behavioral compatibility are independent; an unchanged symbol can conceal a layout break.

Reject superficial reasoning: Recompiling successfully proves old binaries remain compatible.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Recompiling successfully proves old binaries remain compatible.

Delayed assessor check: Change ownership of a returned pointer without changing its C type and identify the binary-compatible but semantically incompatible contract.
