# PR-T19-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1906a"></a>
## T19.06.a

Purity helps reproducible reasoning but does not establish durability or exactly-once effects. State when each external action becomes observable.

Expected relation: Identical state/input yields identical reducer output; failed effects remain explicit and do not get silently treated as committed.

Withheld transfer discriminator: Make an effect non-idempotent and add a request identity/outbox obligation before retry.

<a id="t1906b"></a>
## T19.06.b

Do not compare only reachable nominal states if the public interface accepts arbitrary event encodings. Compiler lowering may turn a switch into a table, but that is not guaranteed.

Expected relation: All three forms agree on valid transitions and reject invalid indices before table access; resource measurements identify the actual compiled form.

Withheld transfer discriminator: Make the state set sparse and compare lookup/admission costs without changing the transition contract.

<a id="t1906c"></a>
## T19.06.c

A static design may be simpler until runtime replacement is genuinely needed. Hot replacement adds quiescence and compatibility obligations absent from a nominal function-table benchmark.

Expected relation: The selected mechanism satisfies the actual variation requirement and exposes its resource/correctness costs; no unsupported universal speed claim.

Withheld transfer discriminator: Require hot backend replacement while operations remain in flight and rederive ownership/version constraints.

<a id="t1907a"></a>
## T19.07.a

The epoch check itself needs a live owner. It does not make an iterator into reclaimed storage safe or enforce synchronization between threads.

Expected relation: The exact traversal prefix and stale rejection hold; end, early-stop and invalidation are distinct results.

Withheld transfer discriminator: Allow value-only mutation while structural changes invalidate and split the validity argument.

<a id="t1907b"></a>
## T19.07.b

Push callbacks invert control and introduce reentrancy obligations. A pull cursor retains its owner relationship between calls; neither is automatically safer.

Expected relation: Both adapters agree under their shared no-mutation contract; reentry/removal behavior is explicit and tested separately.

Withheld transfer discriminator: Suspend the consumer between pulls and compare retained state/lifetimes with a deferred push producer.

<a id="t1907c"></a>
## T19.07.c

A caller callback can recurse even if the traversal loop itself is iterative. The resource contract must include allowed callback behavior.

Expected relation: The ledger separates collection storage, cursor/registration state and stack depth; bounds name the maximum nesting policy.

Withheld transfer discriminator: Replace bounded recursion with an explicit continuation stack and define exhaustion behavior.
