# PR-T47-11 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4711a"></a>
## T47.11.a

A new backend can introduce EAGAIN and asynchronous lifetime. Those require a different adapter contract,not an unbounded retry.

Expected relation: Only positive progress advances; zero/error terminates under the contract; no incomplete page is decoded as complete.

Withheld transfer discriminator: Change to a nonblocking backend with explicit readiness and retry budget.

<a id="t4711b"></a>
## T47.11.b

Preallocation intentionally removes creation semantics from the original contract. Extending the lifetime boundary adds metadata persistence work.

Expected relation: The test establishes the requested API/reopen boundary only; sync failure is reported and no physical power-cut result is inferred.

Withheld transfer discriminator: Create the file during the operation and add the directory-entry durability obligation.

<a id="t4711c"></a>
## T47.11.c

Logging fewer pages changes batch description,validation and recovery completeness. A lower traffic count alone does not validate the new protocol.

Expected relation: Full-image redo costs are explicit; ratio denominator is defined and nonzero; cache/device observations retain scope.

Withheld transfer discriminator: Implement changed-page redo under a new protocol and compare correctness-equivalent amplification.
