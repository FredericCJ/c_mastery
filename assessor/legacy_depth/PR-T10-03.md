# PR-T10-03 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

## T10.06.a — Map syscall numbers, arguments, clobbers, and results to registers.

The syscall interface uses r10 for argument4 and has rcx/r11 side effects; declare compiler operands/clobbers as well as machine register assignments.

Reject superficial reasoning: The fourth syscall argument belongs in rcx because C uses rcx.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The fourth syscall argument belongs in rcx because C uses rcx.

Delayed assessor check: Port the adapter design to a documented Arm64 convention and keep compile-only evidence separate from execution.

<a id="t1006b"></a>
## T10.06.b — Compare syscall ABI with ordinary C-call ABI.

A wrapper bridges different contracts; correct C argument placement does not prove correct kernel argument placement.

Reject superficial reasoning: A C function pointer can directly represent a raw kernel entry convention.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A C function pointer can directly represent a raw kernel entry convention.

Delayed assessor check: Introduce a32-bit ABI with an aligned64-bit syscall argument and derive its split/padding requirement.

<a id="t1006c"></a>
## T10.06.c — Separate raw kernel error returns from libc errno conventions.

Interpretation is operation/ABI-specific; the local write adapter treats raw Linux negative errors explicitly and preserves success byte counts.

Reject superficial reasoning: Every negative-looking machine word is universally an errno value on every ABI.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every negative-looking machine word is universally an errno value on every ABI.

Delayed assessor check: Design an adapter for a syscall whose successful result is an address and revisit the error-range test instead of testing only sign.

<a id="t1007a"></a>
## T10.07.a — Implement partial-transfer handling and interruption policies.

Submitted offsets are0,2,2,5 and exactly seven bytes are accepted once; EINTR consumes no bytes in this script. Backend contract violation is not clipped silently.

Reject superficial reasoning: Retrying after partial progress means resending the entire buffer.

Discriminator: The successive submitted suffixes are ABCDEFG, CDEFG, CDEFG, FG. Total accepted progress is2+3+2. A mock accepting an impossible count must be rejected; min(count,remaining) would conceal a violated backend contract.

Delayed assessor check: Replace EINTR with EAGAIN and define resumable state plus caller-owned lifetime across suspension.

<a id="t1007b"></a>
## T10.07.b — Handle EOF, zero progress, and operation-specific error conditions.

Operation-specific statuses prevent spinning; retries need a declared cancellation/deadline policy. A partial accepted prefix remains owned by the receiver.

Reject superficial reasoning: Zero progress always means EOF or should be retried forever.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Zero progress always means EOF or should be retried forever.

Delayed assessor check: Introduce cancellation after a partial write and explain why rollback of already accepted external bytes is impossible.

<a id="t1007c"></a>
## T10.07.c — Keep syscall wrappers separate from higher-level stream abstractions.

The mock assesses state transitions; real wrapper and final binary require separate ABI/dependency evidence. Buffer storage must remain live until completion/cancellation.

Reject superficial reasoning: A host mock proving the loop also proves register-level syscall correctness.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A host mock proving the loop also proves register-level syscall correctness.

Delayed assessor check: Compose the transfer state with length-prefixed framing and preserve frame ownership across a would-block return.
