# PR-T19-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1904a"></a>
## T19.04.a

Compile observations are compiler evidence. Provide the applicable ISO clause argument and retain exact-C17 source gaps rather than promoting one diagnostic to a universal semantic rule.

Expected relation: The chosen API evaluates runtime arguments once; typed diagnostics have explicit scope; the erased core requires separate runtime metadata contracts.

Withheld transfer discriminator: Add an array argument and a qualified pointer and explain controlling-expression type transformations under the selected edition/compiler.

<a id="t1904b"></a>
## T19.04.b

A generic storage contract must also justify effective type and permitted alignment. Caller-provided hooks can violate invariants; state validation and trust limits explicitly.

Expected relation: Failed append leaves destination count/owners unchanged and cleans only completed staged objects; shallow ownership copying fails the contract.

Withheld transfer discriminator: Replace copy with a move-only insertion that may fail before transfer; define the exact transfer point.

<a id="t1904c"></a>
## T19.04.c

Reject benchmarks that let one version omit destruction, validation or observable work. Report unavailable LTO or counters as unmeasured.

Expected relation: Measurements name toolchain/configuration and equivalent contracts; devirtualization is an observation, not an API guarantee.

Withheld transfer discriminator: Introduce a heterogeneous runtime-selected element type and revisit code-size versus indirection tradeoffs.

<a id="t1905a"></a>
## T19.05.a

The union's physical overlap does not supply algebraic-data-type exhaustiveness or ownership. External tag bytes require admission before payload interpretation.

Expected relation: Only the selected payload is interpreted; text length is explicit and may include zero bytes; empty text is a valid alternative.

Withheld transfer discriminator: Add an owned-text variant and derive copy/move/destruction operations for every tag.

<a id="t1905b"></a>
## T19.05.b

A generated list prevents some synchronization mistakes, but can consistently generate a wrong operation. Rubrics must assess payload invariants, not merely case count.

Expected relation: Valid alternatives have named behavior; malformed tags reject before payload use; missing-case diagnostics depend on the selected flags/compiler.

Withheld transfer discriminator: Generate tag declarations and dispatch metadata from one list, then show a semantic case that generation still cannot verify.

<a id="t1905c"></a>
## T19.05.c

The error variant must itself be fully initialized. A parsing failure may carry a bounded borrowed view only if its lifetime is documented beyond the call.

Expected relation: Every result has a valid selected alternative; overflow rejects before evaluating invalid arithmetic and returns the specified offset.

Withheld transfer discriminator: Change conversion to an accumulating validation result and preserve independent error locations.
