# PR-T44-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4404a"></a>
## T44.04.a

A clamp can hide a violation from final-state tests while a callback observes it. Instruction stepping clarifies which transition occurred, subject to the actual generated code.

Expected relation: The first violation is the fifth admission reaching5; a reject-before-commit repair avoids it. Save actual debugger transcript separately from the model.

Withheld transfer discriminator: Add a callback between increment and clamping to expose the transient invalid state.

<a id="t4404b"></a>
## T44.04.b

Debug information may represent inlined scopes without a physical frame. The selected source scope and optimized availability must be recorded.

Expected relation: The dossier identifies each live object by frame/scope and refuses an expired local as evidence.

Withheld transfer discriminator: Inline the callee and compare logical debugger frames with physical call frames.

<a id="t4404c"></a>
## T44.04.c

Optimization, unwind metadata and stack corruption can all affect reconstruction. Distinguishing those hypotheses requires additional evidence.

Expected relation: Unavailable values remain unknown; observed frames are not a complete execution history; mismatched symbols reject.

Withheld transfer discriminator: Use a tail call and explain why a source-level call may lack a retained frame.

<a id="t4405a"></a>
## T44.05.a

A logical object can move to new storage. Continuing to watch an obsolete address does not track the new object and may inspect invalid storage.

Expected relation: The chosen condition has no side effects and only accesses live storage; the helper alternative changes the experiment.

Withheld transfer discriminator: Replace the watched scalar with one field of a moving allocation and re-establish the watch after relocation.

<a id="t4405b"></a>
## T44.05.b

Hardware/software watches have different granularity and perturbation. A delayed observer can corroborate an effect without locating its origin alone.

Expected relation: The dossier distinguishes violation, store and observation boundaries; stopping granularity is recorded rather than inferred.

Withheld transfer discriminator: Use a buffered event log whose flush occurs after the invalid transition.

<a id="t4405c"></a>
## T44.05.c

The finite geometry fixture is not the actual target geometry. Alternative instrumentation needs its own evidence and cannot be silently labeled equivalent.

Expected relation: Unsupported requests remain unavailable; fallback changes the coverage claim and retains width, thread and lifetime limits.

Withheld transfer discriminator: Move the writer to another thread and assess whether the selected observation still applies.
