# PR-T22-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2204a"></a>
## T22.04.a

Stable IDs support navigation but require governance for changed meaning. Reusing an old ID for a materially different claim invalidates unqualified evidence reuse.

Expected relation: Renaming preserves traceability; duplicate identifiers and stale revision bindings are detected.

Withheld transfer discriminator: Split one requirement into two with explicit supersession links and preserve earlier evidence as historical.

<a id="t2204b"></a>
## T22.04.b

Traceability coverage does not establish test strength. Shared tests are valid only when each mapped objective has a discriminating condition.

Expected relation: The strengthened check fails when rejected append changes length or bytes, and its requirement mapping names that exact property.

Withheld transfer discriminator: Reuse one fixture across capacity and ownership objectives but add separate evidence/rubric clauses.

<a id="t2204c"></a>
## T22.04.c

A requirement can be assessed through analysis rather than execution. Non-applicability must be justified; absent evidence cannot be hidden behind that label.

Expected relation: R3 is uncovered,T9 is orphaned and R9 is unknown; the assertion-free linked test remains a separate quality defect.

Withheld transfer discriminator: Allow a justified analysis-only requirement and represent its reviewed proof artifact without inventing an executable test.

<a id="t2205a"></a>
## T22.05.a

CMake build-tree exports and install exports have different relocation properties. Record the selected tool version and actual consumer evidence.

Expected relation: The installed target references its own installation/dependencies without private absolute build paths; missing dependencies fail clearly.

Withheld transfer discriminator: Move the prefix and let the consumer discover it anew using only the documented package interface.

<a id="t2205b"></a>
## T22.05.b

Constrain file moves to verified learner-owned temporary paths. This exercise never deletes or relocates the curriculum repository or unrelated data.

Expected relation: The consumer still configures,builds and runs with original trees unavailable; no private include path masks missing installation content.

Withheld transfer discriminator: Copy the prefix to a second path with spaces and repeat discovery and execution.

<a id="t2205c"></a>
## T22.05.c

Static dependency propagation and shared runtime dependencies differ by toolchain/platform. Successful in-tree linking can conceal a broken installed interface.

Expected relation: The report identifies concrete dependency and lookup differences on the selected platform without claiming a universal ABI result.

Withheld transfer discriminator: Add a private dependency used only by the static library and verify the exported consumer link interface remains complete.
