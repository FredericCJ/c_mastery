# PR-T21-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2107a"></a>
## T21.07.a

Sanitizers and assertions are development evidence unless explicitly deployed. Neither substitutes for required public admission checks.

Expected relation: Both builds reject external invalid input with unchanged state; internal assertions may differ only under the declared policy.

Withheld transfer discriminator: Compile with sanitizers disabled and identify which checks still execute in production.

<a id="t2107b"></a>
## T21.07.b

Safe-state meaning depends on the real system and board. This local curriculum authoring neither changes host security nor authorizes hardware actuation.

Expected relation: Each policy has a precise observable effect and residual risk; simulated reset/recovery is labeled as a model.

Withheld transfer discriminator: Make the diagnostic sink fail during panic and provide a bounded nonrecursive fallback.

<a id="t2107c"></a>
## T21.07.c

The correct repair depends on the intended contract. Moving every diagnostic expression outside assert would violate a genuine no-evaluation instrumentation promise.

Expected relation: Required evaluation occurs exactly once in both repaired builds; invalid input cannot commit a state change.

Withheld transfer discriminator: Make the expensive expression optional instrumentation and require zero evaluation when disabled.

<a id="t2108a"></a>
## T21.08.a

A narrow timestamp needs an interval bound or era information. The record cannot recover chronology that the representation does not retain.

Expected relation: The declared byte encoding is independent of padding/endianness; storage and per-record work are bounded by the chosen model.

Withheld transfer discriminator: Change timestamp width and derive wrap/ordering limits without silently comparing modular values as total time.

<a id="t2108b"></a>
## T21.08.b

Rate accounting needs a declared clock and refill rule. Do not infer rate limits from a queue capacity or average benchmark.

Expected relation: Each loss/stall has the correct category and bounded behavior; zero-progress transport does not busy-loop indefinitely.

Withheld transfer discriminator: Use reject-newest for high-severity records and derive an explicit priority/admission policy.

<a id="t2108c"></a>
## T21.08.c

A bounded system may intentionally lose diagnostics. Honest loss accounting is stronger than an impossible promise of complete logs under all failures.

Expected relation: No recursive allocation/logging loop occurs; the primary cause survives and fallback saturation is defined.

Withheld transfer discriminator: Make the fallback storage unavailable and specify the last-resort observable policy without claiming lossless reporting.

<a id="t2109a"></a>
## T21.09.a

A shared implementation can serve both audiences only if the interfaces retain their different stability requirements.

Expected relation: The consumer-facing schema and lifetime remain stable; internal diagnostics have a separate contract and identity.

Withheld transfer discriminator: Expose diagnostics across a process boundary and add explicit serialization/capacity rules.

<a id="t2109b"></a>
## T21.09.b

Runtime selection can retain call/argument costs. Document which costs each switch promises to remove.

Expected relation: Each feature can be enabled alone; disabling one does not suppress the other's required diagnostics or alter functional behavior.

Withheld transfer discriminator: Add runtime severity selection within the integrator feature and distinguish compile-time absence from runtime filtering.

<a id="t2109c"></a>
## T21.09.c

Linker garbage collection and optimization are toolchain observations. A source-level no-evaluation promise needs a design that does not depend only on an optimizer choice.

Expected relation: The optional counter remains unchanged and trace-only storage is absent; correctness validation still rejects bad input.

Withheld transfer discriminator: Take the trace function's address in another translation unit and revisit dead-code elimination and interface costs.
