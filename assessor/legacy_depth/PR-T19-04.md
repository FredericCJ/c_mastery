# PR-T19-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1908a"></a>
## T19.08.a

The legacy helper treats zero according to its own F_IO policy. It must not be reused under a backpressure-zero contract without an explicit adapter and revised tests.

Expected relation: No accepted byte is resent; zero progress returns control; the final error retains the exact accepted prefix under the declared contract.

Withheld transfer discriminator: Allow an error accompanied by positive progress and redesign the result as status plus count.

<a id="t1908b"></a>
## T19.08.b

Counting only payload progress loses header/trailer bytes. A composition contract must define whether public counts mean payload bytes, wire bytes or accepted records.

Expected relation: Chunks are [3,1],[2],[3,6]; checksum is computed once for the logical payload; pending state reaches empty only after all five bytes.

Withheld transfer discriminator: Make the transport scatter/gather and derive partial progress across segment boundaries.

<a id="t1908c"></a>
## T19.08.c

Borrowing the original source while returning to the caller requires an explicit retention promise. Copying into owned staging changes cost and lifetime obligations.

Expected relation: Pending bytes remain stable until consumed or quiescent cancellation; capacity rejection transfers no new ownership.

Withheld transfer discriminator: Permit queueing two frames and derive admission, fairness and cancellation-by-identity rules.

<a id="t1909a"></a>
## T19.09.a

Finite identities need a bounded outstanding-token assumption or exhaustion policy. The model must state which one it uses.

Expected relation: Old handles never validate after reuse under the chosen retirement policy; allocation fails cleanly at exhausted slots.

Withheld transfer discriminator: Replace permanent retirement with a quiescent-reuse protocol and prove its additional assumptions.

<a id="t1909b"></a>
## T19.09.b

Weak promotion requires a live control block and synchronized protocol. A zero strong count may destroy the payload while weak metadata remains.

Expected relation: The cycle remains retained under ordinary strong counting; overflow is rejected without creating an uncounted owner.

Withheld transfer discriminator: Convert one edge to weak and define promotion while another thread may release the last strong reference.

<a id="t1909c"></a>
## T19.09.c

Atomic counting only orders operations according to its selected memory order and protocol. It does not grant arbitrary non-atomic payload writes a data-race exemption.

Expected relation: Ownership alone does not establish happens-before; the repair supplies a separate access protocol.

Withheld transfer discriminator: Publish an immutable snapshot and compare atomic reference management with payload synchronization needs.

<a id="t1910a"></a>
## T19.10.a

LTO may alter visibility and eliminate layers. Dynamic loading, interposition and separate compilation can invalidate that observation without changing source signatures.

Expected relation: Every claimed cost reduction is tied to observed code and an unchanged contract; absence of an indirect call in one build is not universal.

Withheld transfer discriminator: Load the backend from a separate shared object and revisit optimization visibility.

<a id="t1910b"></a>
## T19.10.b

Branch/cache counters are hardware/tool-specific. Synthetic counts explain a model but cannot substitute for measured cache effects or target latency.

Expected relation: Correctness outputs and validation are equivalent; direct counts reconcile with the representation ledger; variability is reported.

Withheld transfer discriminator: Make payload size dominate dispatch cost and revise which optimization is consequential.

<a id="t1910c"></a>
## T19.10.c

A valid choice may retain overhead for a useful contract boundary. Assessment rewards a justified decision with counterevidence, not a prescribed pattern.

Expected relation: The decision states its workload/maintenance assumptions and retains all public behavior/failure guarantees.

Withheld transfer discriminator: Add a third backend and reassess whether the simplified design still localizes changes.
