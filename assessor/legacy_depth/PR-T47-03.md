# PR-T47-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4703a"></a>
## T47.03.a

A new collation may merge formerly distinct keys and invalidate persisted separators. It is a format/semantic migration,not a comparator swap alone.

Expected relation: Shorter equal prefixes sort first; embedded zeros are data; equality follows the right-minimum convention.

Withheld transfer discriminator: Change collation to case-folded text under a new key-normalization contract.

<a id="t4703b"></a>
## T47.03.b

The current exclusive-caller design does not imply reentrant safety. Reentry can invalidate scratch/cache state and must not be assumed.

Expected relation: Ordered prefixes match the independent map; normal early stop is distinct from corruption; copied ownership is required for retained values.

Withheld transfer discriminator: Permit callback reentry only after deriving a new serialization/lifetime contract.

<a id="t4703c"></a>
## T47.03.c

A depth bound alone may miss duplicate ownership. The representation requires each allocated reachable node exactly once.

Expected relation: All three views agree on reachable nodes and ordered records; corrupt cycles terminate with rejection,not an unbounded walk.

Withheld transfer discriminator: Add a shared subtree and explain why a tree ownership invariant rejects it even without a cycle.
