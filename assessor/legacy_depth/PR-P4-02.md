## T29.09.b — Detect missed events, rollover, and torn multiword observations.

Counter consistency, event count and timestamp placement are separate properties. Half-range ordering is bounded; a coherent later observation still has an uncertainty interval. Sequence wrap must be distinguished from loss using the declared window.

Reject: A stable timestamp proves exact acquisition time and no lost samples.

Discriminator: require the first divergent state/ownership edge/output or assumption, not only a final checksum. ## T31.10.c — State the difference between detecting a fault and containing its consequences.

A timeout does not stop hardware access. Recovery requires DMA/IRQ quiescence, stale-event rejection and safe output state; reset loops can repeat the hazard. Host state models cannot establish bus/electrical quiescence.

Reject: Detecting a fault or rebooting automatically contains its consequences.

Discriminator: require the first divergent state/ownership edge/output or assumption, not only a final checksum.
