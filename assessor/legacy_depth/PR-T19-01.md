# PR-T19-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1901a"></a>
## T19.01.a

Test the scalar counter boundary independently from lifecycle rejection. A correct final value does not prove no invalid intermediate state was observable.

Expected relation: Increment is legal only when active and below15; stop behavior is explicit and never revives a stopped object implicitly.

Withheld transfer discriminator: Add a suspended state that retains resources but rejects work; derive resume and cancellation transitions.

<a id="t1901b"></a>
## T19.01.b

If registration can invoke inline callbacks, callback-visible state must be ready before registration. Otherwise prohibit callbacks until an explicit activation step.

Expected relation: Failed construction publishes no active session and releases only acquired resources; active work cannot call destruction twice.

Withheld transfer discriminator: Allow callbacks during construction and explain which initialization must move before registration.

<a id="t1901c"></a>
## T19.01.c

ISO C does not provide private ownership or automatic destruction. A malicious cast or undefined client operation is not made safe by an opaque declaration.

Expected relation: The opaque interface prevents ordinary field access through the public incomplete type; it cannot by itself prevent dangling handles or data races.

Withheld transfer discriminator: Require aggregate embedding and compare a typed caller-storage wrapper with a heap factory.

<a id="t1902a"></a>
## T19.02.a

Casting can silence diagnostics without making a call through an incompatible function type defined. The adapter performs actual argument/result conversion and owns its needed context.

Expected relation: Both conforming backends produce the same specified session transitions; the negative assignment is diagnosed under strict flags and never invoked.

Withheld transfer discriminator: Add a backend requiring extra context and use an adapter-owned record with an explicit lifetime.

<a id="t1902b"></a>
## T19.02.b

Const access through one pointer does not prove globally immutable storage if another alias can write it. Place the actual table in immutable storage under the chosen C contract.

Expected relation: One immutable table is reused; each session's context and lifetime remain independent; byte costs use measured sizeof/alignment.

Withheld transfer discriminator: Make one strategy configurable per instance and compare a table pointer with a copied per-instance table.

<a id="t1902c"></a>
## T19.02.c

A pointer to the wrong complete object cannot be made safe just by claiming a larger size. Use a genuine common prefix/byte descriptor protocol with specified object bounds.

Expected relation: Unsupported/short layouts reject without reading absent fields; optional flush returns a documented unsupported result.

Withheld transfer discriminator: Allow a larger future descriptor whose known prefix is compatible and define which unknown flags must reject.

<a id="t1903a"></a>
## T19.03.a

The C representation carries neither automatic capture lifetime nor language-enforced ownership. Copies of the record do not automatically duplicate ownership.

Expected relation: The callback/context pair determines behavior and each context survives the entire invocation/retention interval.

Withheld transfer discriminator: Allow a callback to transfer an owned context and add an exact release callback policy.

<a id="t1903b"></a>
## T19.03.b

Define whether pending removal suppresses later callbacks in the same snapshot. The initial fixture specifies only self-removal; it cannot decide every mutation policy implicitly.

Expected relation: The supplied self-removal trace holds; newly added callbacks wait for the next dispatch; recursive dispatch either rejects unchanged or follows a documented bounded protocol.

Withheld transfer discriminator: Replace snapshot semantics with immediate logical suppression of B and revise the expected trace and reclamation proof.

<a id="t1903c"></a>
## T19.03.c

If callbacks may free the dispatch object, all needed locals must be captured beforehand and the implementation cannot read registry state afterward. Alternatively make such freeing a caller violation and expose safe deferred destruction.

Expected relation: No active context is reclaimed early; each owned context releases once after its last permitted use; completion policy is explicit.

Withheld transfer discriminator: Allow a terminal receiver to free the registry storage and prove dispatch performs no later access to it.
