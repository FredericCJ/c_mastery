## T10.04.a — Trace TLS, stream state, initialization hooks, and runtime setup.

The inspected call chain establishes distinct initialization owners; a prefix reading cannot justify uninspected stream or TLS internals.

Reject superficial reasoning: Linking a libc function from custom entry guarantees its prerequisites have run.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Linking a libc function from custom entry guarantees its prerequisites have run.

Delayed assessor check: Retain thread-local errno in a custom-entry proposal and enumerate the additional implementation evidence required before execution.

## T10.05.a — Compare returning from main, exit, _Exit, and Linux exit syscalls.

Hosted normal exit and immediate termination have different cleanup obligations; observed bytes must be interpreted under explicit buffering and capture conditions.

Reject superficial reasoning: All termination paths flush streams and invoke handlers identically.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: All termination paths flush streams and invoke handlers identically.

Delayed assessor check: Use a multithreaded original process and distinguish raw thread exit from process-wide exit_group without altering other processes.

## T10.05.b — Account for flushing, registered handlers, and process/thread distinctions.

Separate handler execution, userspace buffering and kernel-accepted bytes; capture setup must not silently make the stream unbuffered.

Reject superficial reasoning: Observed missing output necessarily means write lost bytes rather than buffering or skipped cleanup.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Observed missing output necessarily means write lost bytes rather than buffering or skipped cleanup.

Delayed assessor check: Make a handler write through a raw local descriptor and explain what that observation proves independently of stdio cleanup.

## T10.05.c — Define behavior when a custom entry routine unexpectedly returns.

The bridge owns termination and cannot return through argc as an address; a successful helper return must be translated into explicit termination.

Reject superficial reasoning: Returning from custom entry is equivalent to returning from main.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Returning from custom entry is equivalent to returning from main.

Delayed assessor check: Add a failure before argument decoding and preserve a deterministic non-returning error path without libc.
