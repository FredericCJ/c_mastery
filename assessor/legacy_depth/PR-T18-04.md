# PR-T18-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1808a"></a>
## T18.08.a

Allocation freedom, bounded execution and interrupt safety are separate properties. Hosted measurements cannot certify target ISR latency or atomic access requirements.

Expected relation: The original transitive allocation claim fails; repaired claims remain bounded by every reachable callee and target helper audit.

Withheld transfer discriminator: Compile the same core for a freestanding target and inspect object relocations, stack use and implicit helper dependencies.

<a id="t1808b"></a>
## T18.08.b

Publish every callback-visible field before submission. An API that may complete inline must not rely on initialization performed after submit returns.

Expected relation: The synchronous consumer may release context after return; the deferred consumer must wait for terminal quiescence under its contract.

Withheld transfer discriminator: Permit inline completion in an otherwise asynchronous adapter and make initialization safe before either completion path.

<a id="t1808c"></a>
## T18.08.c

A valid terminal state prevents duplicate logical completion; reclaiming callback storage also requires the external producer to be quiescent.

Expected relation: One terminal report and one release occur; late/duplicate notifications are rejected while live state can still validate them.

Withheld transfer discriminator: Make cancellation fail because an irreversible effect has already committed and expose an indeterminate result instead of claiming rollback.

<a id="t1810a"></a>
## T18.10.a

Version numbers communicate policy only when paired with conformance checks and documented migration. ABI sameness cannot establish behavioral substitutability.

Expected relation: The timing/ownership revision is incompatible even if it links; the old entry point preserves its documented synchronous borrow semantics.

Withheld transfer discriminator: Keep timing but change failure-output initialization and determine which old consumers break.

<a id="t1810b"></a>
## T18.10.b

A separate directory alone is insufficient if environment variables or exported targets point into the developer tree. Pin the installed package identity used for the run.

Expected relation: No original source/build path is required; documented old behavior still holds under the supported new implementation.

Withheld transfer discriminator: Relocate the install prefix and repeat without rebuilding the consumer's source assumptions.

<a id="t1810c"></a>
## T18.10.c

The migration is itself code subject to failure and lifetime contracts. Do not label all source-compatible edits safe; delayed behavior may invalidate previously legal stack contexts.

Expected relation: Every migration path retains exactly one release obligation and leaves old callers supported or explicitly rejected at a version boundary.

Withheld transfer discriminator: Introduce a consumer that caches borrowed views across mutation and redesign migration around stable handles or copying.
