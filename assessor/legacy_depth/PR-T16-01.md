# PR-T16-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1601a"></a>

## T16.01.a

A callback promise cannot be verified by casting an arbitrary returned pointer. Caller/provider obligations and inspected backend guarantees remain separate.

Withheld discriminator: Replace the backend with one supporting only fundamental alignment and reject over-aligned requests. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1601b"></a>

## T16.01.b

The local policy avoids relying on disputed/changed zero-size semantics. A standards comparison must keep selected edition and pointer-null conditions exact.

Withheld discriminator: Compare N1570,N3096 realloc wording and exact C17 access gap without relabeling drafts. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1601c"></a>

## T16.01.c

Acquisition reserves storage,not initialized application invariants. C object semantics and OS address availability are distinct layers.

Withheld discriminator: Use a platform mapping/firmware address as backing and require an explicit implementation contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.02.a

Offset divisibility implies address alignment only when the base alignment contract supports it. Pointer arithmetic follows successful extent proof.

Withheld discriminator: The backing base is not aligned to8; derive base-offset correction or reject that precondition. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1602b"></a>

## T16.02.b

There is no unique charge without a declared layout policy. Acceptance requires internally consistent arithmetic and independently reconstructed extents.

Withheld discriminator: Minimum block size rises to16; recalculate absorbed tail versus reusable remainder. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1602c"></a>

## T16.02.c

In-band typed casts into declared bytes need a separate valid storage model. Byte encoding avoids that assumption but adds decoding checks.

Withheld discriminator: Use wider offsets on another data model and derive changed minimum size/capacity. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.03.a

Policy and backing legality are separate. The target allocation loop remains local even if the harness supplies storage through an allowed callback.

Withheld discriminator: Use real allocated backing for a typed adapter while preserving the same offset policy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1603b"></a>

## T16.03.b

Finite generation reuse can revive old tokens. A control-object lifetime precondition remains necessary even with owner tags.

Withheld discriminator: Generation reaches its maximum; retire the owner or use an explicit quiescent reinitialization protocol. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1603c"></a>

## T16.03.c

Counters answer different questions. Including failed requests in live storage or summing nonoverlapping peaks produces a false budget.

Withheld discriminator: Maintain lifetime-cumulative and per-epoch peaks simultaneously. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
