# PR-T12-05 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1212a"></a>

## T12.12.a

A comparator must define the ordering needed by the algorithm. NaN requires an explicit bucket/order policy; signed overflow in subtraction invalidates the comparator before algorithm behavior can be assessed.

Withheld discriminator: Sort records by a floating key containing NaN; define a total policy and prove consistency rather than assume ordinary less-than suffices. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.12.b

The implementation falls back to heapsort on allocation failure. Internal successful merge behavior does not grant a public stable-sort contract, and transitive allocator effects need their own audit.

Withheld discriminator: Change the allocation policy to fail every heap request and predict which observable public properties must remain unchanged. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.12.c

Withheld discriminator: An adversary can observe generator outputs; replace the simulation requirement with an explicitly sourced security randomness contract without implementing production crypto from rand. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
