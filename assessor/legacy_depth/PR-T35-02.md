# PR-T35-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t3505a"></a>

## T35.05.a

Path resolution includes every component. A descriptor stabilizes an opened object,not all future pathname operations.

Withheld discriminator: An intermediate directory can change; final-component flags alone no longer suffice. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t3505b"></a>

## T35.05.b

Descriptor creation and inheritance need one atomic policy transition. A child process is not automatically least-privileged.

Withheld discriminator: Concurrent thread forks between open and fcntl; reproduce as a logical schedule and use atomic creation flags. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t3505c"></a>

## T35.05.c

An explicit argv removes shell parsing but does not authorize arbitrary child options. Validate the callee semantic contract too.

Withheld discriminator: The child interprets its own option syntax; distinguish argument injection from shell interpretation. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T35.08.a

Access mode binds that descriptor. The same user may obtain another descriptor with broader authority unless an additional mechanism prevents it.

Withheld discriminator: Worker reopens its own writable path and show why the original narrow guarantee is unchanged. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t3508b"></a>

## T35.08.b

Least privilege requires enforcement at each boundary. A dispatch table is policy for cooperating code,not a kernel sandbox.

Withheld discriminator: Remove read-log permission and ensure denial precedes reads as well as writes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T35.08.c

Language abstraction and protection domain are different mechanisms; the hardware design requires exact target documentation and execution evidence.

Withheld discriminator: Use an MPU with verified regions and include privileged-code and DMA limitations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
