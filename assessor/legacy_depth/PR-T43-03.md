# PR-T43-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4304a"></a>
## T43.04.a

An instruction count is still independent of microarchitectural overlap, stalls and speculation; model CPI weights are assumptions, not measured properties.

Expected relation: The trace reaches the required first matching index; the mix includes repeated and untaken paths correctly and is tied to its binary.

Withheld transfer discriminator: Change branch direction without changing final index and compare mix and prediction.

<a id="t4304b"></a>
## T43.04.b

Amdahl assumptions include fixed work and additive nonoverlapping phases. Overlap changes the composition equation and can make a local improvement invisible.

Expected relation: Without added overhead the bound is1.25; with0.1 original-time overhead it is1/0.9. Actual residuals remain observations, not corrections chosen to fit the model.

Withheld transfer discriminator: Overlap the improved phase with an unchanged phase and rederive the critical path.

<a id="t4304c"></a>
## T43.04.c

A basis of graph paths is a test-design aid. Predicate correlations can make paths infeasible, and optimization can change the graph representation.

Expected relation: Both metrics use an explicit entry/exit convention; equal values coexist with linear versus quadratic body counts, and no infeasible path is claimed executed.

Withheld transfer discriminator: Add an early exit that changes feasible paths while keeping the graph metric unchanged.

<a id="t4314a"></a>
## T43.14.a

An observation is useful when it can distinguish acceptance. More counters do not compensate for a missing binding constraint.

Expected relation: Each selected measure has units, scope and a decision threshold; omitted energy or unavailable events are not fabricated.

Withheld transfer discriminator: Add a hard stack bound and determine which prior evidence no longer suffices.

<a id="t4314b"></a>
## T43.14.b

A variant that drops error handling or weakens durability is not an equivalent performance alternative. Changed requirements require a new decision, not a retroactive benchmark claim.

Expected relation: B fails the original code/storage constraints; a tradeoff decision cites the requirement and may retain baseline or be inconclusive.

Withheld transfer discriminator: Require a stricter tail deadline while allowing more retained memory.

<a id="t4314c"></a>
## T43.14.c

Reproducibility and independent assessment are separate from author execution. A delayed unseen task is needed to assess transfer rather than familiarity.

Expected relation: Every conclusion resolves to its exact artifact and scope; stale/missing observations remain open, and finite tests do not certify absolute mastery.

Withheld transfer discriminator: Ask a second reader to reproduce one changed-condition decision without author explanations.
