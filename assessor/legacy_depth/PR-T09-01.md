# PR-T09-01 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0901a"></a>
## T09.01.a — Parse headers, section tables, program headers, and symbol tables.

Every table extent must be checked against file length before decoding; unaligned casts and host layout assumptions are unnecessary. Unsupported extended counts must reject explicitly or be implemented correctly.

Reject superficial reasoning: A valid magic number makes subsequent file offsets trustworthy.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A valid magic number makes subsequent file offsets trustworthy.

Delayed assessor check: Add ELF32 or big-endian decoding while retaining the same checked byte-reader contract.

<a id="t0901b"></a>
## T09.01.b — Distinguish link-editor organization from loader-visible mappings.

The declared segment contributes0x30 file-backed bytes and0x20 zero-filled bytes; sections and segments answer different questions. Filesz greater than memsz must reject.

Reject superficial reasoning: The section table alone specifies what the loader maps.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The section table alone specifies what the loader maps.

Delayed assessor check: Remove the section table from an otherwise supported original executable and explain which loader facts remain available.

<a id="t0901c"></a>
## T09.01.c — Inspect relocatable objects, executables, and shared objects.

File extension is not authoritative; object type and metadata establish stage-specific meaning. ET_REL addresses cannot simply be treated as process addresses.

Reject superficial reasoning: All files named .o or .so have identical loading responsibilities.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: All files named .o or .so have identical loading responsibilities.

Delayed assessor check: Add static PIE and explain why ET_DYN alone does not distinguish every executable from every shared library.

## T09.02.a — Explain local, global, weak, undefined, and common symbols.

Local names can coexist; weak/common are object/tool rules, while source declarations retain C constraints. Modern defaults must be recorded rather than assumed.

Reject superficial reasoning: Identical symbol spelling implies one entity and common is a C storage class.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Identical symbol spelling implies one entity and common is a C storage class.

Delayed assessor check: Change tentative definitions to explicit initialized definitions and predict which formerly merged cases become conflicts.

<a id="t0902b"></a>
## T09.02.b — Trace symbol resolution across objects and archives.

Input order, extraction and binding rules explain the selected definition; a trace must identify the supplying object rather than only the final value.

Reject superficial reasoning: The linker searches all possible definitions symmetrically and chooses arbitrarily.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The linker searches all possible definitions symmetrically and chooses arbitrarily.

Delayed assessor check: Put the competing definition in an unextracted archive member and redo the trace.

## T09.02.c — Diagnose duplicate definitions and accidentally exported internals.

The repair gives each internal helper the intended scope; dynamic visibility and C internal linkage are related but distinct controls.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Suppressing duplicate-definition errors repairs conflicting ownership.

## T09.03.a — Build and inspect archive indexes and members.

The archive groups relocatable members and an index; it does not resolve all internal references or establish final inclusion.

Reject superficial reasoning: A static archive is already a fully linked executable component.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A static archive is already a fully linked executable component.

Delayed assessor check: Rebuild the archive after removing a stale member and prove the old object cannot remain silently selected.

## T09.03.b — Explain demand-driven extraction and link-order sensitivity.

Demand-driven extraction explains the successful and unresolved cases under the declared linker; a missing compiler is not the intended order failure.

Reject superficial reasoning: Archive ordering is cosmetic.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Archive ordering is cosmetic.

## T09.03.c — Use grouping or whole-archive behavior only with explicit justification.

Forcing all members can add initialization, code and conflicts; justify the smallest retention/extraction policy and separate section GC from member extraction.

Reject superficial reasoning: Whole-archive is a harmless universal fix for missing symbols.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Whole-archive is a harmless universal fix for missing symbols.

Delayed assessor check: Add a conflicting unused definition and diagnose why whole-archive newly fails while targeted extraction succeeds.
