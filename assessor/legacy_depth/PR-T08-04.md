# PR-T08-04 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0808a"></a>
## T08.08.a — Specify input, output, tied, and early-clobber operands.

The constraint interface must state every dependency; input-only modification is invalid. A successful one-register allocation is not a proof of a missing constraint.

Reject superficial reasoning: Compiler parsing of assembly text discovers all data dependencies.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Compiler parsing of assembly text discovers all data dependencies.

Delayed assessor check: Inline the block in a loop with equal-valued input expressions and explain how register coalescing exposes an omitted early-clobber.

<a id="t0808b"></a>
## T08.08.b — Explain register and memory clobbers and their limits.

Volatile addresses deletion/motion rules only within its documented limits; memory effects and condition-code/register changes need explicit declarations.

Reject superficial reasoning: volatile or memory clobber describes every effect and establishes thread synchronization.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: volatile or memory clobber describes every effect and establishes thread synchronization.

Delayed assessor check: Replace a broad memory clobber with precise operands and state the performance opportunity and new proof obligation.

<a id="t0808c"></a>
## T08.08.c — Compare compiler barriers with actual processor-ordering instructions.

No hardware fence follows from an empty template; neither an undocumented fence nor a clobber alone repairs a C data race.

Reject superficial reasoning: An empty compiler barrier emits a hardware fence or makes ordinary shared accesses race-free.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: An empty compiler barrier emits a hardware fence or makes ordinary shared accesses race-free.

Delayed assessor check: Port the argument to a weaker-memory ISA using its actual fence documentation before claiming equivalent behavior.

<a id="t0809a"></a>
## T08.09.a — Distinguish ordinary calls, traps, interrupts, and exceptions.

Call return state, kernel transition state and asynchronous exception state have different owners; ISO C does not define an interrupt frame.

Reject superficial reasoning: Every control transfer has a normal C caller frame.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every control transfer has a normal C caller frame.

Delayed assessor check: Analyze a signal handler delivery as an OS-mediated user transition and distinguish it from the raw interrupt mechanism.

<a id="t0809b"></a>
## T08.09.b — Identify privilege restrictions on system instructions.

Instruction availability and privilege authorization differ; a fault would not prove a safe privilege transition or escalation.

Reject superficial reasoning: Visible instruction bytes imply permission to execute them on the host.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Visible instruction bytes imply permission to execute them on the host.

Delayed assessor check: Move the privileged experiment specification into a disposable teaching VM and identify the additional environment prerequisites without running it here.

<a id="t0809c"></a>
## T08.09.c — Separate architectural exception state from language-level control flow.

Restoring PC alone omits stack, privilege, status and language lifetime obligations; no C portability claim follows from a machine-state diagram.

Reject superficial reasoning: Architectural exception return is equivalent to returning from a C function.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Architectural exception return is equivalent to returning from a C function.

Delayed assessor check: Compare a cooperative coroutine suspension with a preemptive interrupt and identify the additional state and reentrancy obligations.
