# PR-T47-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4701a"></a>
## T47.01.a

The disk format and in-memory node representation have separate contracts. CRC checks corruption under its model but is not authentication.

Expected relation: The4096octet image matches explicit fields; unused slots are zero by format; alignment of the source span does not affect byte decoding.

Withheld transfer discriminator: Change format version and define migration versus rejection rather than reinterpret old bytes.

<a id="t4701b"></a>
## T47.01.b

Resealing deliberately invalid metadata distinguishes semantic validation from checksum-only rejection without targeting any external file format.

Expected relation: Each structurally invalid but checksummed page rejects before access/publication; exact maximum extents succeed.

Withheld transfer discriminator: Add overlapping logical fields in a future variable-offset format.

<a id="t4701c"></a>
## T47.01.c

The atomic transaction proof does not automatically cover first-time formatting. Recovery must retain evidence needed to diagnose corruption.

Expected relation: Reopen reports failure or the explicitly valid older generation; no established image is silently erased or replaced.

Withheld transfer discriminator: Interrupt initial formatting and specify a separate disposable-image retry protocol.
