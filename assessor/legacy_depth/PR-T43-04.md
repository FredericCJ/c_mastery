# PR-T43-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4305a"></a>
## T43.05.a

A local ownership transfer changes attribution without creating or destroying storage. Deterministic same-time event semantics are necessary for a reproducible ledger.

Expected relation: Half-open intervals avoid overlap at the shared endpoint; each owned allocation is counted once; category maxima retain their own timestamps.

Withheld transfer discriminator: Transfer an owner between components at the same timestamp and preserve global accounting.

<a id="t4305b"></a>
## T43.05.b

Inlining and tail calls alter simultaneous frames. ABI stack alignment, callbacks and interrupt nesting must be included or explicitly unresolved.

Expected relation: Known paths have conditional sums; unknown/dynamic-unbounded paths cannot be given a finite certified maximum. Compiler/build identities stay attached to records.

Withheld transfer discriminator: Enable LTO and rebuild the call graph before combining frame data.

<a id="t4305c"></a>
## T43.05.c

Reducing one category can increase another. A useful decision names which limit is binding rather than collapsing all bytes into one incomparable total.

Expected relation: Each quantity has its own scope and units; retained allocator pages can explain the discrepancy without proving a leak.

Withheld transfer discriminator: Move scratch from heap to a bounded stack frame and reassess the requirement.
