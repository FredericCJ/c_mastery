# PR-T16-05 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1609a"></a>

## T16.09.a

A class policy rounds sizes; a lifetime policy affects reclamation. Their interaction needs measured/derived evidence rather than assuming uniform objects.

Withheld discriminator: Group by both size and lifetime so long-lived objects do not pin every short-lived slab. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1609b"></a>

## T16.09.b

A nonmoving allocator cannot reclaim a partially occupied slab by wishful accounting. Movement requires an ownership/reference protocol.

Withheld discriminator: Consolidation would move live objects; state handle/borrow constraints before proposing compaction. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1609c"></a>

## T16.09.c

Storage reuse and semantic reuse differ. A valid optimization separates persistent cache state from newly owned application invariants.

Withheld discriminator: Cache an expensive initialized shared resource separately from per-request state and define reset boundaries. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
