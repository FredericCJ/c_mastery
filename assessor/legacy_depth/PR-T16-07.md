# PR-T16-07 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1611a"></a>

## T16.11.a

Raw copying is only valid for admitted payload semantics. Shrink cannot leave a fragment too small for its own metadata.

Withheld discriminator: Payload has self-pointers; choose relocation callbacks or explicitly exclude raw byte migration. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1611b"></a>

## T16.11.b

The allocator-byte copy can be no-fail under admitted bounds,but generalized object migration needs a separate failure model.

Withheld discriminator: Copy itself can fail through a callback; stage/rollback and define partial resource cleanup. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1611c"></a>

## T16.11.c

The new object can reuse an address without preserving the old identity. Failure preserves the old object,whereas success follows the API lifetime contract.

Withheld discriminator: Use stable handles with an updated indirection table and state lookup/owner lifetime costs. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
