## T15.01.a

The two bounds differ at equality. Sortedness under the same comparator is a precondition,not something binary search establishes.

Withheld discriminator: Use a descending comparator and derive changed bound definitions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.01.b

lo+(hi-lo)/2 is valid only under0<=lo<=hi<=length. A correct midpoint does not repair wrong equality updates.

Withheld discriminator: Search a logical array too large for lo+hi but with representable length; analyze midpoint arithmetic. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.01.c

Partition correctness does not require a specific permutation unless stability is promised. The stable variant adds memory and failure obligations.

Withheld discriminator: Require stable partition using caller scratch and define insufficient-workspace failure. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.02.a

## T15.02.b

Withheld discriminator: Provide scratch one element short; reject before mutation or state a separately verified alternative. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.02.c
