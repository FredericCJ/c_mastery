# PR-T12-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1201a"></a>

## T12.01.a

The standard library is a collection of facilities across headers. Compilation verifies the selected implementation only; header ownership and freestanding guarantees require an edition-specific source argument.

Withheld discriminator: Replace the hosted implementation with a strict freestanding profile and identify which declarations and linked implementations remain required or supplied. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1201b"></a>

## T12.01.b

Assess source discipline, not guessed cells. The supplied draft/library passages do not establish every requested edition cell; an explicit verified gap is better than false normative attribution.

Withheld discriminator: An implementation provides threads.h as an extension in an older mode but advertises no C11 threads: revise the evidence matrix and fallback contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1201c"></a>

## T12.01.c

snprintf and aligned_alloc have ISO contracts; getline/strtok_r require a separate POSIX claim; memcpy_s belongs to optional bounds-checking facilities. Do not accept feature-test macros as proof of behavior or hardware support.

Withheld discriminator: Port the parser to a hosted implementation without Annex K and to a freestanding target with no FILE layer. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1202a"></a>

## T12.02.a

PRI macros cover the corresponding integer typedefs, whereas %zu and %td cover size_t and ptrdiff_t. Data-model observations must be kept separate from portable requirements.

Withheld discriminator: Move from LP64 to LLP64 or a synthetic 16-bit-int target and explain which format assumptions fail. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1202b"></a>

## T12.02.b

A variadic type mismatch is not repaired by the fact that values fit. The parser range-check must use the destination limit before narrowing, with signs and trailing characters independently validated.

Withheld discriminator: Use an implementation where uint32_t is unsigned long, then where uintmax_t is wider than size_t. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1202c"></a>

## T12.02.c

Macros and compiler-provided declarations can require no linked implementation; selected operations may lower to external calls. Inspect the actual artifact at each stage without generalizing from an optimized-away call.

Withheld discriminator: Enable LTO or optimization so one library call disappears and explain why that does not establish general freestanding availability. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1209a"></a>

## T12.09.a

The format tells the callee how to retrieve arguments, not how to repair their passed types. A diagnostic-free build is not proof that dynamically selected formats match.

Withheld discriminator: Receive a runtime format string from a configuration file; replace unrestricted formatting with a typed format policy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1209b"></a>

## T12.09.b

The width eight/precision three example requires eight visible bytes with padding. Dynamic width/precision have different negative rules; the learner must source these, and avoid cutting an interchange encoding unless permitted.

Withheld discriminator: Use multibyte input and distinguish a byte precision boundary from a Unicode scalar boundary. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1209c"></a>

## T12.09.c

A successful sizing pass does not make a later call infallible if locale/state or input can change. Define stable inputs and failure behavior; stage output when transactional semantics require it.

Withheld discriminator: Change the contract to transactional output on failure and include a formatter whose required-size query itself can fail. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
