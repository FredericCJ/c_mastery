# PR-T12-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1207a"></a>

## T12.07.a

calloc initializes representation bytes to zero. Object value initialization can require typed assignment; alignment and size-multiple requirements must be sourced for the selected edition/implementation.

Withheld discriminator: Allocate an over-aligned concrete type and separate ISO supported-alignment requirements from allocator extensions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1207b"></a>

## T12.07.b

Do not extrapolate the C11 wording into C17 or C23. The separate release operation removes a disputed interface case while the edition comparison remains an explicit research obligation.

Withheld discriminator: A third-party callback returns null for a zero-size request without freeing the old object; prove the adapter still has a defined ownership path. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1207c"></a>

## T12.07.c

Do not evaluate the old pointer after successful realloc merely to compare addresses. Preserve bytes and ownership, not stale-pointer observability; the callback variant requires staging before release.

Withheld discriminator: Replace realloc with allocate-copy-free callbacks whose copy can fail; design an explicit rollback or no-fail-copy precondition. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.08.a

strtol provides end-pointer and range information but does not enforce the whole application grammar. atoi lacks sufficient error reporting for this contract.

Withheld discriminator: Accept a leading plus sign but reject leading/trailing whitespace; derive grammar checks independent of strtol permissiveness. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1208b"></a>

## T12.08.b

Unsigned strto can accept a minus sign and negate in the unsigned return type. Grammar checks must precede or accompany conversion; errno is meaningful only under the documented error contract.

Withheld discriminator: Change the grammar to explicitly allow prefixes and compare base-zero interpretation under the selected edition. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1208c"></a>

## T12.08.c

Do not claim a decimal spelling is exact binary floating arithmetic. The grammar filter and numerical conversion/error contract are independent obligations; uninspected strtod details remain a source gap.

Withheld discriminator: Require a canonical wire float grammar that rejects infinity, NaN and hexadecimal forms; design a validation layer before conversion. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.10.a

scanf width is not a universal storage bound across conversion classes. In N1570 an unrepresentable converted result has undefined behavior, so the safe numeric parser uses a different mechanism.

Withheld discriminator: Accept a token of arbitrary bounded length via explicit tokenization, then apply strto range checks. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1210b"></a>

## T12.10.b

Assignment counts do not certify trailing literal matches or full consumption. Staging a record until all grammar checks pass gives a coherent failure contract.

Withheld discriminator: Permit an escaped delimiter inside the name and derive the state machine before adjusting the parser. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1210c"></a>

## T12.10.c

A loop that retries after matching failure without consuming the bad character cannot progress. EOF indication is retrospective, and recovery needs a well-founded progress measure.

Withheld discriminator: Recover to the next newline after a malformed record and prove every retry consumes input or terminates. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
