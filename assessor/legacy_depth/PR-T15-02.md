# PR-T15-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1503a"></a>

## T15.03.a

A pivot value changing during swaps corrupts the invariant even when comparison code is correct.

Withheld discriminator: The pivot aliases a moved array element; preserve its value or use a safe index strategy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1503b"></a>

## T15.03.b

Stack and work bounds are independent. Each recursive smaller side is at most half the preceding range,but iterated bad partitions still cost.

Withheld discriminator: Use an explicit work stack and prove required capacity rather than choosing an arbitrary constant. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1503c"></a>

## T15.03.c

A fallback present but unreachable in tests is not evidence. The depth policy must depend on admitted range size without logarithm/overflow mistakes.

Withheld discriminator: An expensive comparator changes the model; derive comparisons rather than only elapsed time. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T15.05.a

## T15.05.b

## T15.05.c

Withheld discriminator: Design a median-of-medians variant and identify grouping/recurrence obligations without claiming it already implemented. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
