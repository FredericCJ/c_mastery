# PR-T04-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0401a"></a>

## T04.01.a

Padding and signed representation affect range; use limits rather than sizeof-times-eight as the proof.

Withheld discriminator: Move to a target with16-bit int and explain literal/type changes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0401b"></a>

## T04.01.b

Object sizes do not imply representable pointer differences; uint32_t is an optional exact-width contract and not an automatic size type.

Withheld discriminator: Represent a logical file offset larger than PTRDIFF_MAX while keeping actual pointer operations local. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0401c"></a>

## T04.01.c

Do not silently truncate sizeof-based counts. An octet model can use values0..255 in wider storage, but external transport needs its own conversion contract.

Withheld discriminator: Allow CHAR_BIT==16 and account for size, stream I/O units and byte-order terminology. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0402a"></a>

## T04.02.a

The result type comes from integer promotions, not the operand declaration. Complement output depends on the promoted representation; document it rather than assume8 bits.

Withheld discriminator: Replace unsigned char with a bit-field or an unsigned short that cannot fit int. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0402b"></a>

## T04.02.b

Rank and representability determine the common type. A blanket rule that unsigned always wins is false.

Withheld discriminator: Use a wider signed type that can represent the unsigned operand and recompute usual conversions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0402c"></a>

## T04.02.c

A case must be representable in the source before it tests conversion. Comparing in an inadequately narrow intermediate invalidates the guard.

Withheld discriminator: Change destination to a narrower count type and compose prefix+count*width admission. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0403a"></a>

## T04.03.a

The oracle range, actual arithmetic type and application policy are three distinct layers.

Withheld discriminator: Use saturating rather than rejecting application semantics and derive changed postconditions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0403b"></a>

## T04.03.b

Never negate the minimum to form a magnitude without a proof; division bounds need separate signs and zero cases. B01 extent is reused for the size boundary.

Withheld discriminator: Remove the availability of a wider integer type and derive checks using division/sign partitions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0403c"></a>

## T04.03.c

The inspected builtin computes mathematically then stores a conversion even when its flag reports overflow. Directly passing caller output breaks the wrapper contract.

Withheld discriminator: Change the destination type while keeping operand types and explain infinite-precision extension semantics. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0404a"></a>

## T04.04.a

Truncation toward zero makes nonzero remainder follow the dividend. Do not assume an uninspected old edition has identical rules.

Withheld discriminator: Compare an explicitly inspected older-edition rule; otherwise record the unavailable comparison. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0404b"></a>

## T04.04.b

The division rule conditions both quotient and remainder on quotient representability. A host wider than the synthetic range does not remove the application rejection.

Withheld discriminator: Use a symmetric synthetic signed range and explain why its mathematical edge differs from the actual host type. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0404c"></a>

## T04.04.c

Add m only when the truncating remainder is negative; prove the addition fits because -m<r<0 and m is positive representable.

Withheld discriminator: Allow a negative modulus and explicitly select Euclidean versus divisor-signed convention. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
