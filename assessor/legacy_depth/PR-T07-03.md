# PR-T07-03 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0706a"></a>
## T07.06.a — Distinguish sources, usage requirements, and transitive link requirements.

A static archive can leave unresolved Support calls; propagation of compile requirements and link closure are separate questions. The public layout requirement must reach consumers.

Reject superficial reasoning: A private implementation dependency never affects a final static link.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A private implementation dependency never affects a final static link.

Delayed assessor check: Change Support from static to shared and compare the consumer's link line and runtime dependency closure.

<a id="t0706b"></a>
## T07.06.b — Apply PRIVATE, PUBLIC, and INTERFACE at correct boundaries.

Consumers receive required public definitions without private include leakage; inappropriate exposure must be demonstrated by an independent consumer failure or collision.

Reject superficial reasoning: Global include directories are equivalent to target-local usage requirements.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Global include directories are equivalent to target-local usage requirements.

Delayed assessor check: Move a formerly private type into the public API and update precisely the requirements that now cross the boundary.

<a id="t0706c"></a>
## T07.06.c — Export and consume a library without leaking build-tree assumptions.

The consumer resolves exported targets and dependencies solely from the declared installed prefix; a build-tree export is not accepted as the relocated package.

Reject superficial reasoning: Installing an archive and headers alone supplies a relocatable CMake package.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Installing an archive and headers alone supplies a relocatable CMake package.

Delayed assessor check: Make the dependency independently installed under a second relocated prefix and use explicit dependency discovery.

## T07.08.a — Inspect incremental-build decisions and dependency graphs.

The recorded command is an input; depfiles identify headers discovered during compilation. Missing edges cannot be fixed merely by adding more parallel jobs.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Only file timestamps can invalidate a Ninja build.

Delayed assessor check: Use the same header through two differently spelled paths and diagnose duplicate node identity assumptions.

## T07.08.b — Generate compilation databases for analysis and editor tooling.

A source may have multiple valid compilation entries; selection needs configuration/output identity. The database does not provide linking or source generation.

Reject superficial reasoning: There is exactly one build command per source path.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: There is exactly one build command per source path.

Delayed assessor check: Represent a compiler argument containing a space and prove argv-based replay preserves it as one argument.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The compilation database is a complete project reproduction recipe.
