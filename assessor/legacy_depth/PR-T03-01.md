# PR-T03-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0301a"></a>

## T03.01.a

Thread storage lasts for its thread, not the receiver. Cross-thread access is implementation-defined in the inspected draft and also needs synchronization and liveness; a numeric address alone proves neither.

Withheld discriminator: Pass a thread-local pointer to another thread under a documented implementation contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0301b"></a>

## T03.01.b

The old pointer value becomes indeterminate when lifetime ends. A saved integer observation can describe address reuse but cannot restore the former object or authority.

Withheld discriminator: Record a numeric address before relocation and compare the new allocation address afterward without using an indeterminate old pointer. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0301c"></a>

## T03.01.c

By-value aggregate return does not extend a separately referenced local object. Copy the data or supply a longer-lived owner rather than copy only the pointer.

Withheld discriminator: Return an aggregate containing a pointer and show when a deep copy is required. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0302a"></a>

## T03.02.a

Character access is the permitted inspection route, but observed bytes are not a portable wire format. Member order/alignment can change padding without changing the abstract field values.

Withheld discriminator: Reorder members and compare padding/code interface effects without assuming a packed layout. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0302b"></a>

## T03.02.b

Do not replace unavailable exact C17 text with a silently relabeled C11 or C23 draft. Invalid representations and optional floating behavior require declared assumptions; a byte dump is not normative evidence.

Withheld discriminator: Change the data model or target representation and identify serialized fields that need explicit encoding. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0302c"></a>

## T03.02.c

Padding can distinguish equal record values. Floating zero signs can differ while comparing equal; NaN equality needs an explicit application policy. A canonical encoding is a designed abstraction, not automatic C layout.

Withheld discriminator: Design a canonical byte encoding for semantic equality and decide a NaN/zero normalization policy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0303a"></a>

## T03.03.a

The offset modulus is only meaningful relative to an appropriately aligned base. sizeof(T) and array construction preserve alignment for actual T arrays; arbitrary byte offsets do not.

Withheld discriminator: Use a caller slice beginning at a nonzero offset and recompute usable capacity/alignment. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0303b"></a>

## T03.03.b

The inspected pointer-conversion rule can make a misaligned conversion undefined. Hardware tolerance does not erase the source-language obligation.

Withheld discriminator: Separate a hardware ISA supporting unaligned loads from the C lvalue alignment contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0303c"></a>

## T03.03.c

uintptr_t is optional and its round-trip guarantee does not promise a linear numeric address encoding. A truthful callback may guarantee requested alignment; a component cannot portably authenticate an arbitrary pointer.

Withheld discriminator: Add an over-aligned type and determine whether max_align_t storage suffices. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
