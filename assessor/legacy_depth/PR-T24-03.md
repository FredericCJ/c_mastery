Assessor only. Authored technical arguments do not assert a learner attempt, independent human review or fresh execution of the complete project. The original implementation contract remains binding.

## T24.05.a — Separate byte-stream transport from application messages.

Stream chunking has no message boundary contract; parser state spans header/body boundaries and must consume each byte once.

Reject: One send call produces one receive call.

Evidence discriminator: locate the first task-specific state, return value, ownership transition or artifact that would differ under the rejected explanation. Require that observation or a complete finite derivation; reject a generic checksum, sanitizer absence or source heading as a substitute.

Delayed assessor check: Change the header to a two-byte big-endian length and derive partial-header state and overflow checks anew.

## T24.05.b — Implement framing, partial transfer, half-close, and reconnect policy.

Half-close affects one direction; truncated application frames fail separately. Reconnect creates a new transport session and does not resolve uncertain old effects.

Reject: Receiving EOF invalidates both directions or safely resumes the old parser on reconnect.

Evidence discriminator: locate the first task-specific state, return value, ownership transition or artifact that would differ under the rejected explanation. Require that observation or a complete finite derivation; reject a generic checksum, sanitizer absence or source heading as a substitute.

Delayed assessor check: Add request identities and recover a lost reply without blindly executing the operation twice.

## T24.05.c — Bound queued data and stalled-peer resource use.

Total retained memory includes connection count, queue count, metadata and partially sent frames; each limit needs a rejection or suspension policy.

## T24.06.a — Preserve message boundaries and handle truncation explicitly.

Datagram boundaries and truncation are explicit; discarded suffix bytes cannot be read as continuation. Zero-length datagrams differ from stream closure.

Reject: A returned prefix is a complete shorter message, and zero always means stream EOF.

Evidence discriminator: locate the first task-specific state, return value, ownership transition or artifact that would differ under the rejected explanation. Require that observation or a complete finite derivation; reject a generic checksum, sanitizer absence or source heading as a substitute.

Delayed assessor check: Use an ancillary-data buffer that is too small and handle MSG_CTRUNC separately from payload truncation.

## T24.06.b — Design sequencing, duplicate handling, and loss policies where required.

Observed gaps, duplicates and late arrivals depend on the declared window; wrap requires bounded modular comparisons or a new session.

Reject: A sequence gap proves permanent packet loss immediately.

Evidence discriminator: locate the first task-specific state, return value, ownership transition or artifact that would differ under the rejected explanation. Require that observation or a complete finite derivation; reject a generic checksum, sanitizer absence or source heading as a substitute.

Delayed assessor check: Restart the sender at sequence0 with a new session identity and prevent old delayed packets from entering the new session.

## T24.06.c — Separate local send success from remote delivery evidence.

Local admission to the transport is weaker than delivery or effect; acknowledgments themselves can be lost and retries need idempotence policy.

Reject: Successful send acknowledges remote application processing.

Evidence discriminator: locate the first task-specific state, return value, ownership transition or artifact that would differ under the rejected explanation. Require that observation or a complete finite derivation; reject a generic checksum, sanitizer absence or source heading as a substitute.

Delayed assessor check: Lose only the acknowledgment after processing and show why a retry can duplicate a nonidempotent effect.
