Assessor-only; author reasoning, not independent or learner evidence.

## T48.06.a

The scheduler chooses an identity; assembly and mapping code preserve its execution state. Their tests have different failure surfaces.

Expected relation: Sequence2,0,2,0 follows the model; no-runnable policy is explicit; machine transfer is separately observed.

Withheld transfer discriminator: Replace round-robin with weighted choice while preserving the same context mechanism.

## T48.06.b

Timer delivery, interrupt acknowledgement, save/restore and policy must all work. Progress observations do not prove bounded fairness over all executions.

Expected relation: Both workers advance under actual timer interrupts; each injected defect has a distinct trace and repaired control.

Withheld transfer discriminator: Add an exited slot between runnable peers and retain correct stack ownership.

## T48.06.c

The design intentionally trades simplicity for latency. An analytical bound requires limits on device interaction, interrupts and execution costs beyond a finite QEMU run.

Expected relation: The nonpreemptible kernel interval can postpone user scheduling; no physical bound is inferred from guest elapsed times.

Withheld transfer discriminator: Change quantum and device completion delay independently and explain which latency component changes.
