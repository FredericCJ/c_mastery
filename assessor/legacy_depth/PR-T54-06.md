# PR-T54-06 independent technical assessment

Same-author technical analysis, excluded from learner package. Historical accepted evidence remains unchanged.

<a id="t54-06-a"></a>
## t54-06-a

Submission transfers exclusive buffer access; a completion interrupt is only evidence to inspect terminal device state and visibility. State labels alone do not implement DMA.

Required remaining mechanism/evidence: Actual selected DMA register path, cache adapter and dedicated hardware completion remain required.

Transfer discriminator: Use ping-pong buffers and derive maximum admitted producer burst without reusing device-owned storage.

A repeated output without derivation and scope is at most level1. A source/model check never substitutes for required guest or physical execution.

<a id="t54-06-b"></a>
## t54-06-b

Timeout is not device quiescence. Preserve storage until trusted stop/completion; an old generation cannot publish success into a new request.

Required remaining mechanism/evidence: Actual selected DMA register path, cache adapter and dedicated hardware completion remain required.

Transfer discriminator: Inject an error completion with valid ownership return and distinguish recyclable storage from successful payload data.

A repeated output without derivation and scope is at most level1. A source/model check never substitutes for required guest or physical execution.

<a id="t54-06-c"></a>
## t54-06-c

The memory-master ledger and linker map must prove reachability before submission. Host arrays cannot demonstrate bus access or cache visibility.

Required remaining mechanism/evidence: Actual selected DMA register path, cache adapter and dedicated hardware completion remain required.

Transfer discriminator: Move to another DMA engine and rederive reachable regions, alignment, maximum extent and error flags.

A repeated output without derivation and scope is at most level1. A source/model check never substitutes for required guest or physical execution.
