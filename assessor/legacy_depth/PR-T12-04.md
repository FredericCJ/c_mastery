# PR-T12-04 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1211a"></a>

## T12.11.a

FILE is an opaque stateful abstraction. fclose ends the stream association and makes its FILE pointer indeterminate; retain an independent ownership flag, not comparisons using the stale pointer.

Withheld discriminator: Borrow stdout instead of owning a newly opened file and revise close/flush responsibilities. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1211b"></a>

## T12.11.b

The accepted fixture covers EOF only, so the new error trace is a learner-created extension, not existing execution evidence. fflush on an input-only stream is not an ISO recovery operation.

Withheld discriminator: Copy between nonseekable streams where rollback and positioning are unavailable; define resumability and duplicate-output limits. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.11.c

The underlying OS interface is a distinct contract. Do not prescribe fflush as a universal read-side solution without the platform active-handle rules; this source obligation remains open if not inspected.

Withheld discriminator: Two FILE objects refer to the same underlying open-file state; identify additional active-handle requirements using a newly inspected POSIX source. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.14.a

ISO clock reports processor time used by the program with representability/availability limits. A monotonic elapsed source is a platform contract, and concurrency changes interpretation of aggregated CPU use.

Withheld discriminator: The process runs on several threads and then under heavy descheduling; predict the relationships that must be reconsidered. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.14.b

Withheld discriminator: Another thread mutates process environment through a platform API; specify a coherent synchronization/ownership policy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

Withheld discriminator: Port to an implementation with narrow time_t or a different representation and revisit arithmetic, serialization and thread safety. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
