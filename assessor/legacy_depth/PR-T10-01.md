# PR-T10-01 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t1001a"></a>
## T10.01.a — Trace exec loading, mappings, and initial entry selection.

A dynamic interpreter can receive control before application entry; main is reached through language/runtime startup. Record actual addresses and mapping ownership.

Reject superficial reasoning: The kernel always starts by calling main at e_entry.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The kernel always starts by calling main at e_entry.

Delayed assessor check: Add a supported static PIE and identify the self-relocation path rather than assuming dynamic and static entry sequences coincide.

<a id="t1001b"></a>
## T10.01.b — Identify which responsibilities belong to kernel and dynamic loader.

ELF loading and language/runtime initialization have distinct owners; an ownership diagram must not infer execution merely from metadata presence.

Reject superficial reasoning: The kernel performs all C initialization because it loaded the executable.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The kernel performs all C initialization because it loaded the executable.

Delayed assessor check: Remove the dynamic loader from an original image and identify which retained services must now initialize themselves.

<a id="t1001c"></a>
## T10.01.c — Distinguish an executable entry point from a C function call.

Process entry has no ordinary C caller; the assembly bridge establishes a call contract for its helper and owns final termination.

Reject superficial reasoning: _start is an ordinary C function with a valid caller return address.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: _start is an ordinary C function with a valid caller return address.

Delayed assessor check: Make the helper unexpectedly return a failure code and prove the bridge still terminates rather than executing ret into initial-stack data.

<a id="t1002a"></a>
## T10.02.a — Inspect argc, argument strings, environment, and auxiliary vectors.

The fixture has argv offset8, envp32, auxv48 and extent96; strings may occupy separate information locations. Every read must remain within the supplied extent.

Reject superficial reasoning: Argument strings are contiguous immediately after the pointer array.

Discriminator: The synthetic word table occupies12 eightbytes. argc=2 gives argv at8 and null at24; one env pointer at32 and null at40 gives auxv at48. Termination occupies a type/value pair. Dereferencing8192 as a host pointer is a category error.

Delayed assessor check: Add empty environment and a reordered/gapped string map while preserving the same pointer-table semantics.

<a id="t1002b"></a>
## T10.02.b — Decode addresses with the selected process-entry ABI.

Pointer width, byte order and alignment belong to the selected ABI; synthetic addresses are labels, not host pointers.

Reject superficial reasoning: A host pointer cast is a valid decoder for every process image.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A host pointer cast is a valid decoder for every process image.

Delayed assessor check: Decode a32-bit model on a64-bit host and explain which offsets change and which termination rules remain.

<a id="t1002c"></a>
## T10.02.c — Respect alignment and object-lifetime assumptions during startup.

The original table address must survive stack adjustment; helper frames and initial process storage have different lifetimes. No uninitialized TLS or libc service may be assumed.

Reject superficial reasoning: Aligning rsp may discard the only reference to the entry argument table safely.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Aligning rsp may discard the only reference to the entry argument table safely.

Delayed assessor check: Add an over-aligned helper argument and derive the new bridge alignment while retaining valid entry-table access.

## T10.03.a — Inventory crt0, crt1, crti/crtn, and compiler CRT objects for one toolchain.

Object names/providers vary; source filename folklore does not substitute for the actual link command and symbol ownership.

Reject superficial reasoning: Every Unix toolchain has one interchangeable file named crt0.o.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every Unix toolchain has one interchangeable file named crt0.o.

Delayed assessor check: Repeat under another installed C library/toolchain and compare roles without matching filenames mechanically.

<a id="t1003b"></a>
## T10.03.b — Explain target-specific naming and division of responsibility.

Roles follow actual symbols/code and link ordering; compiler support and C-library startup are not interchangeable.

Reject superficial reasoning: All files containing crt in their name initialize the same services.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: All files containing crt in their name initialize the same services.

Delayed assessor check: Remove a startup fragment in a copied original build and diagnose the first missing responsibility from link or entry evidence.

## T10.03.c — Distinguish startup assembly filenames from standardized interfaces.

ISO C does not mandate this assembly filename or CRT decomposition; installed object provenance and version matter.

Reject superficial reasoning: The source pathname start.S is a standardized external interface.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: The source pathname start.S is a standardized external interface.

Delayed assessor check: Use a custom entry whose file is also named start.S and show why the name establishes no compatibility.
