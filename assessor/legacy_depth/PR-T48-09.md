# PR-T48-09 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4809a"></a>
## T48.09.a

Transport discovery, feature negotiation and queue activation are distinct contracts. New physical devices require their own exact specification and errata review.

Expected relation: Traversal is bounded, unsupported cases remain nonoperational, and negotiated feature/status trace corresponds to the selected modern PCI profile.

Withheld transfer discriminator: Change a BAR base while preserving legal extents and recompute notification address.

<a id="t4809b"></a>
## T48.09.b

One outstanding request simplifies the proof but does not eliminate late-device writes. Timeout alone supplies no quiescence certificate.

Expected relation: Publication precedes availability; exactly the outstanding identity can complete; timeout retains storage and poisons further submission.

Withheld transfer discriminator: Permit two outstanding requests and derive per-request storage/generation needs before implementing it.

<a id="t4809c"></a>
## T48.09.c

An unchanged C loop does not establish portability. The selected mfence and identity address relation are target choices, not ISO C semantics.

Expected relation: The required order has separate compiler, CPU and device arguments; the abstract failing trace is distinguished from an observed QEMU failure.

Withheld transfer discriminator: Port the argument to a noncoherent architecture and list cache/IOMMU changes requiring new evidence.
