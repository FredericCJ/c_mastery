# PR-T02-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0209a"></a>

## T02.09.a

The initialized value and object representation differ. Static aggregate implicit initialization has specific padding rules, but later stores and automatic aggregate operations do not justify general byte equality.

Withheld discriminator: Add a pointer member and distinguish null-pointer value initialization from memset-zero assumptions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0209b"></a>

## T02.09.b

Compound-literal storage duration follows its occurrence scope. Reaching a block literal within a loop does not create an indefinitely retained allocation per iteration.

Withheld discriminator: Move the literal to file scope and compare storage duration and mutation/alias obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0209c"></a>

## T02.09.c

Copying an aggregate copies pointer values, not pointee lifetime. A deep copy or explicitly longer-lived owner is needed; address reuse is not object identity.

Withheld discriminator: Return a structure by value whose member points into the local literal and analyze why value return alone does not cure the escape. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0210a"></a>

## T02.10.a

A double-pointer conversion could permit installing a pointer to const into a mutable int* slot, then modifying a const object; a single-level intuition is insufficient.

Withheld discriminator: Add an opaque view getter returning a pointer to const and retain a separate mutable owner alias. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0210b"></a>

## T02.10.b

Const controls a particular access path. A retained view can observe later mutation or become invalid after ownership transitions; choose and test the view contract.

Withheld discriminator: Retain a view across owner mutation and specify snapshot versus live-view semantics. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0210c"></a>

## T02.10.c

Removing restrict may remove an aliasing promise but does not fix bounds, lifetime or a data race. A volatile model trace is not evidence of real board ordering.

Withheld discriminator: Permit overlapping input/output and replace the restricted operation with a defined overlap-safe algorithm. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
