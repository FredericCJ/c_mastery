# PR-T03-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0304a"></a>

## T03.04.a

The outer elements are arrays, not int* objects. A row-pointer array is a different structure with distinct allocation and ownership obligations.

Withheld discriminator: Replace contiguous rows with separately allocated rows and derive the changed representation. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0304b"></a>

## T03.04.b

Array-object boundaries govern typed arithmetic. Character access can inspect the enclosing object representation when derived from that enclosing object; it is not a general typed flattening license.

Withheld discriminator: Expose the matrix only as an unsigned-char representation and compare which byte inspections are valid. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0304c"></a>

## T03.04.c

An accessor thunk can implement row/column lookup for each representation while keeping the caller contract stable. The pointer cast merely hides the mismatch.

Withheld discriminator: Write a common accessor interface that hides either representation without casting layouts. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0305a"></a>

## T03.05.a

Integer bounds must be established before pointer arithmetic. Empty logical ranges can be represented without manufacturing a null-plus-zero expression.

Withheld discriminator: Use a subview whose offset is relative to unconsumed bytes and permit output aliasing only under a stated contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0305b"></a>

## T03.05.b

A reverse loop can decrement an index before forming the valid pointer, with an explicit begin state. A sentinel outside the permitted array cannot be manufactured for convenience.

Withheld discriminator: Change the cursor into a reverse traversal and handle begin without forming base-1. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0305c"></a>

## T03.05.c

A valid large array does not by itself prove every difference fits ptrdiff_t. Logical offsets can provide a deliberately wider model while each pointer operation stays local.

Withheld discriminator: Compare logical offset ordering against pointer ordering in a fragmented multi-buffer stream. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0306a"></a>

## T03.06.a

A runtime integer zero is not the same source category as an integer constant expression. Wire null should be an application tag/index, not a copied process pointer representation.

Withheld discriminator: Add a pointer field to a serialized record and replace raw-pointer bytes with an explicit nullable index. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0306b"></a>

## T03.06.b

Optional integer types cover valid void-pointer round trips; they do not promise preservation after object lifetime ends or authorize unrelated integer arithmetic.

Withheld discriminator: Move the object between allocations and explain which saved integer observations remain mere history. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0306c"></a>

## T03.06.c

Function-pointer conversions back to the original type are distinct from calling through an incompatible type. A POSIX convention must not be mislabeled an ISO guarantee.

Withheld discriminator: Replace a loaded function address with an exported typed table object and audit table/version/borrow lifetimes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
