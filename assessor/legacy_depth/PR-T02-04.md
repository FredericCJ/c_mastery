# PR-T02-04 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0211a"></a>

## T02.11.a

Inlining optimization does not merge internally linked functions or their local static state into one language entity. Distinct consumer state may be an intentional or accidental API property.

Withheld discriminator: Move helper-local static state into the header and explain the resulting per-unit state identities. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0211b"></a>

## T02.11.b

GCC documents distinct modes. Missing symbols can be masked by optimization; address-taking or a noninlined caller exposes the required external definition. Do not manufacture a difference when observations agree.

Withheld discriminator: Use two optimization levels and take the function address to separate emitted code from definition obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0211c"></a>

## T02.11.c

A consumer should not depend on an accidental include order. Build artifacts and include paths must identify the installed version, or a source-tree header may conceal the defect.

Withheld discriminator: Remove a transitive include from one dependency and determine whether the public API remains valid. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.12.a

A local -Werror policy is stronger than the minimum diagnostic obligation. Constraint classification concerns source translation; dynamic preconditions concern executions.

Withheld discriminator: Run the same negative sources under a permissive extension mode and separate dialect acceptance from ISO classification. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.12.b

A robust negative test records command,status and diagnostics, then verifies that the positive control uses the same available toolchain. A crash or unavailable compiler is not expected rejection.

Withheld discriminator: Change compiler and locale; preserve semantic expectations while allowing message text variation. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

Withheld discriminator: Introduce static analysis and explain which additional properties its bounded model establishes and what remains outside it. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
