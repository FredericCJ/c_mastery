## T47.10.a

A faulty medium can make an incorrect protocol appear safe. Reduced exhaustive schedules help verify the simulator's semantics without claiming all physical behavior.

Expected relation: The model preserves its declared admitted transitions and records which bytes became stable; it is labeled simulated evidence.

Withheld transfer discriminator: Enumerate all pending subsets for a reduced two-page toy protocol.

<a id="t4710b"></a>
## T47.10.b

Checking each key independently for old-or-new permits impossible mixed transactions. Whole-map consistency is the relevant property.

Expected relation: Only complete old/new maps are allowed where specified; acknowledged success and checkpoint recovery require the complete new map.

Withheld transfer discriminator: Add two successive transactions with overlapping keys and distinguish their allowed durable prefixes.

## T47.10.c

Model checking can exhaust a finite abstraction while leaving the abstraction's fidelity and physical adapter assumptions open.

Expected relation: Counts describe actually executed cases; the order proof and finite observations remain separate; new schedules are justified by a mechanism.

Withheld transfer discriminator: Use a bounded model checker for a reduced protocol and state the abstraction relation to CST2.
