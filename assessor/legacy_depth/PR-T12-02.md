# PR-T12-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1203a"></a>

## T12.03.a

Backward copy or an equivalent temporary strategy preserves source data for the right-shift case. Restricting wrappers to offsets in one array makes bounds/ordering claims defensible.

Withheld discriminator: Allow two distinct arrays; explain why relational pointer ordering cannot be a portable overlap detector across them. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1203b"></a>

## T12.03.b

Representation equality and value equality differ. Access through character types is permitted, but reverse typed access still needs a valid representation and object/lifetime/alignment argument.

Withheld discriminator: Use padding-bearing structs and compare memcmp with member-wise value equality. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1203c"></a>

## T12.03.c

The wrapper may define stronger convenience semantics by avoiding the library call. N1570 string-function zero-count wording still requires valid pointer arguments; do not execute invalid calls to infer portability.

Withheld discriminator: Change the wrapper to permit a one-past pointer for an empty live-array span and document the distinct preconditions. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T12.04.a

The adapter needs escaping or a documented rejection policy and additional capacity; merely appending a terminator does not preserve display semantics for embedded zeros.

Withheld discriminator: Parse a network field whose payload may contain zeros and transfer it to a display API that accepts only strings. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1204b"></a>

## T12.04.b

Terminator space consumes one byte when capacity is nonzero. Failure-atomic output and conventional snprintf truncation are different contracts and require different implementations.

Withheld discriminator: Adopt failure-without-truncation instead of prefix publication; derive the extra preflight or temporary-storage obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1204c"></a>

## T12.04.c

The suitability of strncpy changes with the representation contract. snprintf reports required size but has format and conversion obligations; no function removes the need to know actual object capacity.

Withheld discriminator: The destination is a fixed-width zero-padded record rather than a C string; choose and justify a different contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1205a"></a>

## T12.05.a

Preserve the int result until EOF is distinguished. The correction is a domain argument, not a claim that a sanitizer must catch every invalid ctype call.

Withheld discriminator: Use a target where EOF and a sign-extended input byte have the same int value after an incorrect narrowing. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1205b"></a>

## T12.05.b

Encoding decoding and character properties are distinct mechanisms. A byte classifier cannot derive a Unicode property from continuation bytes.

Withheld discriminator: Add combining characters and distinguish code points, grapheme clusters and display width without claiming that wchar_t solves all three. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1205c"></a>

## T12.05.c

ISO and platform locale contracts differ. A lock protocol may protect application accesses but does not imply all third-party code participates.

Withheld discriminator: Two threads require different locale policies; compare process-global mutation with an explicitly sourced platform per-operation locale API. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1206a"></a>

## T12.06.a

Retaining the conversion state while resubmitting already consumed bytes duplicates input. mbstate_t must belong to one logical stream, and the locale assumption must remain stable.

Withheld discriminator: Split a four-byte scalar at every boundary and interleave two independent streams using separate state objects. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1206b"></a>

## T12.06.b

Recovery policy controls resynchronization and must be unambiguous. N1570 leaves state unspecified after an encoding error; a fresh zero-initialized state is a separate new conversion context.

Withheld discriminator: Change from strict rejection to replacement-character recovery and specify exactly how many input bytes each error consumes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1206c"></a>

## T12.06.c

The scalar-to-wire algorithm is independent of host wide-character representation. A 16-bit API may use code units under a platform contract; ISO wchar_t alone does not promise that encoding.

Withheld discriminator: Move from 32-bit wchar_t to a 16-bit platform convention and identify which representation and API assumptions change. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
