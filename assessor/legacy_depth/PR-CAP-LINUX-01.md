<a id="t2001a"></a>
## T20.01.a

A synchronous design can be valid if it blocks input and keeps the backing buffer live; it is not automatically equivalent to the bounded asynchronous queue. A counterexample reuses candidate storage after enqueueing its address, then a second input changes the first pending output. Require explicit copy, immutable shared ownership or delayed reuse, and account for the extra lifetime in the resource ceiling.

**Independent expected relation:** A complete frame is copied or ownership-transferred before its input candidate is reused. Queue-full rejection leaves producer ownership unchanged; dependencies point from adapters to the portable contract, without core-to-Linux callbacks carrying descriptor types.

**Reject superficial evidence:** A pipeline diagram by processing stage proves safe ownership. The learner must show the causal boundary and an independent discriminator; an unrelated compiler/runtime failure is not a semantic negative control.

**Delayed transfer review:** Replace owned frames with reference-counted slabs shared by two consumers. Derive last-release, cancellation and retention ceilings before changing code. Select a new compatible event history and require predictions before execution. Check updated preconditions, resource accounting and retained successful behavior, not recall of the supplied values.

## T35.01.a

CRC is public deterministic error detection: recomputation does not require a secret. The failed property is unauthorized admission, not a checksum failure. Distinguish attacker capability from accidental transport corruption; rate/work budgets are needed even for valid authorized input.

**Independent expected relation:** Unauthorized valid frames do not increment the counter or enter the queue; bad CRC emits no message; authorized valid input still works. The attack changes only synthetic local state in the flawed control.

**Reject superficial evidence:** CRC-valid data is authentic or authorized. The learner must show the causal boundary and an independent discriminator; an unrelated compiler/runtime failure is not a semantic negative control.

**Delayed transfer review:** Move a claimed authorization bit into the wire payload and show why it cannot replace the trusted policy input. Select a new compatible event history and require predictions before execution. Check updated preconditions, resource accounting and retained successful behavior, not recall of the supplied values.
