# PR-T45-05 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4505a"></a>
## T45.05.a

The hosted allocator and process stack need not share the synthetic contiguous interval. Target layout assumptions cannot be generalized from a diagram.

Expected relation: Only the first is fixed-region link overflow; startup, allocator and logical-write defects require their own transition evidence.

Withheld transfer discriminator: Replace the contiguous embedded region with hosted virtual memory and reject the transferred collision model.

<a id="t4505b"></a>
## T45.05.b

A copy image occupies load storage even though execution uses the run region. Link-map evidence and startup copy correctness are distinct obligations.

Expected relation: All endpoints are checked before addition; retained placement and guard constraints are separate; invalid intervals reject unchanged.

Withheld transfer discriminator: Give data a Flash load address and RAM run address and account for both capacities.

<a id="t4505c"></a>
## T45.05.c

Reset categories and retained-memory behavior are board contracts. A host array experiment cannot establish power-cycle persistence.

Expected relation: The invalid range is rejected without mutation; the corrected image matches explicit bytes and link/runtime evidence remains separately labeled.

Withheld transfer discriminator: Introduce a reset-retained checksum field and specify which resets preserve it.
