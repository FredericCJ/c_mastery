## T33.01.a

Alias admission can be safe with complete validation and delayed publication; it must be proved, not assumed from small size.

Withheld discriminator: Allow output to alias one input element and revise access-order/frame obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T33.01.b

Withheld discriminator: The routine waits for callback progress and requires an environmental liveness assumption. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
