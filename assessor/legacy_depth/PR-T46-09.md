# PR-T46-09 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4609a"></a>
## T46.09.a

Budget values are meaningful only with a specified charging scheme. Comparing different schemes as equal time is invalid.

Expected relation: Each counter follows its own units and charge boundary; an ordinary infinite loop leaves GC/host budgets unchanged.

Withheld transfer discriminator: Change collection algorithm and recalibrate its work units without calling them cycles.

<a id="t4609b"></a>
## T46.09.b

Minimal controls isolate mechanisms. Composition adds precedence and cleanup obligations that isolated tests cannot establish alone.

Expected relation: Each case reaches its intended resource boundary and preserves the declared result contract; a refused computation is not silently reported as success.

Withheld transfer discriminator: Compose two near-limit resources and identify which refusal occurs first under the specified order.

<a id="t4609c"></a>
## T46.09.c

Accounting before entry limits invocation count, not duration. Asynchronous conversion introduces cancellation and lifetime requirements.

Expected relation: The counterexample identifies work outside dispatch accounting; the embedding contract needs a separate finite callback/deadline policy.

Withheld transfer discriminator: Replace blocking callback with an explicit pending/resume protocol and derive retained-state ownership.
