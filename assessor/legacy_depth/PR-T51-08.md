## T51.08.a — Derive and defend the state, ownership and ordering contract for event flags with any/all semantics.

Bits represent level/coalesced state: repeated bit4 still gives one set bit. Any sees bit1; all needs both1 and2. A count of occurrences needs a separate representation.

Reject: Repeated event sets count repeated occurrences.

Assessor discriminator: require the first state, result, ownership edge or schedule event that differs under the rejected explanation. A generic stress checksum or missing sanitizer finding is not a substitute for that witness. Confirm the claim stays inside the declared execution and source scope.

Delayed assessor check: Replace one event bit with a monotonically increasing sequence and handle wrap and missed-event detection.

## T51.08.b — Implement a fixed-width event group with set, clear and timed wait. Use bits for data-ready, stop-requested and calibration-done, with both any and all waiters.
