# PR-T44-07 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4409a"></a>
## T44.09.a

A wait graph assumes particular resource and release conditions. Timeouts and cancellation can change liveness without repairing a data race.

Expected relation: Only synchronization supplies the relevant ordering; the stopped schedule corroborates a specific wait cycle, while an abstract possible cycle is a separate claim.

Withheld transfer discriminator: Add a timeout edge that can break waiting and reconsider the deadlock classification.

<a id="t4409b"></a>
## T44.09.b

A signal does not imply the condition remains true for the awakened thread. The loop and ownership protocol must handle competition and spurious returns.

Expected relation: The faulty schedule loses the event; repaired waiting atomically releases/reacquires and rechecks the predicate. No raced C value is prescribed.

Withheld transfer discriminator: Add a spurious wakeup and a second consumer.

<a id="t4409c"></a>
## T44.09.c

Safety, liveness and fairness are different claims. More iterations do not replace the ordering and lifetime argument.

Expected relation: Each forced schedule has a causal invariant argument; detector results cover executed schedules only; teardown cannot destroy a live synchronization object.

Withheld transfer discriminator: Introduce a third waiter and bounded queue ownership.
