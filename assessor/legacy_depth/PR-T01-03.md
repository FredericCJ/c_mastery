# PR-T01-03 additive assessor analysis

Withheld from learner packaging. This strengthens specific assessment criteria while retaining the inspected project implementation contract and historical records. No new learner or independent-review result is claimed.

<a id="t0104a"></a>

## T01.04.a

GCC controls where the driver stops. An object can contain unresolved references; link success still does not show that a process started or reached main.

Withheld discriminator: Compile without a filename suffix using an explicit language selection and show why suffix-based inference fails. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0104b"></a>

## T01.04.b

Only the observed compiler/target mapping is evidence. A source-level local is not a universal stack instruction, and a virtual address is interpreted within a process mapping. Register allocation and inlining may erase expected frames.

Withheld discriminator: Compare optimized and unoptimized builds and identify which source objects no longer have an inspectable slot. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0104c"></a>

## T01.04.c

Missing source syntax prevents object output; unresolved symbol prevents normal link; missing runtime loader/dependency prevents startup; input rejection follows startup. If the loader experiment cannot be run, its execution facet stays open.

Withheld discriminator: Replace a static link with a shared dependency and relocate the dependency to distinguish link success from load-time failure. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.
