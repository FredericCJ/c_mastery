# PR-T45-09 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4509a"></a>
## T45.09.a

A state machine with only pending/done may omit callback execution. The lifetime contract must cover the integration boundary, not just the device result.

Expected relation: Reclaim waits for every possible accessor, including caller/callback control flow; cancellation intent alone leaves the borrow active.

Withheld transfer discriminator: Permit the callback to submit a successor sharing the context.

<a id="t4509b"></a>
## T45.09.b

A late producer may still hold a raw address even when its event is rejected. Safe reclamation requires the producer's quiescence protocol as well.

Expected relation: Exactly one terminal result ends the borrow; stale events cannot mutate the new generation; scratch conflict follows explicit exclusion/disjointness.

Withheld transfer discriminator: Allow nested callbacks with separate scratch leases and derive a finite nesting bound.

<a id="t4509c"></a>
## T45.09.c

Cache visibility, DMA reachability and ownership are different mechanisms. A generic event model cannot supply register-level cancellation or coherency proof.

Expected relation: Host evidence closes only the host protocol; target-specific requirements remain explicit, and no hardware activity is claimed without execution.

Withheld transfer discriminator: Move F439 SRAM buffers to an M7 cached region and derive the changed obligations from exact manuals.
