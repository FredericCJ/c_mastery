# PR-T43-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4301a"></a>
## T43.01.a

A record-count bound requires a fixed-cost comparator assumption. Shared prefixes change byte work without changing the number of comparisons; instrumentation must preserve the comparator result and stability.

Expected relation: Ordering is a,aa,ab; the byte-work bound includes key lengths and the stable identity sequence, not merely record count.

Withheld transfer discriminator: Transfer to graph edges with variable-length labels and output-sensitive matching.

<a id="t4301b"></a>
## T43.01.b

The inversion certificate is independent of the insertion loop. Binary search reduces comparisons but cannot eliminate required record movement under this representation.

Expected relation: All shifts equal inversion counts; equal-key identities preserve order; empty/singleton states perform zero placements. An exhausted counter reports unavailable without a plausible wrapped count.

Withheld transfer discriminator: Replace insertion with binary insertion and derive which count identity survives.

<a id="t4301c"></a>
## T43.01.c

Optimization can remove source operations or duplicate instructions; all three models need a named build and input. An emulator path is functional evidence, not silicon timing.

Expected relation: Static graph and code size stay fixed while dynamic counts differ; retired instruction and cycle evidence require their own target observations.

Withheld transfer discriminator: Enable inlining and explain how function boundaries and counts change without changing the source contract.

<a id="t4302a"></a>
## T43.02.a

The original bound fails to provide a nonzero upper bound at m=0. A corrected all-domain expression separates the degenerate input, rather than hiding it in measured samples.

Expected relation: 3nm<=f<=15nm for n,m>=1; fixed positive m yields Theta(n), while m=n yields Theta(n squared).

Withheld transfer discriminator: Allow m=0 and derive a valid two-parameter expression including n+1.

<a id="t4302b"></a>
## T43.02.b

The sink adds a failure and backpressure contract. Counting only accepted outputs must not erase attempted output work or repeated retries.

Expected relation: The certificate includes Z and stored edges, and distinguishes worst-case over inputs from a bound for each trace.

Withheld transfer discriminator: Change output from materialized records to an interruptible streaming sink with partial progress.

<a id="t4302c"></a>
## T43.02.c

Monotonicity does not recover the unobserved tail. Measurement supports the sampled regime; asymptotic quantifiers need a model proof.

Expected relation: Give explicit piecewise definitions, a divergent witness beyond the sample set and a crossover calculation under stated constants.

Withheld transfer discriminator: Require monotone functions and preserve indistinguishability on the measured interval.
