# PR-T31-04 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t3107a"></a>

## T31.07.a

Counter arithmetic alone does not establish clock calibration or faithful emulator timing.

Withheld discriminator: Frequency changes mid-interval and require piecewise time conversion. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t3107b"></a>

## T31.07.b

Bounded storage needs ownership and overflow semantics. Sequence gaps quantify loss only under explicit wrap/reset rules.

Withheld discriminator: Multiple interrupt producers require a separately proved publication protocol. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t3107c"></a>

## T31.07.c

Instrumentation can change scheduling and the defect itself,not only add a constant delay.

Withheld discriminator: Trace traffic changes cache/interrupt contention and explain nonadditive overhead. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

Withheld discriminator: A segmented ELF has holes and RAM-load sections; distinguish file hash from deployed-address contents. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T31.08.b

## T31.08.c
