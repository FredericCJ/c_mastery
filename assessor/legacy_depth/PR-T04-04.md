# PR-T04-04 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0409a"></a>

## T04.09.a

Choosing a type named long double does not establish an independent higher-precision oracle.

Withheld discriminator: Move to an implementation where double and long double share precision and revise the reference strategy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0409b"></a>

## T04.09.b

Storage-format support and arithmetic handling differ. No observation permits silently enabling a relaxed mode in a strict contract.

Withheld discriminator: Compare flush-to-zero behavior under an explicitly documented target mode. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T04.09.c

Finite expansions require denominator factors from the radix after reduction; this argument transfers without host measurements.

Withheld discriminator: Use a decimal-radix model and choose a rational denominator that is still nonterminating. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

Withheld discriminator: Integrate the kernel into a caller that treats NaN as missing data and reassess valid optimization flags. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
