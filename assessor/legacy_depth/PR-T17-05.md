# PR-T17-05 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1706a"></a>

## T17.06.a

IIR output feeds future state; FIR retains finite input history. State update order must preserve the required previous samples.

Withheld discriminator: Use a nonzero initial IIR state and derive homogeneous plus forced response. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1706b"></a>

## T17.06.b

Numerical boundedness under saturation is not the same as linear-system stability or desired response. The finite experiment cannot establish general stability.

Withheld discriminator: Choose a second-order recurrence and require roots/pole analysis instead of reusing the scalar check. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1706c"></a>

## T17.06.c

A stateful block API needs progress ownership. Returning failure after updating hidden history can make retries duplicate samples.

Withheld discriminator: Allow partial block processing under backpressure and define exactly how many samples committed. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
