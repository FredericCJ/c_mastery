# PR-T46-10 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4610a"></a>
## T46.10.a

The VM cannot sandbox hostile native callback code. The callback remains trusted within its stated lifetime and resource contract.

Expected relation: Only allowed services execute with validated integer arguments; budget is charged at its declared boundary; arbitrary pointers/paths never cross.

Withheld transfer discriminator: Give two VM instances different service capability sets.

<a id="t4610b"></a>
## T46.10.b

A format change is an integration contract change. A successful nominal round trip does not establish compatibility with old persisted data.

Expected relation: Encoding is explicit and length-checked; failures remain host outcomes; store and VM evidence retain separate source identities.

Withheld transfer discriminator: Add a version byte and migration/rejection policy for old values.

<a id="t4610c"></a>
## T46.10.c

Idempotent fixed assignment can mask duplicate execution. A non-idempotent service exposes why uncertainty must be represented explicitly.

Expected relation: The two errors can have different durable outcomes; blind retry is prohibited for non-idempotent effects; guest completion and persistence are separate.

Withheld transfer discriminator: Change the service from assignment to increment and add an operation-ID reconciliation protocol.
