## T43.10.a

Generalized event names do not ensure identical microarchitectural coverage. A denied run supports only an availability conclusion.

Expected relation: Every result includes status and scope; no host permission setting changes and no unrelated process is observed.

Withheld transfer discriminator: Move the same request to another CPU model and identify event meanings requiring new authority.
