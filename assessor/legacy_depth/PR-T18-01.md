# PR-T18-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t1801a"></a>
## T18.01.a

A valid C representation may be invalid for the API. Infinite cannot enter arithmetic as an ordinary negative duration. Conversion rounding and range rejection require explicit contracts.

Expected relation: len>cap rejects; empty success remains distinct from timeout or error; milliseconds are never silently interpreted as ticks.

Withheld transfer discriminator: Replace the infinite sentinel with a tagged deadline and derive wrap-safe admission under an explicitly bounded counter model.

<a id="t1801b"></a>
## T18.01.b

Do not fabricate invalid pointer representations or dereference null to demonstrate rejection. Validate the scalar state first; pointers still require caller-provided valid extent/lifetime.

Expected relation: The first two states reject; empty-null depends on the published zero-length policy; the active resource inconsistency is a contract fault.

Withheld transfer discriminator: Introduce a state produced by a failed constructor and prove which cleanup operations remain legal.

<a id="t1801c"></a>
## T18.01.c

Record sizeof in C bytes, alignment and data model separately. Do not claim LP64 observations prove all targets; exact C17 text remains an explicit source gap.

Expected relation: Wire octets and C bytes are distinct concepts; unsupported CHAR_BIT or absent exact-width types must be explicitly adapted or rejected.

Withheld transfer discriminator: Port the specification to a simulated16-bit-byte target without pretending a host typedef changes CHAR_BIT.

<a id="t1802a"></a>
## T18.02.a

The original foundation anchor stages and permits overlap; it cannot certify the base forbidden-overlap contract. Full-state snapshots must include logical length and all previously visible bytes.

Expected relation: Capacity3 rejects [3,4] after [1,2] unchanged; capacity4 commits [1,2,3,4]; rejected scalar extents perform no copy.

Withheld transfer discriminator: Make source equal the future destination subrange under a separately versioned overlap-allowing API and rederive staging needs.

<a id="t1802b"></a>
## T18.02.b

A bounded equality scan uses only valid in-range addresses and can detect a common byte, with explicit O(cap*n) cost. Offset descriptors enable a cheaper proof. Neither proves an arbitrary pointer's extent is valid.

Expected relation: An aliased nonempty source rejects unchanged; independent disjoint buffers append; empty-source handling follows its documented policy.

Withheld transfer discriminator: Introduce a shared owner/offset descriptor and replace quadratic address-equality comparison with checked interval arithmetic.

<a id="t1802c"></a>
## T18.02.c

Registry membership alone is not lifetime synchronization. External proof or discipline remains necessary unless the complete access protocol closes those cases.

Expected relation: The public contract retains uncheckable caller obligations; scalar rejection precedes access and cannot validate a forged extent.

Withheld transfer discriminator: Add a bounded owner registry and explain which dangling or concurrently reclaimed states it still cannot exclude.

<a id="t1807a"></a>
## T18.07.a

A tagged C struct supplies representation, not exhaustive handling or mandatory checking. Size measurements are ABI observations, not fixed ISO promises.

Expected relation: Both forms represent success0 distinctly from missing/error; ignored status remains possible unless an explicit diagnostic/runtime policy rejects it.

Withheld transfer discriminator: Add partial progress and a terminal status simultaneously; derive why a single success/error tag may need a product payload.

<a id="t1807b"></a>
## T18.07.b

Do not inspect padding bytes as logical evidence. Compare defined fields and declared byte buffers; analysis must distinguish unspecified object representation from promised output state.

Expected relation: The selected parent unchanged-on-failure contract preserves the full prior output state; zero-length success still has a valid status/length.

Withheld transfer discriminator: Allow partial consumption and redesign the result so valid prefix length cannot be mistaken for full success.

<a id="t1807c"></a>
## T18.07.c

Sentinels are valid design choices only when the domain restriction is explicit and enforced at every producer boundary.

Expected relation: All four outcomes remain distinguishable without guessing from the payload; no successful value aliases the error encoding.

Withheld transfer discriminator: Reserve a sentinel by narrowing the value domain and quantify the lost representable values and migration risk.

<a id="t1809a"></a>
## T18.09.a

Required admission must precede memory access. Diagnostics and proofs can strengthen evidence but cannot make absent runtime enforcement execute.

Expected relation: External invalid input rejects under both NDEBUG modes; compile-time guards cannot validate runtime lengths; tests do not enforce production invariants.

Withheld transfer discriminator: Make a previously internal field attacker-controlled through a parser and relocate enforcement to the trust boundary.

<a id="t1809b"></a>
## T18.09.b

No-evaluation instrumentation and always-evaluated input validation have different contracts. A runtime-disabled sink still evaluates ordinary function arguments.

Expected relation: Both modes execute required validation once and preserve state on rejection; optional assertion presence changes only its stated developer-fault behavior.

Withheld transfer discriminator: Disable the entire instrumentation macro and require zero evaluation of its optional expensive argument while retaining validation.

<a id="t1809c"></a>
## T18.09.c

The fault policy is application-specific; no universal rule says panic or retry. What matters is a coherent state and ownership transition under the declared environment.

Expected relation: Exhaustion follows ordinary failure semantics; internal corruption invokes the chosen fault policy; diagnostics preserve the distinct cause.

Withheld transfer discriminator: Move the core into a service process and decide which fault terminates only that process versus propagates a recoverable result.
