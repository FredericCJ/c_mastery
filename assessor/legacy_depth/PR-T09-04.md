# PR-T09-04 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0908a"></a>
## T09.08.a — Define memory regions, output sections, and placement constraints.

The map proves the declared model only; region overflow/alignment and orphan-section policy need explicit checks. No board mapping is inferred.

Reject superficial reasoning: A valid syntax script establishes a physically valid board memory map.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A valid syntax script establishes a physically valid board memory map.

Delayed assessor check: Add a second RAM bank and define placement when a section cannot fit contiguously in either bank.

<a id="t0908b"></a>
## T09.08.b — Distinguish load addresses from execution addresses.

Startup copies16 bytes from load to run location and zeros24 bytes; file offset is obtained from format mapping, not guessed from VMA.

Reject superficial reasoning: VMA, LMA and file offset are interchangeable addresses.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: VMA, LMA and file offset are interchangeable addresses.

Delayed assessor check: Introduce alignment padding between load sections and recalculate the image extent and copy table.

<a id="t0908c"></a>
## T09.08.c — Export linker symbols through documented C/assembly conventions.

Address-valued linker symbols and ordinary objects differ; subtraction/provenance assumptions must be explicitly implementation-bound.

Reject superficial reasoning: A linker symbol necessarily denotes an ISO C allocated object containing its numeric value.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A linker symbol necessarily denotes an ISO C allocated object containing its numeric value.

Delayed assessor check: Use an explicit startup table of address/length records and validate each interval before initialization.

<a id="t0909a"></a>
## T09.09.a — Control section collection, KEEP, and archive extraction.

An unextracted member supplies no input section for KEEP; extraction and section reachability must be diagnosed separately.

Reject superficial reasoning: KEEP pulls every matching section out of every archive automatically.

Discriminator: Ask for the archive member list before inspecting GC output. If the registration member never entered the link, KEEP has no matching input section. Targeted -u/extraction and KEEP solve different predicates; whole-archive is not a minimal explanation.

Delayed assessor check: Replace the archive with directly linked objects and explain why the same KEEP rule now has a different effect.

<a id="t0909b"></a>
## T09.09.b — Account for interrupt tables and registration entries with indirect references.

A retained table must create actual relocation edges to the callbacks; source mention and compiler emission alone do not guarantee final reachability.

Reject superficial reasoning: Taking an address in source always makes an entry reachable after linking.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Taking an address in source always makes an entry reachable after linking.

Delayed assessor check: Store numeric offsets instead of relocation-bearing pointers and identify the lost automatic reachability evidence.

<a id="t0909c"></a>
## T09.09.c — Diagnose missing code caused by unintended section elimination.

The first absent artifact identifies the mechanism; broad retention can hide missing extraction or enumeration bugs.

Reject superficial reasoning: Every missing function after link is fixed by disabling garbage collection.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every missing function after link is fixed by disabling garbage collection.

Delayed assessor check: Change to LTO and show how the compiler/linker boundary shifts the required evidence.

<a id="t0910a"></a>
## T09.10.a — Use map files and linker assertions for memory limits.

Padding and placement affect the map; the rejection must be the budget assertion rather than another linker failure.

Reject superficial reasoning: Summing source sizeof values always equals linked region occupancy.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Summing source sizeof values always equals linked region occupancy.

Delayed assessor check: Include a reserved stack region and prove the combined static allocation cannot overlap it.

<a id="t0910b"></a>
## T09.10.b — Quantify text, read-only data, initialized data, and zero-fill storage.

Zero-fill still consumes runtime memory; initialized data often consumes both load-image and runtime storage. Classification follows actual retained sections.

Reject superficial reasoning: BSS is free because it occupies no ordinary data payload in the file.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: BSS is free because it occupies no ordinary data payload in the file.

Delayed assessor check: Merge identical constants or enable section GC and explain the resulting resource delta without changing the correctness contract.

<a id="t0910c"></a>
## T09.10.c — Compare file size, load image size, and runtime RAM use.

Metadata/debug data and sparse encoding can change file size independently of load/runtime requirements.

Reject superficial reasoning: A smaller ELF necessarily means less flash and RAM.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A smaller ELF necessarily means less flash and RAM.

Delayed assessor check: Convert to a sparse address-bearing format and explain why its smaller file is not a smaller address span.
