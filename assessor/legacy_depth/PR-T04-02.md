# PR-T04-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0405a"></a>

## T04.05.a

Logical width and promoted operand width differ. An expression can be valid C yet violate the declared logical-word contract.

Withheld discriminator: Make logical width smaller than the chosen unsigned carrier and mask input/result explicitly. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0405b"></a>

## T04.05.b

Guard width/count before constructing masks, including the carrier-full-width case. Simultaneous updates need saved original state or a stated priority.

Withheld discriminator: Add overlapping field updates and prove sequential versus simultaneous update semantics. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0405c"></a>

## T04.05.c

An intrinsic may have stricter zero preconditions or carrier width. An adapter must translate rather than infer equivalent contracts from nominal values.

Withheld discriminator: Replace the loop with a supported intrinsic while retaining exactly the zero and width policy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0406a"></a>

## T04.06.a

The protocol defines octet positions; an endian-dependent memory dump is not an implementation of that protocol.

Withheld discriminator: Define a separate little-endian format and prove both recover the same value. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0406b"></a>

## T04.06.b

Bounds and ownership stay per span; staged byte reads can implement the stream contract without alignment or alias assumptions.

Withheld discriminator: Decode across two separately owned spans without first making an invalid cross-object pointer. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0406c"></a>

## T04.06.c

Packing does not settle endianness, effective type, lifetime, unaligned access or version admission. These are separate obligations.

Withheld discriminator: Add an unknown version/flag field and specify reject versus skip behavior before decoding payload. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0407a"></a>

## T04.07.a

The standard leaves allocation/order choices to the implementation; sizeof cannot alone identify every bit location.

Withheld discriminator: Change underlying bit-field type or packing option and assess binary-interface compatibility. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0407b"></a>

## T04.07.b

No physical MMIO is performed. Access width, volatility and side effects belong to the register/ISA contract, not generic bit-field semantics.

Withheld discriminator: Add read-to-clear behavior and explain why even a harmless-looking read changes the state machine. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0407c"></a>

## T04.07.c

ABI compatibility is a composition contract. Length admission precedes member access; a larger producer cannot force an old consumer to read unknown memory.

Withheld discriminator: Permit independently compiled plugins and add size/version negotiation without reading unavailable trailing fields. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
