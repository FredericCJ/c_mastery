## T16.12.a

Backing availability and C effective type are separate claims. Platform memory contracts must be inspected before asserting portability.

Withheld discriminator: Use a dedicated firmware RAM region and identify required linker/ABI/board evidence without flashing hardware. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.12.b

Thread-local placement is not proof that object use ends at thread exit. Cross-thread lifetime changes the reclamation boundary.

Withheld discriminator: One worker exits while another retains its allocation; design transfer/remote-free or reject the use. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.12.c

Allocator synchronization orders allocator state only as its contract specifies. It does not automatically serialize arbitrary later client accesses.

Withheld discriminator: Publish an immutable payload with release/acquire and retain it until all readers finish. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
