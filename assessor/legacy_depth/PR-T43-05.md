# PR-T43-05 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4306a"></a>
## T43.06.a

The independent model must encode the same write-allocation and final-flush rules. An alternative policy requires new expected histories, not renaming the old result.

Expected relation: Hits update recency; dirty eviction and final flush each write once; geometry and index rejection preserve state.

Withheld transfer discriminator: Replace LRU with FIFO and construct a sequence that distinguishes them.

<a id="t4306b"></a>
## T43.06.b

Amplification is a defined accounting ratio, not an intrinsic device constant. Compression and repeated use change the relation without arithmetic failure.

Expected relation: Repeated warm reads can yield a ratio below one under this definition; useful=0 has no ratio; bytes are counted at the named buffer boundary.

Withheld transfer discriminator: Use compressed blocks and distinguish logical useful bytes from encoded transfer bytes.

<a id="t4306c"></a>
## T43.06.c

No global cache flush or privilege change is required. A model transfer count is not promoted to an actual bus trace.

Expected relation: Logical output must match in both runs; unavailable/shared device attribution stays explicit. Warmth is inferred only within the observed setup.

Withheld transfer discriminator: Repeat after an unrelated local process accesses the same file and assess attribution limits.
