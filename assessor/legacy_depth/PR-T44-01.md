# PR-T44-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

## T44.01.a

The assignment changes the local value before the comparison. A nominal accepted input cannot distinguish correct validation from accepting everything.

Expected relation: The faulty guard accepts all supplied values; the dossier distinguishes observation from inference and does not claim a tool result before execution.

Withheld transfer discriminator: Use a stale configuration with correct source to produce the same visible admission error.

<a id="t4401b"></a>
## T44.01.b

Hashes identify bytes but do not capture every environmental dependency or authenticate provenance. Reproduction requires a sufficient configuration boundary.

Expected relation: The mismatched manifest rejects; a reproducible trial includes exact command, exit category and captured output without invented success.

Withheld transfer discriminator: Make an environment variable alter a parsing mode while all file hashes remain unchanged.

Expected relation: One observation distinguishes the hypotheses; the repair addresses the first contract-breaking transition and keeps a rejected alternative.

Withheld transfer discriminator: Diagnose an unchanged parameter with a corrupted capacity instead.
