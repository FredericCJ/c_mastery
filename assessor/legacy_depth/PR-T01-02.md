# PR-T01-02 additive assessor analysis

Withheld from learner packaging. This strengthens specific assessment criteria while retaining the inspected project implementation contract and historical records. No new learner or independent-review result is claimed.

## T01.03.a

Array parameter syntax is adjusted to a pointer; sizeof parameter is pointer size. A pointer-to-array type carries the extent in its pointed-to type, but actual object existence and lifetime remain preconditions.

Withheld discriminator: Change the element array to a two-dimensional array and derive the parameter type and stride. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0103b"></a>

## T01.03.b

A definite-assignment argument enumerates control paths; a single observed branch does not validate the other. Sanitizers and warnings have different coverage, and silence proves neither bounds nor initialization.

Withheld discriminator: Move initialization behind one branch and design a path-sensitive test plus a proof of complete initialization. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

## T01.03.c

A comma operator sequences its operands; argument separator commas do not create that sequencing. Distinguish unspecified ordering of nonconflicting effects from unsequenced conflicting modifications.

Withheld discriminator: Refactor to comma operator versus comma-separated arguments and show why the sequencing argument differs. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.
