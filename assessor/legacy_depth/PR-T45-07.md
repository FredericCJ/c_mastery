# PR-T45-07 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4507a"></a>
## T45.07.a

Do not inspect or compare the old C pointer after successful realloc. Integer address tokens in a model do not authorize evaluating an indeterminate pointer.

Expected relation: Refusal retains old owner/content; success invalidates prior aliases regardless of numeric address and publishes only initialized payload.

Withheld transfer discriminator: Replace resize with allocate-copy-commit-free and compare failure guarantees.

<a id="t4507b"></a>
## T45.07.b

Generation handles work only when all accesses use the protocol and storage remains live while validated. They do not retroactively make arbitrary stale pointers safe.

Expected relation: The model rejects each distinct authority violation; native symptoms remain observations rather than fixed outcomes.

Withheld transfer discriminator: Retire a generation at its maximum instead of wrapping and test capacity exhaustion.

<a id="t4507c"></a>
## T45.07.c

Each policy changes resource costs and permitted operations. ISO C supplies no automatic borrow checker to enforce the chosen discipline.

Expected relation: Both modeled success cases expire old borrows; refusal preserves them; every owned generation has one release obligation.

Withheld transfer discriminator: Allow a borrower to outlive the resize call and choose pinning, copy or rejection with an explicit contract.
