# PR-T11-04 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t1107a"></a>
## T11.07.a — Specify the services required by a selected embedded C library.

The service boundary is library/version-specific; a missing reference is an open requirement, not permission to invent hook semantics.

Reject superficial reasoning: Including a small embedded library automatically supplies heap, files and output devices.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Including a small embedded library automatically supplies heap, files and output devices.

Delayed assessor check: Replace formatted output with a bounded raw-byte service and identify which environment obligations disappear and which remain.

<a id="t1107b"></a>
## T11.07.b — Examine syscall retargeting, heap extension, and stream backends.

Unsupported acquisition must remain visible and preserve state; transport partial progress cannot be reported as full completion. The adapter is not an implementation of every libc hook.

Reject superficial reasoning: Returning a fake success from an absent OS hook is a harmless stub.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Returning a fake success from an absent OS hook is a harmless stub.

Delayed assessor check: Add a bounded arena allocation service with alignment/overflow checks and compare exhaustion behavior with the refusing policy.

<a id="t1107c"></a>
## T11.07.c — Distinguish semihosting dependencies from standalone board operation.

Debugger transport is an external service and can disappear; model success is not physical UART or standalone-board evidence.

Reject superficial reasoning: Output seen under a debugger proves standalone firmware transport works.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Output seen under a debugger proves standalone firmware transport works.

Delayed assessor check: Specify behavior when the debugger service is absent at reset and ensure the firmware contract does not silently block forever.

<a id="t1108a"></a>
## T11.08.a — Specify initialized RAM, stack, exception state, and entry arguments.

Startup owns explicit initialization in the declared environment; the model checks interval responsibilities without proving an actual board reset path.

Reject superficial reasoning: Initializing C globals is solely a language declaration effect even before runtime exists.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Initializing C globals is solely a language declaration effect even before runtime exists.

Delayed assessor check: Add a reset during initialization and specify which state can be safely reinitialized and which retained region must survive.

<a id="t1108b"></a>
## T11.08.b — Define responsibility for TLS and initialization hooks when retained.

Metadata retention, storage creation and ordered invocation are separate mechanisms; each callback has a restricted service/ownership contract.

Reject superficial reasoning: Keeping TLS or constructors requires only retaining their sections.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Keeping TLS or constructors requires only retaining their sections.

Delayed assessor check: Add multiple tasks and define separate TLS instance lifetime, initialization and reclamation responsibilities.

<a id="t1108c"></a>
## T11.08.c — Make unsupported hosted services fail visibly rather than accidentally work.

Visible refusal and unchanged state expose contract violations; a default success value can silently corrupt later reasoning.

Reject superficial reasoning: An absent service can return a plausible default because callers should not use it.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: An absent service can return a plausible default because callers should not use it.

Delayed assessor check: Compose a client that retries a temporarily unavailable service and distinguish retryable NOT_READY from permanent UNSUPPORTED.
