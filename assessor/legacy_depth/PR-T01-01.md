# PR-T01-01 additive assessor analysis

Withheld from learner packaging. This strengthens specific assessment criteria while retaining the inspected project implementation contract and historical records. No new learner or independent-review result is claimed.

<a id="t0101a"></a>

## T01.01.a

Count n additions under the selected recurrence and n+1 live activations for a recursion that calls on n-1 down to0; a different recurrence must state its convention.

Withheld discriminator: Replace recursion with an explicit bounded stack; relate each stack record to an activation. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0101b"></a>

## T01.01.b

For the fixed API, staging is a fixed object. Under variable n it scales unless the algorithm changes. Output storage is caller-owned and must not be silently counted as scratch. Tail-call elimination is not guaranteed by ISO C.

Withheld discriminator: Remove the fixed16 bound and preserve failure atomicity; compare a two-pass strategy with dynamic staging and their aliasing constraints. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0101c"></a>

## T01.01.c

Prove range admission before evaluating acc+x. Use x>0 and acc>MAX-x; x<0 and acc<MIN-x with valid subtraction bounds. The decreasing measure n-k requires validated n and one increment per iteration.

Withheld discriminator: Change sum to maximum selection over a possibly empty range and derive a total contract and invariant. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

## T01.02.a

Reconstruction128+32+8+4+1=173 is independent of the host CHAR_BIT. Synthetic width8 is a problem parameter, not a claim about C char.

Withheld discriminator: Encode a value into a three-octet big-endian wire format on a little-endian host without pointer punning. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0102b"></a>

## T01.02.b

(x&m)!=0 tests intersection nonempty. (x&m)==m tests containment. Empty-set containment explains mask0 without a special arithmetic exception.

Withheld discriminator: Turn a required-permissions mask into a forbidden-permissions predicate and derive a counterexample to reusing the old test. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.

<a id="t0102c"></a>

## T01.02.c

Integer representations and operation semantics are different. Unsigned wrap is defined; signed overflow is not a modulo operation merely because the observed machine wraps. Saturation is also non-associative, e.g. near a positive limit then a negative correction.

Withheld discriminator: Use saturating addition and compare sequential accumulation with reassociation; exhibit a case where grouping changes the result. Reject example-only reproduction; require the exact changed invariant and an independent counterexample to the old explanation.
