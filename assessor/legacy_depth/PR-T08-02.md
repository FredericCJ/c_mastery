# PR-T08-02 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0803a"></a>
## T08.03.a — Map parameters and return values to the chosen ABI.

The weighted sum is204 for1..8 and modulo arithmetic explains the boundary. The return-address push changes stack-relative offsets.

Reject superficial reasoning: All arguments fit in registers or have the same offsets on both sides of call.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: All arguments fit in registers or have the same offsets on both sides of call.

Delayed assessor check: Add a ninth argument and a mixed floating-point argument; classify register resources separately rather than shift every argument blindly.

<a id="t0803b"></a>
## T08.03.b — Analyze aggregate passing and hidden return-storage conventions.

On declared SysV AMD64 integer pair and triple have distinct return mechanisms; hidden storage is caller-owned and must outlive the call. Demonstrate layout evidence before classifying.

Reject superficial reasoning: Every structure return is a pointer or every small structure is returned identically.

Discriminator: For the declared integer pair, require RAX/RDX classification; for the triple require caller storage passed in RDI and the same address returned in RAX. A cast-based incompatible call is not a valid experiment. Mixed SSE/INTEGER return classification is the withheld changed condition.

Delayed assessor check: Use a mixed double/integer pair and explain separate register classes; retain a new pinned ABI classification.

Reject superficial reasoning: A16-byte-aligned rsp is required at every instruction including immediately after call.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A16-byte-aligned rsp is required at every instruction including immediately after call.

Delayed assessor check: Add an over-aligned stack argument and derive the stronger alignment from its actual ABI requirement.
