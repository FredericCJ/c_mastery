# PR-T03-04 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0311a"></a>

## T03.11.a

A wire encoder should assign each transmitted field/byte instead of copying unspecified padding. Conversely, zero-filled bytes are not a universal valid pointer or floating representation.

Withheld discriminator: Add a serialization boundary and initialize only deliberately encoded bytes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0311b"></a>

## T03.11.b

Cleanup may itself read uninitialized fields unless construction state is explicit. DR451 discussions are not a license to invent deterministic behavior for arbitrary indeterminate values.

Withheld discriminator: Add an early failure after one member is initialized and design cleanup that reads only established state. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0311c"></a>

## T03.11.c

Instrumentation and static analysis operate under selected coverage/model assumptions. Keep tool behavior separate from repaired defined-code regression evidence.

Withheld discriminator: Change optimization and initialized branch coverage, then identify why detection changes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0312a"></a>

## T03.12.a

sizeof may exceed flexible-member offset. A safe sizing model accounts for header and count with checked arithmetic; a zero-element flexible member has special formation/access restrictions. Logical count remains an API constraint even if extra bytes physically fit.

Withheld discriminator: Choose a layout with tail padding and compare sizeof/header offset without claiming the padding authorizes extra logical elements. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0312b"></a>

## T03.12.b

A VLA declaration is not an allocator call with a recoverable null result. Size-expression evaluation and actual storage lifetime need separate reasoning; scope transitions and optional support matter.

Withheld discriminator: Move the VLA declarator into a parameter and derive adjustment plus bound-evaluation obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0312c"></a>

## T03.12.c

The flexible payload is contiguous in one allocation; pointer/length can reference separate storage. Sharing trades copies for explicit lifetime management and cannot be inferred from the field type.

Withheld discriminator: Permit shared immutable payload storage and specify ownership/refcount or borrow rules. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0313a"></a>

## T03.13.a

Do not evaluate the old pointer after success even if the allocation happened at the same numeric address. Zero-size behavior is edition-sensitive and should not be smuggled into the nonzero contract.

Withheld discriminator: Separate zero-size policy from resize and compare inspected C17 DR400 with later edition differences. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0313b"></a>

## T03.13.b

Storage address stability is only one dimension. An address can now denote a different logical element after compaction; an end iterator can change even if existing elements stay put.

Withheld discriminator: Make erase shift elements without reallocating and analyze index versus address identity. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0313c"></a>

## T03.13.c

A handle containing an owner address inherits that address stability requirement. Relocating data can be safe while relocating its validation authority is not.

Withheld discriminator: Move the handle table itself and decide whether owner-relative IDs or stable control storage is required. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
