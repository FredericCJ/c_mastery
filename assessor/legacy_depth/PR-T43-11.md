# PR-T43-11 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

## T43.12.a

Instrumentation coverage is a property of the complete build. Runtime termination and buffering affect whether observations are emitted.

Expected relation: Build identities and dependencies are explicit; recursive recorder instrumentation is rejected; unsupported profiling remains separate from the hook result.

Withheld transfer discriminator: Link an uninstrumented helper and identify the missing call boundary.

## T43.12.b

Per-context invocation stacks distinguish recursive frames and concurrency. Nonlocal exits need explicit unwind events or an incomplete-result contract.

Expected relation: The parent complete trace gives9/4 for work and5/5 for child; incomplete traces expose unknown attribution rather than exact totals.

Withheld transfer discriminator: Replace recursion with interleaved task IDs and require a stack per context.

## T43.12.c

The measurement changes the program; perturbation can alter cache and scheduling behavior. A single subtraction does not remove all effects.

Expected relation: Report perturbation and the caller-dependent counterexample; no sample count becomes an exact elapsed duration.

Withheld transfer discriminator: Batch calls to reduce bracket overhead and determine whether the new boundary changes the question.
