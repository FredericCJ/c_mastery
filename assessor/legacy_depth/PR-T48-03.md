# PR-T48-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4803a"></a>
## T48.03.a

A matching total size can conceal exchanged fields. The argument frame pointer must survive temporary alignment of the C-call stack.

Expected relation: The declared frame is176 bytes and every offset matches the actual push/pop sequence; ISA and software fields are labeled separately.

Withheld transfer discriminator: Change diagnostic metadata by one word and repair call alignment without changing iret state.

<a id="t4803b"></a>
## T48.03.b

Diagnostic completeness and bounded progress conflict; an explicit truncation policy is preferable to an unbounded dependency inside the exception path.

Expected relation: Saved state identifies each original trigger; no unbounded formatting dependency enters the freestanding image; normal interrupt return preserves all sentinels.

Withheld transfer discriminator: Exhaust the diagnostic output budget and preserve a minimal first-fault record.

<a id="t4803c"></a>
## T48.03.c

The original single-core diagnostic kernel is not a general recoverable kernel. A known user fault may be contained while the integrated self-test still flags an unexpected event.

Expected relation: Privilege origin and policy, not merely vector number, select containment; the double-fault path has independent stack ownership.

Withheld transfer discriminator: Inject a fault while the ordinary kernel stack is unavailable and state which observation remains possible.
