# PR-T49-05 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4905a"></a>
## T49.05.a

The oracle's first_touch_faults is a model assumption. It is not an OS prediction independent of access type and mapping history.

Expected relation: Unique pages are0,1,3 under the finite model; runtime deviations are explained using mappings, zero-page/COW, huge-page and measurement scope.

Withheld transfer discriminator: Use equal total bytes with interleaved windows and compare working sets by window.

<a id="t4905b"></a>
## T49.05.b

The retained32-page probe is one executable anchor; it does not implement all access patterns or a controlled cold-cache experiment.

Expected relation: Every claimed access contributes to an observable checksum; resource deltas are scoped to actual phases and no universal count is asserted.

Withheld transfer discriminator: Compare read-only first touch with write first touch and explain differing allocation paths.

<a id="t4905c"></a>
## T49.05.c

Observations can falsify a simplistic model but rarely identify a unique cause without interventions and independent counters.

Expected relation: Claims are bounded by measured counters and controls; unavailable isolation stays pending rather than replaced by a model pass.

Withheld transfer discriminator: Introduce a bounded competing reader in a disposable environment and compare uncertainty intervals.
