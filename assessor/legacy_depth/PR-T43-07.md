# PR-T43-07 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4308a"></a>
## T43.08.a

A later error does not roll back earlier accepted bytes. The multi-buffer cursor needs checked cumulative lengths and unchanged borrowed lifetimes.

Expected relation: Accepted bytes are never duplicated; only positive results advance the cursor; retry budget and zero-progress termination are explicit.

Withheld transfer discriminator: Add a vectored write spanning two buffer boundaries.

<a id="t4308b"></a>
## T43.08.b

A file-content boundary and a directory-entry boundary are distinct. A model of atomic rename does not automatically establish persistence after power loss.

Expected relation: The sync failure remains a failure despite readable bytes; timing phases and exact status are separate; no power-loss result is inferred.

Withheld transfer discriminator: Publish by temporary file plus rename and identify the additional directory synchronization boundary.

<a id="t4308c"></a>
## T43.08.c

Shared counters permit only scoped inference. Equal file bytes do not imply equal metadata or physical I/O work.

Expected relation: The ratio512 describes the captured scope only; attribution and allocation granularity remain unresolved without additional evidence.

Withheld transfer discriminator: Compare a preallocated file with a newly created sparse file under equal byte correctness.
