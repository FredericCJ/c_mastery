# PR-T02-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0201a"></a>

## T02.01.a

Parentheses bind b before the array suffix. Expression-based reading shows *b has array type while a[i] has pointer type; the representations are not interchangeable.

Withheld discriminator: Return a pointer to a4-element row through a factory and derive its full declaration. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0201b"></a>

## T02.01.b

A file-scope declaration with initializer is a definition even with extern. A tentative definition may supply a zero-initialized definition at translation-unit end; multiple-unit tolerance is not an ISO guarantee.

Withheld discriminator: Add an initializer to extern int x and explain the resulting definition obligations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0201c"></a>

## T02.01.c

Type aliases preserve compatibility; wrapping changes representation and member access. Ask the learner to expand typedefs mechanically at every use, not rely on spelling.

Withheld discriminator: Replace the alias with a wrapper structure and identify the required call-site changes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.02.a

Pointer completeness does not require pointed-to completeness. sizeof extensions accepted by a compiler must be labeled; opaque value fields cannot be embedded until complete.

Withheld discriminator: Expose opaque handles to two consumers and move an operation requiring layout behind the API. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0202b"></a>

## T02.02.b

Same-unit diagnostics are not proof that a linker sees incompatible cross-unit C types. The public declaration must be shared or independently checked.

Withheld discriminator: Change a callback parameter from signed to unsigned and explain why a function-pointer cast does not adapt it. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0202c"></a>

## T02.02.c

Wrappers improve type separation but do not automatically enforce range, dimensional algebra or physical meaning. A cast/field extraction can bypass discipline.

Withheld discriminator: Add multiplication/division of units and identify guarantees still requiring a specification. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.03.a

A prototype-scope tag can name a different type from a later tag. A prior file-scope forward declaration prevents the accidental split.

Withheld discriminator: Introduce a tag first inside a prototype and compare it with a later file-scope tag of the same spelling. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0203b"></a>

## T02.03.b

Typedef and variable names occupy ordinary namespace. A tag spelling can coexist with a typedef used as an alias, but not every ordinary redeclaration is permitted.

Withheld discriminator: Add a typedef with the same spelling as the ordinary variable and predict the conflict. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0203c"></a>

## T02.03.c

The defect is binding/ownership, not merely style. A callback requires an explicit context or returned result; a similarly named local does not update the caller.

Withheld discriminator: Move the inner operation into a callback and audit which status storage is captured explicitly. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.04.a

Symbol tables are observations and may omit optimized objects; the language declaration determines linkage. Functions have linkage but not object storage duration.

Withheld discriminator: Give two translation units identically named internal state and prove they are distinct objects. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0204b"></a>

## T02.04.b

Scope and prior declarations determine extern linkage. C17 register imposes address-taking constraints; compiler placement in a register is not guaranteed. Thread access/lifetime requires additional rules.

Withheld discriminator: Move the extern declaration into a scope where the prior declaration is hidden and reanalyze linkage. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0204c"></a>

## T02.04.c

Separate translation may hide the mismatch. Optimizer diagnostics can improve detection but do not redefine the language or remove the obligation to match declarations.

Withheld discriminator: Add LTO and compare newly detected mismatches without treating it as a conformance proof. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T02.05.a

Do not infer C23 from a C17 run. Record the later-edition source gap if unavailable; a cast or implicit old-style declaration cannot establish the intended contract.

Withheld discriminator: Compare the empty-list form under an actually inspected later edition and capability-test the compiler. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0205b"></a>

## T02.05.b

static bound is a minimum-access precondition on each call. The compiler need not insert a capacity test; null cannot satisfy a positive minimum.

Withheld discriminator: Add static4 inside array parameter brackets and explain the new caller precondition rather than claiming runtime checking. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0205c"></a>

## T02.05.c

Representational similarity cannot make an incompatible call defined. A compatible thunk still requires the context to stay alive for every invocation.

Withheld discriminator: Retain the callback asynchronously and add explicit context lifetime/cancellation ownership. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
