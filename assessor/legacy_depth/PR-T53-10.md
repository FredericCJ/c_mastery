## T53.10.a — Derive and defend the state, ownership and ordering contract for parallel reduction with deterministic partitioning.

Quotient/remainder partitions cover each element once, with sizes differing by at most1. Empty workers are legitimate if the API permits them. Ownership of input ranges and output partials is explicit; a checksum alone can hide duplicate/missing elements.

Reject: Equal chunk length is required for a correct parallel reduction.

Assessor discriminator: require the first state, result, ownership edge or schedule event that differs under the rejected explanation. A generic stress checksum or missing sanitizer finding is not a substitute for that witness. Confirm the claim stays inside the declared execution and source scope.

Delayed assessor check: Change to a noncommutative reduction and preserve the specified ordering across partitions.

## T53.10.b — Split an input range across1,2,4 CPUs with disjoint ownership, compute checked local sums and combine in fixed order. Include nondivisible lengths and empty partitions.

Mathematical associativity does not make signed overflow defined or floating-point addition associative. Failure must not publish a misleading total; visibility of partials follows completion synchronization. Dynamic job assignment and static partitioning have different evidence obligations.

## T53.10.c — Match a wide independent sum oracle, show distinct CPU execution and report wall time, CPU time and overhead. Do not infer physical speedup from emulator virtual CPU counts.

Different errors can cancel in a total; per-index identity detects duplication/omission. The integer sum oracle is independent arithmetic. Speedup is bounded by serial work and overhead, and emulatorTSC values are not physical throughput measurements.

Reject: A matching total proves all work executed exactly once and scaling is linear.

Assessor discriminator: require the first state, result, ownership edge or schedule event that differs under the rejected explanation. A generic stress checksum or missing sanitizer finding is not a substitute for that witness. Confirm the claim stays inside the declared execution and source scope.

Delayed assessor check: Move partials onto a shared cache line, predict coherence effects and obtain physical evidence before claiming the prediction measured.
