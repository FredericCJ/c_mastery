# PR-T46-07 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4607a"></a>
## T46.07.a

The current generation protocol is scoped to one initialized VM. Reset requires discarding old external handles unless a stronger identity scheme is introduced.

Expected relation: Occupancy and exact generation are checked; exhausted generation cannot alias an old handle; output is unchanged on refusal.

Withheld transfer discriminator: Add an arena-instance identifier to distinguish reset lifetimes.

<a id="t4607b"></a>
## T46.07.b

An arena provides bulk lifetime management, not tracing collection. Copying survivors requires preserving graph identity and handling cycles under a defined mapping.

Expected relation: Arena mode rejects the seventeenth allocation despite unreachable objects; collection mode has a different reclamation contract.

Withheld transfer discriminator: Use phased arenas and transfer a surviving graph to a new region.

<a id="t4607c"></a>
## T46.07.c

A root stack is a resource with capacity and lifetime. ISO C does not enforce balanced push/pop or prevent a client from retaining a stale handle.

Expected relation: External references must be rooted before allocating operations and discarded across reset; root-stack ownership is balanced on failure.

Withheld transfer discriminator: Allow two embedding clients with independently scoped root leases.
