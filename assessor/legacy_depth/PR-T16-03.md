# PR-T16-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1606a"></a>

## T16.06.a

Actual T[] storage avoids inventing typed objects in byte arrays. Occupancy metadata must not grant initialization it has not performed.

Withheld discriminator: Use a byte-only pool for variable client representations and narrow the API accordingly. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1606b"></a>

## T16.06.b

An embedded free link can conflict with a declared payload type unless represented through a valid union/byte/allocated-storage contract. Metadata choices affect legality as well as size.

Withheld discriminator: Payload has stricter alignment or no spare link-sized space; revise the representation. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1606c"></a>

## T16.06.c

Generation solves only finite identity reuse under its protocol. Comparing a pointer to an ended owner is not a portable validation strategy.

Withheld discriminator: The pool control object moves or is destroyed; identify the owner-token lifetime boundary. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
