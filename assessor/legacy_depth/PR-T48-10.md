# PR-T48-10 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4810a"></a>
## T48.10.a

The retained poison policy sacrifices availability to retain ownership. A new retry policy needs operation identity and recovery semantics.

Expected relation: Late completion cannot corrupt recycled memory because storage stays reserved; durable claims require the selected flush boundary.

Withheld transfer discriminator: Add a reset acknowledgement contract and identify exactly when reclamation becomes justified.

<a id="t4810b"></a>
## T48.10.b

The adapter must not let VM/store clients choose arbitrary device pages. Units and authority boundaries compose at the same call.

Expected relation: The image has1024 pages, eight sectors/page, and exclusive slice end83; out-of-range arguments cannot wrap into it.

Withheld transfer discriminator: Change sector size in a model and refuse unsupported real-device geometry.

<a id="t4810c"></a>
## T48.10.c

Guest restart, host process death and physical power failure are different experiments. The source and image identities are part of the observation.

Expected relation: The receipt proves only the executed QEMU/backend sequence; a no-flush lucky survival cannot satisfy the contract.

Withheld transfer discriminator: Use the storage simulator to cut a declared write/flush event and compare its distinct failure model.
