## T07.09.a — Set compiler, sysroot, linker script, and target libraries explicitly.

Compiler selection, memory placement and library compatibility are separate inputs; a missing target dependency is not silently replaced with a host library.

Reject superficial reasoning: Selecting a cross compiler supplies every target runtime and layout contract.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Selecting a cross compiler supplies every target runtime and layout contract.

Delayed assessor check: Change only the linker memory map and identify which compile artifacts may be reused and which link assertions must rerun.

<a id="t0709b"></a>
## T07.09.b — Control find-root behavior and host utility discovery.

Programs resolve as host tools; headers/libraries/packages resolve under the declared target policy. Deliberate host contamination must reject before running.

Reject superficial reasoning: Searching all prefixes until something links is a valid cross-build policy.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Searching all prefixes until something links is a valid cross-build policy.

Delayed assessor check: Add a target package with a nested dependency and verify its discovery obeys the same root policy.

## T07.09.c — Audit multilib and floating-point ABI selection.

Instruction availability and argument placement differ; no x86 runtime result validates Arm interoperability. Refusal to link can be correct evidence.

Reject superficial reasoning: Matching instruction set and object machine ID proves library ABI compatibility.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Matching instruction set and object machine ID proves library ABI compatibility.

Delayed assessor check: Change a fixed-prototype float function to a variadic boundary and revisit the argument rules.
