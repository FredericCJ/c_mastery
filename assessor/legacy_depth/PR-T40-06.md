## t40-06-a

Sender TOKEN_PENDING blocks DATA; receiver can hold permission. A lost ACK may pause progress but cannot grant both endpoints. Matching schema/unit/epoch is independent of transport ACK.

Remaining required work: Per-direction receipts, transactional upper acceptance and complete bidirectional/token/epoch integration remain required.

Transfer discriminator: Cancel token transfer with uncertain delivery and derive why a timeout cannot simply return permission to the original holder.

An expected value without its derivation, first-divergence diagnosis and observation scope is at most level1. Physical criteria cannot pass from a simulation or prose plan.

## t40-06-b

Checkpoints are per direction, so B checkpoint1 is a distinct receipt. Malformed or refused upper DATA cannot commit a new application effect. Retained EduSession has one checkpoint and increments effects before L6/L7 acceptance, so it does not implement these full obligations.

Remaining required work: Per-direction receipts, transactional upper acceptance and complete bidirectional/token/epoch integration remain required.

Transfer discriminator: Use a prepare/validate/commit protocol with a cached response; prove duplicate request replay does not reapply SET and capacity failure leaves the receipt unchanged.
