# PR-T44-05 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4407a"></a>
## T44.07.a

A memory detector may miss legal-address corruption. The analysis must name the abstraction property rather than only the addressability boundary.

Expected relation: Failed nonzero resize preserves old ownership; successful resize ends it; extent and initialized-value obligations remain distinct.

Withheld transfer discriminator: Change a physical out-of-bounds defect into a legal-address wrong-field write.

<a id="t4407b"></a>
## T44.07.b

Detector models and instrumentation coverage differ. The repair argument must precede the invalid transition, even when the report appears at a later use.

Expected relation: Actual diagnostic, silence, setup failure and unavailable results are separate; no UB output is prescribed.

Withheld transfer discriminator: Move the invalid value through copies before consuming it in a branch.

<a id="t4407c"></a>
## T44.07.c

Clearing one pointer does not revoke all copies. A safe protocol must close each access interval or prevent publication of escaping borrows.

Expected relation: The corrected contract preserves failure ownership and rejects the new boundary; stale aliases are not evaluated after lifetime end.

Withheld transfer discriminator: Introduce a borrowed callback view surviving beyond the call.
