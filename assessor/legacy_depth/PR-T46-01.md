# PR-T46-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4601a"></a>
## T46.01.a

A tagged C representation supplies no automatic exhaustiveness or type enforcement. Switch validation and programmer discipline implement the guest-language boundary.

Expected relation: Tags distinguish values; reference equality compares identity without dereferencing; field access separately validates liveness.

Withheld transfer discriminator: Add a new numeric tag and specify mixed-operation rules before implementing coercion.

<a id="t4601b"></a>
## T46.01.b

Converting the decoded unsigned bit pattern to a representable signed mathematical value avoids relying on an out-of-range signed conversion policy.

Expected relation: Raw codec may transport unknown instructions; verified load rejects them; every failure preserves destination and written length.

Withheld transfer discriminator: Decode on a changed data model and audit exact-width and CHAR_BIT assumptions.

<a id="t4601c"></a>
## T46.01.c

Format evolution needs an explicit compatibility policy. Ignoring unknown bytes without a length/version contract can desynchronize parsing.

Expected relation: Container bounds reject before publication; zero entry arity is enforced by verified entry rather than the raw transport contract.

Withheld transfer discriminator: Add an optional versioned section and define skip/reject behavior for old readers.
