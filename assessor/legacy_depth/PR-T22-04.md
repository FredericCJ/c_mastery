# PR-T22-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2208a"></a>
## T22.08.a

A reviewer must not infer independent evidence from authored reference code alone. Record reviewer identity/scope honestly and preserve unresolved findings.

Expected relation: Each finding names the violated contract,causal path,minimal trigger and repair regression; unsupported hypotheses are explicitly rejected.

Withheld transfer discriminator: Review the same mechanism after inlining or LTO and separate source-level ownership defects from changed machine-code observations.

<a id="t2208b"></a>
## T22.08.b

Static call graphs may miss dynamic dispatch. A trace covers a path rather than all paths; both evidence types retain their limits.

Expected relation: The map identifies every owner and publication point on the selected path and includes hidden callback effects.

Withheld transfer discriminator: Introduce a function table backend and update the flow map without assuming all slots share one implementation.

<a id="t2208c"></a>
## T22.08.c

Suppression of diagnostics,larger buffers or changed timing can hide symptoms. Assessment requires the mechanism and an independent regression,not merely a green run.

Expected relation: The reproducer separates hypotheses and the repair restores the stated invariant under both the original and competing cases.

Withheld transfer discriminator: Make the failure intermittent through a deterministic event scheduler and minimize the event order.

<a id="t2209a"></a>
## T22.09.a

Characterization can preserve bugs if used blindly. Mark which behaviors are normative,which are incidental and which are explicitly corrected contract changes.

Expected relation: The characterization suite detects the mutation and distinguishes contractual behavior from accidental implementation details.

Withheld transfer discriminator: Intentionally change one public guarantee and version its expectations while preserving unchanged ones.

<a id="t2209b"></a>
## T22.09.b

Git's exit-code protocol treats several nonzero statuses as bad. The wrapper must deliberately translate harness failures and untestable revisions before bisection.

Expected relation: The identified change is supported by the predicate and retained trace; build/harness failures are not falsely classified as the same defect.

Withheld transfer discriminator: Make adjacent revisions untestable and report the resulting culprit ambiguity rather than inventing certainty.

<a id="t2209c"></a>
## T22.09.c

Internal changes can alter ABI when layout is exposed. The compatibility claim must name its boundary and actual supported consumers.

Expected relation: The pure refactor preserves old consumer tests; the semantic change is named,migrated and tested separately.

Withheld transfer discriminator: Retain source compatibility but alter callback timing and classify the additional lifetime break.

<a id="t2210a"></a>
## T22.10.a

Debug paths,timestamps and build IDs may differ. Do not call unexplained differences reproducible,or assume identical bytes prove correctness.

Expected relation: Every binary resolves to matching symbols and build inputs; synthetic fixture hashes are never substituted for actual artifacts.

Withheld transfer discriminator: Change the compiler while preserving sources and state which reproducibility and behavioral claims must be revalidated.

<a id="t2210b"></a>
## T22.10.b

Known limitations remain visible in the release. Do not silently redefine old acceptance evidence around the new behavior.

Expected relation: A consumer can identify changed behavior,known limits and required migration without reading private source; examples obey failure contracts.

Withheld transfer discriminator: Deprecate a synchronous API in favor of deferred completion and revise the lifetime migration instructions.

<a id="t2210c"></a>
## T22.10.c

Use only disposable directories and synthetic data. A rollback test must cover consumer/data behavior,not merely copying the old file back into place.

Expected relation: Both installs are independently usable; rollback either succeeds under the stated format contract or clearly rejects an incompatible migration without losing the old artifact.

Withheld transfer discriminator: Make version2 write a new persistent format and design a reversible migration or an explicit rollback limit.
