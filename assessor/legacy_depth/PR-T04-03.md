# PR-T04-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0408a"></a>

## T04.08.a

The stored integer is not the physical quantity. Scale conversion can overflow and needs a rounding policy.

Withheld discriminator: Mix two sensor channels with different scales and derive conversion before addition. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0408b"></a>

## T04.08.b

Use quotient and remainder magnitude with a safe signed-range argument. Saturation is application behavior, not permission to overflow first.

Withheld discriminator: Change to ties-to-even and add positive/negative ties with both even and odd retained integers. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0408c"></a>

## T04.08.c

A local quantization bound does not automatically bound a chain; error multiplication and saturation must be considered separately.

Withheld discriminator: Compose two rounded multiplies and derive propagated error including the second operand magnitude. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
