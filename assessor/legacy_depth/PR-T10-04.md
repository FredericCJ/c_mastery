# PR-T10-04 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t1008a"></a>
## T10.08.a — Compare dynamic, static, and static-PIE startup requirements.

Static linkage can still retain startup/helpers and static PIE may relocate itself; each mode has a separate responsibility ledger.

Reject superficial reasoning: No PT_INTERP means no runtime initialization or relocations.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: No PT_INTERP means no runtime initialization or relocations.

Delayed assessor check: Add TLS and identify which previously sufficient minimal startup assumptions no longer hold.

<a id="t1008b"></a>
## T10.08.b — Build a deliberately small executable with stated retained support.

Behavior, ABI validity and declared closure must all hold; size is an additional resource observation. The visible gate does not force every short-write path.

Reject superficial reasoning: Reducing the executable to a small byte count proves correctness and independence.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Reducing the executable to a small byte count proves correctness and independence.

Delayed assessor check: Add bounded decimal formatting without printf and account for its maximum buffer and arithmetic-helper closure.

<a id="t1008c"></a>
## T10.08.c — Audit loader metadata rather than relying on file-size comparisons.

Static linking removes unresolved names while retaining implementation code; origin/call inspection is necessary. Unknown report formats fail closed.

Reject superficial reasoning: An empty final nm -u report proves there are no forbidden dependencies.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: An empty final nm -u report proves there are no forbidden dependencies.

Delayed assessor check: Enable LTO and explain why pre-LTO object reports cannot substitute for inspecting the final image.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A breakpoint at main can diagnose every startup failure.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Adding arbitrary padding or disabling optimization repairs any before-main fault.
