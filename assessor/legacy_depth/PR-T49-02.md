## T49.02.a

Copy-on-write is an implementation technique beneath distinct address-space semantics. Thread object lifetime and synchronization remain explicit.

Expected relation: Each lifetime has one accountable owner/reclamation event; reference count reaches zero at step5 only in the declared model.

Withheld transfer discriminator: Open a descriptor before fork and distinguish shared offset from private memory.

## T49.02.b

Successful nominal probes do not cover partial construction. Cleanup must account for each acquired resource and the API's direct error-return convention.

Expected relation: No owned live entity is abandoned; thread-shared atomic work and process-private data behave as predicted.

Withheld transfer discriminator: Move worker arguments from static to scoped storage and prove the scope encloses every join.

## T49.02.c

A supervisor must preserve uncertainty when a worker dies before publication. The retained result and status are separate observations.

Expected relation: The report distinguishes lifecycle failure from report-channel failure and demonstrates all required reaping/joins.

Withheld transfer discriminator: Replace the result pipe with shared memory plus explicit synchronization and revisit visibility.
