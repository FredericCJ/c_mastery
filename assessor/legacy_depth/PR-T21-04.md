# PR-T21-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2110a"></a>
## T21.10.a

An additive checksum detects only a bounded class of corruption. Two compensating byte changes can preserve it, so it is not authenticity or comprehensive integrity.

Expected relation: The supplied valid vector decodes; truncated/bad records reject; persistence claims remain tied to the selected storage/reset model.

Withheld transfer discriminator: Simulate a reset between payload and commit-marker writes and define recovery selection between two slots.

<a id="t2110b"></a>
## T21.10.b

Debug identifiers bind artifacts but do not prove the captured address is trustworthy or that unwinding is valid after corruption.

Expected relation: Symbol correlation is accepted only for the recorded matching artifact; stale build identity5 rejects when4 is required.

Withheld transfer discriminator: Relocate the binary and explain how load bias and address kind affect symbolization.

<a id="t2110c"></a>
## T21.10.c

A useful crash report may coexist with a failed recovery. Physical persistence, reset and peripheral-state guarantees remain unvalidated without the corresponding dedicated target evidence.

Expected relation: Record acceptance and recovery success are separate results; the recovery procedure has its own preconditions and verification.

Withheld transfer discriminator: Allow a repeated reset during recovery and derive an idempotent restart protocol under the explicit model.
