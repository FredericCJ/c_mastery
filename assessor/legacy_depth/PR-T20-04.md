# PR-T20-04 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2008a"></a>
## T20.08.a

A configuration schema must describe relationships among fields, not just their individual types.

Expected relation: Admission limit never exceeds actual storage; build features and runtime settings are recorded independently.

Withheld transfer discriminator: Make a build feature alter public struct layout and require explicit ABI/version handling.

<a id="t2008b"></a>
## T20.08.b

Keep both identities when needed: raw bytes support provenance, normalized values support semantic equivalence. A hash alone is not an authenticity claim.

Expected relation: Canonical identity distinguishes real policy changes while documented encoding differences normalize; invalid combinations reject unchanged.

Withheld transfer discriminator: Add an unknown required field versus an unknown optional field and define forward compatibility deliberately.

<a id="t2008c"></a>
## T20.08.c

Avoid self-referential manifests and nondeterministic timestamps when claiming byte reproducibility. Identity binding supports traceability, not correctness by itself.

Expected relation: All evidence resolves to its actual source, flags, generated inputs and artifact digest; stale results cannot count for the new build.

Withheld transfer discriminator: Rebuild in a relocated directory and classify path-dependent versus semantic identity changes.

<a id="t2009a"></a>
## T20.09.a

This is a design/contract analysis, not an exploit. No host security configuration or external target is changed; isolation claims require later authorized platform evidence.

Expected relation: Range/status validation can reject malformed results; arbitrary memory writes within shared privilege are outside that guarantee.

Withheld transfer discriminator: Design a process-isolated adapter with bounded IPC and enumerate new crash,timeout and shared-memory lifetime obligations.

<a id="t2009b"></a>
## T20.09.b

Resetting an error streak after success is part of this model, not a universal recovery policy. Restart bounds must state their window/time assumptions.

Expected relation: Modes are normal,normal,degraded,normal,stopped; reporter failure cannot recursively restart or erase the original cause.

Withheld transfer discriminator: Make recovery require reinitializing two dependent adapters and derive rollback if the second restart fails.

<a id="t2009c"></a>
## T20.09.c

Checks contain the specified malformed-value model. They do not protect against an adapter that directly corrupts memory or violates C calling/lifetime rules.

Expected relation: Malformed results become explicit contract faults with no out-of-bounds indexing or duplicate release; ordinary timeouts remain distinguishable.

Withheld transfer discriminator: Allow valid positive progress plus terminal failure and revise validation without rejecting that supported combination.

<a id="t2010a"></a>
## T20.10.a

An impossible combination must be identified rather than hidden behind an abstraction. Copying can satisfy retention isolation at a quantifiable storage/traffic cost.

Expected relation: Each decision cites a requirement and a measured or derived assumption; unsupported properties remain open.

Withheld transfer discriminator: Require caller reuse immediately while transport retains data and choose copying or a revised API with explicit costs.

<a id="t2010b"></a>
## T20.10.b

Coverage graphs are navigation, not proof. Distinct objectives may share artifacts only if their assessment conditions remain independently visible.

Expected relation: Every link has a specific observable obligation; the ineffective test is identified even though the graph is complete.

Withheld transfer discriminator: Share one test across two requirements and add separate assertions/rubric entries for each.

<a id="t2010c"></a>
## T20.10.c

A decision revision is evidence-based when it explains which proof or measurement ceased to apply. Old successful traces remain historical, not proof of the changed system.

Expected relation: The revised decision identifies invalidated bounds and new observable behavior without rewriting historical evidence.

Withheld transfer discriminator: Restore the old workload but add a stricter recovery requirement and determine whether the earlier design becomes appropriate again.
