# PR-T03-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0307a"></a>

## T03.07.a

The allocator supplies storage; initialization supplies values/invariants. The callback that owns partial construction must roll it back before the slot frees storage.

Withheld discriminator: Make initialization allocate a subresource and specify partial rollback ownership. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0307b"></a>

## T03.07.b

Representation copying requires a valid source and appropriate destination storage. Arbitrary external byte patterns can violate representation and invariants even when the size matches.

Withheld discriminator: Use a byte wire decoder that assigns fields into an actual T instead of treating arbitrary bytes as T. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0307c"></a>

## T03.07.c

Alignment, effective type, initialization and cleanup are independent. Nonlocal callback exits or reentrancy can break the existing state machine unless excluded or explicitly modeled.

Withheld discriminator: Add a stricter-aligned second type and a potentially failing destructor with an explicit new state machine. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.08.a

Character inspection is a special rule. Matching representation size alone is insufficient; signed/unsigned corresponding types and specified aggregate relationships need the actual rule, not a blanket ban.

Withheld discriminator: Embed the int in an aggregate and identify the relevant permitted aggregate relationship. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0308b"></a>

## T03.08.b

Union-member interpretation has specified representation caveats and can yield a trap; it is not a general byte decoder. memcpy does not authorize reading a representation invalid for the destination type.

Withheld discriminator: Decode a synthetic wire integer by shifts into a typed value and compare with host representation copying. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.08.c

Disabling an optimization can suppress a manifestation without changing ISO semantics. A compiler-specific alias attribute needs its documented scope and cannot establish unrelated lifetime or alignment properties.

Withheld discriminator: Port to another compiler with different alias extensions and identify arguments needing replacement. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.09.a

The rule is relational over an execution. Read-only aliasing and modified-object aliasing differ; restricted pointer assignment across nested lifetimes has additional constraints.

Withheld discriminator: Move the helper into a nested block and analyze permitted outer-to-inner restricted-pointer assignment. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0309b"></a>

## T03.09.b

A documented in-place branch can use a single association, while a two-restricted-parameter contract may have different obligations. Do not execute a violating call merely to see whether it appears to work.

Withheld discriminator: Allow exact in-place transform but reject partial overlap; derive the new API partition. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.09.c

A compiler report is evidence of a transformation, not a universal speed claim. Include setup, memory traffic and uncertainty; do not count omitted checks as an equivalent implementation.

Withheld discriminator: Change alignment or data distribution while retaining alias guarantees and explain which performance inference changes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.10.a

The live owner and never-reused token are explicit premises. Raw pointer escape bypasses the handle checks; a wider finite counter delays rather than proves absence of wrap.

Withheld discriminator: Allow generation wrap and exhibit a stale-token collision before choosing exhaustion or a stronger lifetime bound. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0310b"></a>

## T03.10.b

Do not invent a universal provenance semantics. A base lifetime violation can already settle a case; other low-level idioms require a bounded authority and may remain unresolved.

Withheld discriminator: Inspect an accessible proposal revision and compare one reconstruction example with the existing C17 argument. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.10.c

An integer encoding may discard information beyond numeric bits on a target. A checked table moves validation into an explicit protocol but still needs a live owner and finite-identity policy.

Withheld discriminator: Replace pointer tags with an index/generation table and compare representation size and lookup cost. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
