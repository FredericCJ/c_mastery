# PR-T03-05 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0314a"></a>

## T03.14.a

Use sanitized local controls only to observe their bounded defect, never as expected-output semantics. Setting one pointer to null does not invalidate its aliases. Correct overlap policy and owner transitions repair mechanisms; shared counts alone do not synchronize payload access.

Withheld discriminator: Change unique ownership to shared references and add a concurrent borrower; separate release accounting from access synchronization. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0314b"></a>

## T03.14.b

The standard supplies a particular initial-member/structure relationship, not arbitrary recovery from any equal-typed address. A general container_of idiom must document its compiler/model assumptions.

Withheld discriminator: Use a member at offset0 and identify what the specific initial-member conversion rule establishes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T03.14.c

Allocator layout and optimization can hide or expose a defect. A proof about a bounded model and a target run answer different questions; neither should be inflated into universal mastery.

Withheld discriminator: Change allocator/compiler/lifetime schedule and predict which original tests cease to discriminate the defect. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
