# PR-T47-09 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4709a"></a>
## T47.09.a

Recovery is interpretation of durable evidence. A plausible page alone does not establish a complete transaction history.

Expected relation: Only a complete generation-consistent batch replays; failure reports retain image evidence and no fresh format occurs.

Withheld transfer discriminator: Add a stale valid marker older than the selected checkpoint and justify its treatment.

<a id="t4709b"></a>
## T47.09.b

Idempotence is a property of the logged operation and protocol. It is not supplied automatically by calling the process recovery.

Expected relation: Repeated full-page replacement yields the same recovered map; logical increment replay would require a different idempotence mechanism.

Withheld transfer discriminator: Replace after-images with logical operations and design sequence/deduplication metadata.

<a id="t4709c"></a>
## T47.09.c

The parent excludes checksum collisions and lying flushes. Demonstrating those limits is valuable but does not falsify a theorem that explicitly excludes them.

Expected relation: Post-acknowledgment corruption is not silently accepted as an old transaction; failure images remain preserved and unsupported faults are explicit.

Withheld transfer discriminator: Construct a CRC collision analysis and explain why checksum validity cannot authenticate data.
