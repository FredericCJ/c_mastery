# PR-T16-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1604a"></a>

## T16.04.a

A mark is capability metadata,not an allocation owner. Commit changes checkpoint structure while storage may remain governed by an outer scope.

Withheld discriminator: Add commit-inner that preserves allocations but removes the checkpoint and define outer rollback semantics. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1604b"></a>

## T16.04.b

A numerically valid surviving object can contain a dangling logical reference. Lifetime architecture includes outgoing references,not just allocation intervals.

Withheld discriminator: A persistent object temporarily borrowsB; require borrow end or promotion before rollback. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1604c"></a>

## T16.04.c

Runtime token validation is bounded by representation and owner lifetime. It cannot enforce all C aliasing discipline automatically.

Withheld discriminator: Escape through a callback-retained pointer and redesign the API to prevent or document it. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.05.a

The top token must identify allocation identity,not only a reused offset. Metadata restoration includes padding/headers charged at allocation.

Withheld discriminator: Add zero-sized requests as rejected operations and prove they cannot manufacture indistinguishable top tokens. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1605b"></a>

## T16.05.b

The two stacks can have different storage,lifetimes and failure behavior. Compiler scope does not invoke arbitrary C cleanup callbacks.

Withheld discriminator: A longjmp skips the manual cleanup path; define a supported control-flow restriction or recovery owner. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1605c"></a>

## T16.05.c

Destruction failure cannot justify silently abandoning remaining owners. The protocol defines whether cleanup is no-fail or records failures while continuing.

Withheld discriminator: A cleanup callback reports failure; specify error aggregation and continued cleanup. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
