# PR-T07-01 supplemental assessor analysis

Assessor only. The accepted project remains the implementation contract. These arguments are authored technical expectations, not fresh experiment or learner evidence.

<a id="t0701a"></a>
## T07.01.a — Invoke preprocessing, compilation, assembly, and linking independently.

The defined input returns exit 0; preprocessing resolves BIAS, compilation produces assembly, assembly produces relocation-bearing objects, linking resolves step. Removing step.o fails at link, not preprocessing.

Reject superficial reasoning: A successful compiler invocation necessarily produced a runnable image.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A successful compiler invocation necessarily produced a runnable image.

Delayed assessor check: Replace main with a separately supplied assembly entry and show which driver-provided startup responsibilities must now be supplied.

<a id="t0701b"></a>
## T07.01.b — Explain each intermediate file and its consumers.

The frozen .i retains 7; the fresh path uses 9. Only preprocessing consumes that header. Object code is not a portable serialized C program.

Reject superficial reasoning: Every downstream stage re-reads source headers.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Every downstream stage re-reads source headers.

Delayed assessor check: Introduce a macro selected by a generated header and diagnose a stale .i even when all .c timestamps are fresh.

## T07.01.c — Reproduce a compiler-driver command using explicit stages.

Driver invocation contains additional target/runtime inputs; equal exit results do not prove byte identity. A failed explicit link must be attributed to a specific omitted input.

Reject superficial reasoning: Replacing the compiler driver with ld and the same two object filenames reproduces its contract.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Replacing the compiler driver with ld and the same two object filenames reproduces its contract.

Delayed assessor check: Reconstruct a static or PIE variant supported by the installed toolchain; identify changes to both compile and link assumptions.

## T07.02.a — Distinguish target triple, CPU, ISA features, and ABI.

Reject superficial reasoning: Changing -march changes the operating-system ABI and sysroot.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Changing -march changes the operating-system ABI and sysroot.

Delayed assessor check: Compare two Arm objects with identical CPU instruction support but different floating-point calling conventions.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Only explicit source paths are inputs to the build.

## T07.02.c — Separate host tools from target executables during cross-compilation.

Generation executes the host tool; compilation only consumes its bytes. A missing generator is configuration failure, not evidence that the target lacks a feature.

Reject superficial reasoning: A cross-build can run any executable it has just compiled.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: A cross-build can run any executable it has just compiled.

Delayed assessor check: Replace the generator with a separately compiled host C tool while the application compiler is a non-native target compiler.

## T07.03.a — Select warnings according to target, edition, and project boundaries.

Const assignment violates a constraint; unused-parameter policy is tool-specific; absence of diagnostics does not justify signed overflow. Record C17 and any C23 probe as distinct modes.

Reject superficial reasoning: Warning-free code is necessarily defined, and every warning is required by ISO C.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Warning-free code is necessarily defined, and every warning is required by ISO C.

Delayed assessor check: Port the policy to a compiler that spells or groups the warning differently without accepting a missing diagnostic.

## T07.03.b — Test expected warnings and expected compilation failures.

Discriminator: Require the causal argument above and an independent artifact or trace that discriminates it from: Any nonzero compiler exit validates an intended negative test.
