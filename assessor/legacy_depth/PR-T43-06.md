# PR-T43-06 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t4307a"></a>
## T43.07.a

The maximum of two timestamps is sufficient only for the parent two-actor model. Adding callbacks introduces a distinct access interval that must be closed.

Expected relation: Release follows the final accessor boundary, which may include callback return and caller return; cancellation intent does not establish quiescence.

Withheld transfer discriminator: Permit a callback to enqueue a successor using the same owner and derive the new lifetime interval.

<a id="t4307b"></a>
## T43.07.b

Cohort latency and window throughput use different populations. Boundary censoring must not silently turn unfinished operations into fast successes.

Expected relation: Union time never exceeds the enclosing window; throughput counts the declared completed class and excludes or separately reports censored operations.

Withheld transfer discriminator: Use a sliding observation window containing requests submitted earlier.

<a id="t4307c"></a>
## T43.07.c

Accounting aggregation and overlap explain the sign. Different APIs may include children or use different units; their contracts must be checked.

Expected relation: Process CPU may exceed elapsed; wall-minus-CPU is not a universal wait metric and per-thread measurement excludes other threads.

Withheld transfer discriminator: Include a child process and determine which CPU accounting clocks change.
