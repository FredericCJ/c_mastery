# PR-T17-01 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1701a"></a>

## T17.01.a

Units belong to the mathematical problem. A relative error denominator near zero requires a deliberate alternative,not an arbitrary pass threshold.

Withheld discriminator: Convert millivolts to volts and derive which tolerances/conditioning measures remain invariant. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1701b"></a>

## T17.01.b

An exact algorithm for the wrong model can remain inaccurate. No real sensor measurement or physical validation is claimed from synthetic inputs.

Withheld discriminator: Change the model to include nonlinear response and determine what old implementation evidence still applies. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1701c"></a>

## T17.01.c

An oracle must state which problem it solves. Comparing against the wrong input interpretation can misattribute conversion error to the algorithm.

Withheld discriminator: Use a nonexact decimal input and distinguish the intended decimal rational from the represented binary input. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1702a"></a>

## T17.02.a

Classic Kahan can still return0 for this ordering; do not replace a derivation with the slogan compensated means exact. Pairwise grouping also matters.

Withheld discriminator: Implement an alternative compensated scheme with different assumptions and compare the actual update equations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1702b"></a>

## T17.02.b

Magnitude ordering is a heuristic under a specific error model. Severe cancellation can amplify small absolute errors into large relative ones.

Withheld discriminator: Sort by magnitude or sign groups and examine a counterexample before claiming universal improvement. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1702c"></a>

## T17.02.c

Changing execution topology changes rounding history. A deterministic tree does not by itself prove better accuracy,while a stronger exact accumulator requires new implementation evidence.

Withheld discriminator: Use a deterministic superaccumulator design sketch and account for storage,carry and final rounding. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T17.10.a

Precision alone does not remove correlated algorithm errors or incorrect modeling. Exact discrete cases are valuable anchors with explicitly limited scope.

Withheld discriminator: Compare two independent high-precision algorithms on an ill-conditioned case and report unresolved disagreement. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T17.10.b
