# PR-T49-01 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

## T49.01.a

The fixture is arithmetic only. It cannot establish that inline assembly names the right registers or preserves compiler assumptions.

Expected relation: The finite fixture translates -9 correctly; each boundary has a named authority and missing target assumptions remain explicit.

Withheld transfer discriminator: Move the wrapper to a second ABI and derive argument/error/clobber changes before reuse.

<a id="t4901b"></a>
## T49.01.b

This is hosted ABI work, not ISO C portability. The retained process/I/O probes are useful controls but cannot close this newly required wrapper task.

Expected relation: Exact requested/sent byte ledgers agree for valid writes; invalid descriptor produces the expected translated error; assembly constraints survive O0/O2.

Withheld transfer discriminator: Use a nonblocking pipe with less free capacity than the requested transfer.

<a id="t4901c"></a>
## T49.01.c

The injection model fixes otherwise nondeterministic events. A real trace and a model trace have different evidentiary scopes.

Expected relation: Positive progress advances exactly that prefix; retryable zero-progress errors preserve it; no loop treats a negative result as size_t success.

Withheld transfer discriminator: Change the destination to a record-oriented contract and explain why byte-stream recovery no longer suffices.
