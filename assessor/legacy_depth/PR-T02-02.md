# PR-T02-02 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t0206a"></a>

## T02.06.a

The tagged protocol should prescribe explicit int/double actuals after caller conversion. General va_arg rules include narrow exceptions; do not claim every nonidentical spelling is necessarily UB.

Withheld discriminator: Change the target to a model where unsigned short does not fit int and revisit the tag contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0206b"></a>

## T02.06.b

va_list representation is implementation-defined. A helper consuming a passed list can invalidate caller traversal; use the inspected ownership rules, not a successful array/pointer ABI accident.

Withheld discriminator: Move the sizing traversal to a helper and specify whether it borrows a pointer to the list or consumes its own copy. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0206c"></a>

## T02.06.c

A tag describes a convention; the callee cannot inspect missing or differently typed unnamed arguments safely. Unsupported tag can be rejected before consuming its unknown payload; mismatched declared payload cannot generally be diagnosed at runtime.

Withheld discriminator: Replace varargs with an explicit tagged array and determine which validation and ownership checks become possible. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0207a"></a>

## T02.07.a

Expression trees and sequencing graphs are distinct objects. Do not infer left-first execution from the drawing layout.

Withheld discriminator: Replace effectful calls with precomputed temporaries and compare permitted observable traces. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0207b"></a>

## T02.07.b

Apply promotions before the usual arithmetic conversions. Host observations are not an independent type derivation; synthetic width16 is explicitly separate from actual unsigned int.

Withheld discriminator: Move a calculation from int32/uint32 to a model with wider int and identify which proof changes. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0207c"></a>

## T02.07.c

The conditional operator evaluates one selected operand but determines a common result type using both. A cast controls conversion, not validity of the original caller input.

Withheld discriminator: Change a signed range-check interface to size_t input and identify lost negative-input information. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0208a"></a>

## T02.08.a

Function execution sequencing and argument-expression sequencing differ. Require the learner to name the actual evaluations, not call every pair of effects arguments.

Withheld discriminator: Move an effect from inside a function body into an argument expression and rederive relations. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0208b"></a>

## T02.08.b

C11 function executions are indeterminately sequenced relative to relevant nonsequenced evaluations; do not transfer that guarantee blindly to modifications evaluating arguments. The exact expression must be analyzed.

Withheld discriminator: Make both emit functions modify shared scalar state inside their bodies and compare with argument-expression modifications. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t0208c"></a>

## T02.08.c

Sequencing repair can change a formerly permitted trace set. If one step fails after a side effect, rollback is a new obligation rather than something temporary variables provide.

Withheld discriminator: Preserve a required callback order while adding a failure between steps and specify partial progress. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
