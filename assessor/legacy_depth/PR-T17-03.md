# PR-T17-03 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

<a id="t1704a"></a>

## T17.04.a

A view contract must define zero dimensions without underflowing rows-1. Arbitrary pointer comparisons cannot generally validate overlap across objects.

Withheld discriminator: Allow a transposed view with two strides and derive a new extent formula. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1704b"></a>

## T17.04.b

Dependencies differ by operation. Output alias admission needs an access-order proof or staging,not a blanket permissive flag.

Withheld discriminator: Permit in-place vector scale but retain nonoverlap for matrix multiplication and justify the distinction. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1704c"></a>

## T17.04.c

Edge tiles need bounded loops. A layout optimization may change arithmetic order,and any performance claim needs actual target/workload observations.

Withheld discriminator: Use a padded3x1 right matrix with dimensions not divisible by block size. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1709a"></a>

## T17.09.a

Layout suitability depends on fields consumed together. A synthetic cache-line calculation is not a measured miss count.

Withheld discriminator: The kernel now needs x,y andlabel together; revise the access-pattern argument. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1709b"></a>

## T17.09.b

SoA improves some access patterns but adds cross-array consistency invariants. Swap-delete must update every associated mapping.

Withheld discriminator: Use sparse stable handles and account for indirection/locality costs. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1709c"></a>

## T17.09.c

A vectorization diagnostic is not a correctness proof. Compiler assumptions and arithmetic transformations must match the admitted API and error contract.

Withheld discriminator: Enable reassociation or fused operations and compare changed rounding/exception behavior. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
