# PR-T21-02 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2105a"></a>
## T21.05.a

A transaction over local state does not roll back an external effect. Strong guarantees need a bounded set of observable state and a justified commit protocol.

Expected relation: The parent strong contract leaves[1,2] unchanged; weaker variants must name valid partial state and recovery obligations.

Withheld transfer discriminator: Add an external notification that can fail after state publication and reclassify the achievable guarantee.

<a id="t2105b"></a>
## T21.05.b

A sequential strong guarantee does not automatically provide concurrent atomicity. Reader synchronization and old-state lifetime need additional proof.

Expected relation: All precommit failures preserve the old configuration; the successful commit establishes the complete new invariant.

Withheld transfer discriminator: Allow concurrent readers and derive a separate publication/reclamation protocol rather than relying on serialized tests.

<a id="t2105c"></a>
## T21.05.c

A volatile cache cannot provide durable deduplication across reset. State exactly which failure model the idempotency contract covers.

Expected relation: Repeated identical accepted requests do not duplicate the promised effect; same-ID/different-content is rejected or explicitly versioned.

Withheld transfer discriminator: Crash after effect commit but before recording completion and analyze the remaining ambiguity.

<a id="t2106a"></a>
## T21.06.a

Returning control to the caller can leave an owned in-flight operation. The API must expose that ownership rather than let stack context disappear.

Expected relation: Exactly one terminal result occurs; timeout alone releases nothing; acknowledgment and completion have distinct protocol meanings.

Withheld transfer discriminator: Let cancellation be best-effort with no acknowledgment and define a safe ownership strategy or expose impossibility.

<a id="t2106b"></a>
## T21.06.b

A local status captured before callback invocation can be returned safely without rereading freed state. The complete callback contract decides what destruction is legal.

Expected relation: No implementation access follows a receiver permitted to destroy the operation; retained resources are released in the promised order.

Withheld transfer discriminator: Move completion to another thread and state which synchronization protects publication and reclamation.

<a id="t2106c"></a>
## T21.06.c

Never validate a generation by dereferencing already reclaimed memory. The event producer must use stable dispatch storage or quiescence guarantees.

Expected relation: Old-generation notifications cannot affect the new request; same-generation duplicates cannot release twice; owner lifetime remains an external precondition.

Withheld transfer discriminator: Exhaust the finite generation range and choose retirement or a proven quiescent reuse policy.
