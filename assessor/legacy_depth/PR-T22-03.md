# PR-T22-03 supplemental assessor analysis

Assessor-only; author reasoning, not independent or learner evidence.

<a id="t2206a"></a>
## T22.06.a

ctypes default return assumptions can be unsuitable for pointers. Correct declarations are a prerequisite; an observed small address is not evidence that an incorrect declaration is safe.

Expected relation: Foreign declarations match the actual public ABI; no private struct layout or default-int return is guessed.

Withheld transfer discriminator: Run a supported32-bit consumer or mark it unavailable, then revisit pointer/size_t/calling-convention assumptions.

<a id="t2206b"></a>
## T22.06.b

A negative version test must exercise actual installed artifacts, not mocked version numbers alone. Keep source,ABI and semantic compatibility claims separate.

Expected relation: Supported pairs preserve behavior and ownership; unsupported pairs fail at the declared boundary without out-of-bounds descriptor reads.

Withheld transfer discriminator: Allow a compatible larger descriptor prefix and define forward-compatible unknown-field behavior.

<a id="t2206c"></a>
## T22.06.c

A Python bytes conversion may copy data while obscuring the original pointer needed for release. Select representations that preserve the declared ownership protocol.

Expected relation: Length controls bytes including embedded zero; exactly the creating owner releases; retained callbacks remain live until quiescence.

Withheld transfer discriminator: Change the API to caller-owned output storage and compare copying,capacity and failure guarantees.

<a id="t2207a"></a>
## T22.07.a

A lockfile alone may omit compiler runtimes or generated artifacts. Provenance is evidence of origin, not a proof of correctness or permission to redistribute.

Expected relation: Every observed target dependency has provenance; host-only tools are separately identified and unexpected implicit helpers are investigated.

Withheld transfer discriminator: Enable LTO or change compiler and repeat the dependency audit for newly introduced runtime support.

<a id="t2207b"></a>
## T22.07.b

Do not infer originality merely from renamed identifiers. Conversely, using a conceptual technique does not automatically mean a file was copied; document the actual process and evidence.

Expected relation: The provenance record matches actual source and dependencies; comparison tools remain outside the mechanism being assessed.

Withheld transfer discriminator: Replace the oracle with an independently derived model and compare what independence does and does not establish.

<a id="t2207c"></a>
## T22.07.c

This is provenance and question identification, not a blanket legal opinion. A real distribution decision requires appropriate current authority; missing information blocks that claim, not the technical exercise.

Expected relation: The ledger points to actual texts and covered artifacts; unresolved distribution obligations remain unresolved rather than approved by inference.

Withheld transfer discriminator: Change distribution from source-only to a linked binary and list which questions require fresh analysis.
