# PR-T16-06 additive assessor analysis

Withheld from learner distribution. Author analysis only; retained historical evidence is not relabeled as fresh acceptance.

## T16.10.a

The baseline generic coalescing fixture is not sufficient buddy evidence. This task supplies a precise required allocation/split history.

Withheld discriminator: Base address is not aligned to64; use relative offsets with a separately proved base contract. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

<a id="t1610b"></a>

## T16.10.b

Buddy identity includes region and order. General pointer-to-integer assumptions are not ISO allocator proofs.

Withheld discriminator: Use multiple disjoint regions and prevent cross-region coalescing despite adjacent numerical addresses. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.

## T16.10.c

A finite number of operations can have unbounded wait if a backend blocks. Hard timing requires a separate scheduling/hardware argument.

Withheld discriminator: A shared allocator adds contention; derive a bounded admission policy or leave latency unresolved. Require the changed invariant or interface argument and distinguish the independent task from reproducing the public case.
