# T07 assessor solution and transfer guide

Withhold this directory and its generated source/command receipts from independent
assessment. Each Python module is an author reference experiment, not a student
implementation. `stages.py`, `graphs.py`, `packages.py` and `provenance.py` retain
the complete original solutions and discriminating controls. The original
`assessor/legacy_depth/PR-T07-*.md` supplies the per-leaf expected reasoning.

## Stages and diagnosis

Preprocessing substitutes BIAS, so a retained `.i` contains7 after the header
changes to9. The frozen executable returns the original success; a freshly
translated one disagrees with the caller's19 expectation. Removing step.o fails
symbol resolution. The assembly entry uses the Linux x86-64 entry contract,
aligns the stack before an ordinary call, and owns syscall exit. It supplies none
of a general hosted runtime's initialization. GCC's emitted link command includes
startup and library inputs absent from a bare `ld main.o step.o`. Static and PIE
reconstructions must expose their different program headers and link inputs.

The diagnostic runner accepts three *different classifications*: valid translation,
tool-policy warning, and constraint rejection. A missing header or compiler is
recorded but cannot prove const-assignment checking. An unresolved external can
survive compilation and fail only at link. Warning push/pop and a TU-local option
must leave the outer/unrelated warning intact. A warning-free signed-overflow
example remains undefined under the stated overflowing inputs.

## Restrict transfer

For `increment(out,in,n)`, require valid extents and, for every object modified
through `out`, no read through the independently restricted `in` association in
that block. Two disjoint arrays satisfy this. For n>0, passing the same array to
both violates the modified-object restricted-access requirement even though an
otherwise identical function without `restrict` could support in-place updates.
The reference executes only disjoint arrays at O0/O2 under both compilers. The
invalid caller is an assessor reasoning case, not a test with portable output.
Unsigned addition is modulo2^32; Python's unbounded sum followed by one reduction
is independent of the C loop's intermediate-width implementation.

NDEBUG must not remove checks needed for campaign acceptance. Sanitizers and
coverage introduce host runtime dependencies; LTO may change helper lowering and
resolution. Inspect the actual bitcode with the matching reader and the final
ELF separately. Empty `nm -u` on a linked artifact does not identify the origins
of definitions already linked into it. Stack protector code needs both a failure
handler and valid guard-initialization contract; providing a symbol with no such
argument is not a complete custom runtime.

## Graphs and package boundaries

The expected rebuilt set after a schema/header/generator change is step.o plus
program; main.o stays unchanged. A directory timestamp or unrelated input changes
nothing. A deleted generated header must be recreated before its consumer.
An invalid schema fails before either new header is published. One grouped recipe
prevents competing producer invocations; this only establishes graph-consumer
coherence, not arbitrary-reader crash atomicity. Alternatives include immutable
generation directories and an atomic manifest switch, provided all consumers bind
the same generation and old outputs have a lifetime policy.

The wrong order-only header graph returns stale7 after a change to9. Repairing
the ordinary edge produces9. Preserving the old header timestamp while changing
its bytes to5 fools freshness again; a complete input digest rejects the cached
identity and forces a rebuild. A digest over only direct source files would miss
the header and is not a repair. Account for full-input hashing costs and trusted
manifest provenance separately.

Tiny's public layout macro is a compile requirement. Support's call is a static
final-link requirement even when its type is private. A public Support type also
requires its include contract to cross the boundary. Two consumer helper values
remain distinct; placing Tiny's private include path first supplies99 and fails
the consumer's check. Avoid claiming PRIVATE means “absent from any final static
link.” The relocated installed export can refer to namespaced dependency targets;
the consuming package resolves their locations. An absolute producer include or
library path is a counterexample to relocatability.

The database represents translation commands, not generation or link commands.
Output/configuration identity distinguishes two commands for one source. Preserve
argv arrays for a macro containing a space. Ninja tracks command changes and
explicit/discovered input edges; it can represent an absolute and relative header
name as distinct nodes. Regenerate the compilation database after relocation.

## Target and supply-chain transfer

The native ELF is64-bit x86-64; the foreign ELF is32-bit Arm. This is a measured
artifact fact, separate from the compiler's advertised target. Softfp and hard
objects can use the same FPU instructions while assigning fixed-prototype floating
arguments differently. Their unsafe combination must be rejected by the safe link
experiment. The variadic boundary follows the base PCS; inspect actual stack,
argument and conversion-helper code rather than extrapolating fixed-prototype rules.

The CMake host generator is executed by an explicitly native compiler build; the
foreign target is compile/link-only until the separately named emulator exercise.
The QEMU lm3s6965evb experiment has its own Cortex-M3 image and semihost contract;
it neither runs the earlier Cortex-M4 object nor validates board peripherals.
Root modes apply recursively to nested packages. The deliberately wrong host
header is rejected by the target selection constraint before any foreign execution.

A dependency version label is not a source hash. Corruption, omission and a
same-label patch fail content verification; a renamed label with identical bytes
demonstrates the distinction. Generated outputs must bind generator and config too.
The three acquisition paths can agree on Tiny(4)=12 while carrying different update
ownership. The offline specimen sets FetchContent disconnected options and an
explicit prepopulated local source path; deletion fails in a fresh output tree.
It neither invokes a downloader nor changes host networking. A source hash from
an untrusted manifest does not authenticate origin.

## Reproduction and delayed release

Whole-file identity, section identity and agreement on the declared computation
are separate claims. Printed path/timestamp metadata remain observable behavior;
do not call the two raw programs wholly observationally equivalent merely because
both compute19. Path mapping does not rewrite an arbitrary generated timestamp.
Only after explicitly normalizing those inputs does the same compiler reproduce
the full binary in this bounded experiment. A different compiler's same numerical
answer supports only that declared computation, not ABI or byte equivalence.

Deterministic archive metadata does not erase member order. With duplicate `choose`
definitions, archive extraction changes actual exit1 versus2. A generated table
with duplicate keys and first-match lookup similarly changes meaning when reordered.
Neither difference is harmless metadata to normalize away.

Issue each original delayed variant after at least seven days. Supply the changed
graph, package, root or input through the original public task, not these solutions.
Require the learner's prediction, fresh artifact identities, first-divergence
diagnosis and a new incorrect control. Record assistance and objective-specific
scores independently. Valid alternatives may use another correct build layout,
dependency cache or publication representation if they satisfy the same observable
contracts and accurately state different costs and assumptions. The finite author
matrix cannot certify absolute mastery, external review or physical execution.
