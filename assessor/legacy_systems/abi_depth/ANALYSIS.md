# T08 assessor analysis and delayed package

Withhold this directory and generated experiment sources from learner exports.
The executable producer imports the existing `assessor/machine_image/sum.S` and
`abi.c` explicitly. Those are reference artifacts, never learner submissions.
The six core profiles and each separate experiment assess only the named contract.
Use the corresponding original AX criterion IDs; no new duplicate objective IDs.

The public contract supplies progression and a common 0–3 rubric. The following
discriminators are mandatory additions to each criterion's existing expected
analysis. Before revealing a result, obtain the learner's prediction and provenance.
Do not accept a correct number whose explanation permits the stated counterexample.

Accept alternate assembly, typed wrappers, or independent layout encodings when
the complete contract is equivalent. Reject an alternative that merely passes
visible values while relying on callee scratch preservation, binary padding,
unmatched CFI, unspecified signed conversion, or an undeclared target helper.
