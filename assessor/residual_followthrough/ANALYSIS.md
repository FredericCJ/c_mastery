# Residual parent evidence assessment

This package reconciles original aggregate requirements with already executed,
mechanism-specific successors. It does not replace a missing implementation with
a status. The clause map is explicit; the source audit verifies actual sources,
logs and generated artifacts against their recorded hashes. Every original
criterion and original variant remains in the mapping with its own provider,
task, rationale and command selectors.

Reject a mapping if its child set is merely a domain count, if it omits a delayed
condition, or if the linked source only addresses a neighboring mechanism. In
particular, T23 read/EOF/partial-write, operation-specific retry, and atomic
effect/receipt publication use different children. The alternate-OS close task
is partial. A Linux syscall wrapper that retires a descriptor before injecting
EINTR cannot establish retained-descriptor behavior in another kernel.

For T36, the repaired ancestor-dominance premise and multi-ancestor AVL deletion
are explicit analyses with counterexamples and actual reference executions. The
new wrapper and sparse-frontier source must be imported; the older generic/matrix
anchors cannot substitute for it. Assembly admission and kernel work have
different counters. A red-black certificate comparison does not implement a
red-black update algorithm.

The serial/Ethernet/seven-layer/network mappings preserve their distinct physical
requirements. Register adapters and CPU images provide author implementations,
not cable, transceiver, pin voltage, propagation, setup/hold or DMA observations.
The T38 dual-rate peer exchange and T39 physical board origin remain unobserved
in the physical dimension even though their software and capture protocol exist.

The T43 through T50 parents bind every original ordinary/changed pair, but their
closure rationale additionally names the mechanism in the aggregate requirement.
The source-current receipt checks do not rerun the original performance campaign,
promise all interleavings, observe hardware counters, or convert emulated reset
into physical power-loss evidence. Original source-access gaps and physical
qualification limits remain explicit.

The T52 defect has a concrete regression witness: stop at raw100/logical100,
incorrectly advance the stopped logical clock at raw110, then resume at raw120
and count20 again to get130. The corrected admission rejects stopped operations
under the saved interrupt mask before mutation. The fresh existing guard checks
120 native +27 M4 +18 real emulated timer-port observations and compiles the old
port against the corrected tests. It requires a semantic failure, not a compiler
error, timeout or machine fault. The first Windows guard attempt failed because
its compiler subprocesses require Linux; the unchanged WSL guard passed32.

All historical bytes are retained. The existing POSIX launcher metadata successor
already proves unchanged criterion and execution fields while binding the current
card; use that successor rather than pretending the old support envelope is
current. The UART envelope refresh reruns its established metadata producer after
validating unchanged execution/output pins, and retains its prior bytes under
this package's history. Global exercise catalog refresh remains the root owner's
operation. No global inventory is changed by these tools.

External review, independent learner performance and elapsed delayed assessment
are not provided by this audit. Source authors and agents performing bounded
checks are not labeled independent human reviewers.
