# Hosted foundations assessor mechanisms

This directory contains an original reference implementation of the small contracts in `labs/foundations/include/foundation.h`. It is explicitly selected for author validation and assessor comparison; learner exports contain only the unsolved stubs. It is not a complete solution to all projects listed in the family manifest.

The size-check omission and unstable-sort mutants must fail their corresponding finite tests after the unmodified reference passes. Public fault/repair pairs are guided observations. A truly withheld assessment needs a new case, a sealed initial dossier and delayed reveal, with independence recorded. Do not award full objective mastery from a green automatic anchor.
