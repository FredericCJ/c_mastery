# Assessor: Domain restriction and reconstruction information

The optional composition is a total pair lens only on configurations whose two
presence flags are1. Put preserves that domain and changes only endpoint.x.
Prove each law by expanding the exact field tuple; no bytes or padding are
needed. The copied public representation does not enforce immutability or
disjoint live storage. Reject an answer treating absent as a default present
value: the missing information cannot be recovered through get-put.

Versioned IO review is injective on the declared focus set because the focus
contains version, code and context. Preview recovers all three, and review
reconstructs the complete active source. Code-only extraction is a useful
projection but is not this prism. A raw invalid C focus is outside the refined
domain; runtime refusal enforces admission, not a language-level refinement.
TIMEOUT in v1 is malformed, TIMEOUT in v2 is a nonmatch, and an unknown version
is distinguished from both. Do not read an inactive union field to compare
SUCCESS or TIMEOUT values.

The pure laws apply to pure get/put. The callback update operation deliberately
exposes effects and failure. Full callback-array validation occurs before any
call, avoiding effects before discovery of a malformed later step. Each result
is staged in a local uint32, copied to staged endpoint.x only on success, and
the entire output publishes after all steps. First-step effects persist when
the second fails. Thus output atomicity is not external rollback; duplicating
an identity callback is observable even if all configuration fields agree.

For the changed case, construction is a distinct authorized value operation:
the caller constructs a completely initialized present configuration, then
uses the partial optic. Neither setter nor callback update may invent a
missing branch. The version2 focus retains context values beyond255 while
version1 rejects them. A failing second step receives the first staged result
and leaves the prior public output unchanged. Require exact traces and all
original R1-R4 arguments rather than crediting one aggregate PASS.

The independent oracle models tuple replacement and explicit relation domains;
its effect traces contain callback counts and inputs, not only final values.
