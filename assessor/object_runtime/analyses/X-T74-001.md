# X-T74-001: assessor analysis

The tag partition is a local representation proof. Canonicalization collapses all numeric NaN payloads before the reserved integer prefix can be interpreted; the inverse integer decoder validates reserved bits and avoids out-of-range unsigned-to-signed conversion. uintptr_t round trip is conditional on the type existing and on a still-live original pointer. A forged word is outside that proof. Compare the union alternative with identical integer/number/pointer admissions, including NaN payload preservation policy. Delayed case: a capability ABI carries bounds outside integer address bits, so an index/generation handle plus explicit lookup replaces bit tagging.

0x7ff9000000000042 as numeric input canonicalizes to0x7ff8000000000000; int32 minimum round-trips as -2147483648; negative zero remains0x8000000000000000. A low-bit-misaligned pointer rejects without changing output.

# Required value and wire follow-through analysis

The new discriminated union separates integer, binary32 encoding and logical
handle values. Select the union member only after validating tag/reserved fields;
stage the complete result before assigning the output. For a payload above
INT32_MAX, `INT32_MIN + (payload - 2^31)` stays representable and avoids an
implementation-defined unsigned-to-signed conversion. An IEEE exponent/fraction
test, not a test of a native NaN value, canonicalizes all binary32 NaNs.

Character access can inspect or construct an object representation; it does not
prove that arbitrary bytes represent a valid double. Require the full native
format contract. Size/radix/precision/exponent and the1.0 representation reject
common mismatches but are not a mathematical characterization of every target
representation. Canonicalize NaNs before storing a native double. The supplied
round trips include both zeros, minimum/maximum subnormals, minimum normal,
maximum finite, both infinities and a supplied NaN payload.

The authority comparison is intentionally staged after X-T74-008. A wire handle
contains no heap identity or authority. Two heaps can both have slot0/generation1;
matching those numbers must not admit the wrong heap's grant. The positive
control retains the allowed object once; the flawed controls change a synthetic
root count without permission. No pointer is fabricated or dereferenced, and no
claim about hostile arbitrary writes or hardware capabilities follows.

Assess R2 with actual union and native-bridge code; R3 with the independent
binary32 rows and typed mutation controls; R4 with the cross-heap grant witness,
the staged prerequisite and the changed-target representation argument. A learner
who treats a successful numeric tag check as pointer authentication has not met
the criterion even if every ordinary round trip passes.
