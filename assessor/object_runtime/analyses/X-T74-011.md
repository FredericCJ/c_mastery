## Actual adapter solution and counterexamples

The implementation in object_runtime_vm.c copies the entire CVM before collecting, builds an ORGraph and stages all root locations. Marking determines a reachable set; stable destination assignment skips retired holes. Source generations must not be copied to new physical cells: old slot0/gen1 garbage and slot1/gen1 live data would otherwise let an old garbage handle designate the moved live pair. Use prior destination generation plus one. Preserve the prior physical generation of vacated cells. Full 32-bit generations are never packed into an eight-bit root slot; the frame holds an identity index and the adapter restores the destination generation afterward.

A compiled program first allocates garbage, then creates p=(77,88), passes it through middle(q) and leaf(r), and stops at a failing integer host callback. It leaves three actual CVM frames. The test adds operand/explicit/foreign copies of p, moves index1 to index0/gen2, and verifies every initialized local through actual cvm_field. Uninitialized poison is ignored; an integer1 remains1. ORV_MUTANT1 skips locals and ORV_MUTANT2 reuses the wrong generation. The other two controls omit foreign cleanup or success publication. A failure after a callback's allocation keeps that allocation but does not publish an output or retain stack-local registrations.

Registration uses actual algo_pool, including finite retirement and partial admission cleanup. The baseline testing and measurement artifacts are contracts rather than generic APIs; the new independent reachable-set model, exact cut schedule and source-bound cost runner implement those interfaces explicitly. The original nonmoving cvm_collect remains a second executable comparison. This is a stopped-state adapter, not a patched baseline dispatch loop or arbitrary exception resumption engine.

LLVM's default rewrite rematerializes derived pointers from a relocated base; the no-rematerialization option emits explicit relocated derived values. Actual lowering may still fold a constant-offset derived reference. The map parser must read all old locations before writing shared base slots. Updating one root while still reading another pair can corrupt the computation. Integer lookalikes must not be rewritten. The native controls read zeroed old storage or a live guard byte and fail an exact value assertion; they do not demonstrate arbitrary code execution.
