# Required pool and foreign-borrow follow-through analysis

The typed pool has three distinct locations: an external generation handle, its
identity entry, and the current physical cell. Collecting dead cells advances
identity generations, while packing preserves them. Reachability begins at
external roots and outstanding pins, so an otherwise unrooted cycle is dead and
a reachable cycle survives. A generation must not wrap; once slot generation4
is reached, new allocation skips it permanently.

For packing, first reserve every pinned physical position. Stage each other live
cell in identity order into the earliest unreserved position. Commit only
unpinned physical cells, then update their identity entries. Rewriting identical
pinned bytes would still be a conflicting access with the foreign reader.
The pinned alternative therefore differs materially from the existing global
borrow rejection policy: it permits other cells to move and may retain holes.

The four central lease controls reuse actual T66 OwPin state transitions.
Cancellation requests a stop but retains ownership. Only externally established
quiescence permits completion; the actual backend test waits for a real pthread
join before finishing. Central generation validation rejects a copied old ticket
after the slot is reused. The mutant prelude detects early unpin/stale completion
before creating a real worker, avoiding an intentionally leaked thread when the
expected assertion fails. Thread sanitizer observations complement, rather than
replace, the ownership proof and controlled interleaving.

Assess R2 with the packing-around-pins argument and generation exhaustion; R3
with all256 masks and the graph/cycle cases; R4 with actual separately compiled
foreign code, allocator-free typed pool operations, cancellation/acknowledgement
and raw-pointer expiry. The caller's premature completion cannot be diagnosed
from the ticket alone: it violates the documented quiescence precondition. A
well-typed C signature does not enforce that lifetime protocol.
