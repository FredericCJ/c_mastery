Require the learner to derive 3421780262 from the fixture inputs independently. Use a separate oracle algorithm or standard host library only for verification, never the target implementation.

Transfer answer obligations: Add a separately verified signature API that returns an explicit verdict and key identifier; inject fail-open and stale-key responses without implementing production cryptography in this exercise.
