# Assessor analysis: PR-T59-07

A core reset invalidates assumptions about peer-owned buffers and cached metadata. A notification is not the payload and does not prove every old-generation operation completed. Update coordination needs generation and quiescence together.

Prove no old-generation peer can retain writable storage at update commit. Separate cache visibility, notification delivery and logical acknowledgement.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: Repair acceptance of a stale acknowledgement after independent peer reboot. A memory barrier cannot repair the missing generation check.

Require the learner to derive 0 from the fixture inputs independently. A matching acknowledgement must refer to the current closed-admission generation.

Transfer answer obligations: Move shared metadata from noncacheable SRAM to cacheable SRAM; derive cache-line ownership/maintenance and repeat physical traces on the dedicated H745 board.

Real erase/program granularity, torn writes, cache maintenance, boot ROM interaction, watchdog reset and physical power-interruption evidence remain required on dedicated boards. Model success is not secure-boot certification.
