# FW-INSTALL assessor analysis

The authorization check occurs before erase starts. A valid signature alone does
not authorize destroying the current image: the authenticated base must also be
one inactive fixed slot and the generation must advance. The owner supplies a
trusted current selection, not an integer labeled active by an incoming packet.
The2144-byte owned copy fixes both source lifetime and padding;67 independently
completed256-bit writes include the signature stored at its fixed offset.

The public model stops at each of53632-bit stores without calling a completion
poll afterward. Visible full data in the final cut still does not publish output.
Every cut compares old actual signed envelopes/signatures and the committed
record byte-for-byte. Initial old-image admission and record construction are
real prior components; the finite cuts do not establish analog power-loss bounds.
Post-program fresh callback corruption must be caught by actual stored-byte
signature verification; checking only the original RAM buffer is insufficient.

Mutation1 removes the active-base refusal. Mutation2 skips actual signed storage
readback after a corrupting refresh. Both must fail FU_CHECK. Erase/program busy
states retain ownership; a timeout cannot safely reset software state or relock a
still-running controller. The target code and rodata must all remain in bank2,
including compiler-generated constants, exception handlers and crypto provider.
Undefined helper symbols or accidental bank1 text invalidate the target claim.

Installation output is not boot authority. The unresolved trial coordinator must
persist an attempted marker before entry, obtain application—not bootstrap—
health from both cores at the same generation, and commit only after quiescence.
The supplied target probe makes none of these claims and does not activate an
installed candidate. For the delayed variant, demand a reset at that precise
handoff/attempt boundary; do not accept a generic reset anywhere in the model.

The initial target link exposed a compiler-generated memcpy for policy structure
assignment. The failed source-bound receipt is preserved. Explicit semantic key/
policy field copying removes that hidden dependency; the final target campaign
must show no unresolved helpers, rather than quietly adding libc.
