# Assessor: durable trial intent

Keep this analysis out of learner packages. The complete implementation is `trial_intent.c`; the public implementation is intentionally incomplete. Use the shared fourteen-field exercise/rubric contract and retain failure traces.

The safety invariant is that only sector5 changes until a separate application-health commit protocol runs. Every reset in this stage must recover the old committed pair through actual signature+digest matching. Even a complete attempt is ignored on cold boot. This is conservative availability, not automatic retry. The parent check prevents reusing a record against a changed journal; exact attempt comparison prevents treating intent completion as launch authorization. Neither CRC is a security signature. A live released peer reauthenticates both candidate images and then requires the selected-startup mailbox match.

The writer validates/stages before erase, preserves controller configuration after completion, verifies32768erasedwords in batches32, and programs160bytes as five distinct fresh words. Hardware busy never releases ownership. No successful readback after a reset is used as proof of virgin ECC. Program-store cut40 can leave every attempt byte valid while the caller has not observed completion; cold fallback must still be old. Erase failure or a readback error cannot be repaired by merely retrying `fh_start` on the same word.

Withheld cases: old parent sequence2 with an otherwise valid sequence2 intent whose parent is1; valid images with a newly revoked key; one component with wrong generation; sequence exhaustion; a corrupted final reserved byte after the hardware reported success. `FT_MUTANT=1` omits parent binding and `FT_MUTANT=2` omits attempt completeness. The assertion that rejects each must fire on its specific valid counterexample. Do not count compilation failure as mutant detection.

For delayed transfer, demand a new durable retry protocol that addresses unknown partially programmed ECC, not merely an attempt counter in the existing word. Assess cleanup/ownership if the deadline expires while flash remains busy. Do not infer arbitrary ECC recovery or peer concurrency from the callback model. Code placement in bank2 addresses read-while-write instruction/constant access; stack/interrupt/DMA/other-core and physical qualification remain explicit preconditions.
