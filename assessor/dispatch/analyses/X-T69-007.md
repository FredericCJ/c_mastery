## Two-hook and movement technical analysis

A global linked bit fails as soon as one object enters two independently selected lists. Each hook needs its own owner and neighbors. On removal, repair predecessor.next and successor.previous before clearing membership; removing the last item repairs both sentinel links. The explicit parent avoids subtracting an arbitrary member offset, but its association and lifetime are still caller invariants. Fold additionally checks the selected parent member equals the actual hook and stages every callback output.

The index model stores all address-independent links in the moved typed array and keeps its authority/generations in the immovable control. Handle equality includes control identity. An old handle must reject after the slot is reused while live; checking only empty slots would miss the generation mutant. A released generation3 slot becomes retired4 and never enters the allocation scan again. At most12 acquisitions are possible, including successful ones later released.
