## Completed rubric transfer analysis

The byte view references a live receiver descriptor, whereas the scalar view references its actual nested int. Those addresses differ, and neither can be replaced by the enclosing object's address. The bytes table is static; the embedded table pointer is captured in the generated view. Changing the scalar value is immediately visible; changing its table requires reconstruction. Both negative controls keep C pointer types and object extents valid and therefore diagnose association rather than trigger undefined behavior. Rust E0515 rejects returning the local trait borrow; the C view has no comparable lifetime enforcement. Marker0 and trait-ref16 are observed Rust target facts, not universal ABI claims.
