# T65.03 private composition analysis

sf_start is the actual copied-frame producer; the adapter does not reimplement
its framing or handle generation. sf_pump accepts a signed count, so its bridge
must retain the er_transfer diagnostic out of band while returning admitted
positive progress. Otherwise the final-byte error is erased by SF_DONE. The
relative count is bounded by the offered suffix before conversion. An invalid
backend report preserves only the last known prefix and requires abandonment,
not automatic replay. Cancel is serialized between callbacks and cannot revoke
a still-running illegal borrower.

Accepted and durable are different coordinates. Known IO may accompany a larger
confirmed prefix; UNKNOWN cannot publish its untrusted fields. Epoch progression
is exactly one per advancing confirmation and checks exhaustion before callback.
The trusted reconciliation assertion is an application premise, not an inferred
proof from file contents. The native controller has separate actual fsync-success
knowledge; its lost reply experiment is not a simulated reboot or physical power
test. The unlinked file removes directory publication from the experiment.

Release after cancellation still requires explicit acknowledgement of an accepted
but unconfirmed prefix. Even a fully durable truncated frame does not become a
valid application transaction; the caller retains responsibility for external
framing/request recovery. Local memory release cannot undo that prefix.

For the sealed delayed attempt, vary the ordering of a partial confirmed epoch,
IO, final accepted bytes, lost acknowledgement and cancellation. Require the
learner to seal both coordinates and the authority for each transition before
providing feedback. The existing finite model and implementation support these
transitions; a fresh input ordering is not evidence that this learner already
transferred the argument independently. Ask which guarantee changes if callbacks
become asynchronous: current synchronous quiescence is insufficient, and a new
borrow/acknowledgement protocol must precede any claim of safe release.

Source code, finite oracle and author execution assess bounded support only.
Neither the additive checksum nor generation handles authenticate another actor;
neither successful fsync nor readable bytes establish tested physical durability.
