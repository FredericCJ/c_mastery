# T65.02 private technical analysis

The complete parser computes into local results and publishes once. A first
field is not a complete transaction. The macro stores the expression into a
caller-named fresh temporary, stores that value through the destination exactly
once and tests the temporary. The destination and initializer must not mention
the new name: its scope begins before the initializer, so textual capture is real.
The positive uses a distinct name; the collision is compiled, never run. Neither
goto nor result return invokes resource destructors. The inline comparison cannot
perform a jump in its caller and is not an equivalent control abstraction.

For incremental input, position is the number of accepted bytes, including sign
and colon. Offending bytes remain unconsumed. Range of each accumulator is always
0..65535. A final nonnegative result is either first+second after checking the
remaining bound or second-first after checking order. No signed minimum or
negative-to-unsigned conversion is needed. A nonfinal complete pair remains
AGAIN because exact end has not been promised. Terminal error retains its original
absolute offset; repeated success republishes only its cached result. Structural
admission has no progress effect and precedes terminal replay.

Independent oracle uses Python grammar matching and whole integers, scans digit
prefixes only to locate the earliest overflowing digit and enumerates every
selected split. It does not mirror the C state machine. Model comparisons include
prior failure, canary sum and consumed-prefix data. The finite width counter test
is a manually initialized reachable-state boundary rather than a SIZE_MAX-byte
physical run. The baseline actual er_parse_pair is a separate implementation,
not the oracle's expected-value source.

## Sealed transfer

Supply three segments where the first ends after minus and the second after colon,
using one scratch buffer that is overwritten between calls. Require proof that
only numeric state survives each borrow, and that no saved input pointer can be
used later. The public anchor executes this changed lifetime model for '-1:2';
select a fresh boundary/failure ordering for the delayed assessment. A malformed
record remains terminal: recovery requires explicit new-operation initialization,
not an undocumented resumption after the offending byte. Author execution of the
scratch case does not establish unaided learner completion.

Score original R1-R4 separately and require the learner to identify which new
assumptions invalidate the prior progress proof. Source consultation is assisted
work. This author implementation and finite campaign are not independent human
assessment, physical validation or universal input proof.
