Use the unchanged objective-specific card rubric: superficial API completion is

## t20-01-a

The synchronous alternative can borrow a decoded message only until its callback
returns. The original counterexample deliberately reuses live parser storage:
the borrowed payload changes from17 to93, while a copied message remains17. No
expired-object access is needed to expose the mistake. The queue alternative
copies exactly the encoded frame and owns it through completion or explicit
discard. Wire validity belongs to the P3 parser; authority belongs to the trusted
policy input; admission belongs to the core; external prefix effects belong to
the sink. Neither framing nor CRC establishes permission.

The changed two-consumer model uses actual OwShared, four42-byte slabs, two rights
per published record and generation retirement. One consumer cancellation cannot
destroy the other's immutable view. The last distinct right destroys once; a
duplicated C token does not create another legitimate right. Reject claims of
atomic or language-enforced ownership: the adapter is owner-serialized. Require
the learner to account for168 slab bytes plus metadata instead of recycling252.

## t35-01-a

The adversary supplies bounded local byte streams, CRC-recomputed payloads and
arrival schedules. The trusted authorization argument is outside that control.
A valid unauthorized frame increments denial only, never acceptance or output;
payload permission bits confer no authority. Corruption exercises validity;
authorized valid frames exercise normal output; a stalled sink exercises bounded
admission. Treating one of these as the other is a rubric failure. The compiled
authority mutant is caught by a synthetic counter change, not a claimed exploit
against a third-party system or arbitrary code execution.

## t23-04-a

The six callback outcomes advance the cursor2,2,2,2,5,13. Zero, AGAIN and
INTERRUPTED preserve both prefix and ownership and return to scheduling; none
justifies unbounded retry. A count exceeding the remaining bytes is rejected
before advancement. The actual er_transfer normalization maps zero to ER_AGAIN,
preserving the separate cursor and first terminal cause. An error-valued er_map
must not invoke its success callback. ISO C does not enforce tagged-union state.

After a terminal error at five bytes, a message retry uses a new transport and
the same trusted epoch/sequence with exact-payload comparison in a four-entry
receipt ledger. Duplicate receipt produces no effect; changed payload conflicts;
full ledger refuses before effect. This is bounded volatile deduplication, not
durability or exactly-once delivery after power failure. The sink cannot erase
the first five external bytes by resetting an internal cursor.
