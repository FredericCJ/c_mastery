# Selected MCP2518FD assessor analysis

The important repair is at the producer boundary: the old command helper did not implement the current erratum-required READ_CRC, nor initialization/FIFO ownership. Keep that history and select this explicit successor. The identity byte is not an unforgeable device proof. Initialization must pass all readbacks and remain poisoned at every injected uncertain SPI phase;490 ordinary transactions produce980 before/after-side-effect fault points in the current source. An independent packet oracle checks these observed counts only after execution; do not publish them as learner answers.

The conservative RAM proof is `(1+depth)*(8+payload)+29*16<=2048`. Real FIFO user addresses are offsets from0x400 and are unreliable during Configuration. With no TEF/TXQ, TX starts at offset0 and RX at8+payload. No dynamic layout arithmetic may write beyond the selected object. Reserve unused default FIFOs conservatively; do not assume their hardware allocation disappears because software never uses them.

A zero-length FD object still has its two header words. PR11.a's mock policy is false. The changed payload-size campaign must cover all16 DLC values for all8 element sizes, including rejection before RAM writes. Merely checking64-byte success does not cover smaller FIFO objects.

TXREQ is set with UINC in one byte write. Separating them can lose a newly appended message as hardware clears an old request. An error after that command is indeterminate; reserve token before the command and poison instead of retrying. Single pending TX and depth1 let terminal empty/error evidence refer to this request without pretending FIFO-level status is a per-message TEF. Cancellation may lose to success. Reset only after TXREQ clear, then observe FRESET acknowledgement before publishing a reusable slot.

READ_CRC detects selected transport faults, yet current erratum6 explicitly permits a bad FIFOCI with matching CRC. Ignore that index in the chosen receive algorithm; use stable object UA, bounded known layout and RX-not-empty, never infer general trusted hardware from a checksum. Both SEC and DED quarantine the state. Byte IOCON writes avoid the documented latch corruption. Sleep/wake is outside the selected supported route and would require additional erratum7 sequencing, so reject any claim that a cold-start test validates it.

The SPI composition uses actual retained PsSpi and PuClock. Its count16 bound forces independent8-byte READ_CRC and12-byte WRITE chunks. Staging belongs to the adapter and outlives an error return; passed controller buffers never remain borrowed. When physical reset cannot clear BSY, the adapter is quarantined, not automatically reusable. This is failure containment, not proof of eventual hardware recovery.

For PR12 zero payload, the sequence is in ID0x300+i because there are no payload bytes. Nonempty frames carry index/pattern/XOR; the check is error detection, not security authentication. BRS must match the selected phase policy; ESI is an observed error-state bit and is not required to remain0. A correct link ACK with wrong ID/payload still fails the application oracle. Missing ACK is terminal under the selected no-retransmission profile, but absence of a peer does not necessarily drive a CAN controller bus-off; the Classic fault producer already contains that counterexample.

Physical dossier tests use marked synthetic inputs only. Their passing result means validator behavior, never a real board or peer observation. Changed-board, raw-capture and seven-day independent tasks remain open. No current rubric may collapse implementation/author validation into independent learner or physical acceptance.
