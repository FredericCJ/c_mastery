Current ISO2024 uses the high-bit initial vector, four protected count/parity bits and includes those in CRC. For ID0x123, BRS1, ESI1, DLC0 the actual constructions have59 versus54 bits and CRC89572 versus44951. The first field incompatibility and the different complete transcript are observable harmless local results. The independent oracle uses polynomial long division, not the C feedback recurrence. A fingerprint match is a bounded regression oracle, not an integrity or conformance guarantee.

At the boundary ending in five equal data bits, there is one fixed stuff bit and no additional dynamic bit. Charging both changes count, CRC and bit positions. This has a separate mutant. CRC width alone misses this mechanism. Hamming-distance results apply to their stated fixed-codeword error model; they are not arbitrary insertion/deletion or security guarantees.
