# Assessor analysis: PR-T61-02

Binary search correctness includes both location and termination. An interval representation determines how empty input, duplicates and the final insertion position behave. Comparing to a linear oracle independently checks the interval derivation.

Prove all indices below lo are<key, all at/above hi are>=key, and hi-lo strictly decreases. Derive memory bounds and handle duplicate values without changing the intended first-position contract.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: A <= comparison implements upper_bound, which passes unique-key examples. An incorrect midpoint update can also loop forever on a singleton interval.

Require the learner to derive 1 from the fixture inputs independently. The loop variant is the nonnegative interval length, which every branch strictly reduces.

Transfer answer obligations: Change to a descending comparator and an opaque record key; rederive the invariant and verify comparator consistency assumptions instead of copying inequalities.

Actual solver version/commands/results, reachable assumption witnesses, complete-unwinding evidence and bounded fuzz campaign logs remain distinct requirements; missing tools do not become successful proof.
