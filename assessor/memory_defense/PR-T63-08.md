# Assessor analysis: PR-T63-08

Early-exit comparisons reveal the first mismatch position through work performed; a full scan removes that particular algorithmic difference. It does not automatically prove constant execution time on every compiler and microarchitecture.

Separate functional equality, source-level work count, emitted branches and measured timing. State memory-validity, compiler and CPU assumptions and residual cache/power/speculation channels.

The reference implementation is in `core.c`; inspect it together with the public test. The named fault is: The early-exit mutant reports only one step for a first-byte mismatch, leaking a prefix relation. ASan can remain clean because the defect is confidentiality, not invalid memory access.

Require the learner to derive 3 from the fixture inputs independently. Inspect the emitted program; a branchless-looking source is not a complete timing proof.

Transfer answer obligations: Change optimization, vectorization and unequal-length policy; derive what remains observable and compare hardened library behavior only as an external benchmark, not a replacement for the first-principles implementation.

Each security dossier must retain attacker input, violated property, necessary exploitability assumptions, harmless target-local success, repaired result and residual mitigation limits. Model violations do not imply arbitrary code execution or privilege escalation.
