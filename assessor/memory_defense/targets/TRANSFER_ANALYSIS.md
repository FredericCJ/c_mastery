# DT1-DT3 assessor analysis

For power-of-two alignment, pad=(-header) modulo alignment is representable in
uint64 and at most4095. Check pad<=limit-header, then tail<=limit-prefix, then
count<=(limit-prefix-tail)/width. Each accepted operation therefore remains in
range. Model widths explicitly; widening the host does not repair a32-bit wire
count or target allocation limit automatically. The same attacker count may
reject on one target and be a valid large request on another.

The forged C view uses a real live object, so the observed77 is a bounded
authority violation without a memory-safety violation. Matching a copied tag is
not authentication. The repair trusts the owner selected by the dispatcher and
checks exact pointer identity and extent before reading. It does not stop arbitrary
C code with direct access to the second array, or protect an owner that has died.
Const-qualified access limits that lvalue; another permitted alias can modify
the same object. The Rust diagnostic checks a different language-level rule;
unsafe code/FFI assumptions remain explicit.

Full-scan steps distinguish the early-exit mutant independently of noisy timing.
Length-dependent exits are allowed by the chosen contract, content-dependent
early exits are not. Generated code must be reviewed under each compiler/flag
set: equal source work is insufficient if the compiler emits a content branch.
The benchmark includes CRYPTO_memcmp only as an external comparison. Its nonzero
result has no ordering meaning. Finite timing samples and observed branch dataflow
do not certify all microarchitectural channels or future toolchains.
