# Ordinary T76 law assessment

For each component max is idempotent, commutative and associative, and includes
both inputs in the pointwise order. Cartesian products inherit these laws. The
negative component grows too: the numeric query need not be monotone because
it subtracts the independently increasing negative sum. With three uint32
components each direction the signed64 query is representable. Checked local
addition preserves inflation; unsigned wrap does not.

The register is max over lexicographic `(timestamp,writer)`, provided each
identity denotes one payload. Equal-identity differing payload is an explicit
conflict outside that compatible domain. It is incorrect to promise that this
pairwise max API will remember and report every historical conflict: a later
event can hide an incompatible old pair. This supplies a counterexample to an
overstated associative total-join or Byzantine-equivocation-detection claim.
Physical recency is separate from the protocol's total order. A valid MAC proves
knowledge of a key, not that its timestamp or increment represents a real event.
