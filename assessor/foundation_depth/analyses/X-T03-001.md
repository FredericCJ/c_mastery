# X-T03-001 assessor analysis

Assessor-only. Require a sealed formation proof before showing this analysis.

## Technical solution

Admit cursor/control/output arguments before dereferencing their control objects; reject position>length and null base with positive length. Compute remaining=length-position only after that admission. Take succeeds when count<=remaining, with a null output pointer value only for the admitted all-zero backing state. On non-null backing, base+position is legal including one-past. Publish the output and new position after the range proof.

Subview offset is measured from the unconsumed suffix. Require offset<=remaining and count<=remaining-offset before forming the derived base. Snapshot parent's base/length/position before writing out because out may equal parent. Returned position is zero; returned length is count. Null/zero handling must avoid even null+0 arithmetic.

Bounds checking does not certify a caller-supplied non-null pointer names an actual sufficiently large live array. This is a precondition, not a portable runtime authenticity check. Same-array pointers can still have a difference not representable by ptrdiff_t; an index proof need not introduce that subtraction.

## Independent evidence

For the six-byte example, parent position1 plus offset2 denotes index3, giving40,50; a child take2 exhausts the child and leaves a distinct parent unchanged. An independent model can represent every view as (backing identity,start,count,position) integers and compare observed bytes and transitions. It must not copy the implementation's pointer-expression ordering.

Reject the early-advance mutant with an insufficient-count request: failure must leave the parent and output sentinel unchanged. For out==parent, reject implementations that update the output length before using the original parent's position. Null empty tests must not rely on a sanitizer catching null+0.

## Rubric review

R1 needs containment through composition, R2 distinguishes formation/access/empty cases, R3 names ptrdiff_t and unrelated-pointer limits. A correct result table with an invalid intermediate pointer fails. Evidence for malformed metadata is not evidence for forged native pointer rejection.

Disallow a hidden allocation or claim that adjacent numerical addresses establish one array.

Test destination capacity2 rejection, empty segments, and an owner teardown analysis. A correct submission changes the interface and its ownership contract explicitly. This changed representation tests whether the original same-array proof was understood.

## Limits
