# X-T03-002 assessor analysis

Assessor-only technical analysis; independent vectors must be derived before disclosure.

## Technical solution

The representation is fixed at eight octets and independent of sizeof(FDRecord). Validate pointers, exact length/capacity, version and reserved bits before publication. Build count from two octets in an adequate unsigned type. Build a uint32_t wire integer from four unsigned octets; promote/cast before shifts so no signed overflow is introduced.

For wire u<=INT32_MAX, convert directly. Otherwise use an expression equivalent to -1-(int32_t)(UINT32_MAX-u), whose cast is representable and whose result reaches INT32_MIN without negating INT32_MIN. Encoding a negative int32_t into uint32_t uses the defined unsigned conversion; extract unsigned octets. A temporary record/buffer preserves outputs on rejection. The codec's checked extent/cursor dependency must be actual code reuse.

The vector flags3,count258,value-2 is 01 03 01 02 FF FF FF FE. Endpoint -2147483648 is wire80000000 and +2147483647 is7fffffff. Value/member equality is checked separately from object byte observations; padding or different host order cannot change the canonical encoding.

## Falsification and assessment

A symmetric endian defect can survive decode(encode(x)); fixed vectors from a separate mathematical derivation expose it. Require every length0–9, reserved flag bit, signed endpoint and unaligned byte-window case. A pointer cast to FDRecord fails even if one host accepts the generated access; compiler extensions do not satisfy the specified ISO component contract.

Assess whether arithmetic narrowing and input alignment are proved, not merely observed. Layout measurements belong to the recorded host and compiler. Character inspection is permitted for a live representation, but observations do not make arbitrary bytes a valid typed object.

## Withheld delayed variant: X-T03-002-DELAYED

Supply a new canonical wire: version2, reserved byte required zero, little-endian count in bytes2–3, little-endian signed value in4–7. Record {count258,value-2} must encode02 00 02 01 FE FF FF FF. Require the learner to separate logical fields from the old flags policy and to preserve outputs when the reserved byte is1.

Then store logical values in int_least32_t/uint_least16_t. On a hypothetical wider type, reject count65536 or value2147483648 before encoding; an exact-width typedef cannot be assumed. Ask whether field equality or representation equality supports cache-key comparison, and require a canonical-byte answer with stated premises.

## Limits

This solution deliberately restricts octets and exact-width facilities for the initial executable. No big-endian physical execution, generic arbitrary-width wire engine or comprehensive alias-analysis proof is claimed.
