# X-T03-004 assessor analysis

Assessor-only. Undefined restricted executions are not golden-output tests.

## Technical solution

For the restricted transform, both accessed positive-length windows are disjoint. Each destination modification and source read must satisfy the restrict association in that invocation. Base inequality is insufficient; windows can partially overlap. With count zero there are no accesses, so identical or null bases are admitted by the chosen interface.

For movement, validate both offsets<=length and count<=length-offset before mutation. The null-empty special state needs no pointer arithmetic. If destination>source, traverse indices backward; otherwise traverse forward (identity can return immediately). The direction proof protects every original source byte until it has been read. Use offsets inside one array, not ordering of unrelated pointers. Zero count must not underflow a reverse-loop index.

The initial {0,1,2,3,4,5}, destination1/source0/count4 must become {0,0,1,2,3,5}. Forward-only copying produces repeated zeros and is a clear defined counterexample in the original byte array. Snapshot expected data is independently constructed before mutation.

## Assessment

Review set diagrams and the actual execution block associated with restricted pointers. A statement that restrict “means pointers differ” fails R1. A mutant with undefined calls is not a valid performance comparator. Compile the forward-only mutant and require the array equality assertion to reject it, not just an unexpected exit.

For generated-code comparison, match input sizes, alignment, non-overlap, compiler flags and observable result. No requirement promises vectorization or a speedup. The compiler may ignore restrict's optimization implications, while its caller obligations still matter.

R4 concerns the overlapping-copy defect from the broader memory-clinic leaf; the unrelated lifetime/double-release parts remain baseline or future coverage. Do not mark the full leaf completely assessed solely from this exercise.
